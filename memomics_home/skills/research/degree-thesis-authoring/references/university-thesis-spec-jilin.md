# 吉林大学研究生学位论文撰写及装帧规范（2023 年 3 月版）摘要

> 来源：`D:\硕士毕业论文\` 下的规范正文（旧版 `.doc`，用 `antiword` 抽取）+ 附件 2 封面扉页 + 附件 3/4 声明 + 附件 5 参考文献国标（扫描版，RapidOCR）+ 附件 6 专业学位名称。
> 用法：写论文章节前扫一遍本表；标 **硕** 的条目与博士不同，别照抄博士版。

## 1. 前置部分（学位论文的组成，**硕士 7 项**）

封面 → 独创性声明 + 使用授权声明 → 序/前言（可） → 摘要与关键词 → 目次 → 插图和附表清单（可） → 注释表（缩略词，可）

**硕博差异（关键）**：硕士前置 **没有** "评阅意见、答辩决议书"（那是博士项）。
**摘要**：硕士中文摘要约 **1000 字**；英文摘要据中文翻译；关键词 **3–8 个**。
**其他前置要素**：单位代码（吉大 10183）、中英文题目、校徽、学位类别（学术学位填"××学硕士"；专业学位按附件 6 的**标准名称**，不得用简称）。

## 2. 字体与层次

| 项 | 要求 |
|---|---|
| 正文 | **宋体**；5 号 / 小 4 / 4 号任选，但**全文统一** |
| 章/节标题 | 标题字号大于正文一号（实现：章标题黑体三号、节标题黑体四号、小节黑体小四） |
| 章节序号 | `第1章` / `1.1` / `1.1.1`；**序号与标题之间空一个汉字**；终止层次不加点 |
| 目录 | 「目录」三号黑体居中；章四号宋体（左 0 缩进）、一级节缩 1 字、二级节缩 2 字；页码右对齐 |

## 3. 页码与页眉

- 页码：**前置部分罗马数字**；**主体与结尾用阿拉伯数字**（第 1 章重新起算）；**封底无页码**。
- 页眉：**仅主体部分**；**楷体小 5 号、居中、普通单划线**；双面印刷时双页页眉为「吉林大学博士（或硕士）学位论文」。
- 实测要求：页眉按节设置 = **该章的章编号及标题**（生成器必须逐节写，漏写属硬性不合规——实测出过一次，靠逐节核验才发现）。

## 4. 图与表

| 项 | 要求 |
|---|---|
| 题注位置 | **图题在图下、表题在表上** |
| 题注格式 | 居中、**黑体**、字号同正文；**题号与题名之间空一格** |
| 表的续页 | 跨页时表头重复 |
| 公式 | 另起一行居中，编号右端对齐；公式与编号用「…………」连接（如 `式 2-1`） |
| 正文引用 | 叙述式「如图 X.Y 所示」「如表 X.Y 所示」，**不用方括号夹注** |

⚠️ **实测缺陷**：md 源里图题行写在图片行**之前**（`**图 X.Y　…**` → `![图 X.Y　…](figures/x.png)` → `图注：…`），生成器按原样落盘 → DOCX 中**图题落在图片上方**，与"图题在图下"相悖。取证方法见 `figure-citation-integrity-audit.md` §1。

## 5. 参考文献

- 著录标准：**GB/T 7714-2015**（附件 5 即该国标扫描件）。
- 全文统一采用 **顺序编码制** 或 **著者-出版年制**（二选一，不得混用）。
- **标注不得出现在标题处**。
- 常用条目（实测采用过的格式）：
  - 期刊：`作者. 题名[J]. 刊名, 年, 卷(期): 起-止页. DOI: xxx.`
  - 会议/专著：`作者. 题名[C]//文集名. 出版地: 出版者, 年: 页码.`
  - 专利：`申请人. 专利题名: 国别, 专利号[P]. 公开日期.`
  - 电子资源：`作者. 题名[DB/OL]. (发布日期)[引用日期]. URL.`
- 核验纪律：每一条的 **PMID / DOI / 卷期页**用 Crossref + Europe PMC 双源核对；只在一个源见过就再查一次（实测：用户口述的期号 `38(18)` 与双源实证 `38(19)` 不一致，按实证著录并在汇报里说明）。

## 6. 装帧

- A4 **横开本、左装订**；页边距 **上、左 ≥ 25 mm；下、右 ≥ 20 mm**（实现用上 2.7 / 下 2.5 / 左 3.0 / 右 2.5 cm）。
- 裁切后成品 **29.1 × 20.7 cm**。
- 印刷：**硕士单、双面均可；博士必须双面**。

## 7. 附：规范解析动作（拿到新学校的规范时照做）

1. `.doc` → `antiword <file>` 抽正文；`.docx` → `read_file`（python-docx 自动抽取）；扫描 PDF → RapidOCR。
2. 逐条抽成"硬指标表"，每条标 **硕/博/通** + **🔴硬性 / ⚪可选**。
3. 落盘为「XX大学学位论文规范_整理标注版.md」，与论文放同一项目目录，后续每轮改稿都对着它核。
