# 学位论文撰写与规范合规

## 0. 铁律（先读，全部为实测教训）

1. **规范优先，先解析再动笔**：拿到学校规范文件 → 抽取正文 → 落盘成「规范摘要 MD」→ 才写论文。**禁止凭通用排版常识代替学校规范**（吉大要求页眉写"章编号及标题"、图题在图下、编号用「图 X.Y」全角空格，凭常识必错）。
2. **数字与事实全部来自用户素材包**：正文每个数字都要能追到具体素材文件；引用逐条核验 PMID/DOI/卷期页。**检索不到就写"未检出"，绝不编造**（宁缺勿造——用户明确验收这一条）。
3. **个人信息不代填**：封面（分类号/学号/学位类别/专业/导师/完成时间）、作者简介、致谢姓名 → 一律**列成待填清单**交给用户。
4. **只改指定项**：用户说"改 X"就只改 X。顺手发现的问题**单列出来问**，不擅自重构/润色（"已经没问题的就不要动了"）。若用户说"按照你想的做"才是授权端到端产出 + 沿途缺陷一并修并汇报。
5. **改稿只改 part 源文件**：`part*.md` → 合并稿 → DOCX 是派生关系，改合并稿会被下一次生成覆盖（详见 `platform-execution-pitfalls` 的 `references/long-doc-revision-and-remeasure.md`）。
6. **计数从文件读，不从记忆报**（实测栽过：口报"3 处已改"，复测仍残留 1 处）。
7. **论证不可自相矛盾**：结论若建立在"某个偏离期望"上，先用论文自己的数字把期望算一遍（如独立期望 = 各级基数连乘）。实测审出一处正片硬伤：声称"150 显著高于独立期望"而实算期望 181（实测反而更低），且同批数据显示 L1∧L2 低于其独立期望（负相关）——**这类"自证反证"级缺陷杀伤力远大于背景不足**。

## 1. 工作流

```
①规范解析 → ②规范摘要落盘 → ③素材→章节骨架 → ④part 分写 → ⑤合并+出 DOCX
   → ⑥完整性审计（图/表/引文/待填） → ⑦改稿轮次（只改指定项） → ⑧终稿复核
```

**① 规范解析**：`.doc`（Word 97-2003 二进制）用 `antiword`；扫描版 PDF 用 RapidOCR（见 `docx-generation` 的 `references/legacy-doc-and-scanned-pdf-extraction.md`）。同时清点附件（封面/扉页/声明/专业名称表/参考文献国标）。
**② 规范摘要落盘**：输出「规范摘要 MD」，每条标注 **硕/博/通** 与 **🔴硬性 / ⚪可选** —— 硕士照抄博士版必错（见 `references/university-thesis-spec-jilin.md`）。
**③ 章节骨架**：素材（如专利交底书）→ 学位论文结构的映射：交底书正文 → 绪论/方法/结果/讨论；参数与数据表 → 材料与方法；图件 → 插图；检索记录与对比文件 → 绪论现有技术小节 + 附表。
**④–⑤** 分 part 写（`part1_front` / `part2a_ch1` / `part2b_ch2` / `part3_ch3_ch4_ch5` / `part4_refs_appendix`）→ 单一生成脚本合并并出 DOCX。
**⑥ 审计**：跑 `scripts/audit_thesis_integrity.py`（图件↔图号、图引用形态、引文↔文献表、待填项、图号连续性）。
**⑦ 改稿**：批量文本改动用一个脚本集中做（每处先 `assert text.count(old) == 1` 再替换；`count==0 且 new 已在文中` 视为已应用跳过 → 幂等可续跑）。**禁止**用 N 次 patch 逐个改，也禁止整篇 write_file 重写（流式截断风险）。
**⑧ 终稿复核**：目录/插图清单/附表清单的**页码列是静态数字**，正文一改就偏 → 交付时明确提示"终稿需在 Word 里按实排复核页码"。

## 2. 图表规范（最容易扣分的地方）

| 项 | 要求 |
|---|---|
| 图题 / 表题位置 | **图题在图下方、表题在表上方**；均居中、黑体、字号同正文；题号与题名之间**空一格**（md 里用全角空格 `　`） |
| 正文引用 | 用叙述式「**如图 X.Y 所示**」「如表 X.Y 所示」；⛔ 不用 `[图 X.Y]` 方括号夹注 |
| Markdown 陷阱 | 图片 alt 文本写的是图题（`![图 2.1　…](figures/x.png)`）——**在不渲染的预览里会显示成 `[图 2.1 …]` 的样子，那不是正文夹注**，别去"改"它；要改就把 alt 换成完整图题 |
| 编号顺序 | 按**首次提及**顺序编号，不按版面位置。实测：图 2.1 在第 1 章 §1.5 先被引用、图 2.2 在 §2.2.2 才出现 → 编号正确，**无需互换**（判据：先查每个图号的首次引用位置，再判是否乱序） |
| 图件复用 | ⛔ 同一张图件挂了两个图号两个图题 = 排版硬伤（实测发生过：为省事复用了现成附图）。审计脚本第一项就是查它 |
| 插图/附表清单 | 清单行数必须与图件数一一对应；无图件的图号要么补真图、要么删掉图号 |

**补真图（用现成数据新绘一张）**：先取正文真实步骤/数字 → matplotlib + `SimHei`，**灰度版式与既有图件对齐**（浅灰底框 `#EBEBEB`、深灰序号徽标 `#404040`、黑边框箭头、白底），同时导出 **PNG+PDF+SVG**（PNG 入稿、PDF/SVG 便于排版复核）→ 自检（尺寸、非白像素占比、灰度档位数）→ **`vision_describe` OCR 核对图内数字与文字无重叠裁切** → 入稿 + 登记清单。图内标题措辞与文档图题**区分开**（避免重复）。

## 3. 引文完整性审计

判据 = **文献表条数 == 正文被引条数，孤立 0、超范围 0、缺号 0**。三个实测要点：

- **区间与逗号引用必须展开**：`[28-31]`、`[9,16,17]` 是合法引用，纯正则找 `[N]` 会把它们误判成孤立文献（实测"15 条孤立"复核后实为 10 条真孤立）。
- **数值区间是假阳性**：正文里的阈值区间 `[30, 500]` 会被当引用（特征是**逗号后有空格、数值远大于文献总数**）→ 审计脚本按"逗号后带空格"排除。
- **孤立文献逐条按内容判定处置**，不硬凑引用：正文有对应但缺编号 → 在正文补挂编号（如 D1–D5 对比表首列补 `D1 [35]`…）；确属与本文无关的残留条目（实测：素材里是 RNA 流程用的工具，本文只引用 ATAC 流程）→ **删除并顺延编号**，删后必须重跑审计确认无断号。

## 4. 典型缺陷与追问式收尾

交付时**主动列出**（不擅自改，问用户）：① 同图两编号；② 有图号无图件（正文写"如图 X.Y 所示"却找不到图）；③ 图序≠首次提及序；④ 清单静态页码；⑤ 多版本产物并存（同一产物出现 v_a/v_b 两份 = 用户明令禁止，删旧留新并说明）。
