# 年龄标签 shuffle 置换检验（验证年龄效应本身是否真实）

> 用途：在跨物种保守性/可替代性评估（Stouffer 聚合、S 评分）**之前**，先验证每一侧喂进 S 评分的年龄效应量 Z_m / Z_h 本身是不是噪声。这是独权的根基检验——如果猴侧 Z_m 是噪声，402 个 A 类的"可替代性结论"猴侧一半依据不成立。

## 判据（置换检验）

1. **真实统计量 obs**：真年龄算每 tile/peak 的 pearson r（连续年龄），统计 |r|>阈值（本案例 0.5）的特征数。
2. **null 分布**：shuffle 年龄标签 N 次（1000），每次重算，统计 |r|>阈值 = null。
3. 富集比 ratio = obs/null_mean：ratio>1 且置换 p<0.05 → 真实；ratio<1 → 不可靠。

## 实测案例（人猴海马 ATAC，2026-09-04，方法=pearson连续年龄+阈值0.5）

| 侧 | 样本 | 年龄 | obs | null_mean | null_sd | ratio | p | 判定 |
|---|---|---|---|---|---|---|---|---|
| 人(peak级) | 40 | 连续20-89 | 6285 | 258 | 1075 | **24.3** | 0.005 | ✅真实 |
| 猴(tile级全) | 20 | 4簇5-31 | 34128 | 147794 | 233597 | 0.231 | 0.815 | ❌不可靠 |
| 猴(启动子近端TSS±2kb) | 20 | 4簇5-31 | 1138 | 8474 | 21247 | 0.134 | 0.798 | ❌更弱 |

## 「真实弱于随机」(ratio<1) 的诊断解释——关键！不是 bug

**判据信号**：null_sd > null_mean（如 147794±233597）→ null 分布极度右偏 → **稀疏/噪声特征在 shuffle 后产生巨量假相关**的指纹。

**根因（实测验证）= 个体技术变异淹没年龄信号，不是荒漠噪声稀释**。诊断三件套：
1. 每样本总可及性 = `rowSums(样本×tile矩阵)`，看同簇内个体差异（本案例同簇内 3~3.5 倍：Y5=5219 vs Y3=14577）。
2. 年龄 vs 总可及性相关 ≈ 0（本案例 cor=−0.084，连整体可及性都跟年龄无关）。
3. 样本量：20 样本 + 4 离散年龄簇功效不足；对照 40 样本 + 连续年龄(20-89) 能检测到 24 倍富集。

## focused 复验模式（判别「荒漠稀释」vs「信号本身弱」）

全基因组弱时，聚焦生物学最强区（启动子近端 TSS±2kb）重跑 shuffle：
- focused ratio > 1 → 全 tile 被荒漠区噪声稀释，真实信号藏在调控区。
- focused ratio 仍 < 1（本案例 0.134，比全 tile 0.231 更弱）→ **信号本身弱 = 技术变异主导，证伪「荒漠稀释」假设**。

## 混淆三分解：深度 vs 细胞数 vs 功效（决定「还能不能救」）

**先认数据语义**：样本×tile 矩阵若值全在 0~1 之间（非整数），是 **cell fraction**（每个样本已除以自己的细胞数），不是原始细胞覆盖计数。「细胞数不均」的深度影响已被除细胞数这一步消掉一半，残留的是**估计精度异方差**（细胞少的样本比例估算更抖）。

三个不同混淆、三种处理，实测效果（猴 20 个体，启动子近端 TSS±2kb，同 pearson+0.5 口径）：

| 处理 | obs | null | ratio | p | 说明 |
|---|---|---|---|---|---|
| 原始 cell fraction | 1138 | 8474 | 0.134 | 0.798 | 基线 |
| **CPM 归一化（抹深度）** | 8332 | 7104 | **1.173** | 0.267 | **唯一翻到 >1，主解药** |
| 细胞数下采样均衡 | 2157 | 6634 | 0.325 | 0.798 | 几乎无效 |
| 细胞数加权（权=细胞数） | 2389 | 8474 | 0.282 | — | 几乎无效 |

**结论（写专利文本直接抄）**：
1. **细胞数不是主因**——下采样（把高细胞数样本统一降到 N0=min）与加权（反方向，信任高细胞数）都只到 ratio≈0.3，救不动。
2. **测序深度才是主混淆**——CPM 归一化（rowSum 抹平 3.4 倍深度差）是唯一把 ratio 拉到 >1 的操作，但仍 p=0.267 不显著。
3. **天花板 = 个体数 + 年龄连续性**——20 个体 + 4 离散年龄簇无论怎么处理都打不到显著；对照人侧 40 个体 + 连续年龄 = 24 倍富集。**数据处理救不了功效不足，别在 20 个样本上抠显著性浪费时间。**

**专利定位**：猴侧 = 同向趋势性证据（非独立显著），独立显著以人侧 40 个体为准。S = min(|Z_m|,|Z_h|) 里 Z_m 要明确降级为「趋势性检验」，不能作双侧对称的硬支柱。

## 伪重复陷阱（libraries ≠ individuals，年龄相关最致命的错）

年龄是**个体级**属性（一个个体一个年龄，同一个体的多个文库共享年龄、共享生物学背景）。年龄相关（pearson/DA）的统计单元必须是**独立个体**，不是文库：

- 本案例猴脑 = 63 文库，但只对应 **21 个个体**（平均每个体 ~3 个文库 = 技术/批次重复）。
- 把 63 文库当 63 个观测做年龄相关 = **伪重复（pseudoreplication）**：技术重复被当生物重复，样本量虚增 3 倍，凭空造出假年龄信号——这正是 shuffle 检验最不能犯的错。
- 正确做法：集群上先把同体多文库的 tile 可及性**聚合（求和/均值）到个体级** → 21 个体 × tile 矩阵 + 21 个体年龄，再算相关。
- **加文库不加个体没用**：个体数决定统计效力，文库数不决定。人 40 文库=40 个体 vs 猴 63 文库=21 个体，差距就在独立个体数，不是文库量。

## 实现要点（向量化，避免逐 tile 循环）

```r
age_c <- ages - mean(ages); denom_age <- sqrt(sum(age_c^2))
xd <- as.matrix(Mf[, keep, drop=FALSE])        # 20 样本 x N focused tile
xm <- colMeans(xd)
num <- as.numeric(age_c %*% xd)                # 交叉积
x_ss <- colSums(xd^2) - nrow(xd)*xm^2
r_true <- num / (sqrt(x_ss) * denom_age)
obs <- sum(abs(r_true) > 0.5, na.rm=TRUE)

# shuffle：只有分子变（age_c 重排），分母 x_ss/denom_age 不变 → 快
for (k in seq_len(N)) {
  num_s <- as.numeric(age_c[sample(nrow(xd))] %*% xd)
  r_s <- num_s / (sqrt(x_ss) * denom_age)
  nulls[k] <- sum(abs(r_s) > 0.5, na.rm=TRUE)
}
```

## 方法一致性铁律

置换检验要跟既有 DA 结果对比时，**先确认相关方法 + 阈值一致**，否则「真实 vs null」对比不公平：
- 本案例 obs=34128 恰好 = `monkey_ageDA_continuous.csv` 里 |r|>0.5 的行数 → 证实之前 DA 用 pearson 连续年龄 + 0.5 阈值，shuffle 用同一套。
- 快速核验：数既有 DA 结果表里 |r|>0.5 的行数，与 obs 对照。

## 陷阱

- `execute_r` 是 R 内核，跑脚本用 `source('xx.R', encoding='UTF-8')`，不是 Python 的 `exec(open(...).read())`（后者是 execute_python 语法，R 内核会报 unexpected symbol）。
- 全零/稀疏 tile 的 sd=0 → pearson r 为 NaN，统计要 `na.rm=TRUE` 或先过滤「≥5 非零样本」覆盖度。
- 全部「额外」噪声叠加（下采样模拟 artifact）：给**所有**样本（含本就低精度的 V5=2549）叠加满额噪声会让 obs 假性升高（1138→2610，误导「下采样有帮助」）。正确做法**只对 N_s > N0 的样本加额外噪声**，方差差 = `xd*(1-xd)*(1/N0 - 1/N_s)`，逐样本乘子 `pmax(0, 1/N0 - 1/NN)`；N_s ≤ N0 的样本保持不动。「加噪反而 obs 升」一定是加噪方式错了（artifact），不是真实效应。
- `execute_r` 持久内核里 `M@x` 曾报 `'x' must be an array of at least two dimensions`（3 次复现）→ 用 `slot(M, "x")` 访问稀疏矩阵槽（显式且稳，S4 标准写法）；同理 `Matrix::rowSums` 而非 base `rowSums` 处理 dgCMatrix。
- 猴年龄 M4 缺失 = QC 剔除（该个体仅 61/63 细胞，极低深度离群点），不是命名跳号。
