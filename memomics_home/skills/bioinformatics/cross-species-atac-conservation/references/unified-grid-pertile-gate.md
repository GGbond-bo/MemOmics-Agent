# 统一同源元件网格 + 跨粒度门控归一化（z̄ = Z/√n）

> 来源：跨物种衰老可替代性专利 v10（memomics-7839e23a，2026-09-12）。两项均已写入权项（网格 → 从权；归一化 → 从权）。

---

## 1. 统一同源元件网格

### 问题
两物种来自不同参考基因组（人 hg38 / 猴 T2T-MFA8），坐标体系与 500bp tile 划分起点均不一致 ⇒ **同源调控元件无法直接配对**，「逐元件比较」在技术上无从下手。这是纯技术障碍，不是统计问题。

### 手段
对每对同源基因，取其两侧基因组坐标中可比的窗口序列，映射为一组带**统一编号（bin 序号）**的同源元件单元；单元内按 测序深度 / GC 含量 / 可比对性（mappability）分层。

实测：**221,069 个同源单元 / 覆盖 16,004 个同源基因**，单元内 tile 数中位两侧均 **4**。

### 为什么值得写进权项
它把「统计规则」变成「**数据处理步骤**」——直接降低 A25（智力活动规则）与 A22.3（显而易见）两项驳回风险。权项写法：
> 将两物种的候选调控元件映射到一套统一编号的同源调控元件单元上；所述映射基于同源基因锚定或全基因组比对链（chain liftover），并在每个单元内按测序深度、GC 含量与可比对性中的至少一项进行分层。

---

## 2. ⚠️ 必须配套的修正：门控量归一化（否则网格是负资产）

### 症状
在 bin 级沿用基因级强效应阈值 `|Z| ≥ 12` ⇒ **门控必然失效**：

| 量 | 实测 |
|---|---|
| 221,069 个 bin 中，人侧 `\|Z\|≥12` 占比 | **0.077%** |
| 猴侧 `\|Z\|≥12` 占比 | **0.0005%** |
| bin 内 tile 数中位 | 4 |

**原因**：Stouffer 聚合 `Z = Σzᵢ/√n` 的单元数远小于基因窗口（基因窗口 tile 中位 65，bin 中位 4），bin 级 `|Z|` 的分布尺度天然够不到 12。

**后果**：加了网格这步却筛不出东西 ⇒ **统一网格从技术增量变成负资产**。这是「前半段修复引入新缺陷」的典型形态，交付前必须连带检查。

### 修法
门控量改为与单元内 tile 数无关的 **per-tile 平均效应量**：

```
z̄ = Z / √n        （n = 该单元内 tile 数）
```

推导：`Z_gene = Σzᵢ/√n` ⇒ 逐 tile 平均 `z̄ = Σzᵢ/n = Z_gene/√n`。

**一般化规则**：任何「聚合后施加阈值」的步骤，**换聚合粒度时阈值必须归一化**，否则阈值在不同粒度间不可比。把「与聚合粒度解耦的归一化量」写进权项，是把它从统计规则变成技术手段的有效方式。

## 4. 一个顺带纠正的误判（值得记住）

曾把「人侧基因级中位 Z = +1.06」解读为**全局漂移**，并据此设计「减漂移」修复。**该判断是错的**：

| 层级 | 人侧中位 Z |
|---|---|
| tile 级 | **+0.0925** ← 真正的原始漂移 |
| 基因级 | +1.0631 ← 被引用的数字 |
| 中位 tile 数 | 65 → √65 = 8.06 |
| 预测 `tile中位 × √n` | +0.746 vs 实测 +1.063 ✓ 量级吻合 |

**+1.06 不是漂移，是 Stouffer 聚合把 +0.09 放大了约 8 倍。** 一个真实效应为 0 但 tile 分布轻微正偏的数据，一聚合必然产生大正偏的基因级 Z。

⇒ **教训**：跨层级引用效应量中位数前，先确认它是不是聚合放大的产物。修法设计前先验证「待修的偏倚到底存在于哪一层」——本会话的「减漂移」修复因此无效（40.1% → 39.2%，可下线）。

**附带发现**：猴侧不服从同一放大律（tile 级 +0.0893，基因级却只有 +0.0723，预测应 +0.63）⇒ 两侧的 Z **根本不是同一个构造**。用同一个 `|Z|≥12` 门槛卡两侧，卡到的是两类不同的东西——这本身是「低于随机」的技术来源之一。
