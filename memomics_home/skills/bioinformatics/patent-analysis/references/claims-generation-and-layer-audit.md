# 权利要求代次定版 与 独权效力分层审计

> 触发：用户问**专利战略层**问题 —— 「你自己也做了新的尝试，你是觉得我们之前的 X 方法能申请专利呢？还是继续新的方法呢？」「我的述求只有一点：<一句话定位>」「继续回到专利设计」。
> 这类问题的答案取决于**"当前送审件是哪一份"**，所以第一步不是分析，是**定版**。

---

## §0 一句话

**战略层问答 = 定版 → 分层 → 对撞 → 才回答。** 跳过定版 = 拿已作废的旧代次下结论，前提错则方向必反。

---

## §1 定版三步（强制的第一步）

1. **列候选**
   - `search_files(pattern='*claim*', target='files', path='<专利根>')`
   - `search_files(pattern='*权利要求*', target='files', path='<专利根>')`
   - 注意：交付目录、`patent/`、项目根**三个位置都可能各躺一份**。
2. **判现行**（三者交叉，缺一不可）
   - 文件名里的版本号（`v15`）
   - 文件 mtime / 生成器时间戳
   - **决策链文档**（`结论_*.md` / `README.md` / 生成器 docstring 的头行）—— 实测最可靠的是 `结论_口径决策链.md` 这种"一次写死"的收敛记录
3. **归档旧代次**
   - 旧版**立即移入 `archive/`**。未归档 = 误送风险，而成本为零。
   - 实例：`patent/权利要求书_….md`（9/4 的 min 版）在被取代后**仍躺在主目录**，是本次误读的直接入口。

### 实测标本（2026-09-13）

| 文件 | 日期 | 独权评分器 | 状态 |
|---|---|---|---|
| `patent/权利要求书_….md` | 9/4 | `S=min(\|Z_m\|,\|Z_h\|)×sign(Z_m·Z_h)` 对称双侧 | **已被取代，仍在主目录** |
| `claims_substitutability.md` | 9/5 | `S=Z₁×w(Z₂)` 主-参考非对称 | 切换说明 |
| `交付_…/claims.md`（v15） | 9/12 | `S=Z₁×w(Z₂)` + S1.5 统一网格提入独权 | **现行送审候选** |

**误读后果（本次真实代价）**：读了 9/4 版 → 得出「独权是 min → 口径之争打不到独权 → 所以继续用 z 方法」。
- 前半**前提错**（现行独权是 `Z₁×w(Z₂)`）
- 后半**方向反**（现行独权的区别特征恰是 `w(Z₂)`，而它正是被实测打穿的那个）

⚠️ 另有同源风险：同一交付目录并存 `附件1_…v16.docx` 与 `…v17.docx` 等多代附件 → **送错一份就是送错一代发明**。定版时顺手把要送的挑进干净的 `送审/` 子目录。

## §2 论证层 / 保护层解耦 —— 但别把"独权不动"推成"独权稳"

正确的结构认识（**这部分判断本身是对的**）：

| 层 | 放什么 | 口径变更是否要动 |
|---|---|---|
| **独权** | 骨架（获取 → 统一网格 → 计算 Z₁/Z₂ → 评分 → 置换 → 分级输出）+ 评分器**形式** | 只写"得到 Z₁ 与 Z₂"，算法细节不下沉 ⇒ **换算法一个字不用改** |
| **从属权** | 具体算法（pseudobulk + 线性模型 + Stouffer sum / z̄ 聚合） | 改这里即可 |
| **优选实施方式** | 可替换口径（per-tile 归一化门控 `z̄ = Z/√n`） | 改这里即可 |

🔴 **但这只解决"要不要改独权"，不解决"独权立不立得住"。**

**区别特征的实测效力必须单独核**，两条判据：

1. **反向侧对照** —— 门控对方向有无区分力
   实测：门控命中率 **同向池 61.34% vs 反向池 64.93%（比值 0.94）** ⇒ 对方向**无区分力**。
2. **匹配零假设三元组** —— (观测率/观测数, 匹配零假设, 配对 z)
   实测：核心元件数 **357 vs 匹配零假设 340.1±16.3（1.05×，p=0.164，未富集）**；
   唯一正面证据 **1.33× 在按长度分层后塌成 1.04×**。

⇒ 结论：**"独权文字不动"是安慰奖**。用户要的"这个方法能不能立住"必须靠上面两条独立回答。

## §3 自洽性对撞扫描（致命级检查）

**规则：同一份交付件里，凡"因为 X 所以放弃/采用 Y"的句子，逐条对撞。**

### 实测标本（同一份 `claims.md` 内，两行互斥）

| 位置 | 内容 |
|---|---|
| 第 100 行 | 以「猴侧 **0.23×、p=0.815（测不出年龄效应）**」作为**放弃 min** 的书面理由 |
| 第 104 行 | 以「**猴侧方向可信**」作为 **`w(Z₂)` 方向门控**的前提 |

→ **互斥**：既然承认猴侧测不出年龄效应，就不能同时假定它的**方向**可信。

### 更深一层：改版理由的历史对撞

把历代「改版理由」按时间排开：

| 时间 | 写下的理由 |
|---|---|
| 9/5 换独权 | 「猴侧年龄效应不独立显著（**1.17×、p=0.267**）」 |
| 9/12 v17 | 猴侧那个数已更正为 **0.23×、p=0.815** |

→ **换独权的理由被自己后续版本撤回了**，而且撤回后更糟（从"弱、不显著"变成"远低于随机"——等于用一个自己刚宣布是噪声的变量做门控）。此后三次修订**无人回头复核**。

⇒ **核查动作**：找出所有"因为 X 所以放弃/采用 Y"的句子 → 按时间排开 → 问一句「**这条今天还成立吗**」。
⇒ **优先级**：**没人回头复核的决定 = 最高优先级**，高于任何数字优化（对撞一次是零成本，返工一轮是天）。

## §4 产物路径必须给全绝对路径

**实测事故**：我汇报时写 `results/组成校正_人侧_*`（相对片段）。第三方审计按字面在 `E:\专利` 全盘搜 → 判「**磁盘上不存在**、四个数查无来源、脚本 docstring 承诺了检验但代码没实现」。

**实际**：文件在 `E:/MemOmics-Agent/results/<sid>/results/`，且逐字复核**完全一致**：

| 指标 | 值 |
|---|---|
| n_peak × n_individual | 525,137 × 40（Age 20–89） |
| R²_age / R²_comp（中位） | 0.015441 / 0.455235 |
| 唯一 Age / 唯一组成 | **4.52% / 96.76%** |
| A 显著 / B 显著 / 存留率 | **309 / 3 / 0%** |
| 组成载荷 Q1→Q4 显著率 | 0.0122% → 0.1165%（**9.6×**） |

⇒ **两条铁律**：
1. **汇报产物一律给绝对路径全串**（`E:/MemOmics-Agent/results/<sid>/results/…`）。片段路径 + 别人的搜索根 = **被误判为造假**。
2. 反过来，**核实"查无来源"类指控时，第一步是核对搜索范围**（它搜了哪个根？文件真的不在吗？），不是慌忙自证或认错。判定要分三档：`✅ 我复现为真` / `⚠️ 对方写错` / `🟡 对方漏掉我补查`。

**同源小坑**：共享目录污染 —— agent 输出文件（如 `_审核agent/audit13_*.py`）可能与他人脚本混放。**目录里文件 ≠ 你的产物**；核实前先看归属（生成器名、docstring 第一人称），别把他人的脚本当自己的核。

## §5 组成校正类结论的专利写法（中介 ≠ 混杂）

**统计事实**：细胞类型组成是**中介**（年龄 → 组成 → 可及性），不是外生混杂。
把中介当协变量调 = **过度校正** —— "校正后塌掉"即使年龄效应 **100% 真实**也会出现。

⇒ 因此那组数字**不是**"年龄效应为假"的证据，而是"**组织级信号与组成强共线**"的描述。

| 写 | 不写 |
|---|---|
| ✅ §二（一）**技术问题**：组织级可及性测量混入细胞类型组成效应 → 两侧组成漂移不同则总效应**不可迁移**（**发现问题的本身是创造性加分**） | ❌ "校正后 309→3，故年龄效应为假"（过度校正推理） |
| ✅ 优选实施方式 = **按细胞类型分层聚合** | ❌ CLR 协变量校正（统计上站不住，写进专利等于把把柄交给审查员） |
| ✅ 只写"问题的发现" | ❌ 任何效果数字 —— 若要写，**必须先真跑出 (观测率, 匹配零假设, 配对 z) 三元组**；跑不通就只写问题、不写数字 |

⚠️ 口径提醒：**只有"问题的发现"是加分，"查不到来源的效果数字"是风险。** 二者的成本差为零，风险差极大。

---

## §6 纪律

1. 战略层问答**不动交付件**。重定位 / 换保护对象 / 改发明名称一律**交用户拍板**。
2. 核实轮一旦发现"我上一轮读错文件"，**先认错、再纠正、再说明对结论的影响**，不要辩解；同时**把对方写错的部分也如实指出**（三分类），不包括糊。
3. 交付这些结论时**不承诺已辩论背书** —— 判定不依赖辩论，先给结果、后补辩论。
