> 上游：`references/method-upgrade-plan-evaluation.md` §7「观测单位重构型」方案（定性论点）
> → **本文件是它的定量执行版**（方案说"两者混在一起"，本文件把两者的份额算出来）。
> 配套探针：`scripts/observation_unit_audit.py`（只盘组成偏移**存量**）→ 本文件做**模型层分解**。
> 可跑模板：`templates/composition_adjusted_pseudobulk_da.R`。

## 0. 一句话

组织级 pseudobulk 的「衰老效应」= **组成项**（细胞类型比例随年龄变）+ **细胞内在项**（类型内部调控变）。
把 CLR 组成的协变量塞进同一个 OLS、再算方差分解，就能把两者份额分开并给出「校正后还剩几个显著」。
**同一批数据、同一个矩阵，只改模型** —— 这是它比换口径强的地方（换口径要换矩阵，代价大且引入新争议）。

## 1. 输入与对齐（错一步全盘皆错）

| 需要 | 来源 | 校验点 |
|---|---|---|
| 个体级 pseudobulk 矩阵 | `ArchR getGroupSE(proj, groupBy="Sample")` → peak × 个体 | `dim` = peak 数 × 个体数 |
| 细胞级元数据 | 每细胞一行：`celltype` + `individual` + `Age` | `table(individual, celltype)` → 个体 × 类型 |
| 个体↔列 对齐 | `colnames(Y)` vs `rownames(W)` | 🔴 **必须 `setequal()` 为真**，且用 `match()` 对齐，**不靠顺序** |
| Age 对齐 | `colData(x)$Age[match(colnames(Y), rownames(cd))]` | `stopifnot(!any(is.na(Age)))` |

⚠️ `getGroupSE` 输出 **`rowRanges` 为 NULL**（无坐标）⇒ 只能在**全基因组分布**层面判定，
**不能**直接映射到具体基因/元件。要落到元件必须先另建坐标表（本类工作的常见后续）。

## 2. 三个模型（向量化 OLS，不要逐行 `lm`）

```
模型 A（现行组织级口径）: log2CPM ~ Age
模型 B（组成校正）      : log2CPM ~ Age + CLR(各细胞类型占比)     ← 组成作协变量
模型 C（纯组成）        : log2CPM ~ CLR
```

- **CLR 必须丢 1 列**（各成分 CLR 之和为 0，全留会与截距共线）。
- 归一化：`log2(t(t(Y)/colSums(Y)*1e6)+1)`。
- 回归用矩阵代数（`Y %*% X %*% solve(crossprod(X))`），残差算 `RSS` 求 `se`/`t`/`p`，BH 校正。
- 规模参考：525,137 peak × 40 个体 × 3 模型 ≈ **0.4 分钟**（R 持久内核）。

## 3. 四项判据（缺一不可，一次跑完）

| # | 判据 | 回答什么 |
|---|---|---|
| 1 | 每个细胞类型占比 vs Age 的 **Spearman ρ** | 组成到底动没动（前提成立性） |
| 2 | **方差分解**（中位 R²）：唯一 Age / 唯一组成 / 共享 | 效应的份额归谁 |
| 3 | FDR<0.05 的 Age 显著 peak 数 **A vs B** → 存留率 + 方向翻转率 | 校正后还剩多少 |
| 4 | 按组成载荷（R²_comp）**四分位分层** → 存留率剂量-反应 | 组成是不是"指纹" |

份额定义（三个都要报，不要只报一个）：
```
uniq_age  = R2_full − R2_comp
uniq_comp = R2_full − R2_age
shared    = R2_age + R2_comp − R2_full      # 可为负（抑制效应），照报
```

## 4. 实测标本（人海马 scATAC，40 个体 Age 20–89 × 525,137 peak）

**① 组成强随年龄变**

| 细胞类型 | Spearman ρ | p |
|---|---|---|
| Astro | **−0.663** | 3.2e−6 |
| OPC | **−0.518** | 6.2e−4 |
| Micro | **−0.445** | 4.0e−3 |
| ODC | **+0.442** | 4.3e−3 |
| ExN | −0.118 | ns |
| InN | +0.050 | ns |

ODC 占比 Young 56.4% → Old 75.4%；Astro 16.8% → 6.4%。

**② 方差分解（中位 R²）**

| 项 | 值 | 份额 |
|---|---|---|
| R²(Age only) | 0.01544 | — |
| R²(组成 only) | **0.45523** | — |
| R²(Age + 组成) | 0.47677 | — |
| 唯一归 Age | 0.02153 | **4.5%** |
| 唯一归 组成 | 0.46133 | **96.8%** |
| 共享 | −0.00609 | −1.3% |

**③ 显著数**：A = **309** / 525,137（0.06%）→ B = **3**（存留率 **0.00%**）；方向翻转 0.97%；中位 |β| 比 1.175（**无收缩**）。

**④ 组成载荷分层**：A 显著率 Q1 0.0122% → Q4 **0.1165%**（单调 **9.6 倍**）；校正后各层**全部归零**。

## 5. 判读（🔴 别推过头）

- ✅ 能说：**组织级 pseudobulk 的衰老效应压倒性由细胞类型组成变化驱动**（96.8% vs 4.5%）。
- ❌ 不能说：**"细胞内在信号不存在"**。L1 辩论裁决 = **modify / confidence medium**，反方保留意见：
  **CLR 可能过校正** —— 若组成变化本身是衰老的**下游中介**（而非外生混杂），把它放进协变量会
  连真实总效应一起移除 → `309→3` 只是"组织级信号与组成共变"的证据，不是"细胞内在这件事不存在"的证据。
- 裁判推荐参数（可直接执行）：主观测单位 → **按细胞类型分层 pseudobulk**（去 Unknown，`min_cells ≥ 20`）；
  分层模型 `每类型内 log2CPM ~ Age + sex + batch + log(n_cells)`；组织级模型保留作双报告。
- 专利动作：组织级元件同向率**降为探索性**。⚠️ 重定位/改口径**交用户拍板**，核实轮不动交付件。

## 6. 坑（本类工作实测）

| 坑 | 症状 | 处置 |
|---|---|---|
| 🔴 **CLR 遇结构零** | `log(0) = -Inf` → 协变量含 NaN → `det(crossprod(X))` = NaN → **全部系数 NaN**、报 `missing values and NaN's not allowed if 'na.rm' is FALSE` | CLR 前 **0.5 零替换**（`Wp=W+0.5; Pp=Wp/rowSums(Wp)`），**原始占比保留给报告**；断言 `anyNA(Z)==FALSE && is.finite(det(XtX))`。实测零格 4/240：hc12/ExN、hc26/ExN、hc77/ExN、hc46426/InN —— 稀疏类型在 n=40 个体里**必然出现零格**，不是数据脏 |
| 🔴 R `data.frame()` 列名含 `%` / 中文混排 | `unexpected input`（**解析期报错，不是运行期**），且 R 会吞掉之前所有 `cat()` 输出、只剩 stderr | 列名**一律 ASCII**（`A_sig_pct` 而非 `A显著率_%`），中文表头最后用 `names(tab) <-` 重命名 |
| `rowRanges` NULL | 拿不到坐标 | 只做全基因组分布判定；要落元件先建坐标表 |
| 循环检测 | 一个检验发一次 `terminal`/`execute_python` | **一个脚本一次跑完全部判据**（模板已合并 4 判据 + 落盘 + 出图） |

## 9. 对称检验：另一物种跑同一套三模型（2026-09-13 实测）

**为什么必须做**：人侧"96.8% 归组成"可能只是人侧数据集的特性。要判断**跨物种对比还能不能救**，
必须让另一物种跑**逐字对称的同一套模型**（同矩阵构造、同三模型、同判定），而不是另写一套。
🔴 判据是**两侧是否同构**，不是各自单独显著与否。

**猴侧实测（`monkey_GroupSE_byIndividual.rds` 538,420 peak × 21 个体 + 猴元数据 8 类）**：

| 指标 | 人侧 | 猴侧 |
|---|---|---|
| peak × 个体 | 525,137 × 40 | 538,420 × 21 |
| 年龄轴 | 20–89 连续 / **27 个整数年龄** | 5–31 / **9 个整数年龄 / 4 组** |
| 组成随年龄（显著项） | Astro **−0.663\*\*\***、ODC **+0.442\*\*** | OPC **−0.524\***、Astro **−0.454\***（ODC +0.010 ns） |
| **模型 A：Age 显著 peak** | **309** / 525,137（0.06%） | **0** / 538,420（0.00%） |
| 模型 B（组成校正后） | 3 | 0 |
| R²_age 中位 | 0.0154（同维度随机基线 0.025） | 0.02875（基线 0.048） |
| R²_comp 中位 | 0.4552（基线 0.125） | 0.5762（基线 0.333） |
| **唯一归 Age** | **4.5%** | **6.4%** |
| **唯一归 组成** | **96.8%** | **95.3%** |

**必须新增的「行 0」判据（年龄轴分辨率诊断，本类任务的对称性前提）**：
个体数 / **整数年龄取值数** / **年龄组数** / 每组内年龄列表 + 组内零方差标记 / **形式 df（n−2）vs 有效分辨率（≈年龄组数）**。
猴侧实测：21 个体 / 9 个整数年龄 / 4 组 / **Young 组 4 只全为 5 岁（组内零方差）** → 形式 df=19 但有效分辨率 ≈4 级。
🔴 汇报时**不得把「有效分辨率≈4」写成「df=4」**——审查员会当场抓这个。

**判读三条（照抄口径，别推过头）**：
1. **两侧方差分解几乎同构**（96.8% vs 95.3%）⇒ "组织级信号以组成为主"**不是人侧特例**，是两物种独立成立。
2. **猴侧 0 显著** ⇒ 组织级口径在猴侧**检不出任何东西**。但 n=21 / 仅 4 个年龄组 / Young 零方差 ⇒ 这是
   **"在现有年龄分辨率下不可检出"，不是"猴无年龄效应"**（L1 反方明确挂出这条，必须写进汇报）。
3. 叠加"两数据集细胞类型构成根本不同"⇒ 组织级同向率**不可解读为生物学保守性**，只能作组成差异的描述。

**诚实标注（两物种共有）**：两侧 `R²_age` 都**低于同维度的随机基线**（1/40、1/21）⇒ 组织级口径本身就不稳，
不只是组成的问题。这条要主动写出来，不要等用户发现。

**工程量参考**：猴侧同套三模型 538,420 peak × 21 个体 ≈ **0.5 分钟**（R 持久内核，向量化 OLS）。

## 10. 🔴 做「细胞类型分层 pseudobulk」之前，先探测计数矩阵本体（2026-09-13 实测）

§8 的路线②（裁判主推荐）成本被估成"中（重跑一次 ArchR）"——**这是按"完整项目"估的**。
本地到手的常常是**瘦身下游件**，直接开工 = 承诺了做不出来的事。

**实测标本（`E:/专利/patent/human_Hf_ATAC_40_clustered.rds`，215.8 MB）**：

| 探测项 | 实测 | 后果 |
|---|---|---|
| 细胞数 | 265,909 × 16 列 | ✅ 细胞在 |
| `Clusters` | 30 个（C1–C30） | 🟡 需外挂注释表映射到 celltype |
| **`celltype` / `individual` / `Age` / `Sex`** | **全部不存在** | 🔴 无法定义分层与协变量 |
| **`peakSet`** | **0** | 🔴 无 peak 集 |
| **`projectMetadata$ArrowFiles`** | **长度 0** | 🔴 项目不认识任何 arrow |
| **`getAvailableMatrices()`** | **仅 `TileMatrix`**（无 `PeakMatrix`） | 🔴 拿不到 peak 级计数 |

⇒ 这是一个只保留 `cellColData + TileMatrix` 的下游对象，**`getGroupSE(groupBy = celltype×个体)` 根本跑不了**。

**承诺成本前必跑的六项探测**（一次 `safe()` 调用全打完，见 `platform-execution-pitfalls` 的 `safe()` 写法）：

```
① colnames(proj@cellColData) + 逐列 length(unique(...))   # 分层列与协变量列在不在
② length(proj@peakSet)                                     # 有没有 peak 集
③ length(proj@projectMetadata$ArrowFiles) + file.exists() 覆盖数
④ getAvailableMatrices(proj)                               # 要 PeakMatrix，不是 TileMatrix
⑤ 元数据协变量（Sex/batch 等）                              # 分层模型要不要加协变量
⑥ 各物种 Arrow 本地覆盖率                                   # 猴侧实测仅 3/63 ⇒ 必须回集群
```

**两条同族的 ArchR API 事实（省下反复试错）**：
- `loadArchRProject()` 传的是**目录**（内含 `Save-ArchR-Project.rds`）；传 `.rds` **文件路径**会报
  `Could not find previously saved ArchRProject in the path specified!`。**单个保存的 ArchRProject 对象直接 `readRDS()` 即可**。
- 项目里记的 Arrow 路径常指向远端集群（如 `E:/hwfssz3/PS_JLU/.../ArrowFiles`，本机不存在）。
  本地已有同名 Arrow 时用 **`Sys.junction(本地目录, "E:/hwfssz3/.../ArrowFiles")`** 秒级接通（**不复制 71 GB**）；
  注意 zip/中文路径用 `Sys.junction` 而不是 shell `mklink`（绕开 cmd 的编码问题）。

**结论一句话**：组织级矩阵（`*_GroupSE_byindividual.rds`）**只能定组织级口径，拿不到分层**；
分层 pseudopbulk 的真身是「**从 Arrow 重建项目 → addPeakMatrix → getGroupSE(celltype×个体)**」，
成本远高于一条 `getGroupSE` 调用 —— **探测完再向用户报成本，并让用户选"本地重建 / 回集群取完整项目 / 先停"**。
