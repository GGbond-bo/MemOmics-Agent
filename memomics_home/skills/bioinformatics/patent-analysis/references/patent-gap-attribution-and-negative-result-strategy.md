# 专利空位归因 + 负结果策略 + 审计汇报纪律

> 触发：用户问「**为什么他们不申请专利？**」「**为什么没人做这个方向？**」
> 「**怎么搞了半天，专利越来越不行了呢？**」「我的方法**是不是白做了**」；
> 或用户准备把**负结果**（无信号 / 低于随机 / 测不出）写进说明书或权项。
> 实测来源：跨物种衰老可替代性专利（memomics-7839e23a，2026-09-13）。

---

## 1. 先把问题问准 —— 「他们不申请」是个假问题

用户常这样问：「这个方向为什么没人申请专利？」——**这个问法本身会导向错误答案**
（会去找\"学者不需要专利\"这类通用理由，而那解释不了**企业也不申请**）。

**正确问法**：不是「他们不申请」，而是「**这个方向上，有技术效果的都申请了；
为什么唯独我这一条具体路径没人申请？**」

**取证：逐格验证，不要泛泛而谈**（把「谁 / 申请了吗 / 证据」列成表）：

| 主体 | 申请了吗 | 证据 |
|---|---|---|
| Horvath 团队（多物种保守位点 + 跨物种年龄评估） | **申请了** | WO2020150705 / CN114599797A，UC Regents；*Nature Aging* 2023 原文利益冲突声明逐字写 "The Regents of the University of California filed a patent application (publication number WO2020150705) related to this work" |
| 浙江大学（跨物种单细胞染色质可及性） | **申请了** | CN117542414A，申请号 202311559190.6 |
| 做「可迁移性评分」的团队 | **申请了** | US20210225460A1，说明书含 transferability score |
| Science 人海马衰老组 / Cell 食蟹猴脑图谱 / SAMap·SATURN·scJoint 等整合方法 | 未检索到 | — |

**关键洞察**：**凡能把\"技术效果\"落成一个可测量输出的，都申请了。**
Horvath 的钟能授权，不是因为他更聪明，是因为**他的输出是一个数值（预测年龄），能被独立样本算误差**。

## 2. 两条硬理由（通用理由之外，且更重要）

### 硬理由一：权利要求的\"输出\"没有可测量的技术效果 → A25(二)

| | Horvath 多物种甲基化钟 | 「方向一致性判定」类 |
|---|---|---|
| 输出 | **一个数值**（预测年龄） | **一个判定**（一致 / 不一致） |
| 可验证性 | 能——独立样本算误差 | 不能——**没有 ground truth** |
| 专利法落点 | 测量方法 → 有技术效果 | 高风险落 **A25(二) 智力活动的规则和方法** |

⇒ **不是没人想到，是这个权利要求形态本身很难被授权**——做了分析的人在起草阶段就会被
代理人劝退。这才是「连企业也不申请」的第一个真原因。

### 硬理由二：没有买方

| | 谁会用 | 谁付钱 |
|---|---|---|
| 衰老钟 | 临床 / 消费级基因 / 药企 | **有** |
| 方向一致性判定 | 只有研究实验室 | **研究豁免 → 不侵权 → 无人付钱** |

### 为什么四条\"通用理由\"不够

「学术激励结构不同 / 先发表自毁新颖性 / 方法类专利举证困难 / 数据比方法值钱」——
这四条**都对，但解释不了企业**（企业不需要学术声誉、不需要发表、有能力执行）。
只给这四条 = 回答不完整，用户会追问「那企业呢？」

## 3. 🔴 铁律：负结果**不得**写进说明书（自证无技术效果 = 自杀）

**这是本类专利最致命也最容易犯的错误。**

专利必须有技术效果。若在说明书里论证「本方法跑出来的结果显示该方向不可用 / 不一致 /
低于随机」，等于**自证这个权利要求产生的输出没有技术效果** → 无实用性 → 驳回。
**你会用自己的数据把自己的专利否掉。**

| ❌ 自毁写法 | ✅ 可授权写法 |
|---|---|
| 「本方法的结果显示两物种方向不一致」 | 「本方法**输出可复现、有明确判据、可判定**的逐元件方向一致性判定与不确定性标注」 |
| 「本方法证明该参考物种不可用」 | 「本方法**用于标定**参考物种能否作为方向参考，并给出该判定的失效边界」 |
| 「筛选出可替代的保守元件集」（若集合实测 < 随机） | 「筛选出**带可信度标注**的候选元件集；技术效果是筛选与标注」 |

**一句话记法**：技术效果 = **方法的可执行性 / 可复现性 / 可判定性**，
**不是**「方法证明了某个生物学结论为真」。这正好也是「筛选方法 → 评估方法」那次定位翻转
（见 `screening-method-effect-argumentation.md`）的措辞落点。

## 4. 「没人申请」的镜像答案：他缺的是**标定用的负对照**

反过来说——要造一台「某物种能否作为方向参考」的判定器，需要什么？
需要一个**答案已知为\"不能\"的案例**来标定判据。

| 做这个方向的人 | 有 ground truth 吗 |
|---|---|
| 只做单一物种的图谱研究 | 没有 |
| 跨物种整合方法（SAMap / SATURN / scJoint） | 没有——是整合方法，不管生物学真假 |
| **你自己** | **有**——同一套网格口径、两物种可配对、结论是「不能」 |

⇒ **负结果在\"专利叙事\"里是负担，在\"方法标定\"里是唯一资产。**
汇报时必须把这层说清，否则用户只看到\"我白做了\"。

**诚实边界（必须一并给，否则是过度承诺）**：这**仍然是很难授权的权利要求**，
能否过最终取决于代理人对 A25 的规避写法。正确表述是
「**从没法写变成了可以写**」，不是「稳了」。

## 5. 检索可达性判定：401 ≠ 000（探针设计教训）

网络受限环境下做专利检索时，**判据是\"内容签名\"，不是 HTTP 状态码**。
本轮实测分类：

| 返回 | 含义 | 该做什么 |
|---|---|---|
| **000**（连接超时） | 该主机不可达（DNS / IPv6 / 被阻断） | 换源，**不要**逐次重试 |
| **403 / 405** | 站点可达但拒绝该请求形态 | 换 UA / 换端点，或放弃该源 |
| **401 Unauthorized** | **网络层通，只缺凭据** | ⭐ 这是唯一\"有救\"的口子——注册免费 API key 后可用（如 USPTO Open Data Portal） |
| 200 但 body 是 HTML 落地页 | **伪可用**（跟随后落页） | 见下条 |

🔴 **200 假阳性**：加 `-L` 跟随重定向后落到 HTML 落地页，状态码 200 但根本不是 API。
**探针与原数据请求必须用同一套 flag，且判据必须是 body 首字符是否 `{`/`[`**。

**射程声明义务**：检索源全挂时，「没检索到」**射程有限**，必须显式声明并请用户在
CNIPA 等未受阻渠道复核——不得把\"我没查到\"表述成\"不存在\"。

## 6. 🔴 审计汇报的\"单向悲观漂移\"（本轮用户原话：「怎么搞了半天，专利越来越不行了呢？」）

**现象**：每轮审计后用户对同一份专利的评价持续下降，而**对象本身并没有逐轮变差**。

**我自己复核出的三条根因（不是数据问题）**：

1. **发现即报，报时未验证** —— 我按「先查最坏假设」审计，每个可疑点一发现就带严重语气报出去，
   **报的时候还没验证**。
2. **撤回比报警安静** —— 本轮提了两个\"bug\"警报，后来都自己撤回了
   （① `z = −qnorm(p/2)` 被当成\"漏写负号\"，实为**代数恒等式**；
   ② 稀疏 tile \"ties 丢失\"，实为 `jt_mid` 与稀疏 `==` 语义**均正确**）。
   但用户记住的是\"又出问题了\"，不是\"那条撤回了\" ⇒ **我的消息时间线系统性偏悲观**。
3. **「发现了一个限制」与「发现了一个缺陷」用同一种语气** ——
   从没问那件最该问的事：**这条到底会不会改变 go/no-go？**

**修正纪律（写进每一轮审计汇报）**

| 动作 | 要求 |
|---|---|
| 报警 | **先在当轮跑完验证**再开口；禁止跨轮丢\"可能是 A 也可能是 B\" |
| 撤回 | **与报警同等醒目**——当轮开头明说「我先撤回上一条的 X」，不埋在段落里 |
| 分级 | 每条发现必须标 **🔴 改变 go/no-go / 🟡 只影响表述 / ⚪ 仅归档**，不给等级的发现不许进正文 |
| 时序 | 汇报\"证据状态\"而不是\"警报流水\"——用户要的是当前判定，不是变更日志 |

## 7. 回答「为什么越来越不行」的骨架（本轮实做）

**分三块，性质完全不同**——混在一起讲就是\"一路下坡\"：

1. **真的走低的**：生物学证据（口径对照 → 显著为负 / 门控 CV 符号翻转 / 组成占 96.8%）。
   ⚠️ 措辞：这些数**在复核之前就是真的**，不是\"变差\"，是**从\"不知道\"变成\"知道\"**；
   没做这轮审计就送审，是审查员替你发现——更晚、更贵。
2. **没变、甚至更值钱的**：方法资产（统一同源网格 + 逐单元归一化，三档配对全显著）。
   **明确列出\"这几轮分析一次都没动摇过它\"**。
3. **我这边的问题**：报告方式（§6 三条根因）。**主动认领，不要用户来问。**

**然后给\"价值曲线相反\"的重构**（本例核心转折）：

| | 专利 | 毕业课题 |
|---|---|---|
| 需要什么 | 技术效果，不需科学真相 | 严谨结论，**负结果合格** |
| 负结果 | 当核心主张 = 致命 | 合格，甚至是完整的限制性结论 |
| 现状 | 只剩防御性写法 | 「建了框架 → 发现元素级不优于组成匹配零假设 → 定位到组成中介」= 完整一章 |
| 曲线 | ↓ | **↑** |

⇒ 「专利在缩水，课题在长大。**你觉得一路下坡，是因为一直用专利的尺子量同一批结果。**」

**收尾必须收敛到\"定一条，不是两条\"**（否则来回切换本身就是漂移的来源）：
给 A（继续走专利，不再做新分析、只收尾文书）/ B（转课题，把负结果做成正式结论链）
两个选项，并说明**每次切换都在制造新的漂移**。用户拍板前**不动交付件**。
