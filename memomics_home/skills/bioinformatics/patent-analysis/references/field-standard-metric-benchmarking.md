触发语：「**我想问问其他文章是怎么做的**」「其他文章也这么算吗」「**只有这一种吗？能不能换其他的计算方法**」
「**你都看到同向率低于随机了，是不是说明计算方法有问题呢**」「**这不就是智力活动吗**」
「我们有数据，应该从实际数据找到合适的计算方法，怎么就直接用 z 值了呢」。

本篇是 2026-09-13 实读三篇全文后的对标结论（非摘要、非记忆）。

## §1 三篇已发表做法（全文实读）

| 论文 | 跨物种对齐 | 打分量 | 显著性/评估 | 归一化 | permutation |
|---|---|---|---|---|---|
| **Wang 2026**<br/>Sci Adv | UCSC **LiftOver (minMatch=0.95)** → 直系同源序列；Biopython 全局比对过滤（match=2 / mismatch=−3 / gap open=−5 / gap ext=−3） | **ΔPr = Pr(human) − Pr(ape)**（CNN 仅用人数据训练，预测可及性差） | **卡方 OR**（ΔPr 阈值 vs 实验 human-increased 区域富集）+ ECDF 分布比较 + Spearman（TF motif 重要性排序一致性） | 未见特殊归一化；motif 重要性按 p 值升序排序后求相关 | **0 次命中** |
| **ATACompass 2026**<br/>Cell Rep Methods | 无需注释的序列表征 | **无打分公式** —— transferability 是**定性讨论概念** | 跨物种**细胞类型标注准确率** | — | 未用 |
| **Ogawa 2025**<br/>Sci Adv | 六物种（含盲鳗）cell-class–enriched OCR | de novo motif → 层级聚类（距离 = 1−Pearson） | **Pearson 相关阈值**：簇内中位 r > 0.5 才判「EC 保守 motif」 | 🔴 **物种内先标准化**：每物种**最强 motif enrichment = 1**，再跨物种比 | 未用 |

### 三条对照结论

1. 🔴 **没有人算「符号一致率 vs 50%」。** 三篇全文 `permutation` 命中 **0**，无人报 concordance rate。
   学界比的是**效应量的相关或差值**，不是二元的符号是否相同。
   ⇒ 同批数据报 **效应量相关 r**（本项目 `r(Z₁,Z₂) = −0.0971, n=16,029`，另有 `corr(|Z₁|,|Z₂|) = 0.2248`）
   即可，这是标准陈述；报「46.36% vs 50%」等于**主动把低点摆到台面上**。
   二者是同一件事的连续版 / 二元版 —— 二元化丢掉强度信息，正对上用户那句「**没考虑数据情况**」。

2. 🔴 **缺的工序通常是「物种内归一化」。** Ogawa 的关键动作是**先把每个物种内部标定好**（该物种最强 = 1）
   再跨物种比。若直接把 tile 级量聚合后跨物种比，**物种间测序深度 / 信噪 / 锚定粒度差异会原样灌进聚合量**
   —— 这正是「同向率随锚定粒度单调下滑」那类偏置的病根（本项目实测 −4.74 pp / log₁₀(n)，t = −6.41）。
   ⇒ 提「我们方法要不要改」时，**先看有没有这一步**，再谈换统计量。

3. 🔴 **跨物种对齐有行业标准，自建方案必须自证增量。** Wang 用 LiftOver(minMatch=0.95)，属公知手段。
   「自建统一同源网格」解决的是同一个技术问题（异参考基因组不可直接逐元件比较），
   ⇒ 写进权项时必须写出**相对 LiftOver 的额外好处**（无 chain 文件也可比 / 支持 tile 级窗口化聚合 /
   不依赖 minMatch 阈值），否则会被认定为「LiftOver 的常规替代」。
   反过来这也说明「统一网格」那条技术问题**是真实存在的**，不是编的。

## §2 换方法要分清换的是哪一层（这是能否改判定的唯一判据）

| 换法 | 有符号 | 解决自相关 | **能改「一致率」吗** | 专利性 |
|---|:---:|:---:|:---:|---|
| Fisher `atanh(r)·√(n−3)` | ✅ | ❌ | **不能**（符号仍 = sign(r)） | 公知常识 |
| Spearman ρ → z | ✅ | ❌ | 几乎不能 | 公知常识 |
| Jonckheere-Terpstra `(J−EJ)/√VJ` | ✅ | ❌ | **不能** | 公知常识 |
| 个体级混合模型 slope → z | ✅ | 部分 | 不能 | 中等 |
| **换聚合方式**（中位数 / 符号多数 / 强度加权 代替求和） | ✅ | **✅** | **能** | **高** |
| **有效自由度 n_eff 校正 + 空间块置换** | ✅ | **✅** | **能** | **高** |

🔴 **一句话判据：换 tile 级公式 → 一致率一个百分点都不会变（符号永远是 sign(r)）；换聚合 / 归一化口径 → 才会变。**
所以「能不能换其他计算方法」的正确答法不是列统计量清单，而是**先定位用户想改的是哪一层**。

### 自相关这一层的技术论证（若要把 n_eff 校正写进专利）

- `Z = ΣZ_tile / √n` 的合法性前提是 **n 个 tile 相互独立**；同一窗口内 tile 物理相邻、可及性高度自相关。
- 若 tile 平均相关 ρ，正确写法是 `Z = ΣZ_tile / √(n(1+(n−1)ρ))`；ρ→1 时应除 n 而不是 √n。
- 实测支持偏差方向的量：`corr(|Z|, log n) = +0.557`；强效应池 n 均值 522.9 vs 非强池 116.3（**4.49×**）。
- ⇒ 可写成完整闭环的**新专利落点**：技术问题（粒度依赖偏置）→ 技术手段（估 n_eff / 空间块置换 / 稳健聚合）
  → 技术效果（任意锚定粒度下判定自洽）。附带好处：校正后若一致率回到 ~50%，说明书里那句
  「显著低于随机」即可换成「与随机无显著差异」——**从自证失败降为中性**。

## §3 报告口径建议（可直接照抄）

1. 主指标报 **(效应量相关 r, n)**，不报 (一致率, vs 50%)；一致率如需给，必同屏给匹配零假设与配对 z。
2. 粒度依赖必须量化成一句可复现的判据（斜率 + t 值 + 分层表），不要只说「有偏置」。
3. 说明「为何用 z」的诚实答案：**因为流水线做了基因级聚合，而聚合需要可加量**（p 不可加、Z 可加）。
   ⚠️ 这是**设计选择不是必然** —— 若不需要基因级聚合，可直接用加权效应量或逐基因 LMM slope。
   用户质疑「为什么非要算 z」时，先承认这是选择，再说明它绑定了哪一步。

## §4 取全文的实操（摘要接口常为空）

```bash
# search_papers 返回的 abstract 常为空串 → 直接取 PMC 全文 XML
curl -s --max-time 60 "https://www.ebi.ac.uk/europepmc/webservices/rest/{PMCID}/fullTextXML" -o {PMCID}.xml
```

- 去标签转纯文本：剥 `ref-list|back|front` 整段 → 剥标签 → 压空白（3 篇实测 53.8K / 57.2K / 80.7K 字符）。
- 纯文本常是**单行大文件**：`read_file` 与 content 模式搜索都会截断/失控
  ⇒ 用持久内核按关键词打**上下文窗口**（±300–500 字符）逐条看。
- 关键词计数即是一份廉价证据：`permutation` / `transferab` / `normaliz` 的命中数直接支撑
  §1 表中「未用 / 是定性概念」这类判定，比读印象可靠。
- ⚠️ **`terminal` 的 `/tmp` 与 `execute_python` 的 `/tmp` 不是同一处**（前者 MSYS 路径、后者 Windows 内核）
  ⇒ 抓取产物一律落到 **Windows 路径**（如 `results/<sid>/data/lit_xspec/`）再交给内核读。
