## §2 🔴 旧口径数字混入新版交付件（头号隐蔽硬伤）

**为什么零残留检查抓不到**：`stale` 清单通常是历次改版时登记的旧**结果串**（如 `336` / `37`）。本次这个数字（`25.3%`）**从未被登记为陈旧串** —— 它是上一代方案的**性能指标**，语境完整、读起来完全合理，`grep` 任何 stale 列表都命不中。

**实测标本（v22 表 7 末行）**：
```
公知常规做法：两队列独立筛选取交集、合并 Z 做 meta 分析、单物种筛选
→ 与本案的区别：不含衰老维度；样本量不对称时对小样本侧对称施加阈值会截断主体侧真实信号
   （召回 1.1% vs 本方法 25.3%）
```
- `25.3%` 来自 **v17 非对称评分法**（当时输出 357 个元件）
- 而 v22 主口径已是 **150 元件三柱 AND**，且**同一份文档第四节刚声明「不依赖方向一致性」**
- ⇒ 这个数字**既不是本方法的实测召回**，又与自家声明**直接打架**

**判据**：交付件里凡出现**具体性能数字**（召回/精度/倍数），先问一句「**它属于哪一代口径**」—— 与正文当前口径代数不符即删。

**修法优先级**：**删数字 > 改写**。改写成**维度差异**句最安全：
```
不含衰老维度；且其在两物种样本量不对称时须对小样本侧对称施加阈值，会截断主体侧的真实信号。
本案以「序列保守 ∧ 跨物种可及 ∧ 物种内年龄效应」三层独立证据判定，不依赖两物种间效应量的
方向一致性，故不受该样本量不对称约束
```
（同一个对比位置，从"我比你强 X%"改成"我的判据维度不同" —— 后者不需要任何实验支撑，前者需要。）

## §3 附图版心换算（缩印可读性）

**换算式**（docx 图片按**英寸**定宽，Word 版心约 **6 英寸**）：
```
缩印比 = 6 / 画布宽度(in)
印刷字号(mm) ≈ 图中字号(pt) × 0.3528 × 缩印比
判据：印刷后 ≥ 2.5 mm 才算可读（下限 2 mm 勉强）
```

**实测标本**（v22 被判 P2）：

| 图 | 原画布宽 | 缩印比 | 图内字号 | 印刷后 | 判定 |
|---|---|---|---|---|---|
| 图 3 | 13.6 in | 44% | 8.5–11.2 pt | ≈1.3–1.7 mm | ❌ |
| 图 5 | 17.0 in | 35% | 7.2–11.2 pt | ≈0.9–1.5 mm | ❌ |

**修复配方（v23 实测）**：
1. **拆图**：把 `1×2` / `1×3` 多面板图拆成**每面板一个文件**（图 3 → 3A/3B；图 5 → 5A/5B/5C）
2. **压画布**：单图宽 **5.2–6.2 in**（≈ 版心 1:1 显示，缩印比 ≈0.97–1.15）
3. **加字号**：`xlabel/ylabel 10.0–10.5` · `title 11.0` · `tick 8.6–12.0` · 注释 8.5–9.5
4. **其余图不动**：原画布 ≤9.0 in 的图缩印比 ≥0.67、字号达标 → **直接复制复用，不重画**（省一轮，且避免引入新差异）
5. 附图说明与 `add_fig` 清单**同步改图号**，并在「附图形式说明」里写明「其中图 3 分为 3A、3B，图 5 分为 5A、5B、5C」

**注意**：`matplotlib` 的 `figsize` 是**物理英寸**，`savefig(dpi=300)` 只影响像素数、不影响换算 —— 像素大 ≠ 缩印后字大，别把 dpi 当解法。

## §4 从属权项无说明书支持 → 补支持段（A26.4）

审核方常同时给两个选项：「**要么在说明书补对应实施例段落，要么先删掉这几项从权**」。
🔴 **优先补段，不要删从权** —— 从权是保护范围，删掉是不可逆的收缩；而补支持段只需把**已在实测里存在的做法**写成段落。

**段落骨架（实测 5 段，每段：特征 → 本实施例怎么做 → 实测数字）**：

| 从权 | 补写要点 | 必带实测数字 |
|---|---|---|
| 加权投票 / 权重标定 | 本实施例取逻辑与（AND）；另一实施方式为加权投票，**权重由目标输出区间反推** | 扫描 N 组阈值组合、M 组落入目标区间 |
| 单元网格与层内匹配基准率 | 对应关系来源、窗口、收敛路径；**零假设用层内匹配基准率，不用绝对 50% 基准** | 收敛前 → 收敛后单元数；**两侧方向一致占比（本实施例 48/150 = 32%）** |
| 跨粒度门控归一化 | `z̄ = Z / √n` 的定义与动机（消除单元长度贡献） | n 的变动范围 |
| 置换检验定阈值 / 零假设口径 | τ 的取法（经验分位 / 置换空分布 / 1.96 三选一写清）；零假设构造方式 | 阈值对应分位 |

**关键**：支持段的实测数字**必须来自已跑过的产物**（不要为写段落新编数），并**显式点明「该口径的必要性已由本实施例实测支持」** —— 把「有描述」升级为「有数据支撑」。

## §5 数据来源与公开信息节

律师判断**新颖性与宽限期**需要知道每个数据集的来源与公开时间。

- **能核实的必须写明**：公开数据集写 **GEO 编号 + 公开年份**（本标本：人侧 40 例海马 snATAC-seq = **GSE278576**，2026 年公开释放），并加一句「本方法对该公开数据仅施加本申请所述的……处理，未改变其原始内容」
- 🔴 **查不到来源的一律不编**。本标本猴侧 20 例来源未知 → 写中性表述「**申请人在本实施例中取得的对应组织测序数据**」，并在汇报里**明确请用户补**（「若猴侧其实是某个公开数据集或某机构提供，告诉我编号我补进去」）
- ⛔ 禁止为凑格式而虚构 GEO/ArrayExpress 编号 —— 交底书是要签字的件，编造来源比留空严重得多

**① `core_properties` 模板残留**（python-docx `Document()` 默认 `created = 2013-12-23`、`author = python-docx`）：
```python
doc = Document()
from datetime import datetime as _dt
_cp = doc.core_properties
_cp.author = ""            # 或申请人名
_cp.last_modified_by = ""
_cp.title = "技术交底书　一种跨物种保守衰老调控元件的筛选方法"
_cp.comments = ""; _cp.category = ""
_cp.created = _dt(2026, 9, 15, 0, 0, 0)
_cp.modified = _dt(2026, 9, 15, 0, 0, 0)
```
探针判据：`cp.created is None or cp.created.year != 2013` 且 `(cp.author or "") == ""`。

**② 申请人栏位**：只有 姓名/电话/身份证/地址 四栏会**直接退件**（律师要据此起草委托书与请求书）。至少补「**申请人姓名/名称**」「**发明人姓名（可多位）**」「**邮政编码**」。值由用户手填 —— 用户明确说过「除了申请人信息我自己填写」，**不要代填、不要编**。

**③ 「可运行装置 / 逐层基数 X→Y→Z」这类声明必须有实体文件在交付目录内**。审核者会直接去交付目录找 `results/*.csv` 与 `*.py`，找不到就判「**材料缺失 / 正文声称与交付物不符**」。修法：建 `vN_溯源档案/results/`（清单表、单元表、扫描表、统计 json）+ `vN_溯源档案/scripts/`（全流程复现脚本），**归档进交付目录**，不是只躺在 `results/<sid>/`。

**④ 只送单文件**：交付目录常并存多代次（含已作废旧口径）档案。必须在目录索引里写死一句「**只送 `01_送审_vN/<主件>` 这一个文件**」并说明「整包发送可能被按旧口径理解」。

## §7 验收探针（一个脚本一次跑完全部检查）

🔴 **不要"想到一项检查就再写一个小脚本"** —— 交付后核验连发多个探针会触发系统循环检测（本项目已多次实测被拦）。**一个产物配一个探针**，一次输出全部 `PASS/FAIL`。

**必含的两条写法**：

```python
# 全文 = 段落 + 表格单元格（只扫段落会造假 ✘ —— 公开号在表里、申请人字段在表里）
txt = "\n".join(p.text for p in d.paragraphs)
for t in d.tables:
    for r in t.rows:
        for c in r.cells:
            txt += "\n" + c.text

# 内嵌图：数量 + 逐张字节数（对上源图 = 未被替换的头号嫌疑）
media = sorted(n for n in zipfile.ZipFile(P).namelist() if n.startswith('word/media/'))
```

**本轮 17 项检查清单**（可直接照抄改关键词）：结构计数（段落/表格/字数/图数）→ 每处 P0/P1 修复的新串在 + 旧串不在 → 文档属性 → **备注残留扫描**（`待跑` / `占位` / `供代理人参考` 全 0 命中）→ `sys.exit(1 if FAIL else 0)`。

**Windows 脚本路径坑**：`/tmp/xx.py` 在 MSYS bash 下传给 Windows Python 会被解析成 `E:\tmp\xx.py` → `can't open file`。**探针写到会话 `scripts/` 目录**，用绝对路径调用。
