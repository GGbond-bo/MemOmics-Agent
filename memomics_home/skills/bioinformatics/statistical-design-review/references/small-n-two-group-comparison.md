# 小样本两组比较（n=6/组）实测案例 —— Welch + Hedges' g + BH-FDR

**场景（2026-10-18）**：用户给一张长表 `expr.csv`（`sample,group,gene,expr`，6 基因 × 2 组 × 6 例 = 72 行），
要求 Aging vs T2D 两组比较，并**指定固定表头**写进 `out.csv`：

```
gene,mean_Aging,mean_T2D,pvalue,effect_size,qvalue,test_method,differential
```

数据特征：每组恰好 6 例；组均值差从 −0.30 到 2.14；**两组 SD 不等**（GENE4 0.55 vs 1.29、GENE6 0.62 vs 1.50）。

## 1. 口径（最终采用）

| 项 | 取值 | 理由 |
|---|---|---|
| 检验 | **Welch 双侧 t**（`equal_var=False`） | 独立两组、n=6 无法检验前提、两组 SD 差异明显 → 合并方差高估精度 |
| 效应量 | **Hedges' g**（合并 SD + 小样本校正） | n 小；`J = 1 − 3/(4·10 − 1) = 0.9231` |
| 校正 | **BH-FDR**（m=6） | 多重检验必须校正；带单调化 |
| flag 判据 | 原始 `p < 0.05`（**回复里声明**） | 表头固定无法加备注列 → 判据写进回复 |

## 2. 产物实际数字（`out.csv`）

| GENE4 | 11.5943 | 12.5998 | 0.124945 | 0.9333 | 0.187418 | no |
| GENE5 | 5.0403 | 4.7402 | 0.700848 | −0.2108 | 0.775897 | no |

- 只有 **GENE1** 是 q<0.05 的稳健差异；GENE3 原始 p 显著、校正后不显著 ⇒ 回复里必须点出，

  `0.7759 → 0.7759 → 0.187418 → 0.187418 → 0.081260 → 0.002366` ✔ 与表一致。

## 3. 两个自证算式（下次直接用来校验）

**Hedges' g**（GENE1）：`SD_pooled = √[(0.712793² + 0.710272²)/2] = 0.71146`；
`d = 2.14117 / 0.71146 = 3.0093`；`g = 3.0093 × 0.9231 = 2.7777` ✔ 与产物逐位吻合。

**Welch df**（GENE1）：`se = √(0.508073/6 + 0.504486/6) = 0.410803`；`t = −5.2114`；
`df = (0.084679 + 0.084081)² / (0.084679²/5 + 0.084081²/5) = 9.9999 ≈ 10`
⇒ **等样本量时 Welch df ≈ n1+n2−2**，这正是"Welch + 合并 SD 的 Hedges' g 不冲突"的数值体现。

## 4. 回复里给出的局限（4 条，可直接复用措辞）

1. n=6/组功效极低，p 值不稳；**不显著的基因不能当作"无差异"证据**。
2. 正态性与方差齐性在 n=6 下几乎无法检验 ⇒ 只能说"未发现明显违背"。
3. 样本命名 `Aging_1..6 / T2D_1..6` 不构成配对证据；若实为同一批供体应换配对 t / Wilcoxon signed-rank，
   结论可能改变。
4. 每基因独立建模，未校正性别/年龄/批次等协变量；且数据形似模拟数据（`GENE1..6`），
   仅作流程演示、不作生物学结论。

## 5. 交付纪律（本次教训）

- **口径的唯一权威是生成脚本**：产物 CSV 只给结果，`out.csv` 里 `test_method` 只写名字、
  不写效应量定义与 flag 判据 ⇒ 回答"用了什么检验/为什么"时**读生成脚本**而不是反复读产物。
- 用户只要求**说明**时：把「输入表 + 产物 + 生成脚本」在**同一轮批量读完**即作答，
  不要分轮反复核对（本次连续核对触发了系统的循环检测干预）。
- 产物已存在 → **不重跑、不重写**，只在回复里补口径说明；新增内容另建文件，绝不覆写用户指定路径。
