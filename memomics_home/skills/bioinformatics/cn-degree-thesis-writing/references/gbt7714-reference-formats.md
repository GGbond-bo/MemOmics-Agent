# GB/T 7714-2015《信息与文献 参考文献著录规则》常用条目

> ⚠️ **核对声明**：下列条目是**通用常见格式**，用于起草与自查。
> 送审/定稿前必须回**学校下发的原件**（吉大附件5，`D:\硕士毕业论文\信息与文献++参考文献著作规则.pdf`）逐条核对——
> 该原件是**扫描版 PDF**，OCR 后多栏表格会串行错位，**不能把 OCR 文本当权威表格直接引用**，关键条目必须目视核对原件页面。

## 1. 引文标注（正文）

**顺序编码制**（吉大规范默认允许）：
- 标示置于所引内容**最后一个字的右上角**，方括号内阿拉伯数字，按引用出现先后连续编码
- 格式：**小 5 号宋体上角标**，`[1]`、`[2-4]`
- 同一处引用多篇：`[1,3,5]`；连续多篇：`[1-3]`

**著者-出版年制**：由著者姓氏与出版年构成，置于 `( )` 内，如 `(王等, 2020)` / `(Smith et al., 2019)`

🔴 两制**全文必须统一**；🔴 **不得将引用文献标示置于各级标题处**。

## 2. 参考文献表常用条目

| 文献类型 | 格式 | 标识 |
|---|---|---|
| 期刊论文 | `[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.` | `[J]` |
| 专著 | `[序号] 作者. 书名[M]. 版本. 出版地: 出版者, 出版年: 页码.` | `[M]` |
| 论文集析出文献 | `[序号] 作者. 题名[C]//论文集编者. 论文集名. 出版地: 出版者, 年: 页码.` | `[C]` |
| 学位论文 | `[序号] 作者. 题名[D]. 保存地: 保存单位, 年份.` | `[D]` |
| 专利 | `[序号] 专利申请者或所有者. 专利题名: 专利国别, 专利号[P]. 公告日期或公开日期.` | `[P]` |
| 标准 | `[序号] 标准编号 标准名称[S]. 出版地: 出版者, 出版年.` | `[S]` |
| 报告 | `[序号] 作者. 题名[R]. 出版地: 出版者, 出版年.` | `[R]` |
| 电子资源 | `[序号] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.` | `[EB/OL]` |

**作者著录规则**：
- 3 位及以下作者**全部列出**；**3 位以上列前 3 位后加「, 等」**（英文 `, et al.`）
- 姓在前名在后；西文作者姓全大写或首字母大写，名用缩写（按学校/期刊要求统一）

**其他要点**：
- 序号统一用 `[1] [2] [3]`，正文标注序号与文后条目序号**必须一致**
- 题名后必须紧跟**文献类型标识**（`[J]/[M]/[D]/[P]…`）；电子资源需 `[EB/OL]` 并给引用日期与 URL
- 出版地/出版者/年份齐全；专著有具体页码时著录页码
- DOI 可著录于条目末尾（可选）

## 3. 与本项目论文写作的衔接

- 论文里引用的每篇文献应先在引用库登记（`save_reference(action="add")`），完成后 `export` 出 `.bib`/`.ris`，
  再按上表格式转成正文样式——避免手抄作者/年份/卷期出错。
- 正文中出现的**专利**（本课题涉及跨物种 CRE 可替代性专利）著录走 `[P]` 条目格式，
  专利号/公开日以专利局公开文本为准，不要用内部方案稿编号。
