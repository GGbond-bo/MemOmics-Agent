# 高校学位论文规范 → DOCX 实现映射（吉林大学硕士版实测）

> 来源：《吉林大学研究生学位论文撰写及装帧规范》2023 年 3 月版 + 附件 2/3/4/5/6。
> 换其他学校时，按同构替换本表即可——结构不变，只换数值与字体名。
> 标记：🔴 硬性要求 / ⚪「可根据需要」的选做项。

---

## 一、论文结构（前置 7 项 + 主体 + 结尾 3 项）

**前置部分（硕士 7 项，顺序不得调整）**

```
1 封面 🔴   2 原创性声明 + 关于学位论文使用授权的声明 🔴   3 [序或前言] ⚪
4 摘要及关键词 🔴   5 目次页 🔴   6 [插图和附表清单] ⚪   7 [符号/缩略词/术语注释表] ⚪
```

⚠️ 硕士前置**没有**"指导教师评阅意见 / 答辩决议书"这两类学位材料（那是博士的）。
⚠️ 序/前言与摘要二者的内容可二选一（并入绪论亦可），不要重复。

**主体部分 🔴**：`引言(绪论) → 正文 → 结论 → 参考文献 → [注释] ⚪ → [附录] ⚪`
- **正文从另页右页开始，每一章另起页**。
- 结论是"最终、总体的结论"，**不是各段小结的简单重复**，须明确指出创新点。

**结尾部分 🔴**：`作者简介及在学期间所取得的科研成果 → 后记和致谢 → 封底`
- 科研成果按"学术论文 / 专利 / 专著 / 获奖"分类，**以公开发表时间顺序**列出。

## 二、16 项硬指标 → python-docx 实现

| # | 规范要求 | 实现方式 |
|---|---|---|
| 1 | 前置 7 项顺序固定；正文从另页右页开始、**每章另起页** | 每章 `doc.add_section(WD_SECTION.NEW_PAGE)` |
| 2 | 页码：前置**罗马数字** / 主体与结尾**阿拉伯数字**；**封底不要页码** | 分节 XML 注入 `w:pgNumType`（`w:fmt`=upperRoman/decimal）；**只给主体第一节设 `w:start`=1**，后续节不设即续号 |
| 3 | 页码位置：单页印刷**右下角**；双面：单页码右下、双页码左下 | footer 段落 `alignment = RIGHT`（单面） |
| 4 | **页眉**：主体部分使用；**居中**；**楷体小 5 号**；横线为**普通单划线**；单面印刷页眉 = **章的编号及标题** | 每节 `header.is_linked_to_previous=False` → 楷体 9pt 居中 + 段落 `w:pBdr/w:bottom` 单线。🔴 **章标题必须显式传入该节**，漏传即空页眉 |
| 5 | 正文字体**宋体**，字号 5 号/小 4 号/4 号任选其一，**全文统一**；标题可大正文一号 | Normal = 宋体 12pt（小四）；`w:rFonts` 需同时设 `w:ascii`/`w:hAnsi`/`w:eastAsia` |
| 6 | 章节序号：`第1章` / `1.1` / `1.1.1`；**序号与标题间空一个汉字**；**终止层次不加点** | 标题文本直接用全角空格 `　` 连接（如 `第1章　绪论`）；节标题序号**顶格** |
| 7 | 章标题字体 | 黑体三号 16pt（顶格）；一级节标题 黑体四号 14pt；二级节标题 黑体小四 12pt |
| 8 | **图**：图号图题排在图**下方**、以图所占位置**居中**、图号与题名**空一个汉字**、**黑体**、字号＝正文 | 图片段落居中 → 紧随 `**图 X.Y　题名**` 段落，黑体 12pt 居中 |
| 9 | **表**：表号表题排在表**上方**、居中、空一格、**黑体**；跨页**续表**左上角注"续表"并重复表头 | 表题段落设 `keep_with_next=True`；表用 `Table Grid` 样式，表头行加粗（重复表头靠在 Word 里设首行重复） |
| 10 | **公式**：另起一行居中；**编号右端对齐**，公式与编号间用"…………"连接 | 公式行居中、编号含在文本内（如 `…　　（2-1）`）；用 4 空格缩进 + 行尾 `（N-M）` 正则识别 |
| 11 | 摘要：**硕士约 1000 字**；英文摘要据中文翻译；**关键词 3–8 个** | 摘要正文与正文同字号；题目宋体居中且比正文大一号 |
| 12 | 摘要排版："关键词："左**顶头**、**宋体加粗**、与正文**隔一行**；关键词**另起一行**、左**空两个汉字**、词间**逗号**分隔 | 关键词行设 `left_indent` 2 字符 + 加粗"关键词："run |
| 13 | 目次页："目 录"**三号黑体居中**；条目**四号宋体**按层级缩进（章 0 / 一级节 1 字 / 二级节 2 字）；页码右对齐、**不用括号**、用"…………"连接 | 静态目录文本行，四号宋体 |
| 14 | 引文标注：顺序编码制或著者-出版年制，**全文统一**；🔴 **不得置于各级标题处** | 顺序编码制，标注只放正文句末 |
| 15 | 参考文献按 **GB/T 7714-2015** 著录 | 见下方第四节 |
| 16 | 装帧：**横开本左侧装订**、A4；天头/订口 ≥ **25 mm**，地脚/切口 ≥ **20 mm**；裁切后 29.1×20.7cm；封面纸 120 克白色布纹纸 | 页边距上 2.7 / 下 2.5 / 左 3.0 / 右 2.5 cm（全部满足下限） |

## 三、封面与声明页（易漏的附件项）

**封面要素**：分类号（《中国图书资料分类法》第四版）、**单位代码 10183**、密级（一般"公开"）、研究生学号、学位类别、**校徽（蓝色 3×3 cm）**、中文题目（**黑体三号**）、英文题目（**Arial 小三号**）、作者姓名（须与身份证件完全一致）、专业名称（**不得用简称**）、导师姓名（**姓名与职称之间空一个汉字**）、培养单位、论文完成时间（**封面下部居中**）。

- 🔴 **中英文题目总长不超过 30 个汉字**（起题目先数字数）。
- 学位类别：学术学位填"××学硕士"；专业学位直接写标准名称（查附件 6 的《博士、硕士专业学位名称》）。
- **书脊**以宋体小 4 号或 5 号字打印。

**扉页（附件 2）**：论文题目宋体三号 / 英文题目 Arial 三号；作者姓名、专业名称、指导教师、学位类别、答辩日期（年月日）均**宋体四号**。

**声明页（附件 3、4）**：**标题 3 号宋体，正文 4 号宋体**；授权声明需勾选论文级别（□硕士 □博士）并填学科专业、论文题目、双方签名、日期、联系地址（邮编）、联系电话。

## 四、参考文献著录（GB/T 7714-2015 常用条）

| 类型 | 格式 |
|---|---|
| 期刊 | `[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.` |
| 专著 | `[序号] 作者. 书名[M]. 版本. 出版地: 出版者, 出版年: 页码.` |
| 学位论文 | `[序号] 作者. 题名[D]. 保存地: 保存单位, 年份.` |
| 专利 | `[序号] 专利申请者或所有者. 专利题名: 专利国别, 专利号[P]. 公告日期或公开日期.` |
| 电子资源 | `[序号] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.` |

- **3 位以上作者：列前 3 位后加"等"/"et al."**
- 文献类型标识：专著 M / 期刊 J / 学位论文 D / 专利 P / 论文集 C / 标准 S / 报告 R / 电子资源 EB/OL。

## 五、自查清单（交付前逐条打勾）

**结构类**
- [ ] 前置 7 项齐全且顺序正确；主体从另页右页开始、每章另起页
- [ ] 目录收录范围完整（含结论、参考文献、附录、作者简介、致谢），页码不带括号

**格式类**
- [ ] 页码：前置罗马 / 主体阿拉伯 / 封底无 / 位置正确
- [ ] 页眉：**逐节有内容**、楷体小 5 号居中、单划线
- [ ] 正文字体全文统一；标题大正文一号
- [ ] 章节序号「第1章」「1.1」「1.1.1」，序号与标题空一个汉字，终止层次不加点
- [ ] 图：图号图题在**图下方**居中、空一格、黑体、字号＝正文
- [ ] 表：表号表题在**表上方**居中、空一格、黑体；跨页续表注"续表"并重复表头
- [ ] 公式：另起行居中；编号右端对齐，用"…………"连接
- [ ] 缩写词首次出现括注英文原词；量和单位用国际标准符号
- [ ] 引文标注全文统一，且不出现在任何标题处
- [ ] 参考文献严格按 GB/T 7714-2015
- [ ] 封面：单位代码 10183、校徽蓝色 3×3cm、中英文题目总长 ≤ 30 汉字、导师姓名与职称空一格
- [ ] 摘要：硕士约 1000 字；英文摘要据中文翻译；关键词 3–8 个
- [ ] 声明页：标题 3 号宋体 / 正文 4 号宋体；授权声明勾选"硕士"
- [ ] 装帧：横开本左装订、A4、上左 ≥25mm、下右 ≥20mm

## 六、非汉语撰写的情形（备用）

若论文用非汉语撰写：**硕士中文摘要不少于 3000 字**（博士不少于 5000 字）。英文摘要据中文摘要翻译。
