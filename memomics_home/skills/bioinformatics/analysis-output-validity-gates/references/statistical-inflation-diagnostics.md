# 统计有效性门：数值"好看"但不可能是真的（假阳性膨胀诊断）

> 覆盖第一类静默无效产出的**姊妹情形**：产出不是全 0 / 全 NA，而是**数值齐全、分布像样、显著基因一大把**——
> 但统计量在数学上不可能成立。典型：细胞级 DEG 报出 85–99.7% 的基因"显著"。
>
> 触发：新方法一上来显著基因暴多 / 比老方法多几十到几万倍 / 用户问"是不是方法更好了" /
> 显著性看起来太漂亮 / p 值小到离谱 / 换方法后结果差异巨大。

## 0. 核心判据

> **显著率高得离谱不是"威力更强"，先假定是假阳性膨胀，再用数字证明或推翻。**
> 真实生物学数据里，**不可能有 50%+ 的基因在同一对比中差异表达**。
> 每个"新方法更好"的结论，都必须先过本页六问。

⛔ **禁止**：看到新方法显著基因变多就汇报"方法改进了"。**必须**先跑六问自证。

## 一、六问诊断协议（逐项算出数字，不许眼看）

对照物 = 同一批数据的**已审查老方法**结果，取**单一亚群/单一对比**做对照（排除混合效应）。

| # | 诊断 | 怎么算 | 健康值 | 膨胀信号 |
|---|------|--------|--------|---------|
| D1 | **p 值分布** | `p.median()`、`(p<0.001).mean()`、`(p>0.5).mean()` | p 中位 ≈0.5、p>0.5 占比 ≈50% | p 中位 <1e-10；p<0.001 >90%；p>0.5 <5% |
| D2 | **FDR 口径复现** | 对 p 列自己跑 BH，与给出 fdr 列比对吻合率 | 好复现（>90%）＝口径清楚 | 不能复现 → 口径不明，先问清家族范围 |
| D3 | **SE 直接对比** | 新方法 `se` 列 vs 老方法 `|logFC/t|` 反推，取中位比值 | ≈1 | **>3 即 SE 被低估**；>20 极严重 |
| D4 | **效应量是否脱钩** | 显著基因 \|效应\| 中位 **vs** 全部基因 \|效应\| 中位 | 显著基因明显右移 | **两者几乎相等 → 显著性由分母驱动，与效应无关** |
| D5 | **方向指纹** | 显著基因 up/down 比值 | ≈1（真生物学会有正负） | 严重单向（如 46:1）→ 系统性偏倚 |
| D6 | **已知阴性对照** | 一个此前多方法一致的阴性对比，看新方法报多少 | 仍近 0 | 报出成千上万 → 特异性崩塌 |

**D3 + D4 是最致命的两条**，它们是"假精度"的指纹：
- D3 给根因（SE 被压小），D4 给后果（显著性跟变化大小脱钩）。
- SE 低估倍数 k → 有效样本量被高估 **k²** 倍（k=26.4 → ≈700 倍），这解释了 p 值为何集体下溢。

## 二、实测参照值（人骨骼肌，24 供体 / 48 样本 / 10 亚群）

用户新方法：细胞级 MAST-style `glmer` + RUV 校正（`method="glmer"`，nRUV=5）。
对照老方法：pseudobulk + dreamlet `~0+type+(1|individual)`，`ddf="KR"`。对照亚群 Pure Type I。

| 对比 | 老方法显著 | 新方法显著 | 倍数 |
|---|---:|---:|---:|
| Aging | 29,550 | 59,681 | 2.0× |
| DM | 1 | 36,473 | 36,473× |
| Ex_Young | 22 | 24,624 | 1,119× |
| Ex_Old | 1,246 | 51,241 | 41× |
| Ex_DM | 4 | 23,640 | 5,910× |

六问结果（Pure Type I / Aging）：

| 项 | 新方法 | 老方法 |
|---|---|---|
| 显著率 | **99.7%**（7,290/7,310） | 19.7% |
| p 中位数 | **2.40e-288**（double 下溢区） | 0.148 |
| p<0.001 占比 | 99.3% | — |
| p>0.5 占比 | 0.1%（应≈50%） | — |
| SE 中位 | **0.0066** | 0.1670 → **低估 26.4×** |
| 显著基因 \|coef\| 中位 | 0.2478 | 0.841 |
| **全部基因 \|coef\| 中位** | **0.2477**（与显著基因几乎相同！） | — |
| up/down 比值 | **46.96** | 0.86（≈1:1） |

**判定：假阳性膨胀，非方法改进。** 该结果不可作主分析结论。

## 三、根因：随机效应有没有真的进 SE

**必做的一步**：新方法声称含供体随机效应时，**实测 RE 是否真的传递到了 SE**，
不要因为公式里写了 `(1|individual)` 就假定它生效。

在本数据上实测 `MAST::zlm(method="glmer")`：

```
加 (1|individual) 随机效应后 SE 中位 = 0.050
不加随机效应        SE 中位 = 0.052   ← 几乎不变
```

而该数据 **ICC = 0.418**（同一个人的细胞高度相似）。RE 对 SE 毫无影响 → 供体相关性没被吸收，
细胞仍被当独立重复 → SE 被压小几十倍。

> 一般化教训：**"公式里有随机效应" ≠ "SE 反映了随机效应"。**
> 验证方式：同一批数据跑 RE / 无 RE 两版，比 SE 分布；SE 没变 = RE 没生效。

## 四、与 ICC / 细胞深度的关系（为什么细胞级老出事）

同一数据实测（零假设下随机分组，看假阳性率）：

| 每供体细胞数 | 细胞级 FPR | 供体级 FPR |
|---|---:|---:|
| 5 | 25.0% | 6.0% |
| 20 | 53.5% | 6.5% |
| 100 | 73.0% | 5.0% |
| 500 | 92.0% | 9.0% |
| 1000 | 93.5% | 3.5% |

**细胞越多，细胞级错得越狠**（噪声被当信息）；供体级稳定围绕 5%。

方差的硬上限（组均值）：

```
Var(组均值) = σ² × [ ICC/n_donor + (1−ICC)/(n_donor × m) ]
                    ↑ 不随细胞数变        ↑ 随细胞数变小但趋于 0
```

ICC=0.418、n_donor=12、m=7138 时，第一项占 **99.98%** —— 细胞数只贡献 0.02%。
**细胞数增加 1427 倍，正确的 SE 只降 11.5%；细胞级假设下却降 97.4%。**

## 五、三条合法途径（不是对错关系，选一条即可）

⛔ **不要把"必须 pseudobulk"或"必须随机效应"说成硬规定** —— 这是过度绝对化的错误表述。

真正的红线只有一条：

> **样本/供体层的变异必须出现在模型里。用哪种机制是自由选择。**

| 途径 | 检验单位 | 代表 |
|---|---|---|
| 样本级 pseudobulk | 样本/供体 | muscat / dreamlet / limma-voom `duplicateCorrelation` |
| 混合模型 `(1\|sample)` | 细胞（带随机效应） | NEBULA（负二项 GLMM）/ MAST `glmer` |
| **RUV/SVA 估计因子当协变量** | 细胞 | 猴脑图谱 Cell 2026（PMID 42612631）：样本级 pseudobulk → edgeR 残差 → `RUVr(k=10)` 取前 5 因子 → 细胞级 `MAST::zlm(~ Age + subtype + W_1..W_5)`，**无随机效应项** |
| pseudobulk 残差/PC 当协变量 | 细胞 | 同上，其引用 |

该 Cell 论文的判据同时值得注意：`pctcut=0.1`（只在 >10% 细胞表达）→ 缩小 BH 家族；
判据 = `Q<0.05` 且 `|log2FC|>0.25`。**但注意**：这个 0.25 是在**细胞级 coef** 上设的，
搬到 pseudobulk 表上几乎恒真（pseudobulk 过 FDR 的基因 logFC 本就 >0.25），**不能直接搬**。

## 六、查出膨胀后怎么办（禁止只报"方法不行"）

1. **不许只给否定**：明确说清"哪个数不可用 + 为什么"，并给出**可执行的补救路径**。
2. **主分析退回已审查的方法**（本案例 = pseudobulk dreamlet 那套）。
3. **给细胞级结果加「供体级一致性」过滤**：要求基因在 **≥70% 供体**中同向变化才保留 ——
   能同时压掉方向偏倚与假阳性，剩下的是可信候选。
4. **或换 SE 正确的工具**：NEBULA（显式建模供体随机效应）。
5. **确认用户实际跑的版本**：若有 RE 版仍膨胀 → 该工具链 SE 不可信（见第三节）。
6. **把六问数字写进汇报**，让用户能自己复核，而不是只给结论。
