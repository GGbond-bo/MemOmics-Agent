# 链特异归属审计 —— 反义/重叠基因的表达量可信度核查（§十三 配套）

**触发**：合作方/审稿人质疑「某个基因的表达量到底可不可信」，且该基因与反义 lncRNA 或另一基因重叠。
真实案例：`MEF2C` ↔ `MEF2C-AS1`（GRCh38 / Gencode v32 primary assembly，审计图 `44d_MEF2C_AS1_audit_map`）。

> 结论一句话：**这个质疑的根本不在 GTF 注释位置，而在 read 归属；归属只能在 RNA 层查，ATAC 答不了。**

## 1. 为什么这件事只能落在 RNA 层

| 层面 | 归属单位 | 是否感知基因模型与链 |
|---|---|---|
| RNA-seq | read → 比对 → **链特异归属到基因模型** → UMI 计数 → 归一化 → coef/FDR | ✅ 是 |
| ATAC-seq | fragment → 基因组区间 / peak | ❌ 否（无「这条 read 算给 MEF2C 还是给 MEF2C-AS1」这一步）|

- 「RNA 就是表达量」没错 —— 但**表达量的上游正是归属**。质疑表达量可信 = 质疑归属，
  所以验证必须在 RNA 层做。
- 用 ATAC 去「验证表达量归属」= 用尺子量温度（ATAC 没有链感知的基因模型归属步骤）。
- 在 GTF 上核对注释位置只能证明「注释本身对不对」，不能证明「reads 落到了对的基因上」——
  两件事不可互相替代；用户问「他是不是想让我在真实数据上统计」时，方向对，但**层面要落在 RNA**。

## 2. 文献锚点（回答合作方时直接给 PMID，便于对方自查）

- **Zhao et al. 2015, BMC Genomics, PMID 26334759** —— 无链信息时，反向链重叠位点的基因
  表达量难以甚至无法准确定量；这正是链特异 RNA-seq（dUTP / Illumina strand-specific 建库）存在的理由。
- 用户要求：参数/机制类答复必须查证原文再下结论；引用要落到 PMID，不能只写\"有文献支持\"。

## 3. 验证配方（分级，成本从低到高）

**L1（默认，便宜，不用 BAM、不用 ATAC）**
- 输入：**pseudobulk counts + GTF**（本次 = Gencode v32 primary assembly；数据 = 已有骨骼肌 RNA 的 DEG 来源矩阵）。
- 动作：对重叠基因对（sense/antisense）逐 UMI/read 归属统计 —— 问题基因的 counts 里，
  有多少落在自己的链上、有多少可被反义转录本解释。
- 结论口径：给出「可归属比例」，而不是直接判「表达量是假的」。

**L2（只有 L1 存疑时才做，需要比对产物）**
- `featureCounts -s 1` vs `-s 0` vs `-s 2` 三态对比；或 HTSeq `-s yes/no/reverse` 对比。
- 需要 BAM / 链特异比对信息 → 成本高，先跑 L1 再决定。

## 5. 五层判据（逐层收窄可能的竞争窗口）—— 正面回答「如何区分 A 与 B 的 reads」

| 层 | 判据 | 把窗口缩到 | 靠什么实现 |
|---|---|---|---|
| ① | **链方向 strand** | 类别上分开 | read 带来源链；链特异定量只归给方向一致的基因，反义 read 不计入正链基因 |
| ② | **外显子 vs 内含子** | 只剩外显子重叠 | 标准计数按外显子；跨基因跨度里大部分是内含子，不进计数 |
| ③ | **UMI 锚点几何（3′ vs 5′）** | 3′ 建库下 ≈0 | 3′ 化学 UMI 锚在转录本 3′ 端；两基因 3′ 端相距很远且都不在共享区内 → 共享区内无 UMI 锚点。**5′ 建库逻辑反转**（两 5′ 端恰在共享区边界），此层失效 |
| ④ | **唯一外显子重定量** | 实证 | 剔除共享 exon，只用各自独有 exon 重算 + 重跑模型，看结论变不变 |
| ⑤ | **参数自检 + 结果独立性** | 自证 | RSeQC `infer_experiment.py` 验链特异真生效（比例≈0.5 = 没生效）；两基因 counts 是否同向同幅 |

**① 是决定性的那一层**；③ 依赖建库方式（必须先问清 3′ 还是 5′）。

### 5b. 实测坐标分解（MEF2C 位点，Gencode v32，可作模板）

| 项 | 值 |
|---|---|
| MEF2C | chr5:88,717,117–88,904,257（**负链**，protein_coding）|
| MEF2C-AS1 | chr5:88,883,328–89,466,398（**正链**，lncRNA）|
| 基因跨度重叠 | **20,930 bp** = 88,883,328–88,904,257 |
| 其中内含子 | 20,508 bp（不进计数）|
| **外显子重叠** | **仅 422 bp，3 段**（139 / 17 / 266 bp）＝ 跨度重叠的 **2.02%** |
| 两基因 3′ 端距离 | 749,281 bp（≈750 kb），**且都不在共享区内** |
| 共享区两端 | 左界 = MEF2C-AS1 的 5′ 端；右界 = MEF2C 的 5′ 端 |

⚠️ 命名纪律：这种「TSS 相隔 20.9 kb、各自朝中间转录」的构型**不要叫 head-to-head / 双向启动子**
（经典 head-to-head 是 TSS 紧邻、背向、共用双向启动子）。准确说法是**5′ 相对而向、两端各有一个启动子**。

### 5c. 结果独立性 —— 最有说服力的一条自证

- **counts 真的混了** → 两基因会同向、同幅变化（同一批 read 被计两次）
- **各自独立计数** → 一个升、一个平/降

实测：MEF2C-AS1 运动后多亚群显著上调（最大 coef 0.81，FDR≈0），MEF2C 在 5 对比 × 10 亚群全部不显著
（最大 |logFC| 0.45，最小 FDR 0.33）→ **一升一平 = 独立计数，没有交叉污染**。

## 6. 三个必须纠正的常见说法（不改口会被反驳）

1. **"在 ATAC 上统计两个基因的重合区变多变少"** —— ❌ 物理上只有一段 DNA，ATAC 不带链信息 → 只有一个数，
   不是一个基因一个数。**而且会退化成循环论证**：反义基因转录时 Pol II 占据该区、核小体被置换 →
   该处可及性本就升高，"A 上升"与"A 所在段可及性升高"是同一事件的两种读法，不是两个独立证据。
   正确说法：**"统计这个共享区间的可及性"**，且必须拆成两端 TSS 分别测。
2. **"可及性变多 → 基因被上调"** —— ❌ 可及性是转录的**必要不充分**条件（还看 Pol II 起始/暂停释放、
   延伸、RNA 稳定性）。实证反例：单细胞 multiome 观测到染色质与转录组的**时间性解耦**
   （DUET-seq, PMID 42801560）。结论上限只能是"该位点被重塑/更活跃"，不是"基因被上调"。
3. **预设变化方向** —— ❌ 不能假定"运动后必然变开放"。已发表人骨骼肌耐力训练 ATAC 是往**闭合**走
   （de Smalen 2025, Mol Metab, PMID 40623475，标题逐字："Endurance training promotes chromatin closure
   and timely repression of the post-exercise immediate early stress response"）。

## 7. 若真要做 ATAC 侧（把位点拆开测，不要整段平均）

```
① A 基因 TSS 窗口（TSS ± 2 kb）   → 变化 = A 侧调控活动
② B 基因 TSS 窗口（TSS ± 2 kb）   → ★ 只有这里变，才支持"刺激影响了 B"
③ 两 TSS 之间的共享区              → 找共享增强子 / 双向调控元件
④ 外显子重叠段（占比通常极小）      → 参考用
```

- 每样本每区间计片段 → CPM/FRiP 归一 → **同供体 Pre/Post 配对检验**（Wilcoxon / 配对 t）+ FDR
- **必须按供体配对**，不能把 Pre 组 / Post 组当独立样本比（个体差异会淹没信号）
- 判别：只有②变→支持假设｜只有①变→变化属另一侧基因，不能外推｜两端都变→共有调控｜都不变→该位点非响应
- 先确认**哪个 TSS 在目标组织里真用**（多转录本 / 多替代启动子时，gene 边界 ≠ 在用的启动子）：
  看 ATAC 峰落在哪、RNA 覆盖从哪起
- 区间内查 TF motif 可显著增强佐证

## 8. 需要向数据方确认的两项（不确认就做不实）

1. **建库化学：3′ 还是 5′**（决定第 ③ 层是否成立）
2. **定量时的链特异设置**：哪个工具、是否开了 strand/chain 参数、参照哪个注释版本
   —— **跨 GENCODE 版本的 count 不能直接比**（反义基因注释在版本间会变）

## 9. 边界

- 本 reference 只覆盖「归属 / 表达量可信度」这一类质疑。
- DEG 参数（FDR/logFC 阈值、样本不平衡、对比组设计）不在这里 —— 走本 skill §六/§八 与
  `deg-analysis` 的 Critical Pitfalls。
- **领域空白提醒**：MEF2C-AS1 的 PubMed 命中全部集中在肿瘤 ceRNA / 5q14.3 结构重排 / 血液肿瘤，
  **无任何骨骼肌或运动相关研究**。因此"AS1 变化 → sense 基因变化"在该组织**没有文献支撑**，
  属待验证假说（反义 lncRNA 常有自己的启动子、独立受调控）——须靠证据而非假定。
