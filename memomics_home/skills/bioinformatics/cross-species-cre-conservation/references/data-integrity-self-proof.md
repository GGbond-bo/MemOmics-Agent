# 数据真实性自证（data-integrity self-proof）

> 触发场景：用户质疑"**你是不是改了我的数据？这不是真实数据吧**"——常见于两版输入文件跑出不同结果、
> 或用户认为自己跑的版本才是"原始"、你的版本是"修复版"时。
> 2026-09-11 实测闭环（人猴海马跨物种可替代性专利）。

## 核心原则：不辩解，做复算；把验证权交给用户

辩解（"我没改"）零说服力。正确动作序列：

```
① 说清"手改"在物理上不可能   → 体量证据（448 MB / 567 万行）
② 给出生成脚本原文           → 零硬编码 = 纯计算，谁读谁信
③ 用用户的原始输入独立重算   → 逐位比对，报 max|Δ| 与机器精度同量级
④ 把命令交给用户自己跑       → 消除"仍需信任你输出"的最后一环
```

第 ④ 步最关键：**"我跑给你看"仍要求用户信任你的输出；"给你命令自己跑"才终结质疑。**

## ① 体量证据（30 秒可得，无需计算）

```bash
ls -la --time-style=full-iso <file>     # 大小 + mtime
md5sum <file>                            # 指纹
wc -l <file>                             # 行数
head -3 <file>                           # 首行（坐标体系、列名、数量级）
```

本次实测：`448 MB / 5,674,190 行`、`456 MB / 5,296,656 行`——**逐 tile 生成的百万行级产物不存在手工修改的空间**。

## ② 生成脚本原文 = 最便宜的"非篡改"证据

读脚本并检查三件事：
1. **有没有硬编码数值**（本次 `compute_monkey_continuous_age_r.R` 全文 1.6 KB，零硬编码）
2. **是不是纯公式**（本次就是标准 Pearson：`r = num / sqrt(ss_age * ss_col)`）
3. **输入从哪来**（本次读 `E:/专利/file/*`，而导出脚本 `export_monkey_tile_matrix_continuous.R` 里
   `out_dir = /hwfssz3/PS_JLU/zhangxiao6/export_continuous` → **集群路径，用户自己跑的，非本地生成**）

## ③ 独立重算 + 逐位比对（决定性动作）

用**用户提供的原始输入**重跑推导公式，再与磁盘上那份文件逐位对：

```r
.libPaths(c("E:/R-libs/R-4.5.3", .libPaths()))
suppressMessages({library(Matrix); library(data.table)})
M <- readRDS("<用户下载的原始矩阵>.rds")
# ...按生成脚本的核心公式重算...
valid <- !is.na(r)
mine <- data.table(chr=coords$seqnames[valid], start=coords$start[valid],
                   end=coords$end[valid], r=round(r[valid], 6))
orig <- fread("<磁盘上那份产物>.csv", select=c("chr","start","end","r"))
m  <- merge(orig, mine, by=c("chr","start","end"), suffixes=c(".orig",".recalc"))
dd <- abs(m$r.orig - m$r.recalc)
cat("合并行数 =", nrow(m), "/", nrow(orig), "\n")
cat("max|Δ| =", max(dd), "| 不一致个数 =", sum(dd>0), "\n")
```

**判读标准**：

| max\|Δ\| | 结论 |
|---|---|
| ≤ 1e-15（double eps≈2.2e-16 量级）| **逐位一致 = 纯计算结果，无人工修改**；少量"不一致"只是 `round(x,6)` 边界舍入 |
| ~1e-3 以上 | 存在舍入口径差（换过精度/排序）→ 需解释 |
| 数量级差异 | 确实是另一份数据 → 走 §两版差异归因 |

本次实测：**合并 5,674,190 行 100% 覆盖、max|Δr| = 1.11e-16**（机器精度）、耗时 44 秒。

## ④ 交给用户的验证命令（收尾）

把 §③ 的脚本路径 + 输入路径 + 期望输出写进回复，让用户自己跑一遍得同样结果。
同时给出 md5 供比对：

```

产物  monkey_ageDA_continuous.csv              448.0 MB  2026-09-04 01:05
md5   32cb7360bdca94807ca0f3df52935747
```

**时间链自洽**也是硬证据：脚本 mtime `01:03:44` → 产物 mtime `01:05:25`（晚 2 分钟）。

## §两版差异归因：先分层，再下结论

两版输入跑出不同数字时，**差异必然落在下面三层之一**，逐层排查，不要跳到结论：

| 层 | 现象 | 归因 |
|---|---|---|
| **坐标层** | 仅坐标标签平移，r/p 值**不变** | 1-based / 0-based 写法 |
| **管线层** | r/p 值大面积不同 | 聚合方式、**数值变换（log2(CPM+1) vs 原始比例）**、过滤阈值 |
| **实现层** | 实体数差几个（<1%） | 锚定/桥接算法实现细节 |

**判别铁律：坐标体系差异只移动坐标标签，不会改变统计值。** r 值大面积不同（corr≈0.89、tile 数差 37 万）
⇒ 一定是**管线层**，与坐标无关。

### 本次两版实测（管线层差异全表）

| 环节 | all 版 | continuous 版 |
|---|---|---|
| 聚合 | `getGroupSE(scaleTo=NULL)` 原始 counts **求和** | 每样本**平均可及性**（0~1 比例）|
| tile 过滤 | `rowSums(cnt) >= 2*ncol(cnt)`（≥40 counts）| 仅去零方差 |
| **数值变换** | **`log2(CPM + 1)`**（RNA 口径）| **无变换**（原始比例）|
| 坐标 | `(idx−1)*500+1`（1-based）| ArchR 原始（0-based）|
| tile 数 | 5,296,656 | 5,674,190 |

方法学取捨：TileMatrix 是二值化的（每细胞 0/1），tile counts 本质是"细胞数"而非测序 reads 数——
`log2(CPM+1)` 是为深度 counts 设计的，套在 tile 上属口径错配；**"每样本开放细胞比例"更贴合 ATAC 语义**。

## ⚠️ "修复版"标签可能被贴反：先查谁真的就地改写了文件

用户可能把**自己跑的那版**当"原始"、把你的当"修复版"。**查脚本头部的自述**：

- 本次 **all 版才是被就地修改的**：`fix_ageDA_coords.R` 头部写"6 个文件坐标已就地修正"，
  用 `fwrite(d, f)` **直接改写 6 个 CSV**（虽声明 r/p/q 列不动）。
- **continuous 版是全新计算的新文件**，全程无"修改已有文件"这个动作。

判据：找 `fwrite(...)` / `write.csv(...)` 的**目标是否为输入文件本身**（就地改写）vs **新文件名**。

## 交付要求：把口径锁死到文件级（回应"别人无法复现"）

选哪个版本**不能解决**"无法复现"——机制上要写死：

1. 输入文件**绝对路径 + md5**
2. **集群侧导出脚本**（含 `out_dir`，证明数据从哪来）
3. **本地计算脚本**（公式、n、是否变换、过滤阈值）
4. 期望输出：行数 + 关键统计量

这样任何人拿到 ArchR project 都能跑出**同一个文件**（md5 相同），复现才算立住。
