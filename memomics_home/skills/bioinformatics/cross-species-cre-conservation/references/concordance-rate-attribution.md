> 一句话答案：**主因不是猴侧数据差，而是元件网格未对齐（方法缺陷，占 5–6pp）；其次是大样本侧全局漂移污染了强度筛选；参考侧 n=20 排第三。真实一致性未知 —— 当前 40% 是"方法噪声 + 生物学解耦"的混合物。**

>
> 🔁 **后继扩展（2026-09-13）→ `references/layered-concordance-diagnostics.md`**：

## 1. 探针 0 —— 基准不是 50%，而是"边际保持的独立配对期望"

```python
import numpy as np, pandas as pd
df = pd.read_csv("E:/专利/M2/pipeline_out_all/v5_substitutability_all.csv")
Zh, Zm, Pm = df.Z_human.values, df.Z_monkey.values, df.p_monkey.values
m = (np.abs(Zh) >= 12) & (Pm < 0.05)          # n = 890
sh, sm = np.sign(Zh[m]), np.sign(Zm[m])

ph = (sh > 0).mean(); pm = (sm > 0).mean()
base = ph*pm + (1-ph)*(1-pm)                    # 独立配对期望同向率
```

实测：

| 量 | 值 |
|---|---|
| 人侧 Z>0 占比（890 子集） | **0.583** |
| 猴侧 Z>0 占比（890 子集） | **0.542** |
| **独立配对期望同向率** | **0.507** ← 真实基准 |
| 硬抛硬币基准 | 0.500 |
| 观测同向率 | **0.4011** |
| 差 | **−10.6 pp** |
| 置换 null（N=20000，打乱 Z_m 符号） | 451.2 ± 14.6 |
| 置换 z | **−6.44** |
| p（单侧富集） | **1.0000** |

**关键**：边际偏斜本身就值 0.7pp。**必须报"低于独立配对基准 10.6pp"，不能报"低于随机 10 个百分点"**。
"随机更高"的正确表述 = **观测低于独立配对基准**（即同向比随机配对还少），而非"随机异常高"。

**置换实现注意**：打乱 Z_m 的**符号**（保 |Z_m|、保 p_m、只破方向配对）——这是"配对是否携带信息"的正确零假设；打乱 ortholog 配对是另一个问题（见 SKILL.md 检验二）。

## 2. 探针 1 —— 元件网格是否对齐（最大单一杠杆）

```python
same = nth == ntm                              # n_tiles_h == n_tiles_m
for lo in [1, 5, 10, 20, 30]:
    s = same & (nth >= lo); d = (~same) & (nth >= lo) & (ntm >= lo)
    cs = (np.sign(Zh[s]) == np.sign(Zm[s])).mean()
    cd = (np.sign(Zh[d]) == np.sign(Zm[d])).mean()
    print(lo, s.sum(), round(cs,4), d.sum(), round(cd,4), round(cs-cd,4))
```

实测：

| tile 数下限 | 同源网格 n / 同向率 | 异源网格 n / 同向率 | 差 |
|---|---|---|---|
| ≥1 | 1,544 (9.6%) / **0.5052** | 14,466 / **0.4596** | +0.0456 |
| ≥5 | 1,519 / 0.5069 | 14,054 / 0.4588 | +0.0481 |
| ≥10 | 1,410 / 0.5085 | 13,349 / 0.4583 | +0.0502 |
| ≥20 | 881 / 0.5165 | 11,387 / 0.4567 | +0.0598 |
| ≥30 | 617 / **0.5186** | 9,758 / **0.4544** | **+0.0642** |

**读法**：网格一致（两物种用同一批物理区域）时同向率回到基准 51–52%（=方向无关系）；网格不一致（各自 liftOver 重建）时掉到 45–46%。**⇒ 至少 5–6pp 的"不一致"来自在比不同的基因组区域，属方法缺陷，不是生物学。**

**推广判据**：任何跨物种元件级方向比较，先按"两侧网格是否同源"分层。若同源组回到基准、异源组显著低 ⇒ 报"主因是网格对齐，非生物学"。

**辅助观察（非独立证据，勿单用）**：`n_tiles_h ∈ [0,5)` 同向 0.5207 → `[40,∞)` 0.4551（tile 越多同向率越低）；`corr(tile 比 ntm/nth, 同向) = +0.0073 (p=0.354)` 不显著。前者可能受"多 tile 基因 = 长基因/复杂位点"混杂，只作旁证。

## 3. 探针 2 —— 排除"功效不足"解释

按 |Z_m| 四分位分层：

| |Z_m| 分位 | 同向率 | n |
|---|---|---|
| Q1（弱） | 0.4350 | 223 |
| Q2 | 0.3829 | 222 |
| Q3 | 0.4054 | 222 |
| Q4（强） | 0.3812 | 223 |

**几乎不动（甚至 Q4 最低）** ⇒ **不是"样本不够/功效不足"**。若纯为功效问题，同向率应随 |Z_m| 单调上升。

⚠️ **反例警示（易混）**：不要用"猴侧显著率随覆盖度单调上升（33.9%→67.1%）"当功效证据——那条链证明的是 **p<0.05 是检验力而非方向信号**（语义相反，见 SKILL.md 检验四）。

## 4. 探针 3 —— 大样本侧全局方向漂移

| 量 | 人侧 | 猴侧 |
|---|---|---|
| mean(Z) | **+1.2454** | +0.0925 |
| median(Z) | **+1.0631** | +0.0723 |
| skew | +0.169 | −0.207 |
| \|Z\| 中位 | 3.360 | 1.859 |
| Z>0 占比（全 16,010） | **0.5934** | 0.5102 |
| p<0.05 占比 | **0.677** | 0.478 |

**无信号 Z 分布应以 0 为中心**。人侧中位 +1.06 ⇒ **全局性方向偏移**（归一化 / 深度 / 批次），于是 `|Z₁| ≥ 12` 的 1,404 个基因有相当部分是被全局漂移推上去的，**不是实体特异衰老信号**。拿这批去问"参考侧是否同向"，问的其实是**两套漂移是否对得上**。

**判据**：任一侧 `|median(Z)| > 0.3` ⇒ 漂移信号，须先中位数/分位数居中再谈富集。
**新增检查**：`mean(Z_human) = +1.25` 同时也提示"Z 分布不是零中心的检验统计量" —— 送检前应确认 Z 的构造（`sign(r)·Φ⁻¹(1−p/2)` 在无信号时应中心为 0）。

## 5. 探针 4 —— τ_A 敏感性扫描（回应"为什么非得是 12"）

```python
for tau in [1.96,2,3,4,5,6,8,10,12,15,20,30]:
    A = np.abs(Zh) >= tau; B = A & (Pm < 0.05)
    c = (np.sign(Zh[B]) == np.sign(Zm[B]))
    phc = (np.sign(Zh[B])>0).mean(); pmc = (np.sign(Zm[B])>0).mean()
    base = phc*pmc + (1-phc)*(1-pmc)
    print(tau, A.sum(), B.sum(), c.sum(), round(c.mean(),4), round(base,4), round(c.mean()-base,4))
```

**结论**：**从 1.96 到 20 的每一档都低于基准**；只有 τ=30（n=47，样本过小）翻正。
⇒ **不是 τ_A=12 选得不好，而是该统计量在任何切割下都不支持"同向保守"。**
⇒ τ_A=12 的真实身份 = **规模门槛**（把清单压到几百个），1.96 才是显著性门槛。**12.3× 富集的落脚点正是这个可自由选择的规模门槛** ⇒ 同时中"循环论证"与"阈值自由度"两枪。
⇒ 副产物：**"专利式富集"（n_conc/(n_strong×0.05)）随 τ 从 4.31 单调升到 7.43，与 12.3× 不在同一量纲** —— 说明该指标对阈值的选择极端敏感，不能作为技术效果断言。

## 6. 归因结论模板（四句话，可直接交付）

1. **主因是元件网格未对齐** —— 占 5–6pp，属方法缺陷（同源 51.9% vs 异源 45.4%，tile≥30）。
2. **次因是大样本侧全局漂移** —— 人侧 median Z = +1.06（应≈0），强效应池被漂移污染，筛出来的"强"不等于"实体特异"。
3. **参考侧 n=20 给不出可靠方向** —— 趋势存在，但 corr(age, coverage) = −0.32、**p=0.175 不显著**，**不得声称已证实混杂**；只能说"最老样本恰好覆盖度最低（V5=29岁60.6%、V6=31岁69.7%、V4=31岁70.9%），且删掉它们即翻正"。
4. **真实一致性未知** —— 当前 40% 是"方法噪声 + 生物学解耦"的混合物，做完 ①②③ 才知道真实值，**不可当生物学结论直接使用**。

## 7. "更好的算法"六条（按回报排序）

| # | 改法 | 针对 | 回报 |
|---|---|---|---|
| 1 | **统一元件网格**（两侧 liftOver 到同一坐标系 / 只用双向可映射 orthologous tile） | 网格未对齐（−5~6pp） | **最高** |
| 2 | **深度校正**（零膨胀/深度校正模型，如 PACS） | 覆盖度混杂 | 高 |
| 3 | **消除全局漂移**（中位数/分位数居中；median Z = +1.06 必须归零） | 全局漂移 | 高 |
| 4 | **收缩估计替代极端阈值**（经验贝叶斯 / limma-voom 型 shrinkage，弃用 \|Z\|≥12） | 阈值自由度 + 循环论证 | 高 |
| 5 | **换统计单元**（tile → 调控域/基因体聚合，或上提到细胞类型层） | 信噪比 | 中高 |
| 6 | **跨物种正交投影**（SATURN / scGPT 类共享潜空间） | 物种特异技术噪声 | 中 |

**①+②+③ 必做**——它们不改结论方向，作用是把技术噪声从生物学解耦里剥离。

### 8.4 由文献得出的整体判断（结论句，可写进毕业论文）

> 跨物种衰老的"保守 vs 发散"**高度依赖层级与粒度**：表达层 + 多物种 + 大样本 → 保守（Tyshkovskiy 2026、Takasugi 2023）；染色质层 + 双物种 + 小样本 → 发散（Wennmalm 2005、Beilina 2026、Hwang 2026、本研究）。
> **我们的 40% 落在这个谱系的"发散端"——但方法缺陷（网格未对齐 + 全局漂移）让它比真实值还要低。**
