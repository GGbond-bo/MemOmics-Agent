## 0. 一句话结论

**用户不是反对「质控」，是反对「你替我下判断，却给不出出处」。**
自造阈值的三条死路：① 改了结果却不在 methods 里（筛除型）；② 不改结果却改了交付语义
（`qc_flag=SUSPECT` 等于宣判结果有误）；③ 把文件搬走本身就是一种结论。

## 2. 四个被否决的参数（逐个拆解）

| 参数 | 值 | 机制 | 改结果？ | 危险等级 |
|---|---|---|---|---|
| `COR_CUT` | 0.70 | RUVr 出 k 个 W 因子后，丢掉 `\|cor(W_i, stim)\| ≥ 0.7` 的因子 | ✅ **会改**（少几个协变量，模型变了） | **高**：等于悄悄改模型 |
| `SIG_CUT` | 0.30 | FDR<0.05 占全部检验行 >30% → 判可疑 | ❌ | **中**：只加一列，但那列是价值判断 |
| `ONEDIR_CUT` | 0.95 | 显著基因单向占比 >95% 且 sig>100 → 判可疑 | ❌ | **中**：同上 |
| `QUARANTINE` | TRUE | 可疑表移入 `quarantine/` 子目录 | ❌ | **中**：用户找不到文件 + 搬运即结论 |

**关键澄清（用户认可的表述）**：
> 这套东西的作用是**证明结果没坏**，不是**把坏数据修好**。
> Aging 的批次混杂、用药与分组共线是**设计层**的问题，任何后处理都救不了。

**唯一有文献依据、被保留的那一个**：`USE_CDR`（= log10(每细胞检出基因数+1) 作协变量）。
MAST 原文 Finak et al. 2015 *Genome Biology*（PMID 26653891）即建议用 cellular detection rate
作为协变量 —— 有出处的可以留，没出处的（本章上表 4 个）不能留。

## 3. 猴脑参考实现逐行对照（用户提供的原码）

**它有的**（这些才是「参考实现口径」）：

| 行 | 内容 | 作用 |
|---|---|---|
| `nruv = 10; uruv = 5` | 估 10 个 W，**只把前 5 个**放进模型 | **固定常数的因子取舍**，不是自动阈值 |
| `uqobs$Age <- NULL` | 合并 W 前先把 Age 从协变量里拿掉 | 避免与被检验变量重复（列名冲突） |
| `pcut = 0.1` | 基因需在 >10% 细胞中检出 | 表达频率过滤 |
| `sample_counts >= 10` | 样本进入分析的最小细胞数 | 样本级下限 |
| `if (file.exists(path_name)) next` | 断点续跑 | 工程便利 |
| `fulldf = fulldf[!is.na(fulldf$coef),]` | 剔掉 NA coef | 唯一的结果行过滤 |

**它没有的**（我加的全部）：

- ❌ 任何 `cor(W, 协变量)` 相关性筛选
- ❌ 任何显著率 / 单向占比阈值
- ❌ 任何 `qc_flag` / `SUSPECT` 标记列
- ❌ 任何 `quarantine/` 隔离目录
- ✅ 直接 `write.csv(fulldf, file = path_name)` 收工

**为什么它不需要**：它的「防 RUV 过度校正」靠的是**固定 k=5 这个人工决定**（先验验证过再加因子没收益），
不是靠运行时阈值。**人先想清楚，然后 85 次批跑不再动摇** —— 这才是官方范式。

## 4. 与参考实现**仍存**的 3 项方法学差异（比标记列重要得多）

删掉自造阈值 ≠ 与参考实现等价。这三项必须交给用户拍板，不能悄悄按自己的来：

| 项 | 参考实现（猴脑） | 我的 v7 | 后果 |
|---|---|---|---|
| **W 因子数** | `nruv=10` 估、`uruv=5` **固定入模** | `k = min(10, max(2, floor(df_resid/3)))`，全部入模 | 我的每组 k 在 2–10 浮动、**逐组不一致**；要可比须固定 5 |
| **p 值来源** | `summary(zlm.obj, doLRT = pathstr)` → `component=='H'` 的 `Pr(>Chisq)`（**Hurdle LRT**）+ `component=='logFC'` 的 coef | **Wald z**（分量 C，退化才用 D） | **两种检验给出不同基因列表**，影响远大于任何标记列 |
| **协变量** | `~ Age + subtype_new + W_1..W_5`（Age 为数值化年龄） | `~ stim + W_1..W_k + cdr [+ batch] [+ (1\|individual)]`（stim 为 0/1） | 连续年龄建模 vs 二分组；它多一个 `subtype_new` |

**⚠️ 参考实现自身的可疑写法（提醒用户核实，不替他担保）**：

```r
RUVr(round(d_e$counts), as.character(rownames(d_e$counts)), k = nruv, res1)
```

按 `RUVSeq::RUVr(x, k, residuals, center = TRUE, ...)` 签名，`k` 已用命名参数匹配后，
第 2 个位置参数会落到 `residuals`、第 3 个落到 `center`。
**建议用户先跑 `Rscript -e 'args(RUVSeq::RUVr)'` 核一眼再决定是否照抄** ——
「参考实现」不等于「无 bug」，但**指出它的问题不能用来替自己的发明开脱**。

## 5. 手术式删除配方（可复用）

删 4 个参数会牵动散落多处的列/目录/变量，逐个人工 patch 极易留下悬空引用。
用**一次变换 + 每条断言唯一命中 + 禁用词残留扫描 + 语法校验**：

```python
# 1) 每处替换前断言「恰好命中一次」，多命中/少命中一律 FATAL 退出
for i, (old, new) in enumerate(REPL, 1):
    n = s.count(old)
    if n != 1:
        print("FATAL: 替换块 %d 命中 %d 次（应为 1）" % (i, n)); sys.exit(1)
    s = s.replace(old, new)

# 2) 写出后扫禁用词 —— 常量名 + 它派生的列/目录/中间变量都要在清单里
BAN = ["COR_CUT","SIG_CUT","ONEDIR_CUT","QUARANTINE","suspect","qc_flag","w_dropped",
       "qdir","up_frac","sig_rate","SUSPECT","Wdiag","r_bio","r_tech","keep_w",
       "dropped","ncnt_smp"]
left = [(t, ln, line) for t in BAN for ln, line in enumerate(s.splitlines(), 1) if t in line]
assert not left, left          # 有残留就打印 (token, 行号, 行内容) 定位
```

```bash
# 3) 静态语法校验：只 parse 不执行，不读大数据对象（本项目 rds 794 MB）
Rscript -e 'e <- parse("script_v7.R"); cat("PARSE_OK 表达式数=", length(e), "\n")'
```

**本次实测**：5 处替换 → 17 个禁用词零残留 → `PARSE_OK 表达式数= 73`，
文件 30154 字节 / 599 行（原 v6 为 32117 字节 / 631 行）。

**踩过的检索坑**：把**文件路径**直接传给按目录检索的工具会返回 0 命中，
误判成「文件不存在」。先用 `files` 型检索 / `ls` 确认文件在盘上，再 `grep -n` 定位行号。
