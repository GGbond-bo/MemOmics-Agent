# 效应量变换分层 + 冗余参数预注册（专利 claim 里的统计纪律）

> 来源：2026-09-13 跨物种衰老可替代性专利（memomics-7839e23a）。用户以**领域统计专家**身份给出四点评审意见，
> 其中两点击中要害：① claim 里三个统计量被混用；② 校正实验的结论会被冗余参数（ρ）的估计方式预决定。
> 本文件是这两条的可执行配方。与 `z-statistic-and-conditional-null-audit.md` 互补：
> 那份管「零假设口径与 z 的复现」，本份管「**变换层与聚合层的归属，以及跑之前的预注册**」。

## §1 🔴 三个量别混：先定"单元统计量是什么"，再谈改哪个

claim 里出现的三个量**输入不同、层次不同、不能互换**：

| 量 | 输入 | 性质 | 适用条件 |
|---|---|---|---|
| **Fisher-Z 变换** | **相关系数 r** | 效应量方差稳定变换 `atanh(r)·√(n−3)`，SE `=1/√(n−3)` | ✅ 单元统计量**是相关性**时直接可用 |
| **p 反推 z** | **p 值** | `sign(r)·Φ⁻¹(1−p/2)`，p 机器零时**饱和** | 单元统计量是 p 值时可用，但**该换的不是 Fisher-Z** |
| **Stouffer 合并** | **各单元 z 分数** | `Σzᵢ/√n` | 聚合层标准做法 |
| **Stouffer + 有效自由度** | 各单元 z 分数 + ρ | `Σzᵢ/√(n(1+(n−1)ρ))` | 单元间**存在自相关**时的正确聚合 |

### 1.1 判定程序（做任何"改公式"动作之前必走）

**第一步不是讨论公式，是去磁盘确认锚定单元的统计量到底是什么。**

```
单元统计量是「相关系数 r」  → 分支①：Fisher-Z 适用，可引用已授权专利背书
单元统计量是「回归 t/z」    → 分支②：Fisher-Z 根本不适用
                             正确解法 = p 在机器零处截断/转对数域，
                             或直接用效应量 + 标准误的逆方差加权
```

**本案实证（分支①）**：

| 证据源 | 原文 |
|---|---|
| `claims.md` 权 2 | "……进行 **Pearson 相关分析**，得到相关系数 r 与双侧显著性 p" |
| `06_repro_full_pipeline.py` L219 | `Zs.append(np.sign(r) * norm_ppf(1 - p / 2.0))`；`p = max(p, 1e-300)` |

⇒ 单元统计量 = Pearson r ⇒ **Fisher-Z 适用**（分支①）。分支②不适用本案。

### 1.2 "p 机器零饱和"要**实测**，不要当理论担忧说

| 指标 | 实测（`M2_repro_gene_conservation_all.csv`，16,029 基因） |
|---|---|
| 人侧基因级 p 落机器 eps（<1e-15） | **19.07%**（近 1/5） |
| 猴侧 | 2.10% |
| 脚本对饱和的处理 | `p = max(p, 1e-300)` —— 只防下溢，**不恢复信息** |

⇒ 人侧 1/5 的单元其 p 已无分辨率，`Φ⁻¹(1−p/2)` 在这些单元上完全由机器精度决定。
**`atanh(r)` 不依赖 p 分辨率** —— 这是 Fisher-Z 在本案的实质价值（不是"更时髦"）。

### 1.3 Fisher-Z 落地参数（写死进从属权）

| 参数 | 值 | 说明 |
|---|---|---|
| 单元 z | `atanh(rᵢ)·√(n_donor − 3)` | n 是**供体数**，不是 tile 数 |
| 本案 n_donor | 人 40 → √37=6.08；猴 20 → √17=4.12 | 两侧均满足 n≥4 |
| 边界 | `|r|` winsorize 至 **0.999**（atanh 上限 3.80） | 防 atanh 发散 |

### 1.4 🚫 命名纪律（写进权项前必查）

- `ΣZᵢ/√n` **本身就是 Stouffer 合并** —— 不要称它"Fisher-Z"。
- 有效自由度修正是**聚合方差层**的事 ⇒ 准确命名 **"Stouffer + 有效自由度"**。
- ⛔ **不要把"Fisher-Z"与"n_eff 校正"并列写成一条从属权**（如"权 2 增加 Fisher-Z 变体"）——
  两者层次不同，混写等于在权项里写一个统计上不成立的表述。
- ✅ 正确做法：**拆成两条独立从属权**
  - `权 2a`：单元层 Fisher-Z 变换（n = 供体数，|r| winsorize）
  - `权 2b`：聚合方差层 Stouffer + 有效自由度（ρ 估计法写明）

## §2 🔴 冗余参数预注册：跑校正实验之前必须冻结

**为什么必须冻结**：`n_eff = n/(1+(n−1)ρ)` 对 ρ 极敏感 ——
ρ 小 → n_eff≈n → **什么都不变 → 新定位失败**；ρ 大 → 大变。
而 ρ 从空间自相关估计，**估计方法本身是可调的自由度** ⇒ 存在"调到能通过"的嫌疑。
这正是审查员（以及日后无效宣告里的对方）最会咬的地方。

### 2.1 冻结口径（预注册，跑前写死）

| 路 | 方法 | 参数 | 地位 |
|---|---|---|---|
| **路 A** | **变异函数核**：按染色体排序 tile，算 lag-k 相邻 tile 的 \|Z\| 序列相关，拟合指数模型 `ρ(d)=exp(−d/λ)` | **无自由参数**（λ 由数据拟合决定，不由人选） | 🔴 **主口径来源** |
| **路 B** | **空间块置换**：块大小 B ∈ {1kb, 5kb, 25kb, 100kb} | 四档 | 敏感性分析（**全报**） |

⛔ **禁止**：跑完后换块大小、换 λ、换阈值、换主口径；只报最好的一档而隐去其余三档。

> ⚠️ **本次 Agent 自犯并自纠**：草案里预设了 `B=5kb` 当主口径，被 L1 辩论裁决否掉
> （"5kb 需独立依据，若无依据主口径应待定"）⇒ 撤销，主口径改由路 A 的 λ 决定（数据决定，零人工自由度）。
> **教训：主口径不该由 agent 挑一个数。**物理锚点（如"5kb ≈ 典型基因窗口 ±2kb 的跨度"）
> 只能用于**事后合理性检查**（λ 落在 [1kb,25kb] 之外须说明原因），不得当主口径依据。

### 2.2 必须同时报"影响量"，不只报一个数

报 **n_eff 对最终指标的影响曲线**（ρ 从 0→1 连续变化时，目标指标随 n_eff 的响应曲线 + 与 50% 基准的交点），
而不是只给校正后的单一数字 —— 单一数字无法区分"校正有效"与"ρ 调到刚好"。

### 2.3 阳性 / 阴性对照三件（缺一不可）

| 对照 | 设计 | 预期 | 作用 |
|---|---|---|---|
| 阳性 1 | **同物种拆分半样本**（如人 40 例随机拆 20/20，各自算效应量再比方向一致率） | **≥65%** | 证明流水线能找回"已知应同向"的方向 |
| 阳性 2 | 同侧 bootstrap 重采样 1000 次 | 分布集中 ≥65% | 排除单次拆分偶然 |
| 阴性 | 年龄标签置换 | **50% ± 2%** | 验证零假设基准正确 |

🔴 **判据**：阳性对照未达 ≥65% ⇒ **流水线本身失能，校正实验结果无解释力，不得用于改写权项**。

### 2.4 报告口径

- 方向一致率报**分位数/分布**（P10/P25/P50/P75/P90 + 分布图），**不用单一均值**。
- 均值异常先查**是否被少数超大元件驱动**：看去掉 top 1% 大 n 元件后倍数是否仍 >2；
  否则披露"该均值由少数超大元件驱动"。

## §3 定位改写的取舍：命题换、技术效果不换

改定位 = **拿新颖性换安全性**，但别把商业价值一起换掉：

| 写法 | 后果 |
|---|---|
| 只写"偏置校正手段" | ❌ 保护范围缩水成"一个统计校正方法"——换一种校正即设计绕过 |
| 命题 = 偏置校正；**技术效果 = 输出可替代性判定** | ✅ 既挡 A25（有技术手段），又保住应用层保护范围 |

⇒ **独权必须同时含"校正手段"与"输出判定"两个限定**，技术效果作为**用途限定留在独权里**，不降级为应用场景。

### 3.1 改定位后必须补的创造性论证（否则审查员走 D1+D2 显而易见组合）

光在差异表里"罗列"差异不够，必须写出**为什么组合不显然**。四点抗辩链模板：

| # | 抗辩点 |
|---|---|
| ① | **手段维度不同**：D2 按序列替换率的**基因组位置维度**校正 vs 本案按锚定单元数的**数据结构维度**校正 —— 校正量纲与数据来源都不同 |
| ② | **D2 完全不碰空间结构**：本案 n_eff 所依赖的 ρ（空间自相关）在 D2 体系中无对应物 |
| ③ | **D1 的对齐 ≠ 统一网格**：D1 是坐标迁移、判定单元是"重叠比例"、**不含效应量**；本案是在异构参考基因组上建统一编号网格后逐单元算效应量 |
| ④ | **组合无技术启示**：D1/D2 的技术问题都不是本案的技术问题，二者**均未识别**本案的现象 ⇒ 本领域技术人员无动机组合 |

并写死三点（缺一不可）：`① 统一同源网格下的按粒度分层`、`② 有效自由度对空间自相关的校正`、`③ 主-参考非对称方向门控`。

## §4 外部专家评审意见的吸收规程

用户（或其请的评审人）以**领域专家/审查员**身份给出逐条评审意见时，回应形态固定：

1. **逐条判定表**（意见 → 判定 → 落地位置），**不要写成散文式感谢+复述**。
2. **每条判定先做实证闭合**：能当场用磁盘证据判定的（如"单元统计量到底是什么"），
   **先去读文件确认再表态** —— 不要凭印象说"接受"或"这条不适用"。
   本次即：审查员的"分支框架"正确，但本案落哪一支必须查 `claims.md` + 脚本才能定。
3. **产出新版本草案文件**（v18→v19），**⛔ 不覆盖旧版本**（保留便于对照）。
4. **裁决可以否掉自己草案里的预设** —— 本次 L1 辩论否掉了 agent 自己写的 `B=5kb` 主口径；
   处置 = 接受并在文件中**显式写"撤销"**，不要悄悄改掉。
5. 剩余项**分两类**：可当场自补的立刻补；超出 agent 职责的转成"**送代理前待办**"，
   ⛔ 不要为"让评审好看"把法律/程序判断自己写进交底书。
