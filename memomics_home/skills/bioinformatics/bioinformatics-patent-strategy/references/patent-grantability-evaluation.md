# 专利授权前景评估 + 答辩准备（评委/答辩委员会视角）

用户说"你作为专利评委老师，这个专利怎么样？能通过吗？作为毕业课题可以吗？"时启用。
这是**第三类专利任务**，区别于另外两类：
- `patent-analysis` = 拆解**别人**的专利（竞品规避）
- `bioinformatics-patent-strategy` 撰写部分 = **写**自己的交底书/权利要求
- **本文件 = 评估自己的专利能否授权 + 准备答辩**（授权前景预判 + 答辩金句）

## 核心原则：评委先验数据，再听故事

评估的第一动作不是读故事，是**复现代码逐项核对数字**。先跑复现脚本，把每个声称的数字（候选数/核心元件数/漏检率/富集倍数/整体相关）对一遍，全部吻合才开口评"能通过吗"。数据真实 = 答辩底气；数字对不上 = 一票否决。

## 五维授权前景判定表（交付骨架）

每一维给出「判断 + 通过概率 + 关键风险」三栏：

| 维度 | 法律 | 判断要点 |
|------|------|---------|
| 新颖性 | A22.2 | 现有技术是否已教导"核心技术组件"（注意：要分辨 News&Views 作者 ≠ 原始研究作者） |
| 创造性 | A22.3 | **核心战场**。靠"问题→方案→可量化效果"闭环 + 对比实验硬扛，不是靠"无教导"一句话 |
| 客体 | A2/25条 | 动词链落脚"输出清单/装置/介质"，是否脱敏纯算法 |
| 清楚性 | A26.4 | 概念口径是否焊死（如"元件 vs 基因"三阶映射） |
| 充分公开 | A26.3 | 数据可复现、代码可跑、实施例能否支撑技术效果 |

最后给一句总评：能过概率约几成，卡不卡在创造性这一关，作为毕业课题够不够格。

## 三个最尖锐问题 + 答辩金句（核心交付物）

交付必须包含**答辩委员会一定会问的 3 个最尖锐问题**，每个配一条能背的防守金句。这是评估区别于"撰写"的独特价值——不是帮用户写专利，是帮用户**预演被拷问**。

### 通用提问套路（按此生成）

1. **小样本侧测不准，凭什么拿它当硬门槛？**（"你一边说猴侧测不准只能做方向参考，一边又用猴侧 p<0.05 当核心元件门槛，矛盾"）
2. **核心公式是不是换了个写法？**（"S=Z₁×w(Z₂) 是不是 min(|Z₁|,|Z₂|) 换个马甲？"）
3. **创造性到底在哪？**（"不对称评分在 meta-analysis 的 primary/replication 设计里是公知常识"）

### 关键答辩金句：整体测不准 ≠ 逐元件 p 值无信息

这是跨物种小样本场景最致命问题的唯一站得住的防守，务必写进答辩稿：

> 参考物种"整体"年龄效应测不准（如整体富集 1.17×、p=0.267），不等于"逐元件" p 值无信息。
> 整体富集说的是"猴侧年龄效应总体弱于随机波动"，但逐元件 p 值仍能区分"方向可信 vs 方向不可信"。
> 铁证 = 富集倍数：在"主体侧强效应 + 同向"的 537 个子集里，参考侧 p<0.05 的命中率高达 336/537 = **62.6%**，
> 远超随机基线 5%。若参考侧 p 值纯是噪声，这个数应掉回 5%。所以 p<0.05 门槛虽松，筛出的信号是真的。

**逻辑**：用「高命中率(62.6%) vs 随机(5%)」反证「门槛虽松但有鉴别力」，把"测不准"的软肋翻成"元件级信号真实"的论据。

### 创造性金句：创新在"组合 + 场景 + 分级输出"，不在单个算子

> 创造性不在"非对称"三个字本身，而在"把它用在跨物种衰老染色质可及性这一特定场景 +
> 用置换检验导出强效应阈值 τ_A + 核心/不可判定分级输出"的组合。权利要求 3+4+5+11 的组合
> 是现有技术无法通过单一已知方法拼出的协同效果。

## 答辩评估 vs 撰写评估的分工提醒

- 用户问"能不能过 / 能当毕业课题吗" → 用本文件的评委视角框架（五维表 + 三问 + 金句）
- 用户问"怎么写才能过" → 回到 §4 创造性防御 + §11 交底书规范
- 两者都要"先验数据"，但交付物不同：一个是"通过概率 + 答辩预演"，一个是"补强后的文件"

## 工作实例（2026-09-09/10 跨物种衰老可替代性专利）

复现全对（候选 16031 / 对称 min 核心 37 / 非对称核心 336 / 漏检 89% / 富集 12.5× / 整体 r=−0.0627）。
五维判定：新颖性 ~90% / 创造性 55-70%（主战场）/ 客体 ~85% / 清楚性 ~90% / 充分公开 ~85%。
总评：约六成能过，卡在创造性；作为毕业课题够格。最致命问题 = 猴侧 n=20、4 个离散年龄簇（5/10-12/22-23/28-31 岁）、整体年龄效应不显著（p=0.267），却拿 p<0.05 当门槛——防守金句即上文"整体测不准≠逐元件无信息 + 62.6% 命中率"。

### ⚠️ 口径冲突遗留风险（2026-09-10 发现）

`disclosure_substitutability.md` v2.1（2026-09-05）把 A 级收紧为双侧强效应同向 `min(|Z₁|,|Z₂|)>12` → 37 个核心元件；但 v3 docx 仍用非对称门槛 → 336 个核心元件。两套口径不能并存于同一份交底书——如果口径已收紧到 37，"对称 min 法 37 → 本方法 336，修复 89% 漏检"的创造性论证就不成立（收紧后本方法也是 37）。评估专利授权前景时，如发现口径冲突未解决，应在评估报告里明确标注"口径冲突未解决，需发明人拍板后才能定稿"。

### ⚠️ 公式溯源风险（2026-09-10 发现）

v3 docx 把 Z 写成了 Fisher Z 变换 `0.5×ln((1+r)/(1−r))`，但三份权威源文件全部写的是 Stouffer Z `Σ[sign(r)·Φ⁻¹(1−p/2)]/√n`。评估时如发现公式与源文件不一致，应标注为"致命错误（A26.3 公开不充分风险）"，优先级高于其他所有问题。
