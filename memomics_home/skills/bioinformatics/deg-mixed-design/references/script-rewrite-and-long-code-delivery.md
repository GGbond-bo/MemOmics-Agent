# 「重新写一版完整脚本给我看看」—— 重写协议与超长代码交付

> 2026-11-03 实测（Immune RUVr+MAST v5 → v6，原脚本 688 行 / 32 KB）。
> 触发语：**「你重新写一版最新的 DEG 代码给我看看」「给我一版干净的脚本」「这版太乱了重写」**。

---

## 一、先判断「重写」的边界：改什么、不改什么

用户说「重写」时，**默认意思是「结构重排 + 修掉已知缺陷」，不是「换一套统计方法」**。
擅自更换已定稿的统计口径 = 用户前面几轮确认全白费，一定会被退回。

固定做法：动手前先列表

| 类别 | 处置 |
|---|---|
| **已验证的统计主体** | **原样搬过去**（本例：残差预算 k、秩亏自动降级、W–stim 共线闸门、CDR、显著率哨兵、断点续跑、分片） |
| **已发现的真缺陷** | 修，并在交付时点名「第 N 处：v5 的 X 换成 Y，因为 Z」 |
| **纯可读性** | 结构重排、去历史注释、去掉多余依赖（如 `dplyr::recode` → base `match`） |
| **输出后缀** | `_v5.csv` → `_v6.csv`（必然换，否则断点续跑会把 v6 当"已完成"跳过） |

⚠️ **必换后缀的副作用要主动说**：「v6 会重跑全部 N 次拟合」。并给替代方案——
「如果想省时间，可以改成复用 v5 已出的表、只重算标记列，几分钟就完」。用户随口一提就省几小时。

## 二、交付形态：**不要一次性贴全文**

688 行脚本一次贴进正文 → **触发输出长度上限，代码块被从中间切断**（实测断在 `MEMO_SHARD` 分片逻辑处），
必须靠系统「continue exactly where you left off」续写，用户侧看到的是半截代码。这是最差的形态。

正确顺序（按序，缺一不可）：

1. **先落盘**到 `results/<sid>/scripts/<name>_vN.R`，正文第一行就给绝对路径。
   这样即使后面被截断，用户手里也有完整文件。
2. **正文给两张表**（这才是用户真正要审的东西）：
   - 「vN 相对 vN−1 改了什么」逐条编号 + 每条的**原因**
   - 「没改的」清单（证明统计主体一字未动，用户才敢用）
3. **代码分段贴**：按功能区分 2–3 条消息，每段开头写清「第几段 / 覆盖哪几行职责」。
   优先贴用户最需要审的三段：**参数区 → 判定函数 → 模型公式构造**；数据表硬编码段可以只给「N 行，见文件」。
4. 如果只能一次贴完 → **从靠后的段落开始省略并注明**（`# … 48 行样本名见文件，此处略 …`），
   **宁可省略数据表，不要省略逻辑**。

⛔ 反面：把 700 行原文整块扔出去，指望它恰好不截断。

## 三、落盘后必须自证「能 parse」，且要说明校验状态

R 脚本交付前跑 `Rscript -e "parse('<file>')"`（不执行、不读数据）。
⚠️ 若该轮被门禁/工具权限拦下没跑成，**必须在交付里显式写「本轮未做 parse 校验，首次运行前先跑一次」**——
不能默认用户以为验过了。这一条是会让人白等一轮的诚实边界。

## 四、重写的典型产出结构（可直接照抄骨架）

```
§1 路径与参数        ← 全部 Sys.getenv 可覆盖，硬编码只留开关默认值
§2 样本级元数据表    ← batch_tab / clin_tab，stopifnot(nrow == N, !anyDuplicated)
§3 工具函数          ← make.tform / waldFromZlm / batchModelable / assessConfound
§4 读入与元数据装配  ← readRDS → 组别映射 → 样本级合并 → 命中率自检
§5 全局设计核查      ← 交叉表 + Cramer's V，落 CSV 备查（每次跑都留证）
§6 运行计划          ← 亚群子集 / 分片 / 负对照模式
§7 主循环            ← 7.1 子集 → 7.2 配对 → 7.3 batch → 7.4 混杂 → 7.5 stim
                         → 7.6 过滤 → 7.7 RUV → 7.8 W 闸门 → 7.9 公式
                         → 7.10 合并 → 7.11 溯源列 → 7.12 哨兵落盘
```

每段开头一行 `## ===== N. 名称 =====`，子节编号 `7.x` —— 用户问「第 7.4 段那行」时能秒定位。

## 五、交付结尾必须回答的两个问题

用户审完代码必然会问（提前答，省一轮）：

1. **「这样跑会不会重跑？」** → 说清断点续跑判据（`file.exists(fn)` + 新后缀 ⇒ 全量重跑）。
2. **「哪些结果不能信？」** → 把混杂标记列的含义一句话讲完
   （`batch_confounded=TRUE` 的比较组只能表述为「分组+批次混合效应」）。
