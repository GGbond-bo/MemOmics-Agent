# 单元素改版的像素差分核验（含跨解释器渲染陷阱）

> 场景：图已定稿，用户提"还有个小问题"——删面板字母 a–e / 对调一处计数顺序 / 改一个字，
> 并明确要求"**其他的不变**"。交付要求：不能只说"看着没变"，要给**确定性证据**。
> 实测日期 2026-09-29，图族 = 5 面板 × 8 亚群同轴背离柱大图（`fig_deg_updown_8sub_MF_*`）。
> 版式常量与 `yfrac()` 公式见同目录 `multipanel-diverging-bar-frame.md`，本文只讲"改一处 + 证明只改一处"。

## 1. 四步协议

| 步 | 动作 | 纪律 |
|---|---|---|
| 1 | `cp 脚本N.py 脚本N+1.py`，只 patch 目标行 + 改 `STEM` | **旧版文件永不覆盖**，逐版留档；其余行逐字保留 |
| 2 | 渲染 | 必须用**会话持久内核**（`execute_python` + `exec(open(脚本, encoding="utf-8").read())`）；⛔ 不要 `terminal python x.py` 冷启动 |
| 3 | 差分 | `python scripts/pixel_diff_single_change.py OLD.png NEW.png --quiet 0.25 0.80 0.85 1.0` |
| 4 | 结论 | 报：差异像素数与占比 / 包围盒行范围 + y-frac / x 簇数与簇宽 / 静区差异 |

**通过判据**：静区差异 = 0 **且** x 方向簇数 = 本次改动的独立元素个数。

## 3. 🔴 跨解释器渲染陷阱（本会话真踩，差点误判）

同一条脚本、同一份数据，只换了渲染解释器：

| 渲染解释器 | matplotlib | 与 v4 差分 | 判读 |
|---|---|---|---|
| `E:/MemOmics-Agent/.venv/Scripts/python.exe`（**会话持久内核**，v4 本来就是它渲的） | **3.10.9** | **13,320 px，全落在 Σ 行；柱区 0、底部 0** | ✅ 正确的"只改一处"证据 |
| `C:/Users/.../Python312/python.exe`（误用冷启动 `python x.py`） | 3.11.0 | **111,449 px 散布全画布；柱区 33,277、底部 41,022** | ❌ 假象，会误导成"版式也被改坏了" |

- 两者**都解析到 Arial**，但 matplotlib 版本不同 ⇒ 字形/hinting/字距细节全变，**每一处文字都略有像素差**。
- ⇒ **差分有效性的前提 = 两版同渲染器**。差分前先跑 `scripts/pixel_diff_single_change.py --probe`
  打印解释器路径 + matplotlib 版本 + 字体链。
- 发现大范围差异时的排查顺序：**先查解释器/mpl 版本 → 再查数据 → 最后才怀疑版式**。
  处理：用内核重渲覆盖旧输出，再重跑差分（覆盖后 v5 与 v4 的差异立刻收敛到 Σ 行）。
- 配套纪律：`terminal python x.py` 冷启动不仅慢（每次重新 import matplotlib），
  在"同版本核验"场景里还会**污染证据链**。

## 4. 顺序类问题的确定性判据（OCR 不可靠时的替代）

- **规则**：文字（计数/图例/箭头）的左右顺序必须**等于**柱子的左右几何顺序。
  本例 = 左 Down 蓝、右 Up 红；用户给的例子 `380 | 16535`（非 `16535 | 380`）即此意。
- **密集小号数字行别信 OCR**：6.6 pt 的 `380↓ | ↑16,535` 整条 OCR 只读出一个"一"（置信 0.53）。
  改用颜色簇 x 位置：

  ```python
  band = B[int(.765*H):int(.815*H)]                      # Σ 行的纵向带
  m = lambda c, tol=90: (np.abs(band - np.array(c)).sum(axis=2) < tol)
  red, blu = m((178,24,43)), m((33,102,172))             # #B2182B / #2166AC
  # 逐面板取簇的 x 范围，与面板中心 (L+PW/2)*W 比较 → 报"在左/在右"
  ```

  容差要给足（**90**）：抗锯齿会把核心色压深，容差 40 会假阴性（同 SKILL.md 的"精确颜色计数"反例）。
- **改一处顺序，顺带检查其余顺序元素**：本图族有 3 处顺序编码 —— 柱（蓝左红右）、
  右上共享图例（Up 在上 / Down 在下）、顶部 Σ 计数条。只调 Σ 会让图例仍与柱子相反。

## 5. 用户矛盾表述的处理

用户原话可能同时含两句互相矛盾的要求：
- 散文句：*"为什么红色数值在左边……不应该红色数值在左边吗"*（= 维持红在左）
- 具体例子：*"aging 下面的数值 16535|380，不应该是 380|16535 吗"*（= 对调成蓝在左）

处理：按**具体例子 + 图内几何一致性**执行（对调），并在回复里**明说是按哪句做的**、
给一句"要反过来就说一声"。不要只挑一句执行而不声明——用户下一轮会问"你按哪个做的"。
