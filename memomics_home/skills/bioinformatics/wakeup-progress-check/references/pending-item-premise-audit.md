## 1. 先证伪，再追问（本轮唯一实质发现）

### 规则

把任何一项登记成「**待用户供给 X**」（DOI / 篇名 / 文件路径 / 参数 / 分组口径）**之前**，
必须先在本地确定性地找一遍 X。**本会话已有原始文件时，答案往往直接躺在文件里。**

> 把机器能闭环的事推给人，是「挂起项」最常见的伪影：
> 一个假的挂起点会让任务永远停在「等用户」上，还会每轮唤醒重复消耗 token。

判定口径（缺输入 ≠ 只差点头）：

| 登记状态 | 真实含义 | 机器可否闭环 |
|---|---|---|
| 「缺输入：待用户给 DOI/篇名/路径」 | 输入其实可从本地文件自证 | **可以** → 先自证 |
| 「纯 yes/no 决策」 | 需要人做取舍（要不要补卡、要不要恢复唤醒） | 不可以 → 才可真挂起 |

### 实测配方（PDF → DOI / 题名 / 作者 / 出处，零网络）

```python
import fitz  # pymupdf
doc = fitz.open(path)
print(doc.page_count)
print({k: v for k, v in (doc.metadata or {}).items() if v})
txt = "\n".join(doc[i].get_text() for i in range(min(2, doc.page_count)))
import re; print(sorted(set(re.findall(r"10\.\d{4,9}/[-._;()/:A-Za-z0-9]+", txt))))
```

- **Springer 把 DOI 塞在 `doc.metadata['subject']`**，形如 `Nature, doi:10.1038/s41586-024-07892-1`
  ——不要只看 `title`/`author` 就下结论说「元数据里没有 DOI」。
- 触发条件是 `metadata['format']`、`creator: Springer` 这类出版商标记；其他出版社可能只在正文页脚。
- 正文正则 `10\.\d{4,9}/…` 做**二次确认**（元数据可能缺失或被改写）。

### 案例（可复现的具体数字）

- 文件：`<数据目录> transfer enables artificial intelligence to yield chemical knowledge.pdf`
  24,214,769 B，16 页。
- 元数据直读得：DOI `10.1038/s41586-024-07892-1`；title 同名；一作 `Nicholas H. Angello`；
  通讯 `Aspuru-Guzik / Burke / Schroeder / Diao / Jackson`；出处 **Nature 633, 351 (2024-09-12)**。
- 台账里「待用户给篇名/DOI」**连挂 6 轮、5 次无答复**，本轮一读元数据即作废
  ⇒ 该挂起项从「缺输入」降级为「纯 yes/no」。

### 动作

1. 台账（`notes.md` + `task_plan.md`）写明「**旧记录作废**」，并说明新判据。
2. 汇报里说清「不再需要用户提供 X」（更正认知），但**不做邀约**（见 §2）。
3. ⛔ 证伪 ≠ 重列待决项：更正写进正文与台账即可。

## 2. 零 delta 轮的回复卫生（串扫描是语义规则，不是词表）

SKILL.md 里的词表（`待你决定`/`待决定`/`请提供`/`说一句`/`即可恢复`/`仍挂起`）**能被同义改写绕过**。
2026-10-15 本轮实测逃逸措辞：**「等你一句话（二选一或都要）」**。

⇒ 两条硬化要求：

1. **词表追加**：`等你一句话` / `待你一句话` / `二选一` / `需要你选` / `等你点头` / `要不要` / `你说一声`。
2. **判定改语义**（优先于词表）：回复末尾只要在**要求用户做出选择或提供输入** ⇒ 整段删，不看具体用词。

配套规则：**新发现不构成重列待决项/发起邀约的理由。**
本轮有新发现（DOI 证伪）→ 发现进正文；待决项仍只进 `notes.md`。
发前跑 `replay_reply_lint.py --ledger`。

## 3. 附：从 SKILL.md 迁入的两条 tick 坑（压缩时保留，勿再丢）

- **`.loopx/` 是隐藏目录**：`search_files` 默认找不到 → 必须用 `find`（或直接拼绝对路径）。
- **task_plan 用 patch 的缩进漂移坑**：给 `task_plan.md` 打补丁时，缩进层级不一致会把 `**Status:**`
  顶出首列，越修越歪 ⇒ **改前读全整份再 `write_file`**（或把插入点选在同一缩进层级的唯一锚点）。

## 4. 终态 tick 的核验指纹（够用即停）

一次 `md5sum`（产物）+ 一次 `ls -la`（交付物字节 + mtime）+ 一次「晚于冻结时间的新文件」扫描
⇒ 三源同值即判零 delta。**不要**每轮重读全文、重跑合并、重渲染。
第 12 轮唤醒时 `cards.json` md5 `17dd2962…db3e` 已是**第 16 次同值**：数字本身就是「无需再查」的证据。
