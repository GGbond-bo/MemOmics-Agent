## 1. 先证伪，再追问（本轮唯一实质发现）

### 规则

把任何一项登记成「**待用户供给 X**」（DOI / 篇名 / 文件路径 / 参数 / 分组口径）**之前**，
必须先在本地确定性地找一遍 X。**本会话已有原始文件时，答案往往直接躺在文件里。**

> 把机器能闭环的事推给人，是「挂起项」最常见的伪影：
> 一个假的挂起点会让任务永远停在「等用户」上，还会每轮唤醒重复消耗 token。

判定口径（缺输入 ≠ 只差点头）：

| 登记状态 | 真实含义 | 机器可否闭环 |
|---|---|---|
| 「缺输入：待用户给 DOI/篇名/路径」 | 输入其实可从本地文件自证 | **可以** → 先自证 |
| 「纯 yes/no 决策」 | 需要人做取舍（要不要补卡、要不要恢复唤醒） | 不可以 → 才可真挂起 |

### 实测配方（PDF → DOI / 题名 / 作者 / 出处，零网络）

```python
import fitz  # pymupdf
doc = fitz.open(path)
print(doc.page_count)
print({k: v for k, v in (doc.metadata or {}).items() if v})
txt = "\n".join(doc[i].get_text() for i in range(min(2, doc.page_count)))
import re; print(sorted(set(re.findall(r"10\.\d{4,9}/[-._;()/:A-Za-z0-9]+", txt))))
```

- **Springer 把 DOI 塞在 `doc.metadata['subject']`**，形如 `Nature, doi:10.1038/s41586-024-07892-1`
  ——不要只看 `title`/`author` 就下结论说「元数据里没有 DOI」。
- 触发条件是 `metadata['format']`、`creator: Springer` 这类出版商标记；其他出版社可能只在正文页脚。
- 正文正则 `10\.\d{4,9}/…` 做**二次确认**（元数据可能缺失或被改写）。

### 案例（可复现的具体数字）

- 文件：`<数据目录> transfer enables artificial intelligence to yield chemical knowledge.pdf`
  24,214,769 B，16 页。
- 元数据直读得：DOI `10.1038/s41586-024-07892-1`；title 同名；一作 `Nicholas H. Angello`；
  通讯 `Aspuru-Guzik / Burke / Schroeder / Diao / Jackson`；出处 **Nature 633, 351 (2024-09-12)**。
- 台账里「待用户给篇名/DOI」**连挂 6 轮、5 次无答复**，本轮一读元数据即作废
  ⇒ 该挂起项从「缺输入」降级为「纯 yes/no」。

### ⛔ 1-b 绑定校验 —— 缺这一步，证伪会「自证错的东西」（2026-10-17 tick#27 实测翻案）

上面那条「降级为纯 yes/no」的结论**是错的，已在 tick#27 翻案**，保留在此作反例：

| 项 | 当时怎么想 | tick#27 实查 |
|---|---|---|
| 读到的 DOI | 以为是被跳过的「第 32 卡」的 DOI | 是**本会话主论文自己**（《Closed-loop transfer》, Nature 2024）的 DOI |
| 出处 | `doc.metadata['subject']` | 同一个 DOI 也出现在 `paper.md` / `paper_raw.txt`（主论文解析产物）⇒ 它就是主论文的 |
| 后果 | 「输入已备 ⇒ 降级成纯 yes/no」 | **输入从未齐备**；错判在台账里存活 6+ 轮，靠后续交叉验证才翻案 |

**规则（新增，强制）**：从文件/元数据里读出的标识符（DOI / PMID / 篇名）**必须回绑到目标条目本身**
才算「输入已备」。回绑方式（至少一条）：

1. **目标条目自己有记录**：目标定义的来源清单里该条目带的 `doi`/`pmid`/`title` 与你读到的一致；
2. **位置/编号对得上**：用已确证的编号体系定位目标（见 §5），再比对该条目的字段；
3. **反向排除**：若同一标识符也出现在会话里**更显眼**的另一份文档（主论文 / 主产物）中，
   默认它属于那份**更显眼**的，除非 1 或 2 能证明它属于目标。

> 一句话判据：**「我读到的这个 ID，凭什么说它是它的？」** 答不上来 ⇒ 不许登记「输入已备」。
> 自证 ≠ 随便 grep 到一个 ID；自证 = **ID 绑定到目标条目**。

### 动作

1. 台账（`notes.md` + `task_plan.md`）写明「**旧记录作废**」，并说明新判据。
2. 汇报里说清「不再需要用户提供 X」（更正认知），但**不做邀约**（见 §2）。
3. ⛔ 证伪 ≠ 重列待决项：更正写进正文与台账即可。

## 2. 零 delta 轮的回复卫生（串扫描是语义规则，不是词表）

⇒ 两条硬化要求：

1. **词表追加**：`等你一句话` / `待你一句话` / `二选一` / `需要你选` / `等你点头` / `要不要` / `你说一声`。
2. **判定改语义**（优先于词表）：回复末尾只要在**要求用户做出选择或提供输入** ⇒ 整段删，不看具体用词。

## 4. 终态 tick 的核验指纹（够用即停）

一次 `md5sum`（产物）+ 一次 `ls -la`（交付物字节 + mtime）+ 一次「晚于冻结时间的新文件」扫描
⇒ 三源同值即判零 delta。**不要**每轮重读全文、重跑合并、重渲染。
第 12 轮唤醒时 `cards.json` md5 `17dd2962…db3e` 已是**第 16 次同值**：数字本身就是「无需再查」的证据。

## 5. 编号反解：把「第 N 个缺件」变成可指认的具体条目（tick#27 新配方）

挂起项写成「第 32 张卡待补」是**不可执行**的 —— 没有篇名、没有 DOI，谁都不知道指哪篇。
只要落盘数据里有编号体系，就能反解出真身。三步：

### 5.1 找编号的来源，别猜

产物里的 `n` / `id` 常是**某个池子的列表位置**，不是论文自带编号。做法：

```python
# ① 拿产物里编号 → 找一个"已知锚点"（已确认的条目）反查它在池子里的位置
pool = json.load(open('data/essential45.json', encoding='utf-8'))
src  = json.load(open('data/cards_source.json', encoding='utf-8'))
ok = all(str(pool[int(c['n'])-1]['id']) == str(c['pmid']) for c in src if 'pmid' in c)
print('编号 = 池子位置(1-based)?', ok)      # True 才认这套编号
```

- **判据**：用**全部已确认条目**做「位置 ↔ 自带 ID」逐条匹配（本会话 31/31 命中）；
  只挑 1–2 个看起来对上就下结论，会被巧合骗到（本会话试过 1 个锚点，序号对不上，差点判「编号体系不可解」）。
- 至少两个独立锚点 + 一次全量校验，才允许用该编号定位目标。

### 5.2 读目标自己的字段，并判体裁

反解出编号后，读该条**自身字段**（`title` / `doi` / `pmid` / `year` / `abstract` / `oa` / `type`），
**判体裁**决定它值不值得做深读卡：

| 字段特征 | 体裁 | 处置 |
|---|---|---|
| `abstract` 空 + `type` 空 + `oa=N` | **新闻稿 / 评论 / news feature** | 不做深读卡，直接建议跳过（本会话 n=32 = Nature news feature） |
| 有 `abstract` + 有 `type` | 研究论文 / 综述 | 可做卡，按引用数排序优先 |

> 这一条能拦住「为了补一张卡去精读一篇新闻稿」的无效工作量。

### 5.3 输出「未做清单」，把决策升级

反解后**不要**只回答「第 N 个是 XX」——把**同类缺件的全清单**列出来（编号 → 篇名 / 年 / 期刊 / 引用数）：

- 决策从「**补不补第 32 张**」（不可执行）升级为「**补哪几篇**」（可一句点单）。
- 全清单同时暴露「哪几篇是真研究论文、价值最高」，避免盯着一篇新闻稿耗轮次。

### 5.4 落盘

- 台账逐条写「编号体系 = 池子位置（N 条校验通过）」+ 目标条目全字段 + **翻案记录**（若与前轮结论冲突）。
- 前轮的错结论要**双向更正**：备注一条 + 把被替换的原文标注作废（否则错结论会被后续轮次反复引用为「已确认」）。
