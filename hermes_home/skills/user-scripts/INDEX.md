# 用户脚本库总索引（User Scripts INDEX）

> **用途**：登记所有"用户提供且实际运行验证通过"的脚本，支持跨会话回忆与复用。
> **触发**：用户说"之前那个脚本 / 那个分析 / 那个代码 / 上次的 XX" → 先查本索引。
> **分类规则**（SOUL.md 用户脚本铁律）：画图→`plotting/`，比对/对比流程→`comparison/`，其他按用途建类。
