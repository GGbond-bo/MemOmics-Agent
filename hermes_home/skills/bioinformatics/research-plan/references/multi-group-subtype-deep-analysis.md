# Multi-Group × Subtype Deep Analysis Playbook

> 当用户有 ≥4 组复杂比较 + 细胞亚型分解时使用此模板
> 来源: 2026-07-14 会话 — 人类骨骼肌 6 组 (Young/Old/T2D × Pre/Post) × 肌纤维亚型 (Type I/IIA/IIX) 深度分析

## 核心诊断框架

当用户已经做了 UMAP + marker heatmap + 组成分析 (sccomp)，问"还要做什么"时：

| 已做的分析 | 回答了什么 | 没回答什么 |
|-----------|-----------|-----------|
| UMAP | 有哪些亚群 | 亚群**内部**发生了什么 |
| Marker heatmap | 每个亚群的身份基因 | 身份是否在条件间**变化** |
| 组成分析 (sccomp/MiloR) | **比例**变了 | **基因表达**变了没有 ← 最关键缺口 |

> 组成分析说 "Type IIX 在 T2D 中比例减少"，但不回答：剩下的 Type IIX 纤维是正常的还是功能受损的？

## 必须补的 3 个核心分析维度

### 1. 亚型内 Pseudobulk DEG (必须做)
- 在每个亚型内部做 Pre→Post 比较 → N 个对比 (N_亚型 × N_条件)
- 核心故事线：比较不同条件下运动应答的 DEG 数量 → "X 条件钝化了 Y 亚型的运动应答"
- 出图：DEG 数量条形图 + UpSet/Venn 图展示跨条件共享 DEG

### 2. 基因集评分 + 主题箱线图 (必须做)
- 按生物学主题组织评分：代谢/收缩/衰老/去神经化/萎缩/炎症等
- 每个主题面板 = 3 格 (每亚型 1 格)，每格内 6 组配对箱线
- **不要所有基因混在一张图上** — 按主题分组，每个主题 3-4 个基因 + 1 个综合评分
- 箱线图配色：条件 1=蓝/条件 2=橙/条件 3=红；Pre=浅/Post=深

### 3. 应答指数 (Condition-specific Responsiveness Index)
- 命名格式：`[治疗]_[参数]指数` (如 ERI, MRI, DRI)
- 公式：`Index = (Post_score - Pre_score) / sd(Pre_score)`
- 等级：> 0.5 强应答 / 0-0.5 中等 / < 0 无应答
- 核心对比：不同条件下同一亚型的应答指数差异

## 可选增强维度

### 4. 多条件 DotPlot (CNS 标配)
- row = 12-15 marker 基因, col = 亚型 × 条件

### 5. 亚型转换轨迹
- Monocle3/Slingshot 鉴定转换中间态
- 比较不同组的 pseudotime 密度分布 (ridgeline)

### 6. 亚型特异 GSEA
- 每亚型 × 每条件做 GSEA → 共享通路网络图

### 7. 条件特异性"特征基因"
- 在对照组中定义某亚型的响应特征
- 在其他组中计算该特征的表达变化

## 出图策略：复杂多组对比的通用规则

| 策略 | 说明 |
|------|------|
| 拆分主题 subpanel | 不要所有信息塞一张图 |
| 箱线图+统计标注 | 配对 Wilcoxon / LMM + FDR |
| 热图+箱线+条形 三件套 | 概览 → 细节 → 统计 |
| 创新指标单独成 panel | 如 ERI 独占 1 panel |
| 配色有生物学含义 | 不随机，条件=色调，Pre/Post=深浅 |
