# CNS 级完整研究方案模板

> 此模板基于 2026-07-14 会话产物：人类骨骼肌 衰老 × T2D × 运动 snRNA+snATAC 多组学方案
> 当用户说"深度不够"/"CNS级别"/"分阶段"时，默认启用此模板

## 必须包含的 14 个段落

1. **文献依据表** — 7-8 篇核心文献，含 PMID/DOI、关键方法版本号、与本研究相关性、来源标记 [KB]/[PMID]
2. **核心假说** — H₀/H₁ 明确陈述 + 4 条可检验预测链（每条预测对应具体检验方法）
3. **Gap 分析表** — 3 篇最相关论文 vs 本研究的填补，逐行对比
4. **创新性声明** — 与每篇对比文献的"已有工作 vs 本研究新增价值"
5. **分析方法与论证** — 每步骤含方法 + 包/版本 + 理由（验证哪条预测），非"常用/标准"
6. **技术路线图** — 4 组件 Mermaid：3.1 总览漏斗（含数据输入圆柱节点+决策菱形+Figure输出）、3.2 故事线决策树、3.3 多组学数据流、3.4 方法版本速查表
7. **Phased 分析** — 每个 Phase：生物学问题（一句）+ 分析方法表 + 关键对比 + Figure 三一结构
8. **Figure 策略** — 每张 Figure 含：内容描述 + 具体数值预期 + 如不符合则备选解读
9. **统计方案** — 功效分析 + 多重检验 + 效应量阈值 + 阴阳对照 + 交互效应检验
10. **实验验证路径** — 正交验证(IF) + 公共数据验证 + 阳性对照基因集
11. **备选方案与风险** — 5-6 风险 × (可能性 + 缓解策略)
12. **专利分析** — 3 专利方向 × (对应Phase + 技术方案 + 权利要求示例)
13. **可执行待办** — Phase × 任务 × 技能绑定 × 优先级
14. **可复现性声明** — 代码/数据/环境/随机种子/容器
15. **质量检查** — Loop Gate 10 项 checkbox

## Figure 三一结构（每张 Figure 必须）

| 三一结构 | 内容 |
|---------|------|
| **内容** | 具体描述子图 (a)(b)(c)(d) 各展示什么 |
| **预期** | 具体数值预测（如"Type II 肌核 Young 49% → Old 29% → T2D 22%"） |
| **备选** | 如预期不符合的替代解读和后续分析调整 |

## 三条故事线（择一深入）

- **故事 A (钝化线)**: P2 DEG 数量 Young >> Old >> T2D → "T2D 锁死了运动应答"
- **故事 B (加速衰老线)**: P5 MOFA+ 单因子分离所有组 → "T2D = 加速衰老表型"
- **故事 C (去神经化线)**: P3 T2D 去神经化比例最高、运动仅部分逆转 → "汇聚于 MAF-RUNX1"

## 专硕应用类增强

当用户是专硕时，额外要求：
- 每 Phase 至少对应一个可专利技术方案
- 假说以应用价值为导向（"能不能替代/预测/诊断"优于纯机制）
- 专利分析含权利要求示例
