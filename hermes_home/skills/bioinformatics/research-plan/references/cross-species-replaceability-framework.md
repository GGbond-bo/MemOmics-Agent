## 核心问题

"猴海马某个基因和人海马都高表达——是物种保守性（可代替）还是个体特异（不可靠）？"

**答案：方差分解框架。** 总变异 = 物种 + 个体 + 年龄 + 残差。

---

## 五层递进评估体系

### Level 1 — 细胞组成可代替性 (S_comp)
- Dirichlet-multinomial regression: `cell_type_proportion ~ species + age + species:age`
- S_comp = 1 − JS(P_monkey, P_human)
- species p > 0.05 → 组成无显著差异

### Level 2 — 基因表达保守性 (S_expr)
- Per cell type pseudobulk → Spearman r
- **关键**: r_cross_species vs r_within_species (Mann-Whitney U)

### Level 3 — 衰老轨迹平行性 (S_trajectory)
- V = [log2FC^old/young_gene1, ..., log2FC_geneN]
- cos(θ) = V_monkey · V_human / (‖V_monkey‖ ‖V_human‖)
- **进阶**: 连续年龄模型 `expression ~ age + species + species:age + (1|id)` — 交互项检测衰老速度差异

### Level 4 — 方差分解 🔑 核心创新
- Mixed Model: `expression ~ species + age + species:age + (1|individual_id) + ε`
- **SDI** = |β̂_species|² / σ̂²_individual

**ABCD基因分类**:
| 级别 | 条件 | 含义 |
|------|------|------|
| A 完全可代替 | SDI<1 且 cos(θ)>0.8 | 表达+衰老方向均保守 |
| B 定量可代替 | SDI<1 但 cos(θ) 0.5-0.8 | 保守但衰老幅度不同 |
| C 方向可代替 | SDI 1-3 但 cos(θ)>0.8 | 方向一致但基线不同 |
| D 不可代替 | SDI>3 或 cos(θ)<0.5 | 根本物种差异 |

### Level 5 — IRS 综合指数
```
IRS = 0.2×S_comp + 0.3×S_expr + 0.3×S_trajectory + 0.2×(1−P_D_class)
```
- >0.80: 高度可代替 | 0.60-0.80: 有条件 | <0.60: 不可代替

## 五维方法验证体系

### 1. 进化锚点验证
人>猴>小鼠的IRS排序必须成立。Spearman ρ < -0.8, p < 0.05。

### 2. 消融实验
去掉Level 4 → D类基因检出率降幅>50% → 证明Level 4不可替代。

### 3. 内部一致性
| 方法 | 通过标准 |
|------|---------|
| Bootstrap (1000次) | 95% CI宽度 < 0.10 |
| 个体交叉验证 (LOIO) | IRS_sd < 0.05 |
| 参数敏感性 (网格搜索) | >95%权重组合下排名不变 |

### 4. 外部数据验证
独立GEO数据集 → ΔIRS < 0.10

### 5. 预测性验证
- 文献验证: D类基因文献分歧率 → Fisher OR>5, p<0.01
- 药物验证: 猴有效人失败的AD药物靶点在D类基因中富集

## 数据质量预检清单

- [ ] 个体数 ≥ 4 / 年龄组 (≥3可做，≥4稳定)
- [ ] 每个体细胞数 ≥ 1000 (pseudobulk最低要求)
- [ ] 批次效应已识别
- [ ] 排除细胞数<500的个体 (pseudobulk无意义)
- [ ] 年龄为连续值(优于二元分类)
- [ ] 连续年龄模型中包含species:age交互项

### 案例: 猴海马数据 (21个体)
| 组 | 个体数 | 可用 | 排除 |
|:---|:---:|:---:|------|
| Young(5岁) | 4 | 4 | — |
| Middle(10-12岁) | 5 | 4 | M5(455) |
| Old(22-23岁) | 6 | 4 | O4(849)+O5(384) |
| Exceptionally old(28-31岁) | 6 | 6 | — |
| **合计** | **21** | **18** | 3 |

## 完整 S100-S600 分析序列

```
S100  数据获取
  ├─ 物种A (猴)海马 snRNA-seq: 4年龄组, ≥5/组
  └─ 物种B (人)海马 snRNA-seq: 正常衰老, 匹配年龄梯度
       → 推荐 GSE278576 (40正常供体) + GSE186538 (细胞类型锚定)
       详见 references/human-hippocampus-aging-datasets.md

S200  细胞类型锚定与跨物种基因对齐
  ├─ marker genes + scArches 锚定共享细胞类型 (6-10类)
  └─ 基因对齐: 1:1 ortholog (Ensembl BioMart) [独权]
     └─ 备选实施例: ESM-2 蛋白质语言模型嵌入 [从权]
        ⚠️ ESM-2 不进独权 — 审查员会以"黑盒/充分公开不足"驳回

S205  🔑 跨物种技术批次效应校正
  ├─ Harmony/scVI 残差化 → 消除实验平台/解离方案差异
  ├─ 验证: UMAP 上同类型细胞跨物种充分混合
  └─ 无法充分混合的细胞类型 → 标记风险
     ⚠️ 没有这一步 = 审查员会说"你测的是批次差不是物种差"

S300  分层可替代性评估 (每细胞类型独立)

  S310 细胞组成层
  └─ Dirichlet-multinomial: proportion ~ species + age

  S320 🔑 基因表达层 — pseudobulk 个体聚合
  └─ 三重相关: r_cross vs r_within, 判定物种差≤个体差?

  S330 衰老轨迹层
  └─ cos(θ) = (V_monkey · V_human) / (|V_monkey| × |V_human|)
     基因集: Hallmarks of Aging / SenMayo / SASP (不用AD基因集)

  S335 🔑 年龄等效变换 (在 S340 之前)
  └─ age_scaled = (age - mean)/sd per species
     或 猴→人等效年龄 = 猴年龄 × 3.5
     解决"猴5岁≠人20岁"的跨物种年龄不可比问题

  S340 🔑 方差分解层 — 混合效应模型
  └─ expression ~ species + age_scaled + species:age_scaled + (1|individual)
     SDI = |β_species|² / σ²_individual  [统计量进独权,阈值进从权]

  S350 功能层
  └─ 衰老基因集 × 各层判定 → 通路可代替性图谱

S400 🔑 四级基因分类 (A/B/C/D)
  ├─ A: SDI低+cos(θ)高 → 完全可代替 → 进入专利C签名
  ├─ B: SDI低但cos(θ)中 → 定量可代替
  ├─ C: SDI中但cos(θ)高 → 方向可代替(基线不同)
  └─ D: SDI高 → 不可代替 → 进入专利C排除清单

S500  综合可替代性指数 (IRS) 输出
  └─ IRS = 加权(S310+S320+S330+S340+S350)
     权重区间由网格搜索确定 [不进独权]

S600 🔑 方法验证体系
  ├─ S610 进化锚点: 人 > 猴 > 小鼠 排序成立
  ├─ S620 阴性对照: 物种标签置换检验 p<0.05
  └─ S630 文献交叉验证: D类基因文献分歧率 OR>5

```

  独权核心: pseudobulk聚合 + Mixed Model SDI + species×age交互 + ABCD分类
  授权概率: 65-75%

专利C: 抗衰老化合物筛选方法 ("筛药物")
  独权核心: 跨物种保守性过滤签名 + 细胞类型特异逆转评分 + D级靶点排除
  授权概率: 55-65%

同日提交 → 互不构成抵触申请
权要错位 → A评估框架 / C筛选框架

学校只要求受理 → 3个月可行:
  M1: 锁定人源数据 + 跑分析
  M2: 撰写两份交底书
  M3: 同日提交 → 受理通知书 → 毕业条件达成
```

### 关键教训

- **ESM-2 不进独权** (黑盒风险), 进从权+实施例 — "在另一实施例中, 可采用蛋白质语言模型实现跨物种基因对齐"
- **SDI 统计量进独权, 阈值进从权** — "计算物种效应与个体效应的方差比"; "所述阈值为0.5-3, 优选1"
- **不要用AD基因集** — 猴是正常衰老模型, 用人AD病人数据比对正常衰老猴 → 科学上不成立。改用 Hallmarks/SenMayo/SASP
- **人源数据挖AD研究的健康对照组** — 这是最大的隐藏宝库

**必须有生物重复！** 每组≥3个体才能区分物种vs个体差异。

## 专利差异化

现有跨物种专利（阮航/郭国骥/周展）全部聚焦**细胞类型注释**。
本框架聚焦**定量评估可代替性**。

**关键差异**: ESM-2蛋白质嵌入(所有基因可比较，非仅1-1同源) + pseudobulk层级mixed model + species×age交互效应。
**规避**: 纯统计推断，不用深度学习(Transformer/异构图/元路径)。

独立权利要求 = [数据输入] + [不可替代组件] + [具体步骤(计算机实现)] + [可验证效果]
