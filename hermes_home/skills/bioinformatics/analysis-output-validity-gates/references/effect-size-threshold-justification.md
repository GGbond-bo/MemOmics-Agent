# 效应量阈值（|logFC| / |coef|）的依据审计与选择

> 触发场景：用户提出「加 `|coef|>0.2` 还是 `>0.25`」「这个阈值有文献支持吗」「不保证效应量，
> 获得的基因很可能是假的」「按 `fdr<0.05 & abs(coef) > θ` 筛基因」——任何在 DEG 结果上叠加效应量门的场景。
>
> 首次沉淀：2026-09-29 · human skeletal muscle / aging + exercise · 细胞级 glmer+RUV vs pseudobulk dreamlet。
> 配套探针：`scripts/coef_threshold_audit.py`（一次跑出下文全部判据）。
> 归属说明：本文件是「产出有效性自证门」在 **DEG 显著性读数** 上的实例化 —— 阈值问题的真身是分母失校。

---

## 0. 铁律：先查分母，再谈阈值

**效应量阈值不能救一个失校的 p 值集合。** 阈值讨论之前必须先跑分母膨胀检查：

| 检查 | 判据 | 本项目实测 |
|---|---|---|
| ① 显著集 vs 全集效应量 | 两者中位数几乎相等 → 「显著」完全由分母决定 | 0.2478 vs 0.2477 |
| ② \|z\|=coef/se 量级 | 中位 \|z\| 远超 1.96 | 3.66–10.39 |
| ③ SE 量级 | 比合理值低一个数量级 | 低估 ~26×（等效有效样本量高估 ~700×） |
| ④ 根因 | 细胞级模型 df 被当作细胞数（数千），而非供体数 | 24 供体 × Pre/Post，n=7–10/组 |
| ⑤ 症状指纹 | 显著率异常高 + 方向极度不对称 | 显著率 85.1% / 57.4%；上:下 = 22,709:469 = **48:1** |
| ⑥ 对照 | 正常对比组方向应接近 1:1 | 运动四组 ≈1:1（正常） |

**修法（顺序不可颠倒）**：加供体随机效应 `(1|individual)`（**参考方法原文即如此，见 §1**），
或换 NEBULA 等设计感知工具 → **然后**才谈阈值。

> **结论**：阈值门只能**减少**假阳性，不能**消除**。给结论时必须同时声明分母问题。
> 显著率 >70% 或方向比 >10:1 → 先怀疑分母，不要把「基因多」当成方法更强。

## 1. 先审来源方法的官方代码，不要假设它有阈值

方法若源自某篇论文，**先去读它的官方仓库脚本**，确认阈值是否真的写在那里。

实测（猴脑 NHPABC，`snRNA/04.Identification_of_differentially_expressed_genes(DEGs)/RUV_MAST_pDEG_MBA.R`）
关于显著性只有两行：

```r
fulldf$fdr = p.adjust(fulldf$p, 'fdr')
fulldf = fulldf[!is.na(fulldf$coef),]
```

**没有任何 `|coef|` 阈值** →「0.2/0.25 是从原始方法继承的」不成立，它是自定阈值。

⚠️ **不要凭记忆引用文献阈值 —— 必须回原文逐段核对「模态」与「统计量」。**

### 实证更正（重要，别再犯）

先前把 **0.25 说成「猴脑 RNA DEG 阈值」是错的**。回原文核对后：

| 分析 | 模态 | 原文阈值 |
|---|---|---|
| sDAREs（阶段特异差异可及性） | **ATAC** | `P < 0.05` 且 `log2FC > 0.25` ← **0.25 真正出自这里** |
| longDAREs | ATAC | `P < 0.0002` 且 `\|log2FC\| > 1.1` |
| pDAREs | ATAC | `\|R\| > 0.5` + `P<0.05` + 置换 `P<0.1` + `\|age coef\| > 0.005` |
| **pDEGs / sDEGs** | **RNA (MAST v1.12.0)** | 只写「蛋白编码基因过滤 + MAST」；**代码无效应量门** |

两处差异：① **模态不同**（ATAC ≠ RNA）；② 该 sDARE 用的是**未校正 `P<0.05`**，比 FDR 松。
把 0.25 当「RNA DEG 先例」引用 = 张冠李戴，审稿人一查就破。

✅ **但猴脑有一处确实该抄**：methods 原文写明 sample 被建模为随机效应
（"sample was modeled as a random effect"）→ 这正是 `(1|individual)` 的原文依据。

## 2. 边界带诊断：p 值能不能区分两个阈值？

取被更严阈值砍掉的那一带（`0.20 < |coef| ≤ 0.25`），看它还剩多少统计证据：

| 对比组 | 边界带基因数 | 占显著 | 边界带 fdr 中位 | 边界带 \|z\| 中位 | 保留组 \|z\| 中位 |
|---|---:|---:|---:|---:|---:|
| Aging | 11,111 | 18.6% | 7.0e-31 | 11.67 | 15.28 |
| Ex_Old | 4,210 | 8.2% | 3.9e-16 | 8.33 | 12.20 |
| DM | 367 | 1.0% | 8.7e-16 | 8.55 | 14.27 |
| Ex_DM | 311 | 1.3% | 6.6e-37 | 13.05 | 18.81 |
| Ex_Young | 172 | 0.7% | 4.4e-45 | 14.49 | 16.78 |

**读法**：边界带 fdr 仍在 `1e-16 ~ 1e-45`、`|z|` 仍有 8–14 → **p 值说它们和保留下来的「一样显著」**。
⇒ 阈值卡在哪**不是统计判断，是生物学判断**；既然 P 值无从区分，就用「最小生物学意义效应」来定，
并在方法里**显式声明是自定标准**。

## 3. z 等效尺度：这个阈值实际要求几倍 SE？

`θ / 显著集 se 中位` = 等效要求的 SE 倍数，与 **1.96**（p<0.05 惯例）对比：

| 对比组 | se 中位 | θ=0.20 ≡ z | θ=0.25 ≡ z | 显著集 \|z\| 中位 |
|---|---:|---:|---:|---:|
| Aging | 0.0200 | 10.0 | 12.5 | 10.39 |
| Ex_Old | 0.0233 | 8.6 | 10.7 | 5.55 |
| DM | 0.0173 | 11.5 | 14.4 | 5.13 |
| Ex_DM | 0.0159 | 12.6 | 15.7 | 3.66 |
| Ex_Young | 0.0119 | 16.9 | 21.1 | 3.85 |

⇒ θ=0.25 相当于要求 **10.7–21.1 倍 SE**，比统计门槛严 5–10 倍；
而显著集里一大半基因 `|z|` 不到 4 → **两个筛选维度在砍完全不同的基因集**。

## 4. 正对照校准：用已知真信号反推阈值代价

取领域公认差异基因（本例 21 个：CDKN1A / GADD45G / FBXO32 / MYOG / NR4A3 / MYBPH / HSPB1 /
PPARGC1A / ULK1 / TFEB / FOXO3 …），看能否过阈 —— **把阈值成本翻译成生物学语言的关键一步**：

| 对比组 | θ=0.20 召回 | θ=0.25 召回 |
|---|---:|---:|
| Aging | 47.7% | **33.2%**（砍掉 2/3） |
| Ex_Old | 32.4% | 24.6% |
| Ex_DM | 8.8% | 4.9% |
| Ex_Young | 2.8% | 1.4% |
| DM | 1.7% | 0.6% |

> 想让 Aging 保住 ~80% 已知信号，θ 需降到 **0.10 以下**。

⚠️ 正对照不能只看「过没过阈」，要列出**具体基因的 \|coef\| 值**：
本例 FBXO32=0.424（过），而 GADD45G=0.438、NR4A1=0.453、MTOR=0.355、ULK1=0.410 落在 0.10–0.30，
正是被 0.25 拦掉的区间。**同一通路的不同基因散落阈值两侧**，是阈值人为性的直接证据。

## 5. 量纲换算

`log2(1.2) = 0.263` → **θ=0.25 ≈ 1.19 倍**，θ=0.20 ≈ 1.15 倍，都属「生物学上几乎没变化」的量级。
本项目 KB（`deg.yaml`）pseudobulk 约定的 logFC 阈值是 **0.5（≈1.41 倍）**，比 0.2/0.25 更符合常规预期。
用户「大于 1.2 倍算初步有变化」的直觉换算成 log2FC 就是 0.25 附近 —— **先认可用户算得对，再谈代价**。

## 6. 落地口径（methods 措辞）

| ❌ 不要写 | ✅ 要写 |
|---|---|
| "threshold as in <某文献>" | "a self-imposed minimal biologically meaningful effect size (≈1.19×, log2FC = 0.25)" |
| 只报过滤后基因数 | 同时报：显著率、边界带诊断、正对照召回、分母/SE 校准的限制声明 |
| 单一阈值 | **阈值敏感性表**（多档并列）比单值抗审稿 |

---

## 7. 二选一的裁决逻辑（可直接复用）

1. **先看正对照代价** → 哪个阈值砍掉更多已知真信号，哪个更差。
2. **再看保守性需求** → 若上游 p 值已失校（§0），越保守越好 → 偏严一侧。
3. **冲突时如实并列，不要粉饰** → 本例 θ=0.25 正对照代价高但对失校 p 值更安全；
   按用户「最小生物学意义效应」标准选 0.25，并**明确写出代价**（"减少假阳性、不消除假阳性"），
   而不是声称它「更正确」。
4. **给更优路径** → 能修分母（供体 RE / NEBULA）就优先修分母；或改**排名法**（每亚群 top-N / top 5%），
   避开「绝对刻度不可靠」。

## 8. 一步到位

```bash
python scripts/coef_threshold_audit.py \
  --in Aging.csv --name Aging --in Ex_Old.csv --name Ex_Old \
  --group celltype --theta 0.20 0.25 \
  --poscontrol CDKN1A,GADD45G,FBXO32,MYOG,NR4A3,MYBPH,HSPB1,PPARGC1A,ULK1,TFEB,FOXO3 \
  --out threshold_audit.csv
```

输出即 §0–§4 全部判据。列名自动识别，可用 `--coef/--se/--p/--fdr/--gene/--group` 覆盖。
