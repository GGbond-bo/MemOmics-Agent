# 多因素干预研究：分段深度分析策略

## 适用场景
- 2+ 条件（如 Young/Old/Old+T2D） × 干预前后（如运动 Pre/Post）
- 目标：避免"一把抓"式泛泛分析，逐层深入

## 四阶段通用框架

```
Phase 1 — 基线损伤图谱
  问题: "我们在哪？"—— 疾病/衰老状态的基线差异

Phase 2 — 干预效果检验
  问题: "干预能逆转什么？"—— 差异中的差异(DiD)分析

Phase 3 — 深度机制挖掘
  问题: "为什么有些不可逆？"—— 锁定最显著的分子通路深钻

Phase 4 — 多组学整合与模型
  问题: "整体机制是什么？"—— 跨模态验证 + 概念模型
```

---

## Phase 1 — 基线损伤图谱（snRNA 为主）

### 方法
1. 全部样本整合 → QC → Harmony 批次校正 → 聚类 → 注释
2. 纤维亚型细分：MYH7(Type I) vs MYH2(Type IIa) vs MYH1(Type IIx)
3. MiloR 差异丰度分析
4. Pseudobulk DESeq2（每个亚群独立跑，formula = `~ group`）
5. 功能富集

### 关键对比（以 3条件×2时间为例）
- **对比 A**：Young vs Old —— 衰老效应
- **对比 B**：Old vs Old+T2D —— 疾病附加效应
- **对比 C**：Young vs Old+T2D —— 衰老+疾病的总和效应

### Figure 结构
- 左侧：全局 UMAP（细胞类型着色）
- 右侧：堆积图 —— 各纤维亚型比例在两组间变化
- 底部：MiloR 差异丰度热图

### 与已发表工作的关系
明确列出已经有类似数据的文献，说明你的**额外价值**（新条件/新模态/新时间点）。例如：
- `[KB] Lai 2024 Nature` 已做了 Young vs Old，你的创新在 T2D 维度
- `[PMID] Hansen 2025 J Physiol` 已做了 T2D 基线 snRNA，但你加上衰老维度

### 决策点
- 细胞比例差异显著（效应量大）→ 继续 Phase 2
- 差异微小 → 提前转向 GSEA / WGCNA 等更灵敏的分子分析

## Phase 2 — 干预效果检验（snRNA + 开始 snATAC）

### 方法
- DESeq2 交互效应公式：`~ group + time + group:time`
- 三分类运动响应基因：
  - **共享响应**：所有三组都显著且方向一致的基因
  - **条件特异性**：仅某组响应的基因
  - **钝化基因**：Young 有、Old 减弱、Old+T2D 无响应
- Gene Set Enrichment (GSEA)：看钝化基因的富集通路

### Figure 结构
- 左：三组 Pre→Post 火山图（并排三列）
- 中：DEG 数量柱状图 —— 预计 Young(2000+) > Old(800+) > Old+T2D(300+)
- 右：共享响应 vs 条件特异性响应基因的韦恩图
- 底部：钝化基因的 GSEA 热图

### 核心预期
PPARGC1A (PGC-1α)、ESRRG、NRF1 等经典运动响应基因：
Young ↑↑ → Old ↑ → Old+T2D → (无显著变化)

### 辩论点
运动钝化原因：是"表观遗传锁死"还是运动强度差异？
→ 如有 VO2max/HbA1c 数据，作为协变量纳入

## Phase 3 — 深度机制挖掘（snRNA + snATAC + SCENIC + scTour）

### 策略
从 Phase 2 中找出**变化最大的分子通路**，做一个定向深挖。

### 以"骨骼肌去神经化"为例的深挖模板
1. **提取目标亚群**：从肌纤维群中提取 MYOG+/CHRNG+/NCAM1+ 去神经化肌核
2. **Sub-clustering**：看是否有早期 vs 晚期去神经化异质性
3. **scTour (VAE)**：无监督伪时间轨迹（分路线独立跑，避免混淆）
4. **snATAC chromVAR**：MAF motif 偏差评分，Footprinting 验证结合位点
5. **SCENIC GRN**：推断 MAF → MYH1/MYH2/MYH4 调控网络

### Figure 结构
- UMAP highlight 目标亚群
- 6组堆叠比例图 —— 预期 Young(1-2%) < Old(5-8%) << Old+T2D(12-15%)
- scTour 伪时间轨迹（关键基因沿轴变化：MAF↓ MYOG↑ RUNX1↑ MYH2↓）
- MAF motif 偏差 + ATAC track + SCENIC 网络图

### 核心原则
**不是预想好通路去验证**，而是 Phase 2 的 DEG 富集到什么通路就追什么。
如果 DEG 富集到 "神经肌肉接头/突触信号/肌生成" → 追去神经化
如果 DEG 富集到 "线粒体/氧化磷酸化" → 追线粒体自噬/MQC
如果 DEG 富集到 "炎症/免疫" → 追免疫细胞通讯

## Phase 4 — 多组学整合与模型（MOFA+ / RGCCA + 概念图）

### 方法
- **MOFA+**：snRNA(基因表达) + snATAC(基因活性评分) 双模态
  - 提取 Factor 1（衰老因子）vs Factor 2（T2D 因子）
- **RGCCA**：交叉验证 MOFA 结果
- **Peak2GeneLinks**（ArchR）：看衰老/T2D 下哪些 peak-gene 关联被破坏

### Figure 结构
- Factor 1 × Factor 2 散点图（6组着色）
- 每组因子的 boxplot/UMAP 着色
- Factor 荷载基因的 GO 富集

### 关键解读
- 疾病和衰老在 factor 空间**完全重合**（仅 Factor 1 分离）
  → T2D = 加速衰老（重要结论，可写入摘要）
- 疾病和衰老在 factor 空间**特异地分离**（Factor 2 有额外分离）
  → T2D 有独立于衰老的损伤机制（更创新）

### 概念模型："干预可逆性梯度"
```
Young → 运动后几乎全可逆（染色质可塑性强）
Old → 运动部分可逆（去神经化可部分擦除）
Old+T2D → 运动高度有限（染色质被"锁定"）
```
每个箭头上标注你的数据证据（如 MAF motif 可及性数据、线粒体基因启动子状态）

## 如何从已发表论文学习分析结构

### 步骤
1. **搜**：找 `{species} {tissue} {direction} {technique}` → 至少 3 篇
2. **解构**：画每篇论文的 Figure → 每张 Figure 回答什么问题？
3. **对应**：标注技术对应表
   ```
   Figure 1: UMAP (snRNA) → 你的 Phase 1
   Figure 2: DEG heatmap → 你的 Phase 2
   Figure 3: Trajectory/Motif → 你的 Phase 3
   Figure 4: Multi-omics factor → 你的 Phase 4
   ```
4. **找 Gap**：哪些 Figure 你的数据能做但别人没做？→ 这是你的创新
5. **记录**：参考论文的方法结构记录到此文档的 `## 案例` 部分

## 阶段性审查点

每个 Phase 结束后，回答：
- **继续**：结果与预期一致 → 进入下一 Phase
- **转向**：结果出乎意料但有趣 → 调整方向，聚焦新发现
- **终止**：效应量极小，数据质量不行 → 报告用户，讨论原因
