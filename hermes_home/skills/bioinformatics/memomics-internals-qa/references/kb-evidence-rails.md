# 知识库证据铁轨与结构（源码取证，2026-10）

知识库是 MemOmics 相对同类系统（Biomni / Paper2Agent / BioMaster / Co-Scientist）
的**结构性差异**所在：那几篇的知识要么不存在、要么绑死单篇、要么无门槛；
MemOmics 赌的是「**知识必须带出处、必须分组织、必须能回溯**」。

## 一、三道证据铁轨 = 工具层强制拒绝（非文档建议）

实现：`memomics/bio_tools/save_knowledge.py`

| 铁轨 | 位置 | 拒绝条件 |
|---|---|---|
| 铁轨 0 | L206–207 | 名称 / 分类含非法字符 → 拒（**防路径穿越**） |
| 铁轨 1 | L214–216 | `verified=unverified` → **拒**（`force` 仅限 bootstrap） |
| 铁轨 2 | L219–221 | `source=data_driven` 或 `domain_convention` 但 **无 evidence** → **拒** |
| 铁轨 3 | L309–312 | `kb_category` 不在白名单 → 拒 |

**这是硬门禁：工具层面拒绝写入** —— 和「README 里写一句『建议带证据』」完全不是一回事。

> 取证方法：搜 `save_knowledge.py` 里的 raise / reject 分支，确认**拒绝**而非仅警告。

## 二、三知识域 + 五级目录

| 域 | 落盘路径 | 解决什么 |
|---|---|---|
| **biology**（默认） | `<物种>/<组织>/<方向>/<类别>/<assay>/` | **防跨组织串味**——骨骼肌的 QC 阈值不能用到海马（实测两套阈值确实不同：肌肉 snRNA MT%<5%、单细胞放宽到 20%） |
| **common** | `common/<方向>/<类别>/<assay>/` | 物种无关的方法学知识（软件用法、统计规范） |
| **chemistry** | `chemistry/<类别>/` | 化合物 / 试剂 / 条件；类别用 `direction` 传：compounds / pharmacology / reactions / reagents / conditions |

`kb_category` 白名单：`01_生物学知识` / `02_质控参数` / `03_测序方法` / `04_个性化`

## 三、检索与注入（闭环的关键两跳）

- **检索**：`search_knowledge` —— fts5 + **路径加权**（同组织同方向的知识排前面），
  支持**中英文语义映射**（`人 / 人类 / 患者` → `Homo_sapiens`，`小鼠` → `Mus_musculus`）。
- **注入辩论**：`debate_analysis` 的 `knowledge_base_info` + `auto_kb`（默认开，
  按 物种+组织+方向 自动检索注入）——所以辩论的正反方**不是空手吵**。

**闭环全貌**：分析产出 → **带证据回写**（`source=data_driven` + 运行证据）
→ 下次检索复用 → 辩论时再被引为论据。
这才是「减少错误」的机制来源，不是「建了个静态库让人查」。

## 四、规模与构成：统计口径必须现场算，别背

实测（2026-10）**237 条结构化 YAML**。但**构成比总数更重要**：

- `*_empirical.yaml`（技能自进化的运行记录）**88 条**
- 真正从文献提炼的 `paper_*` **仅 19 条**
- 其余为方法/组织类条目

⛔ **不要把「自进化运行日志」混算成「文献知识」**——汇报时会被追问。
统计命令：`search_files(target="files", pattern="*.yaml", path="memomics/knowledge_base")`
后按文件名前缀分类计数。

## 五、诚实边界（必须主动说）

| 边界 | 说法 |
|---|---|
| **可溯源 ≠ 为真** | 铁轨保证 evidence **非空**，不保证 evidence **是文献引用**。实测有条目 evidence 字段填的就是 `record_run` 的日志行 —— 满足「非空」，但不是一个引用 |
| 门槛拦什么 | 拦得住「**空手入库**」；拦不住「**证据质量差**」 |
| 覆盖不均 | 骨骼肌 / 海马 / 肝脏 / 心脏较厚；其他物种组织基本只有 `default_kb_method` 种子条目（条目自身标着 `source: default_seed`、`从摘要推断 + 默认值`）——是**占位**，不是验证过的知识 |
| 体量 | 文献知识规模还撑不起「很大程度上减少错误」这个说法；当前能保证的是「**参数有据可查、不会张冠李戴**」 |

## 六、汇报措辞模板

> 知识库确实是 MemOmics 相对那几篇的结构性优势（**带证据回写 + 分组织隔离 + 进辩论** 三位一体），
> 但它现在的文献知识体量还小 —— 能保证的是「参数有据可查、不会张冠李戴」，
> 真正的减错还需要文献知识继续灌进来。
