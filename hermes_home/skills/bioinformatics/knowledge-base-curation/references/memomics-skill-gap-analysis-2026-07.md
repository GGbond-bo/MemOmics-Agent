1. **分析端强，临床端弱** — 286 个 skill，临床相关 <5 个
2. **转录组饱和，代谢/表观空白** — scRNA-seq 有 44 个 skill，代谢组学 0 个
3. **英文生态完整，中文生态缺失** — 无中文文献检索、中文写作辅助
4. **分析能力强，写作能力弱** — 能跑全流程但不能自动写论文
5. **已有 paper-summary 和 academic-paper-writing** — 但两者之间缺少"分析结果→论文初稿"的桥梁
