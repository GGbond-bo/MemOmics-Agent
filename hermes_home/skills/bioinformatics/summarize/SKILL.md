# 智能总结 (summarize)

智能总结分析结果/文献/对话/数据：自动识别用户想总结什么，生成结构化摘要。

## 适用场景

- **分析结果总结**：分析跑完后，自动总结关键发现（细胞数、聚类数、差异基因数、关键通路）
- **文献要点提取**：用户给了文献后，提取核心发现、方法、数据量
- **对话浓缩**：长对话后生成摘要，避免上下文过长
- **数据概况**：scan_data 后自动总结数据基本信息（物种、细胞数、基因数、注释状态）

## 触发条件

当用户消息包含以下模式时自动触发：
- "总结一下" / "帮我总结" / "总结结果"
- "概述" / "摘要" / "归纳"
- "总结分析" / "总结文献" / "总结数据"
- "summarize" / "summary"

## 工作流程

1. **识别总结对象**：根据上下文判断用户想总结什么
   - 如果刚跑完分析 → 总结分析结果
   - 如果刚读了文献 → 总结文献要点
   - 如果对话很长 → 总结对话历史
   - 如果刚 scan_data → 总结数据概况
2. **提取关键信息**：
   - 分析结果：细胞数、聚类数、标记基因、差异基因、通路富集
   - 文献：研究问题、方法、样本量、关键发现、局限性
   - 对话：用户需求、已完成步骤、当前状态、待办
   - 数据：物种、组织、细胞数、基因数、注释状态、QC 状态
3. **生成结构化摘要**：按 背景→方法→结果→结论 结构输出
4. **验证关键数字**：摘要中所有数字必须来自实际数据，不能编造

## 输出格式

### 分析结果总结
```
## 分析结果总结

### 背景
- 物种: 人类 | 组织: 骨骼肌 | 样本: 6个(3年轻+3老年)
- 数据量: 24,580个细胞, 28,031个基因

### 方法
- 质控: 过滤 <200 基因 / >20% MT 的细胞
- 降维: PCA → UMAP
- 聚类: Louvain (resolution=0.5)
- 注释: SingleR + 手动确认

### 关键发现
1. 识别出 8 个细胞亚型
2. 老年组中炎症细胞比例显著增加 (p<0.01)
3. 差异基因富集到 TNF 信号通路

### 结论
老年骨骼肌中炎症微环境改变可能是衰老相关功能下降的关键因素。
```

## 使用示例

### 总结分析结果
```
用户: 总结一下刚才的分析结果
→ summarize 识别: analysis_result
→ 提取: 8个亚型、3个关键差异通路、24580细胞
→ 输出结构化摘要
```

### 总结文献
```
用户: 帮我总结这篇文献的要点
→ summarize 识别: literature
→ 提取: 研究问题、方法、样本量、发现
→ 输出文献摘要
```

## 🗣️ 辩论机制（debate_analysis）

本 skill 在执行后，如果涉及**参数选择、方法决策、结果判断**等不确定环节，**必须**调用  工具进行多角色辩论。

### 辩论规则
- **正方 3 位专业编辑**（各自独立，互相看不到）：生物学编辑 / 统计学编辑 / 生信编辑
- **反方 4 位专业编辑**（各自独立，互相看不到，也看不到正方）：生物学编辑 / 统计学编辑 / 生信编辑 / 历史经验编辑
- **裁判**：看到所有 7 方论点后给出裁决 + 置信度（高/中/低）
- **上下文隔离**：每个编辑是独立的 LLM API 调用，messages 只包含自己的 prompt
- **分科知识库**：生物学编辑用 biology_kb / 统计学编辑用 statistics_kb / 生信编辑用 bioinfo_kb / 历史经验编辑用 history_errors
- **辩论结果自动归档**到 results/.../log/debate_*.json

### 触发场景
- 参数选择有多个合理选项时（如分辨率 0.4 vs 0.6 vs 0.8）
- 结果可能受方法选择影响时（如不同注释方法给出不同结果）
- 生物结论需要验证可靠性时
- QC 阈值不确定时（如 MT% 阈值 10% vs 15% vs 20%）

### 不触发场景
- 参数有明确知识库推荐且无争议时
- 纯计算步骤（如保存文件、读取数据）
