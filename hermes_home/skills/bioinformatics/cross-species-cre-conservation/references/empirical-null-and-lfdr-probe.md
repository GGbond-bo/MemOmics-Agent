## 1. docx 正文取证：两个必踩的坑

```python
import os, re, zipfile, glob
docx = sorted([d for d in glob.glob(BASE + "/*.docx")
               if not os.path.basename(d).startswith("~$")],   # ← 坑①
              key=os.path.getmtime)[-1]
with zipfile.ZipFile(docx) as z:
    xml = z.read("word/document.xml").decode("utf-8", "ignore")
txt = re.sub(r"<[^>]+>", "", xml)                              # ← 坑②
```

| 坑 | 症状 | 修复 |
|---|---|---|
| **① `~$xxx.docx` Word 锁文件** | `zipfile.BadZipFile: File is not a zip file`——它在 mtime 排序里**永远最新**，`sorted(...)[-1]` 必中 | 过滤 `os.path.basename(d).startswith("~$")` |
| **② docx 是 zip 不是文本** | 直接 `open().read()` 得到乱码/二进制 | 读 `word/document.xml` 后 `re.sub(r"<[^>]+>", "", xml)` 去标签 |

## 2. 经验零假设标定（Efron 25–75 百分位稳健估计）

```python
def emp_null(z):
    q25, q50, q75 = np.percentile(z, [25, 50, 75])
    return q50, (q75 - q25) / (norm.ppf(.75) - norm.ppf(.25))
```

### 实测（all 口径 `M2/pipeline_out_all/v5_substitutability_all.csv`，16,010 元件）

| 轴 | μ | σ | 判读 |
|---|---|---|---|
| Z_human | **+1.063** | **4.856** | 严重过度离散（σ≈4.86×名义值）+ 全局正漂移 |
| Z_monkey | +0.072 | 2.765 | σ≈2.77× |

- 中心区（双侧 \|z−μ\|<1.5σ）`n=11,023`，`rho0 = −0.057`（零假设下两物种近乎不相关）
- `pi0 = 0.9172`（中心区占比 0.6885 / 理论 0.7506）
- `|Z_human|` 分位：中位 **3.36** / P90 11.27 / P99 24.70 / P99.9 38.24 / max 70.89
  —— 若真为 N(0,1) 零假设，中位 \|Z\| 应 ≈ 0.674。**中位 3.36 = 整体量级被抬高约 5 倍。**

### 关键推论

```
|Z₁| ≥ 12  在经验零假设下 = (12 − 1.063)/4.856 ≈ 2.25σ  → 双侧 p ≈ 0.024
文档里"12" 读起来像 12σ 铁证，实际只是 ≈2.25σ ⇒ 它是【规模门槛】不是【显著性门槛】
```

与主 SKILL.md 探针 4（τ 敏感性扫描：1.96→20 全低于基准，只有 τ=30 翻正）**独立互证**。

### sigma>1 的可疑来源排查顺序（未查清前不得主张"高置信"）

1. **p 值用的 n 是供体数还是 tile/细胞数**——用 tile 数代入相关检验会系统性夸大约 √(n_tile/n_donor) 倍；
2. **Stouffer `ΣZ/√n` 的独立性前提**——同一供体在多个 tile 上的效应不独立时，`√n` 归一化不足；
3. **是否做过全局居中**——本数据人侧 median Z = +1.06（应≈0，见主 SKILL 探针 3 / 修复 ③）。

## 3. 二维经验贝叶斯 + local FDR 探针

### 配方（4 步，全量 16,010 元件 5.8 秒）

```python
# 1) 二维直方图 → 高斯平滑 → 联合密度 f
H, xe, ye = np.histogram2d(np.clip(z1,-80,80), np.clip(z2,-80,80),
                           bins=[np.arange(-80,80.5,0.5)]*2)
f = gaussian_filter(H, sigma=1.5) / (H.sum()*0.25)

# 2) 二维零假设密度 f0（含 rho0）
C = np.sqrt(1 - rho0**2)
u1 = (G1-mu1)/s1; u2 = (G2-mu2)/s2
f0 = norm.pdf(u1)/s1 * norm.pdf((u2-rho0*u1)/C)/(s2*C)

# 3) lfdr 网格 → 逐元件取值
lfdr = np.clip(pi0*f0/np.maximum(f,1e-300), 0, 1)

# 4) 五态判定（sig = 经验零假设下双侧 p<0.05；Q=0.05）
#    A 同向可信      : sig1 & sig2 & 同号 & lfdr≤Q
#    B 反向可信      : sig1 & sig2 & 异号 & lfdr≤Q
#    C 单侧可判定    : sig1 ^ sig2
#    D 双侧但证据不足: sig1 & sig2 & lfdr>Q
#    E 无信号        : 其余
```

脚本：`scripts/ebayes_lfdr_probe.py`（跑完输出 `lfdr_probe_summary.json` + 散点/热图）。

### 实测结果

| 状态 | 元件数 | 占比 |
|---|---|---|
| A 同向可信 | **106** | 0.66% |
| B 反向可信 | **168** | 1.05% |
| C 单侧可判定 | 2,528 | 15.79% |
| D 双侧但证据不足 | 146 | 0.91% |
| E 无信号 | 13,062 | 81.59% |

- 双侧过阈 420，其中**同号仅 156（37.1%）**，独立零假设期望 50%
- 符号置换（保 \|Z_m\|、破方向配对，N=20,000）：观测 156 vs null **209.8 ± 10.1 → z = −5.33**
- 同一数据换成现行阈值法（\|Z_h\|≥12 + 猴侧经验零假设显著）：强元件 1,404 / 猴侧显著 322 / **同向 123 : 反向 199**

### 判读（可复用）

| 该方案救什么 | 该方案不救什么 |
|---|---|
| ✅ **逐元件误差控制**（lfdr 不依赖被否的循环分母，替代 12.3× 那类论证） | ❌ 效果层结论——lfdr 口径下**反向仍多于同向**（168 > 106） |
