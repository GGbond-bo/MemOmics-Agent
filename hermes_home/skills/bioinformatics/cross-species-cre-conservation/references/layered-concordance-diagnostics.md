# 分层诊断：同向率/一致性统计量的结论是「生物学」还是「统计量产物」

> 触发句：「**当前计算的方法还有可能改变吗？能设计更好的办法吗？**」「换主口径到底要换成什么」
> 「同向率是怎么算的？为什么这么低？」
> 适用类：任何 **率 / 一致性 / concordance / sign-match** 类指标（跨物种同向率、精度-召回、
> 富集命中率、跨数据集复现率）在主指标被质疑、或要做主口径替换时。

---

## 0. 先抓现行定义（不要凭印象谈"配对了多少"）

本项目的同向率定义只有一行（`scripts/21_null_convention_comparison.py:29-33`）：

```python
sd = np.sign(zh) == np.sign(zm)      # 逐基因比较符号，等权 1 票
GLOBAL_RATE = float(sd.mean())        # 46.36%
strong = np.abs(zh) >= 12.0           # 主体侧强效应池
gate   = strong & (pm < 0.05)         # 门控触发
```

**三个隐含选择**（三个都能单独替换，且都不改数据）：
① tile→基因的聚合统计量 = Stouffer `Z = ΣZ_i/√n`（**假定 tile 独立**）
② 观测单位 = **基因级单点**
③ 主指标 = **全局等权平均**

⚠️ 谈"改进算法"前必须先把这三条抓出来 —— 三者混在一起谈会得出"这是数据性质"的错误结论。

## 1. 探针 A · 按主体侧效应强度分层（先分清「稀释」还是「梯度」）

实测（人猴海马，n = 16,029 基因，`M2_repro_gene_conservation_all.csv`）：

| \|Z_h\| 区间 | 基因数 | 占比 | 同向率 |
|---|---|---|---|
| [0,1) | 2,827 | 17.6% | **0.4938** |
| [1,2) | 2,436 | 15.2% | 0.4709 |
| [2,4) | 3,797 | 23.7% | 0.4730 |
| [4,8) | 3,897 | 24.3% | 0.4562 |
| [8,12) | 1,663 | 10.4% | 0.4402 |
| **[12,∞)** | 1,409 | 8.8% | **0.4131** |

**两种截然不同的读法（必须先分清，否则归因全错）**：

| 形态 | 含义 | 处置 |
|---|---|---|
| **弱池 ≈50%、强池 <50%，单调下降**（本次） | 存在**真实的反向梯度**；全局率低**不是**被噪声基因稀释 | 往探针 B/C 走，判它是生物学还是统计量产物 |
| 弱池显著 <50%、强池 ≈50% | 才是"被无信号基因稀释" | 改用条件率即可解决，不必换统计量 |

🔴 **禁止**：不做分层就直接说"因为分母里噪声基因太多所以被稀释到 50%" —— 本次实测**恰好相反**（弱池 0.4938 最接近 50%）。

## 2. 探针 B · 长度混杂分解（决定性，但有一个恒等式陷阱）

### 2.1 混杂确认

```
corr(|Z_h|, n_tiles_h)     = 0.506
corr(|Z_m|, n_tiles_m)     = 0.400
corr(n_tiles_h, n_tiles_m) = 0.726
corr(|Z_h|, |Z_m|)         = 0.225
```

机制：Stouffer `ΣZ/√n` 假定 tile 独立；tile 相关时（同一基因内高度相关）分母 `√n` 偏小 ⇒
**|Z| 随 tile 数系统性膨胀**；而两物种长度相关 0.726 ⇒ 长基因两侧同时膨胀
⇒ 真实同源配对"共同触发"必然多于随机配对 ⇒ 置换检验的 1.33× 里含长度成分。

### 2.2 🔴 恒等式陷阱（本次实际踩中，务必避开）

按 `n_tiles` 分层、算每层同向率、再按 n 加权平均 —— **结果必然恒等于全局率**。
这是加权平均的**恒等式**，不是检验，信息量为零。

实测输出（我第一版就报了这个数，是错的）：

```
全局同向率           = 0.4636   (n=16029)
长度匹配后同向率(MH) = 0.4636      ← 恒等式，无信息量！
```

**真正的检验 = 层内强-弱差 对比 全局强-弱差**：

| 量 | 值 |
|---|---|
| 全局强-弱差（\|Z_h\|≥12 vs <12） | **−0.0554** |
| 层内强-弱差（按 \|Z_h\| 中位数切半，5×5 联合分层加权） | **−0.0186** |
| ⇒ 长度解释掉的份额 | **约 2/3** |

> 推广：**任何"分层后重算率"的操作，都要先问一句"这个加权平均是不是恒等于总体率"**。
> 若是恒等式 → 改报"层内效应差 vs 总体效应差"，或"观测 vs 层内匹配零期望 + 配对 z"。

### 2.3 另一条可选的等价检验

不重算率，而是**在分层内做匹配零假设**：按 `(n_tiles_h × n_tiles_m)` 五分位联合分层，
层内保持配对结构做置换 → 得匹配零期望 → 报 (观测率, 匹配零期望, 配对 z) 三元组。
这条比 2.2 更强（能出显著性），但要求层内样本量足够。

## 3. 探针 C · 层内方向一致性（判「生物学 vs 统计量产物」的决定性判据）

在每个 `(n_tiles_h, n_tiles_m)` 层内，按 `|Z_h|` 中位数切强弱两半，算同向率差：

### 🔑 判据（可推广到任何分层裁决）

> **若效应的符号随混杂层翻转（本次：短基因层 +0.03、长基因层 −0.08），则该结论主要是
> 「统计量 × 混杂」的交互产物，不是生物学结论。**
> 真实的生物学效应不会在混杂分层里翻转符号。

本次结论：现行口径下的"系统性反向"，**大概率是「Stouffer sum 型 Z × 基因长度」造出来的技术假象**。

## 4. 探针 D · 加权（旁证，用来判断"该不该用等权+全局平均"）

| 加权方式 | 加权同向率 |
|---|---|
| `min(\|Z_h\|, \|Z_m\|)` | 0.4393 |
| `\|Z_h\|·\|Z_m\|` | 0.4277 |
| 等权（现行） | 0.4636 |

**加权后更低** ⇒ 幅度加权放大的是"反向"成分 ⇒ "逐基因等权 + 全局平均"不该当主指标。

## 5. 可替换的 5 个环节（回答"能不能设计更好的办法"）

| 环节 | 现行 | 问题（已实测） | 替代 |
|---|---|---|---|
| ① tile→基因聚合 | Stouffer `Z=ΣZ/√n` | 假定独立 → 长基因 Z 膨胀（corr=0.506） | **Brown 法** / 有效 tile 数 `n_eff` 校正 / `z̄=ΣZ/n` |
| ② 观测单位 | 基因级单点 | 长基因内部异质被抹平 | 统一网格 bin 级，**折叠到基因**后再统计 |
| ③ 加权 | 逐基因等权 | 无信号基因各贡献≈50% | 效应量加权 / 或只报条件率 |
| ④ 零假设 | 打乱同源配对 | 保留长度结构 → 期望算错 | **`(n_h × n_m)` 联合分层匹配零假设 + 配对 z** |
| ⑤ 主指标 | 全局率 | 口径敏感、信息量低 | **剂量-反应斜率**（条件率随主体侧强度变化） |

### 5.1 方法学依据（已回原文核实，勿凭记忆引用）

- **`ΣZ/√n` 的独立性假定与 LD 问题同构**：SNP 在基因内因 linkage disequilibrium 相关，
  而 Fisher/Stouffer 类方法假定独立，会破坏 type I error 控制。
  → **Cinar O, Viechtbauer W. "A Comparison of Methods for Gene-Based Testing That Account
  for Linkage Disequilibrium." Front Genet 2022.** **PMID 35601489** / doi:10.3389/fgene.2022.867724。
  原文结论（逐字）：*"standard methods for this purpose (e.g., Fisher's method) do not account
  for the dependence among the tests due to linkage disequilibrium"*；模拟比较后
  **Brown's method 对基因特征最稳健**，且多数场景下功效优于 Bonferroni。
  **本项目映射**：tile 之于基因 ≈ SNP 之于基因（都是"单元内相关、方法假定独立"）。
- **相关 p 值合并的现代实现**：**metacp — BMC Bioinformatics 2025, PMID 40253343**
  （doi:10.1186/s12859-025-06126-z，通用包，支持 dependent / independent 两种）。

## 6. 推荐设计（三步，可直接落地）

```
① 换聚合统计量  Z = ΣZ_i/√n  →  z̄ = ΣZ_i/n（长度中性）
                              或 Brown 校正版 Z
② 换零假设      打乱同源配对  →  (n_tiles_h, n_tiles_m) 五分位联合分层，
                              层内保持配对结构做置换 → 匹配零期望
③ 换主指标      全局率        →  条件率曲线：按 |z̄_h| 分位，
                              每个点给三元组 (观测同向率, 匹配零期望, 配对 z)
```

**收益**：把"全局率是否 < 50%"这个**零假设依赖、口径敏感、信息量极低**的命题，
换成"随主体侧强度单调变化"的**可检验斜率**。

**注意与专利落点的关系**：三步里 ②③④ 是"面向测序数据的处理手段"（可顶 A25.1(2)），
⑤ 属统计报告规范。哪些进独权、哪些进从权，取决于已锁定的权项重心 —— **不要自行改**。

## 7. 诚实边界（汇报时必须一并给出，缺一即为过度声称）

1. **层内加权差仍为负（−0.0186）** ⇒ 长度不能解释全部。
   正确表述是「**现行"系统性反向"这个强结论站不住**」，**不是**「正向已成立」。
2. **换口径后的"翻正"多半是别人的临时构造统计量**。本次审计方在 bin 级 z̄ 口径下得到
   剂量-反应 0.5233→0.6358（方向与现行相反），但那是"每基因取最强 bin 一个观测"的
   探索性构造，**过匹配零假设前只是假设，不是结论**。
3. **只有"换口径会改变判定方向"时才值得换**；只改幅度 = 立即停止口径纠结
   （判据见 `caliber-switch-impact-attribution.md` 与 `premise-falsified-disposition.md`）。
4. **换口径/改统计量属于方法学层面变更** ⇒ 若它同时影响 claim 落点，
   必须交用户拍板，核实轮不动交付件。
