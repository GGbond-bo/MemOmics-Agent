## 铁律 0 · 定义层问题只答定义层（用户原话「简单一点」）

用户问「**是怎么算的**」时，要的是**那一行公式**，不是归因辩论。

| ✅ 给 | ❌ 不给 |
|---|---|
| 一行定义式 | 统计量语义讨论 |
| 3 行可跑代码 | 归因四探针 / 网格对齐 / 长度混杂 |
| 一行数字 | claim 分层重定位 |
| （可选）该定义的已知弱点 | 「要不要我再算个加权版？」之外的第二、第三个 offer |

## 1. 同向率（concordance rate）—— 只数符号

```python
Z1 = d['Z_human']; Z2 = d['Z_monkey']
conc = (np.sign(Z1) == np.sign(Z2)).mean()      # 7431 / 16029 = 0.4636
```

- 分子 = 符号相同（都升 or 都降）的元件数 = **7431**
- 分母 = 总元件数 = **16029**
- 一句话语义：**这个基因人年龄大了是升还是降，猴也是升还是降？**

**已知弱点（唯一，主动说）**：与 `|Z|` 大小无关 —— `|Z|=0.1` 的小波动与 `|Z|=15` 的强信号**各计一票**。
这正是「没考虑数据情况」的准确所指；改法方向 = 按强度加权（本轮实测加权版更低：`min(|Z_h|,|Z_m|)` 加权 0.4393、`|Z_h|·|Z_m|` 加权 0.4277，均 < 等权 0.4636，见 `layered-concordance-diagnostics.md` 探针 D）。

## 2. 「随机」—— 打乱一侧符号重算（置换零假设）

```python
rng = np.random.default_rng(20260912)
s1  = np.sign(Z1)
null = [(s1 == rng.permutation(np.sign(Z2))).mean() for _ in range(2000)]
```

| 量 | 值 |
|---|---|
| 2000 次均值 | **0.5021**（理论 0.5000：两边独立时同向 = 掷硬币） |
| 标准差 | 0.0039 |
| 极值区间 | 0.4883 – 0.5161 |
| 观测 | **0.4636** |
| 差 | z = **−9.99** |

**两句话回答完**：46% = 符号相同的元件占比（7431/16029）；随机 = 把猴侧符号打乱 2000 次重算均值 50.2%，观测比它低约 10 个 z。

## 3. 三条引用纪律（防串口径）

1. **「随机」≠ 恒等于 50%** —— 50% 只是边际平衡（正号各半）时的特例。边际偏斜时正确基准 =
   `p₊ᵐ·p₊ʰ + (1−p₊ᵐ)(1−p₊ʰ)`（本项目 890 子集 = **50.7%**）。见 `concordance-rate-attribution.md` 探针 0。
2. **本定义（0.4636）与门控 z（+3.85/+3.09/+3.27）是两个不同问题，严禁互相引用**：
   前者比**绝对 50%**（全局池）；后者比**按 |Z₁| 分层后的层内基准**（0.4459/0.4377/0.4289，恒 < 0.5）。
   两者不矛盾——一个说「整体比掷硬币差」，一个说「在同等强度内比同层平均好」。
3. **问「随机怎么算」时不要顺手给归因**。归因（网格未对齐 5–6pp / 长度混杂 2/3 / 全局漂移）在
   `concordance-rate-attribution.md` 与 `layered-concordance-diagnostics.md`，等用户问「**为什么**这么低」再给。

## 4. 附带技巧：产物在、生成脚本找不到时，用产物反解公式

本轮验证门控三档 z 的来源时，grep 一度返回 0（中文路径假阴性，见 `platform-execution-pitfalls` 的 `limit_reason: search_timeout` 条）。
**不依赖脚本也能定案**，三步：

1. **复现**：按候选公式逐 thr 复算 obs/exp/z → 与磁盘 CSV **逐字一致** ⇒ 公式被复现（本次 7/7 含 NaN 行一致）。
2. **看参数漂移方向**：若「期望」列随集合规模**单调漂移**（0.4568 → 0.4289），说明期望是**分层观测率**而非固定先验 —— 这是零假设构造的指纹。
3. **找符号反例**：搜「率 < 0.5 但 z > 0」的行 —— 本次 `thr=0.5`（obs **0.4781**, z **+1.83**）一举证明零假设基准 **< 0.5**，即「z>0」**不可读成「优于随机」**。

⇒ 三条合起来足以在**无脚本**的情况下判定零假设语义（完整四问判据见 `patent-analysis` 的
`references/null-hypothesis-selection-and-circular-null-audit.md` §2；配套探针 `scripts/repro_pertile_gate_z.py`）。
