## 1. 先算门槛，再看结果 —— tile 级 FDR 有硬地板

BH 第一步门槛 = **α / N**。

| 粒度 | N | q<0.05 所需最小 p |
|---|---|---|
| 5000bp tile（人） | 5,555,162 | **9.0e-9** |
| 500bp tile（猴 all 版） | 5,296,656 | 9.4e-9 |
| 启动子 / promoter 级 | ~2×10⁴ | **2.5e-6** |

**症状指纹（一眼可判）**：不同行的 `p` 差好几倍，而 `q` **一字不差是常数**。
本次实测：6 行 `p` 从 0.115 → 0.845，`q` 全部 `0.9999978`。BH 包络落在平坦段 ⇒
全表无一能过 ⇒ `q < α & r > 0` **必然 0/0**（与物种、与检验方法都无关）。

**三个数先打出来再谈解释**：
```r
c(min_q = min(out$q), min_p = min(out$p), n_pass = sum(out$q < 0.05))
```
`min(q) ≈ 1` ⇒ **这是判据问题，不是生物学结论**，禁止写进结论段。

### 1a. 顺手验一句恒等式，把\"判据不可达\"与\"q 算错了\"分开

BH 落在平坦段时 **`q_min ≡ p_min × N`**（最小 p 的包络值）。**一行即可判 q 列算术是否正确**：

```python
print(min_q, min_p * N, min_q / (min_p * N))   # 比值 ≈ 1 ⇒ q 算对了，问题纯粹是量级不够
```

实测标本（猴 `M2/monkey_ageDA_all.csv`）：`q_min = 0.6265`，`p_min = 1.1829e-7`，
`p_min × N = 1.1829e-7 × 5,296,656 = 0.6265` ✓ ⇒ **q 列无 bug**，
纯粹是\"现有最小 p 比门槛大 12.5 倍\"（9.44e-9 vs 1.18e-7）。

⇒ **汇报口径**：有这条恒等式才能说\"**判据在当前设计下不可达**\"（而非\"q 算错了\"或\"没有效应\"）。
反推样本量也有用：由 `p_min` 与 `r` 反推自由度可估出 n（标本 n≈21–22），
用于回答\"要多少个体才可能过线\"。

**出路（按推荐度）**
1. **换粒度（唯一根治）**——tile 按 promoter±2kb / 基因体合并，N 降 3 个数量级，
   门槛从 9e-9 松到 2.5e-6，功效立刻恢复，结论还能落到基因（可解释、可主张）。
2. 效应量 / 分位阈值（`|z| ≥ 99.9% 分位`）——**必须在方法里明写**「tile 级 FDR 无法通过、
   改用 top-0.1% 效应量阈值」，否则评审会当成 P 值操纵。
3. 直接对有序趋势 p 做 FDR —— 仍需过 9e-9，先跑一遍确认是否 0。

## 3. 报统计量是 bug 之前，先跑合成自证（本轮真实翻车记录）

本轮连续提出两个"bug"假设，**全部被实测推翻**，其中一个把**代数恒等式**当成了 bug 证据。
固化流程如下，任何一次想报"这个统计量坏了"之前先走一遍。

### 3a. 代数恒等式不是 bug 证据 —— 但它可能是**另一个缺陷**的证据
`p = 2·pnorm(−|z|)` ⟹ `|z| = −qnorm(p/2)` 是**恒等式**，不是"负号被硬编码"。
**判据**：声称"列 X 是列 Y 的换皮"之前，先问一句——**这个关系能不能由定义式直接推出**？
能 → **不要把恒等式本身当作 bug 上报**。

🔴 **但别就此结案 —— 这正是本轮最贵的一次教训**：恒等式成立恰恰说明该统计量
**只是 p 的换皮、不含方向**，这是一个**真实的缺陷**，只是形态与"漏写负号"不同。
两条必须一起说，缺一条就误导：
1. **"漏写负号"是错的归因** → 撤回；
2. **"z 由双侧 p 反推 ⇒ 无方向 ⇒ 下游同向 / 一致性指标全部退化"是成立的缺陷** → 保留。

本次实际后果：我先把 ① 喊得很响、后来安静地撤回，用户读到的净效果是"这条也没事"，
**反而让 ② 这条真缺陷被一起埋掉**。判据与修法见 **§9**。

### 3c. 统计量正确 ⇒ 剩下的可能性只有"对齐"

同一批 40 个数上，**秩统计量与 Pearson 的符号必须一致**（除非重尾到极端）。
本次 6 行全部出现 `r > 0` 而 `J` 远低于 EJ（f1588：`r = +0.141` / `J = 101`，EJ=300）
⇒ **先怀疑两列不是同一行**，而不是先怀疑数据。

**代码级隐患（本次真实存在）**：`r <- r[valid]` 做了过滤，而 `J` / `zJ` / `pJ` **没有做同一过滤** ——
一旦 `valid` 含 FALSE（本次 `零方差移除 = 0` 侥幸掩盖），装配 `data.frame(...)` 时两列会**静默错位**。

⇒ **铁律：所有派生向量用同一个 mask 一起过滤**
```r
r <- r[valid]; p <- p[valid]; J <- J[valid]; zJ <- zJ[valid]; pJ <- pJ[valid]
stopifnot(length(unique(lengths(list(r, p, J, zJ, pJ)))) == 1L)
```

## 4. Jonckheere-Terpstra 有序趋势检验（小样本替代连续回归）

四阶段有序设计（两侧组名字符串完全一致：Young / Middle / Old / Exceptionally old）下，
连续 Pearson 是**模型误设**（组内零方差 + 年龄非等距 + 杠杆效应）。

**★ 显式有序编码 —— 唯一会静默反向的地方**
```r
ORD <- c(Young = 1, Middle = 2, Old = 3, "Exceptionally old" = 4)
g   <- ORD[as.character(stage_col)]     # 禁 factor() 默认字母序（E<M<O<Y 会全反）
stopifnot(!anyNA(g))
```
打印 `data.frame(individual, stage, score)` 逐行核对 Y→1 / M→2 / O→3 / V→4。

```r
J <- 0
for (pr in combn(4, 2, simplify = FALSE)) {
  A <- lcpm[, g == pr[1], drop = FALSE]; B <- lcpm[, g == pr[2], drop = FALSE]
  J <- J + rowSums(sapply(seq_len(ncol(B)), function(q)
        rowSums((B[, q] > A) + 0.5 * (B[, q] == A))))   # 0.5 项 = ties 记半分
}
ni <- table(g); N <- length(g)
EJ <- (N^2 - sum(ni^2)) / 4
VJ <- (N^2 * (2*N + 3) - sum(ni^2 * (2*ni + 3))) / 72
z  <- (J - EJ) / sqrt(VJ); p <- 2 * pnorm(-abs(z))
```

**量纲自查（跑完立刻对）**：跨组配对数 = Σ_{a<b} ni_a·ni_b，**EJ = 跨组配对数 / 2**。

| 设计 | N | 跨组配对 | EJ | sqrt(VJ) |
|---|---|---|---|---|
| 人 4×10 | 40 | 600 | **300** | 41.43 |
| 猴 4/4/6/6 | 20 | — | 124 | 现算 |

**判读要点**
- `z` 分布应以 0 为中心。**中位数 ≈ ±4 ⇒ J 有系统性偏置（或方向编码反了），不是生物学结论。**
- `同向(r 与 z 同号) = 100%` 在 z 单边时是**同义反复**，不作方向一致性证据。
- 小 n（每档 4–6）下 `q < 0.1` 很可能为 0，**这本身就是结果**——改报
  top-500 / top-2000 的方向集中度 + 效应量分位，比"是否显著"信息量大得多。

## 7. 「显著数只有零假设期望的 1/10」的机制诊断（统计量收缩）

**症状**：p<0.05 的 feature 数远**低于**零假设期望（本次 0.47% / 0.39% vs 期望 5%）。
直觉会往\"检验方法选错\"或\"效应不存在\"走——**先做下面两件事，别急着下结论**。

### 7a. 统计量收缩比（最决定性的一步，零成本）

```python
sd_obs = r.std()                       # 或 z.std()
sd_theory = 1/np.sqrt(n - 1)           # Pearson r 在零假设下的理论 sd
print(sd_obs / sd_theory, z.std() / 1) # z 的理论 sd = 1
```

| 量 | 实测 | 理论 | 比值 |
|---|---|---|---|
| 连续版 `sd(r)` | 0.141 | 0.236 | **0.60×** |
| 阶段版 `sd(z)` | 0.619 | 1.0 | **0.62×** |

⇒ **两套口径、同一个收缩比 ⇒ 不是 Pearson 特有，是数据层面的共同成分。**
统计量被系统性压缩到 ~0.6 ⇒ **p 值系统性保守** ⇒ 显著数被压到远低于零假设期望。
**"显著数低于期望"本身不是\"无效应\"的证据，它是\"检验被压缩\"的指纹。**

### 7b. 找共同成分（收缩的来源）

```python
# 取前 2000 个 feature 做 PC1
u, s, vt = np.linalg.svd(X[:2000] - X[:2000].mean(0), full_matrices=False)
print((s**2 / (s**2).sum())[0])        # 本次 → 0.938
print(spearmanr(vt[0], age))           # 本次 → rho = 0.162
```

本次实测：**PC1 解释 93.8%，且与年龄 rho 仅 0.162** ⇒ **主变异是技术性的（深度/覆盖度），不是年龄**。
所有 feature 的个体排序形状雷同 → 每个 feature 的年龄相关都被挤进同一条窄带 → 整体收缩。
**换检验方法碰不到这一层**（这是为什么\"换个更好的统计量\"救不了）。

### 7c. 但必须同时排除\"深度混杂\"这件事本身

```python
print(spearmanr(lib_size_per_individual, age))   # 本次 rho = −0.15, p = 0.52
```
本次**无混淆** ⇒ 收录为**好消息**，写进汇报（否则用户会以为是深度问题）。
⇒ 诊断三元组固定为：**收缩比 → PC1 占比与它跟年龄的关系 → 深度 vs 年龄**。

**汇报口径**：结论定性为「**数据硬限制**」而非「统计方法问题」时，
必须同时给这三条实测；且措辞为「现有数据与口径下检测不到，且检验校准异常已定位」，
**不得**说成「已证明不存在效应」。

## 9. z 值的定义审计 —— 「当前算法对不对」类问题的标准答案（2026-09-13）

**触发**：用户问「**你觉得当前的算法是对的吗？z 值的做法。为什么要这么做呢？**」
或任何「这个统计量的定义对不对 / 为什么要用 z / 换个更好的统计量行不行」的追问。

### 9.0 先读权威脚本，再回答（本轮实证，顺序不可颠倒）

**对话里贴的代码 ≠ 磁盘上交付的脚本。** 本次实测：
`scripts/01_l3_human_ageDA.R`（44 行）与 `01_l3_monkey_ageDA.R`（39 行）
**根本没有 z 列** —— 只有 `r` / `p`（t 反推）/ `q`（FDR）。
带 `J` / `z` / `p_trend` 的那一段是**后来加进对话的版本**，不在交付脚本里。

⇒ 回答"当前算法对不对"之前，**先 `read_file` 读交付脚本正本**，不要凭对话记忆答。
两版并存时，先点明"存在两个版本"，再分别判 —— 与 claim 的"先定版"同一条铁律。

### 9.1 判定：框架对，实现错

| 问题 | 判定 |
|---|---|
| 要不要用 z | ✅ **对** —— 见 §9.3，跨粒度聚合需要可加量 |
| 怎么算出 z | ❌ **错** —— `z = qnorm(p/2)` 是从**双侧 p 反推**，而双侧 p 的定义里 `\|·\|` 已把符号吃掉 |

`z = qnorm(p/2)` 与 `p` **严格单调一一对应** ⇒ **零信息增量**：
`\|z\| ≥ 阈值` ≡ `p ≤ 阈值`，只是换了单位。**"归一化"的功劳属于 `/√n`，不属于 z 变换本身。**

### 9.2 四条机器可判的退化指纹

| # | 指纹 | 实测标本 |
|---|---|---|
| ① | **同行 `r` 与 `z` 符号矛盾** | f1587 `r = +0.081` 而 `z = −4.44`；f1588 `+0.141` / `−4.80`；f1592 `+0.253` / `−3.77` —— 同一行的两个数不可能同时描述一条趋势 |
| ② | **z 分位数全负、不以 0 为中心** | `50/90/99/99.9% = −4.42 / −3.77 / −3.33 / −3.04` |
| ③ | **"同向(r 与 z 同号) = 100%" 是同义反复** | top-K 按 `\|z\|`（= 按 p）排序，z 恒负 ⇒ 该句实际是"\|r\| 最大的 K 个 tile 的 r 全为负"，**不是一致性检验** |
| ④ | **`\|z\|` 依赖 n** | 同一真实效应在 n=20 与 n=200 下 `\|z\|` 差 ≈ √10 倍 ⇒ **跨粒度阈值不可比**（§1 换粒度的坑的另一面） |

🔴 **②③ 是定义假象，必须当轮撤回，不得当数据结论上报。**
本次"z 一边倒全负""同向 100%"两条结论即由此产生，均已撤回。

### 9.3 为什么还要用 z（动机是对的 —— 别把动机一起否掉）

| 动机 | 为什么必须 |
|---|---|
| **可加性（根本理由）** | 门控 `z̄ = ΣZ/√n` 要求单元 Z 近似 N(0,1) 且可加 —— **p 值不可加，z 可加**。没有 z 就没有跨粒度聚合（独权 S1.5 的技术基础） |
| 统一尺度 | Pearson 给 t(df)、Spearman 给 rho、JT 给 J（秩和量纲）—— 三把尺子必须统一到 N(0,1) 才能放同一阈值下比 |
| 阈值可比 | 定一个门槛（`\|z̄\| ≥ 1.2/1.5`），不必为每种检验单独定 p 阈值 |

⇒ **错的是"用 p 的反变换冒充统计量的标准化"，不是"用 z"本身。**
回答用户时必须把这两半分开说，否则等于把整个统计框架一起否掉。

### 9.4 正确写法（三选一，均有符号）

```r
zJ       <- (J - EJ) / sqrt(VJ)             # ✅ 首选：检验统计量标准化，天然有符号，H0 下 ≈ N(0,1)
z_signed <- sign(r) * qnorm(1 - p_trend/2)  # ✅ 保留 p 反推，但把方向补回来
z_fisher <- atanh(r) * sqrt(n - 3)          # ✅ 相关系数的标准做法（Fisher）
```

⚠️ **本轮最刺眼的一条**：`zJ <- (J - EJ)/sqrt(VJ)` **原版代码里本来就有**，
后来改成 p 反推**反而把方向丢了** —— 等于**从对的改成了错的**。改统计量前先看原版是不是已经对。

### 9.5 连带影响：哪些结论要撤、哪些不动

| 前几轮结论 | 判定 |
|---|---|
| 「z 分位全负 / 不以 0 为中心」 | ❌ 定义假象，**撤回** |
| 「同向(r 与 z 同号) = 100%」 | ❌ 退化指标，**撤回** |
| 全局同向率 vs 匹配零假设（用 `sign(Z₁)` vs `sign(Z₂)`） | ⚠️ **不受本次影响**（元件级相关系数本身有符号）—— 但该零假设另有**循环性**问题，见 `patent-analysis` 的 `references/null-hypothesis-selection-and-circular-null-audit.md` |

### 9.6 ✅ 已闭合（2026-09-13）：三档 z 的来源 = 条件性零假设，**不是** p 反推

**追溯结论（用户追问「查这三个 z 的实际算法来源」时先读这段）**：

| 项 | 值 |
|---|---|
| 生成脚本 | `交付_跨物种衰老可替代性专利/scripts/`**`03_three_baseline_comparison.py`** |
| 期望基准 | **L39–42** `q = qcut(\|Z_h\|,10)` → `base = Series(sd).groupby(q).mean()` → `p_base = base.reindex(q)` |
| 门控集合 | **L96–101** `m = (\|z̄_h\|≥thr) & (\|z̄_m\|≥thr)`，`z̄ = Z/√max(n,1)`（**L92**） |
| z 的公式 | **L59–62** `obs=sd[mask].mean(); exp=p_base[mask].mean(); var=Σp(1−p)/n²; z=(obs−exp)/√var` |

**复现逐字一致**（输入 `P3_L1_data/M2_repro_gene_conservation_all.csv`，N=16,029）：

| thr | n_out | 观测率 | exp_rate | z（复现） | z（磁盘） |
|---|---|---|---|---|---|
| 0.3 | 4534 | 0.4532 | 0.4568 | −0.49 | −0.49 ✓ |
| 0.5 | 1506 | **0.4781** | 0.4546 | **+1.83** | +1.83 ✓ |
| 0.8 | 240 | 0.5750 | 0.4499 | +3.90 | +3.90 ✓ |
| **1.0** | **75** | 0.6667 | 0.4459 | **+3.85** | +3.85 ✓ |
| **1.2** | **24** | 0.7500 | 0.4377 | **+3.09** | +3.09 ✓ |
| **1.5** | **8** | 1.0000 | 0.4289 | **+3.27** | +3.27 ✓ |

**① 三个 z 不是 p 的反变换** ⇒ §9.1 的\"无方向\"缺陷**不波及它们**。它们由 `obs`/`exp` 两个**观测率**直接构造，可正可负、可动。

**② 但它们的语义被读宽了（这才是真正的风险）**：
`exp_rate` 是\"**同等 |Z₁| 十分层内的观测同向率**\"，而它**恒 < 0.5**（0.4568 → 0.4289）
⇒ 🔴 **决策性反例：`thr=0.5` 行 `concordance = 0.4781`（低于掷硬币）而 `z = +1.83`（正）**
⇒ **`z > 0` ≠ `同向率 > 50%`**，即 **`z=+3.85` 不能被读成\"门控能挑出同向/可迁移元件\"**，
只能读成\"**门控集合比同等 |Z₁| 强度的其他元件更同向**\"（层内残余富集）。

这也消解了表面矛盾：**\"全局 46.36% vs 随机 50%（z=−6.66）\"与\"门控 z=+3.85\"并不冲突** ——
一个比**绝对 50%**，另一个比**层内均值 0.4459**（本身就 < 50%）。

**③ 循环性量级（必须收紧措辞，勿冤判）**：被检验集合**横跨多层**（thr=1.0 落层 3–9），
**自我包含仅 0.2%–0.7%**（thr=1.5 最轻 0.2%）⇒ **不满足**循环零假设三判据中的\"包含性\"
⇒ **不是恒等式、检验会失败，判\"循环\"是过重的**（本轮曾一度暗示\"同一循环构造\"，已撤回）。
**但仍是条件检验**（期望来自观测自估），**不得用来主张\"优于随机\"**。
（`thr=0.3` 行自我包含达 **28.3%**，那一档才需按循环口径警惕。）

**④ 分层变量与选择变量共用 Z₁**：分层用 `|Z₁|`，而选择用 `|z̄₁|=|Z₁|/√n_h` 与 `|z̄₂|`
⇒ \"层内可比\"只是近似成立，且门控额外选了 Z₂ 的强度。**这一条在 L14–16 的设计注释里没有声明。**

**⑤ 送审时的最小修正（不必删数字，改写语义即可）**：把\"门控筛出同向元件（z=+3.85）\"
改成\"**在同等 |Z₁| 强度条件下，门控集合的同向率高于同层基准（层内条件检验）**\"，
并**把 `exp_rate` 一并列出**（0.4459 / 0.4377 / 0.4289）——列出来反而更安全：
它同时暴露\"基准本身低于 50%\"，与 §三（十二）的诚实披露口径一致。

**方法论推广**：拿到任何\"匹配零假设 z\"，先做四问 —— ① 期望从哪儿来（外部先验 / 置换 / **观测自估**）；
② 被检验集合落在其所属层的比例（≈100% 在单层 ⇒ 恒等式、数值即不可用）；
③ **`exp` 是否低于无信息基准**（低于 ⇒ 禁称\"优于随机\"）；
④ 同一常数是否被复用到规模不同的多个集合（是 ⇒ 伪匹配）。
完整判据表 → `patent-analysis` 的 `references/null-hypothesis-selection-and-circular-null-audit.md` §2。
