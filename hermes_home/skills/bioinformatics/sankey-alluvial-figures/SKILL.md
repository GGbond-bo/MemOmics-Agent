# 桑基 / 冲积图：布局归一化与几何自检

桑基图的"标签没对齐色块""间隔忽大忽小""节点叠在一起"，**根因几乎总在布局归一化，不在标签或配色**。
本 skill 把踩过的坑固化成两条铁律 + 一套可断言的几何自检。

## 何时用

- 画/改桑基、冲积、流向图：亚群 ↔ 基因、三组共同 DEG（UP/DOWN）、时间点流向、通路↔基因
- 用户说：标签没跟色块对齐 / 亚群和基因要跟自己的色块对齐 / 节点叠住了 / 间隔太大 / 往上挪一点
- 同一张图要出 UP + DOWN（或多种权重规模）的成对版本时 —— **这是最容易被"只错一张"骗过去的情形**

## 铁律 1：间距/高度一律按「可用高度」归一，绝不按数据权重

```python
# ❌ 错：把权重之和当成比例系数
gap    = GAP * tot / (n - 1)     # tot = 权重之和（UP 图 = 102）→ 间隙总和 2.244
usable = 1.0 - gap * (n - 1)     # = -1.244（负！）

# ✅ 对：间隙 = 整列高度的固定比例，与权重量级解耦
gap    = 0.10 / (n - 1)          # 全列固定 10% 用于间隙
usable = 0.90                    # 其余 90% 按权重分配
```

- `usable < 0` ⇒ 每个节点高度为负 ⇒ **相邻节点区间重叠**（实测 ITIH4 `[1.00,1.27]` 压在
  MEF2C-AS1 `[0.89,1.14]` 上）⇒ 后画的色块盖住前一个的下半截，而**标签仍画在真实中心**
  ⇒ 视觉上就是"标签掉到色块下沿"，越靠列顶偏得越多（实测 72 / 53 / 27 px）。
- **判据：间隙的分母永远是可用高度（1.0 或画布高），不是 `sum(weights)`。** 任何间距参数都套这一条。

### 推论：只有一张图错位 ≠ 标签 bug

同样代码下 `tot` 大的那张才会把 `usable` 压成负数。实测 UP `tot=102` 崩、DOWN `tot=24`
`usable=0.472` 侥幸正常 —— 用户看到的就是"UP 图不对齐，DOWN 图好好的"。
⛔ 不要顺着"只错一张"去调单张图的标签偏移量；**先查两图的节点区间是否重叠**。

## 铁律 2：出图前跑像素级几何自检（比人眼看图可靠）

三项硬指标，全过才 `savefig`；断言放在循环内部，UP/DOWN 各跑一次：

| 自检项 | 判据 | 实测参考值 |
|---|---|---|
| 标签中心 ↔ 所属色块中心 | 偏差 = 0 px（容差 ≤1 px） | 0.00 px ✅ |
| 相邻节点区间重叠 | 对数 = 0 | 0 对 ✅ |
| 列标题 ↔ 顶端节点间距 | > 0（不压字） | 210 / 287 px ✅ |

- 偏差用**像素**断言（与用户肉眼看到的是同一个量），不要用数据坐标。
- 📎 断言的三项实现 + 完整病例 → `references/sankey-label-block-alignment.md`

## 本用户的版式与流程惯例

| 项 | 惯例 |
|---|---|
| 导出 | **PNG + SVG + PDF + TIFF 四格式，300 dpi**（缺格式会被要求补） |
| 改版 | 重出前把上一版整组备份到 `figures/_backup_sankey_vN/`，可逐版对照 |
| 计数方向 | 共同 DEG 流向图：**蓝 DOWN 在左、红 UP 在右**（已确认口径，勿改） |
| 图内说明文字 | **英文** |
| 标签 | 必须贴紧自己的色块（"亚群和基因要跟自己对应的色块对齐"），不留白缝 |
| 汇报 | 说清"根因是什么 + 修了什么 + 自检数字"，不要只说"已修好" |

## 定位错位的常用手段

1. **局部裁剪**：把可疑区域裁成临时 PNG（`_tmp_up_top.png`、`_tmp_up_topleft.png`）放大看，比盯整图快。
2. **打印每个节点的区间与中心**：区间重叠一眼可见 —— 重叠是根因，标签偏差只是表征。
3. 布局函数写成 `layout(w, tag)` 并在其中 `print` 调试量（`usable`、每节点 `[y0,y1]`），比看图猜快得多。

## 坑表

| 现象 | 根因 | 处置 |
|------|------|------|
| 标签"掉"到色块下沿，越靠顶越明显 | 间隙按总权重算 → `usable` 为负 → 节点区间重叠，标签仍在真实中心 | 铁律 1：间隙 = 固定比例 / (n−1) |
| 只有 UP（或只有重权重那张）错位 | 该图 `tot` 大，把 `usable` 压成负数 | 不要调标签；查区间重叠 |
| 间隔忽大忽小 / 越靠下越挤 | 间隙总量随权重量级漂移 | 固定比例，与权重解耦 |
| 自检通过但仍想再看一眼 | 断言已是像素级证据 | **不要再反复裁剪/重看**（重复查看动作会被系统判为监控循环）——断言过即交付 |
