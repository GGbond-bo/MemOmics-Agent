# 五效应 d/p/q 口径规格卡 + 「计算口径反推」方法

定稿日期 2026-09-15。触发场景：用户问「**你这个五效应是怎么计算的**」「这个数字怎么来的」「你有没有算错」。

---

## 1. 结论先行（全表 1100/1100 复现锁定）

用原始 `E:/骨骼肌锻炼/MF_AUCell_meta.csv`（508,661 细胞 × 58 列）从零重算 `effect5_d_v2.csv` 全部 **1100 格**：

```
d  最大绝对差 7.216e-15   命中 1100/1100
p  最大绝对差 8.216e-15   命中 1100/1100
q  最大绝对差 1.132e-14   命中 1100/1100
```

⇒ 三项都是浮点精度级一致，口径**唯一确定**，不存在第二解。

| 量 | 实现 | 一句话 |
|---|---|---|
| 单位 | 个体（donor）级 | 每个 `(type × annotation_L3 × donor)` 内取细胞打分**均值** |
| d | `(mean_B − mean_A) / sp`，`sp = sqrt(((n1−1)s1² + (n2−1)s2²)/(n1+n2−2))` | pooled-SD Cohen's d（**不配对**） |
| p | `scipy.stats.ttest_ind(x, y, equal_var=False)` | **Welch 双样本 t** |
| q | BH，作用在**全表 1100 个 p** 上 | 22 基因集 × 10 亚群 × 5 效应 |

效应定义（后项 − 前项，正 d = 后项高）：

```
Aging   = O_Pre  − Y_Pre      (独立：老年 vs 年轻)
T2D     = OD_Pre − O_Pre      (独立：糖尿病 vs 单纯老年)
ExYoung = Y_Post − Y_Pre      (同批人前后)
ExOld   = O_Post − O_Pre      (同批人前后)
ExT2D   = OD_Post− OD_Pre     (同批人前后)
```

donor 构成：Y 10 / O 7 / OD 7 = **24 人**（图标题 `n=24` 指总 donor 数，不是单次比较的 n）。

## 2. 复现的两个必踩坑

### 2.1 donor 键要先剥 `_Pre/_Post` 后缀

`samplename` 是 `Old_10_Pre`、`Old_10_Post` 这种**带时点的字符串**，不是纯个体 ID。直接
`ind.pivot(index="samplename", columns="type", values=score)` 会得到 **0 行**（没有任何一个 samplename 同时出现在两个 type 里）。

```python
meta["donor"] = meta["samplename"].str.replace(r"_(Pre|Post)$", "", regex=True)
```

剥完后先核一次分母：`sub.groupby("type")["donor"].nunique()` → 应得到 `Y_Post 10 / Y_Pre 10 / O_* 7 / OD_* 7`（Σ 不同时点的 donor = 24）。子集 `LRP1B+(I)` 实测 31,331 细胞 / 24 donor。

### 2.2 细胞级算 = 伪重复，必须个体级聚合

细胞级独立检验（11,880 vs 11,603 细胞）得出的 p 是 `4.59e-164` 量级 —— 与表里的 `0.0458` 差 160 个数量级，**一眼可判不是这条口径**。n 越大越要警惕：伪重复会把 p 压到毫无意义的量级。

## 3. 公式变体排除表（实测，供同类审计直接套用）

以 `scoreI_AUC × LRP1B+(I)` 为例（CSV 真值：Aging d=−1.128564 / p=0.045758）：

| 变体 | d | p | 判定 |
|---|---|---|---|
| 独立 pooled d + **Welch t** | −1.128564 ✅ | **0.045758 ✅** | ✅ **唯一同时命中** |
| 独立 pooled d + Student t | −1.128564 ✅ | 0.036925 ✗ | 排除 |
| 独立 pooled d + Mann-Whitney | −1.128564 ✅ | 0.055327 ✗ | 排除（**skill 旧文写的就是这个，错**） |
| 独立 pooled d + Brunner-Munzel | −1.128564 ✅ | 0.034449 ✗ | 排除 |
| 配对 dz = mean(diff)/sd(diff) | −0.278837 ✗ | 0.400843 ✗ | 排除（且 d 就错） |
| 配对 dav = mean(diff)/sp | −0.363404 ✅* | 0.400843 ✗ | *d 在 n1=n2 时与 pooled 等价，p 不命中 |
| 细胞级 d + Welch t | 量级差 3 个数量级 | — | 排除 |

**关键判读规则**：d 能命中但 p 不命中 → **不是聚合层级的问题，是检验族选错了**（继续在 t/Wilcoxon/MWU/Brunner 里试）；d 与 p 都错 → 先怀疑聚合层级（细胞级 vs 个体级）。

> ⚠️ n1 = n2 时 `sqrt((s1²+s2²)/2)` 与 pooled sp 数值恒等 —— 所以**运动三项（同批人，n 相同）的 d 值无论配不配对都一样**，只有 p 会变。不要拿 d 相同就断定「用了配对」。

## 4. FDR 校正范围会改变解读

| 校正范围 | Aging/LRP1B+(I) 的 q | 全表最大差 |
|---|---|---|
| **全表 1100 格**（实际用的） | **0.289276** | 1.1e-14 ✅ |
| 每个效应内 220 格 | 0.081844 | 0.700 ✗ |
| 每个 score 内 50 格 | 0.285989 | 0.648 ✗ |

Q：为什么星号这么稀疏（1100 格里 Aging 轴 34/40 显著、运动轴几乎为 0）？—— **分母大**。全表校正下 Aging 那格 q=0.289；若只在效应内校正会降到 0.082（仍 >0.05）。**报告 q 值时必须同时说明分母是多少格**，否则读者无法判断保守程度。

## 5. 口径问题必须一并披露的两件事

1. **运动三项是配对设计却用了独立检验** —— 同一批人 Pre/Post 取样，按独立两组处理。配对 t 的 p：
   | 效应 | 现用（Welch 独立） | 配对 t |
   |---|---|---|
   | ExYoung | 0.427211 | 0.400843 |
   | ExOld | 0.452131 | **0.287374** |
   | ExT2D | 0.834052 | 0.850066 |
   ExOld 差得最多（0.45→0.29），但**都 >0.05，结论方向不变**。要不要切配对是口径决策 → 交用户拍板，不要默默改。
2. **FDR 分母 1100**（见 §4）。

## 7. 「计算口径反推」通用流程（可迁移到任何结果表）

用户问「这个数怎么算的 / 有没有算错」时**禁止凭记忆答**，按此四步用工具反推：

1. **拿真值**：从结果表取 1 个格子（`d / p / q` 三元组），挑方向生物学上可预期的组合（便于后续核符号）。
2. **穷举变体**：写一个脚本对同一格枚举 {聚合层级：细胞级 / 个体级} × {d 公式：pooled / 配对 dz / dav} × {检验：Welch t / Student t / MWU / Wilcoxon / Brunner-Munzel / 配对 t}，**打印谁命中**，不要人肉算。
3. **单格命中后立刻全表验证**：`merge` 自己的结果与 CSV，报 `max|Δd| / max|Δp|` 与**命中格数 N/1100**。**只看头几行不算验证**（用户对结论稳定性零容忍）。
4. **q 单独反推**：p 全中后试不同 BH 范围（全表 / 分效应 / 分亚群），按 `max|Δq|` 判哪个是实际用的。

产物形态 = 可复跑探针（本项目 `scripts/verify_effect5_formula.py`）+ 一张「变体 × 是否命中」表 + 一句「只有 X 同时命中 d 和 p」。

**汇报模板**：① 一句话结论（口径是什么）② 定义表（五个效应对比谁减谁）③ 三步计算 ④ 复现证据（max|Δ| + 命中数）⑤ **主动披露口径弱点**（配对未配对、FDR 分母），并说明结论是否受影响。

## 8. 口径升级方案评估：Hedges' g（独立）+ 配对 d（运动前后）—— 2026-09-25 用户提议

用户原话：「**不应该是 Aging 和糖尿病独立比较（Hedges' g (grp2 − grp1)），三组运动前后配对比较（Cohen's d2 (Post − Pre)），这两个方法怎么样？**」
附图 = `FigA2_program_5effects`（绘图脚本 `scripts/fig_A2_5effects_v3.R`，只读预计算表）。

### 8.1 判定：方向对，但有 3 个必须补的点

| 提议 | 判定 | 补充 |
|---|---|---|
| 独立比较用 Hedges' g | ✅ 更正确（小样本无偏） | 只能 **5 列统一用 g**，不能只给 2 列 |
| 运动前后用配对 d | ✅ 检验层面正确 | 效应量必须 **d_av**、禁 d_z；且 d 侧数值其实不变 |
| 未提及 | ⚠️ 遗漏 | 同一色标可比性 + FDR 分母要不要随之重算 |

### 8.2 Hedges 校正因子 J（实算）

`J = 1 − 3/(4·df − 1)`，`df = n1 + n2 − 2`

| 比较 | n1 / n2 | df | J | g/d |
|---|---|---|---|---|
| Aging（O_Pre vs Y_Pre） | 7 / 10 | 15 | 0.9492 | 0.95 |
| T2D（OD_Pre vs O_Pre） | 7 / 7 | 12 | 0.9375 | 0.94 |

⇒ 校正幅度 ~5–6%。**只给 Aging/T2D 上 g、运动三列留未校正 d** ⇒ 两族在同一 `TwoSlopeNorm(−3,0,3)` 色标上系统偏 5% —— 小于视觉分辨阈但足以让"跨列比大小"不严谨，且审稿人一问"为什么只对两列做小样本校正"很难答。
**规则：g 要上就 5 列全上**；t 值/p 不变（仅 d 乘 J），重算只影响色块深浅。

### 8.3 配对效应量三兄弟与放大倍率

`d_z = mean(diff)/SD(diff)`｜`d_av = mean(diff)/s_av`（二时点 SD 的合并/平均）｜`d_rm = mean(diff)/SD_pre`

关系：`SD(diff)² = s1² + s2² − 2·r·s1·s2` ⇒ s1≈s2 时 `d_z = d_av / √(2(1−r))`

| r | √(2(1−r)) | d_z / d_av |
|---|---|---|
| 0.0 | 1.414 | 0.71×（d_z 更小）|
| 0.5 | 1.000 | 1.00× |
| 0.7 | 0.775 | 1.29× |
| **0.8** | 0.632 | **1.58×（虚高 58%）** |
| 0.9 | 0.447 | 2.24× |

⛔ **本图禁用 d_z**：五面板共用一条 ±3 色标，d_z 会把运动列按个体内相关 r 放大数十个百分点 → 与独立列不可比。**用 d_av（与独立列同尺度）**。

### 8.4 ⚠️ 反直觉但必须说清：运动三列换配对 d，颜色不变

n1 = n2 时 `sp = √((s1²+s2²)/2)`，与 d_av 的尺度定义**数值恒等**（见 §3 注）⇒
**把运动三项从"独立 pooled d"改成"配对 d_av"，d 一位小数都不变、色块完全一样；只有 p 变**（配对 t：ExOld 0.4521→0.2874、ExYoung 0.4272→0.4008、ExT2D 0.8341→0.8501，全 >0.05）。

⇒ 回答用户时**不要把"换成配对 d"说成会改图**；真正收益在检验功效（p）与描述精度。

### 8.5 回答这类口径咨询的四段式（用户满意度最高）

1. 现状口径一句话（含出处：图脚本行号 + 表生成脚本）
2. 提议逐条判（对 / 半对 / 有坑）
3. 主要风险点（此处 = d_z 放大 + g 只上一半 + 色标不可比）
4. **弹窗给选项让用户拍板**（沿用现状 / 5 列统一 g / 三列全配对重算），**不擅自改脚本重跑**
