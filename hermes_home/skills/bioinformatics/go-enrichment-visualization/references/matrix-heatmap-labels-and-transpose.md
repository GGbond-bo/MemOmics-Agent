## 1. 用户的三条原话 → 正确动作

| 用户原话 | ❌ 错误反应 | ✅ 正确动作 |
|---|---|---|
| "label 变小一点啊，**这么长干什么**？" | 只把 `cex` 调小 | **先缩短显示名，再降字号**。只降字号 = 字小了但依旧又长又挤——用户嫌的是「长」。 |
| "标签**对齐自己的热图**啊" | 以为是距离/偏移问题去挪 | 锚点必须落在**那一格的中心**，不是格边界。 |
| "亚群在 y 轴、基因集在 X 轴" | 只换绘制循环顺序 | 转置 = **矩阵 + 色条 + 画布几何**三件一起改（见 §3）。 |

### 1.1 缩短显示名的做法（保留列口径不变）

列名是数据列名（`scoreOxPhos_AUC`），**不能改**；改的是**渲染用映射表**：

```r
DISP <- c(scoreOxPhos = "OxPhos", Glycolysis = "Glycolysis",
          FattyAcidMetabolism = "Fatty acid metab.", AMPK_PGC1a = "AMPK-PGC1a",
          scoreInsulin = "Insulin signaling", scoreSarcoomeric = "Sarcomeric")
# 渲染时用 DISP[[g]]，取数与核对矩阵时仍用原名 g
```

原则：剥冗余前缀（`score*` / `*_AUC`）、把驼峰长名规范化缩写，目标 **≤18 字符**。

### 1.2 格中心对齐（45° 与水平两种）

```r
# x 轴：45°，锚在列中心 → 标签"指向"自己那一列
text(colx[g] + 0.5, -0.12, DISP[[g]], srt = 45, adj = c(1, 1), cex = 6.2/9)

# y 轴：水平标签，锚在行中心
axis(2, at = NSUB - seq_len(NSUB) + 0.5, labels = SUBS, las = 1, tick = FALSE)
#        ↑ 行 i 的中心 = 顶边 - i + 0.5
```

## 2. 🔴 45° 标签静默裁切（图不报错）

长标签 + `adj=c(1,1)` 超出画布底部 → R 直接切掉，**不报错、文件大小正常、人眼扫一眼看不出**。
实测：老版 FigA3 的 10 个亚群只渲染出 8 个（`RSS` / `Specialized MF` 丢失）。

**核验（唯一可靠方式）**：`vision_describe` 读 PNG → 数 OCR 文本条数：

```
预期标签数 = 亚群数(10) + 基因集数(18) = 28
OCR 命中 < 28  ⇒  有标签被裁切
```

**下边距反推公式**：

```r
max_chars <- max(nchar(DISP))                       # 最长显示名
label_h_in <- max_chars * 0.55 * (pt / 72) * sin(45 * pi / 180)
mai_bottom <- label_h_in + 0.1                      # +0.1 in 余量
```

`0.55` = 平均字符宽 / 字号的经验比（sans 字体）。加完**再 OCR 复核一次**，不要凭公式收工。

## 3. 转置（行↔列互换）三件套

用户说"X 放在 y 轴、Y 放在 X 轴"时，最容易只改绘制顺序 → 得到变形版面。

| # | 改什么 | 具体做法 |
|---|---|---|
| ① | **矩阵不重算** | 沿用同一个行内 z 矩阵，只调换取值下标 `ZS[g, ci]`（列=基因集、行=亚群）。重算 z 会悄悄改口径 |
| ② | **分组色条跟着搬** | 左竖条 → **顶部横条**；组名由竖排（`srt=90`）改横排（`adj=c(0.5,0)`）并居中于该组跨度 `mean(axis_span[[grp]])` |
| ③ | **重算画布几何** | 列数/行数变了，原 `figsize` 必错。见 §4 |

## 4. 画布几何：色块正方形反推

```r
U    <- 0.42                    # in / 数据单位 —— 同一个 U 才保正方形
XMAX <- 列数 + 组间间隙合计      # 例：18 列 + 5×0.25 = 19.25
NTOP <- 行数 + 0.8              # 顶部留白给色条 + 组名
MAI  <- c(bottom, left, top, right)   # 英寸；bottom 由 §2 公式定，left 由最长行名定
W <- XMAX * U + MAI[2] + MAI[4]
H <- NTOP * U + MAI[1] + MAI[3]
```

配套两条 base R 几何铁律（缺一即错位）：

- `par(xaxs='i', yaxs='i')` — 否则 R 默认向外扩 4%，色块被压缩并偏位。
- `par(mai = MAI, ps = 9)` 后用 `cex = pt/9` 换算字号，保持与 matplotlib 版一致。

## 5. 组间隙用于表达「隔离」

分组间隙是**语义工具**，不只是排版留白：

```r
GAPX <- 0.25
GAPX_AFTER <- c(Artifact = 0.7)      # 技术伪影/QC 组后面加大间隙
```

依据：L2 辩论双方 + 裁判一致共识——解离诱导应激伪影（PMID 34074577）不应与生物学程序等权展示 ⇒ 单列 + 加宽其后间隙，**而不是只靠颜色不同**。

## 6. 用户问「图里的分类对不对？」的处理

1. **先 diff 两处常量**：脚本里的分组常量（如 `PROG_GROUPS`）vs 交付给用户的分类文档（原表 `Class` / 机制轴表）。两者常是两套体系，不一致就是"不对"的来源。
2. 如实说明差异表（基因集 / 图上分组 / 应有分类），**不要顺着现有图解释分类**。
3. 动手改分类 = 改**色条 + 列行顺序 + 组间隙**，不是只改图例文字。
