# 栅格级版式取证 —— 「标签贴没贴着热图」「有没有对齐」「其他元素动没动」

> 触发场景：用户对**几何观感**提返工（"label 要贴着热图啊" / "对齐了吗" / "离得太远了"），
> 或需要证明"这次只动了 X，其他没动"，而脚本 diff（改常量）本身说服力不够。
> 基础图族的装饰版式（外侧色块 / 竖排轴名 / 标题）见 `references/r-base-graphics-outer-layout.md`。

---

## 0. 铁律：先定位测量方法，再报数字

**测量方法不可信时，禁止用它的数字宣称"已验证"**；两个来源（脚本设计值 vs 像素实测）打架时，
**先定位污染再汇报**，不要先报一个数、下一轮再改口（该用户对"结论老是变"零容忍）。
本会话实例：先报了"墨迹距热图 1 px"，随后被判为污染，真实缝是 3 px —— 结论没变但数字得改口。

---

## 1. 参照系：热图边界必须算出来，不能用"看起来"

```
热图左边界 x_px = MAI[2](in) × dpi          # MAI=c(0.75,1.35,0.55,0.35) @300dpi → 405 px
热图右边界 x_px = 画布宽_px − MAI[4] × dpi
```
所有左侧测量一律以 `x_px(热图左边界)` 为原点换算数据单位：`单位数 = (405 − x_px) / (CELL × 300)`。

## 2. 列剖面（最快建立版图全貌）

```python
from PIL import Image; import numpy as np
a = np.array(Image.open(png).convert("RGB")).astype(int)   # 必须 convert("RGB")，调色板模式会崩
prof = (a.max(2) < 248).sum(0)                              # 每列非白像素数
for x in range(0, W, 20): print(x, prof[x])
```
判读（本图族实测值）：
| 区域 | 每列计数 | 说明 |
|---|---|---|
| 色块列 | ≈1300 | 17 行 × 格高，实心 |
| 热图列 | 800–1200 | RdBu 中间色近白，计数被拉低（**不能用固定阈值判"有没有热图"**） |
| 标签列 | 100–200 | 文字墨迹 |

⚠️ 用"彩色像素数 > 2000 找热图"会失败——RdBu 中段饱和度低。判定热图列要用**已知几何**（§1），不要靠颜色统计去"找"。

## 3. 🔴 污染坑：深色热图格会被判成"文字墨迹"

找深灰文字（`#1A1A1A`）常用阈值 `max(RGB) < 200` —— 但 **RdBu_r 最深端 `#053061` 的 max(RGB)=97 也满足**。
后果：热图首列被算进"标签墨迹"，把缝隙量小（实测假读数 1 px vs 真值 3 px）。

**排除污染（二选一或并用）**：
```python
ink = (a.max(2) < 200) & (a.min(2) < 120) & ((a.max(2) - a.min(2)) < 25)  # 近灰且暗 = 文字
# 或直接把测量带限制在热图边界左侧 2px 以外
band = ink[:, 150 : HM_L - 2]
```

## 4. 对齐方向判定（右对齐 vs 左对齐）

对每个标签行取 y 带内的墨迹左右端点，比较 **右端极差 vs 左端极差**：极差小的一侧 = 对齐侧。
```
OxPhos 右端 392 / Glycolysis 382 / Sarcomeric 395 ...  → 右端极差小 → 右对齐（贴热图）
```
⚠️ **y 带必须落在行中心**。若直接用 OCR 报的 box 顶坐标当中心，会切掉字的下半 → 量出的宽度偏小
（实测 `Autophagy` 只量到应有宽度的 ~55%，右端被算小 60 px，判定失真）。
稳妥做法：按脚本几何算行中心 `y_px = (TOP − (i − 0.5)) × CELL × dpi + MAI[3] × dpi`，或把 y 带放宽到 ±14 px。

## 5. 脚本内自检（设计值，用来交叉验证像素）

```r
pdf(NULL); par(mai = MAI, ps = 9, family = FAM)
plot.new(); plot.window(xlim = c(0, NCOL), ylim = c(0, TOP))
lw <- strwidth(DISP[PROGS], cex = 6.0 / 9); dev.off()   # 量完立刻 dev.off()！
cat(sprintf("标签右端 %.3f 单位 = 距热图 %.4f in | 最长标签左端 %.3f | 色块右边界 %.3f → %s\n",
            LBLX, abs(LBLX) * CELL, min(LBLX - lw), LB0,
            if (min(LBLX - lw) > LB0 + 0.05) "无重叠 OK" else "⚠️ 与色块重叠"))
```
三个坑：
1. **量完必须 `dev.off()`** —— 否则留下隐式设备，把随后开的 `png()` 吞成全白（判据 `extrema == (255,255)`）。
2. `pdf(NULL)` 没有 Arial（会打一堆 PostScript 警告）→ 字宽是回退字体的近似值。**只用来判"有没有相撞/超界"，绝对值别当交付数字。**
3. **符号别写反**：锚点在热图左侧 ⇒ `LBLX` 为负，缝隙 = `|LBLX| × CELL`；直接 `LBLX * CELL` 会打出负数（本轮真打出 `-0.0102 in`）。「可用宽度」同理是 `LBLX - LB0` 方向。
4. 自检块放在**出图循环之前**，否则自检失败时坏图已落盘。

## 6. 本会话实测基线（同图族可直接复用）

| 项 | 值 |
|---|---|
| 画布 | 4.25 × 6.122 in（107.9 × 155.5 mm）@300dpi = 1275 × 1836 px |
| 热图左边界 | x = 405 px（MAI[2] = 1.35 in） |
| 分类色块列 | x = 91–145 px（LB1 = −4.11 / LB0 = −3.40 数据单位） |
| 竖排轴名 | x ≈ 76–88 px（LNX = −4.27 单位 → 距色块左边界 0.16 单位） |
| 行标签右端 | v4 = −0.10 单位（缝 20–23 px ← 用户否决）→ **v5 = −0.04 单位（缝 3 px ← 用户要的"贴着"）** |
| 用户判定 | 「贴着热图」= 视觉上无白缝；0.010 in（3 px ≈ 0.25 mm）被接受 |

## 7. 定稿前核验清单（本类改动最多核 3 项，然后交付）

1. 4 格式文件大小非空（png/pdf/svg/tiff）；
2. 脚本自检 stdout 打印「标签右端距热图 X in / 是否与色块重叠」；
3. **一次**栅格核验（列剖面 + 目标区域墨迹/彩色计数）。

⛔ 定稿后反复重测同一件事会触发系统"循环失控"强制中断。要再改就直接改常量重出。
