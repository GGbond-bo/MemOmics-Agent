# B 类 CRE 检出方法论 —— 方法的核心创新

## 为什么 B 类是盲区

```
现有方法的能力边界：

phastCons/GERP (纯序列):
  A 类 ✅ | B 类 ❌ (失明) | C 类 ✅ | D 类 ✅
  能看到序列保守或不保守，但不知道序列保守的 CRE 是否真的被 TF 结合。

表达层可替代性 (原专利 A):
  A 类 ✅ | B 类 ❌ (失明) | C 类 ✅ | D 类 ✅
  能看到靶基因表达是否保守，但不知道上游 CRE/TF 机制是否一致。

本方法 (三层 ATAC):
  A 类 ✅ | B 类 ✅ | C 类 ✅ | D 类 ✅
  第一次覆盖了 B 类——这就是方法增量。
```

## B 类检出逻辑

```
for each CRE:
  if phastCons > 0.8 AND Jaccard > 0.5 AND footprint_divergence > 0.3:
    → B 类

解释：
  phastCons > 0.8: 序列高度保守（灵长类参考阈值）
  Jaccard > 0.5: 两个物种在同一细胞类型中都开放
  footprint_divergence > 0.3: 至少一个关键 TF 的结合模式显著不同
```
