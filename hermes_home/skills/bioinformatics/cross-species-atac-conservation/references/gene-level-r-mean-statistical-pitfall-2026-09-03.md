# 基因级 r_mean 统计缺陷：评估跨物种保守性相似性不可用 tile r 算术平均（2026-09-03 诊断定稿）

## 触发场景

用户追问"这套算法真的能评估跨物种保守性相似性吗？设计够严谨吗？"，并点名 BNIP3（文献支持其在人海马 CA1 随龄下降）——要求重评专利算法本身是否合格。诊断过程发现的不是个别 bug，是**统计层的系统性缺陷**。

## 数据流（本项目 M3 管线）

```
tile(500bp) 活性 vs 年龄 Pearson r  →  基因锚定(tile 落基因区间)  →  r_mean = 该基因所有 tile 的 r 算术平均
   →  ortholog 基因对 (r_human, r_monkey)  →  方向一致/相反 判定  →  "保守性相似基因"清单
```

- `m3_conservation_gene.csv` 列：`macaque_gene_id, human_gene_id, symbol, r_human, r_monkey, n_tiles_h, n_tiles_m`
- **注意：`n_tiles_h/n_tiles_m` 是 tile 数，不是样本数**（本会话当场纠正——此前把 BNIP3 的 39/37 误读成个体数）。个体数 = 人 40 / 猴 20（由 tile 级 r/p 反推：猴 r=0.435/p=0.055→n=20；人 r=0.117/p=0.471→n=40）。
- `r_human/r_monkey` 实为 `m3_stepA/B` 产出的 `r_mean`（tile 级 r 的算术均值），不是标准 Pearson 相关系数。

## 三处统计硬伤（实证）

### ① r 不能直接算术平均
Pearson r 不是线性可均的量，必须 atanh(z) 变换后再平均。正负 r 直接平均会互相抵消：一个 +0.5 与一个 −0.5 的 tile 平均成 0，被误判"无变化"，实际两个 tile 剧烈反向。→ 真实信号被抹平，方向相反基因系统性漏检。**这是"漏掉 BNIP3 这类方向相反基因"的根因之一。**

### ② 方向判定信噪比 ≈ 抛硬币
16029 ortholog 基因对中：方向相反 8604（**53.7%**）、方向相同 7425（46.3%）。绝大多数 |r|<0.16，弱相关下符号随机摆动 → "方向相反"名单基本是噪声，不是生物学信号。

### ③ Fisher z 功效坍塌
人 40 / 猴 20 不均衡 + r 太小 → `SE = sqrt(1/(40-3) + 1/(20-3)) ≈ 0.293`，要达到 p<0.05 需 atanh 差异 >0.57（对应 r 差异 >0.52）。实测 r 全在 ±0.16 内 → **仅 10/7311 个方向相反基因 Fisher z 显著（0.14%），29 个 p<0.1**。

## BNIP3 顶点实证

```
人 r=-0.157（39 tile均值）  猴 r=+0.112（37 tile均值）
Fisher z = -0.92, p = 0.357  ← 不显著
```
- 人侧方向与文献一致（CA1 随龄下降 ✓）
- 但"人降猴升"的跨物种分歧在 n=40/20 下**统计上不成立**，只是趋势
- 结论：算法在人侧方向没错，但"跨物种分歧"主张证据不足——暴露的是**功效问题**，不是 BNIP3 本身错

## 概念偷换（最深层问题）

"保守性相似性"被偷换成"衰老响应方向一致"。真正的跨物种保守性必须**三层独立、分开报告**：

| 层 | 是什么 | 用什么测 | 本项目状态 |
|---|---|---|---|
| 序列保守 | DNA 序列被纯化选择保持 | phyloP/phastCons | ✅ 已做（L1） |
| 活性保守 | 同源增强子两物种同脑区均有活性 | 同源峰 H3K27ac | 🔶 部分（GSE67978 尾状核跨界借用，非海马） |
| 衰老响应一致 | 两物种衰老时同向升降 | **方向 + 交互项检验** | ❌ 用 r_mean 方向判定顶替，且统计错误 |

**"方向一致"顶替不了"保守性"**——一个基因可序列高度保守、正常活性保守，但衰老反应两物种分歧（BNIP3 正是如此）。方向一致/分歧本身是独立生物学，不该被当作"保守性"的判据混用。

## 正确修复路线（未完成，下次执行）

| 优先级 | 修复 | 消灭的病根 |
|---|---|---|
| P0 | tile r 改 **Fisher z (atanh) 加权平均**，或直接 tile 级跨物种配对（liftOver 同源 tile 逐 tile 比） | ① 算术平均 |
| P0 | 方向判定改用**交互项模型**：`活性 ~ species × age` 交互 FDR，不是两个独立 r 相减 | ②③ 方向噪声 + 功效 |
| P1 | 概念三层拆分（序列/活性/衰老响应）分开报告 | ④ 概念偷换 |
| P1 | 下沉到细胞亚群（需 scATAC，当前 bulk 无法答"哪个亚群"） | ⑤ 无亚群 |

**Fisher z 的正确 n = 个体数**（人 40 / 猴 20），用 tile 数会系统性低报 p。公式：
```python
z1 = atanh(r1); z2 = atanh(r2)
se = sqrt(1/(n1-3) + 1/(n2-3))
z = (z1 - z2) / se;  p = 2 * (1 - norm.cdf(abs(z)))
```

## 一句话结论
这套算法（gene-level r_mean + 方向一致性判定）**不能可靠评估跨物种保守性相似性**——方向判定 ≈ 抛硬币 + 弱相关符号噪声 + 功效坍塌三重污染。修复必须：① Fisher z 加权平均替代算术平均 ② species×age 交互项模型替代两个独立 r 相减 ③ 概念三层拆分 ④ 下沉到细胞亚群。
