# 方向迁移预测 + 置换检验（预测方向的公式 · 定音）

> 用户诉求：「我的目的就是要一个预测方向的公式，然后验证这个公式能够计算猴子能不能预测人，要一个专利。」
> 本文件给出可复现的公式 + 验证协议 + 一处必查的符号交叉核对坑。脚本见
> `scripts/predict_direction_transferability.py`（会话 sid memomics-cd677556）。

## 一、公式（方向迁移预测器）

每基因 g，两侧 Stouffer 组合 Z 已算好（`Z_monkey` / `Z_human`，定义见
aging-response-surrogacy-stats.md：`Z = Σ sign(r_i)·norm.ppf(1−p_i/2) / √n`）：

```
预测公式:  pred_human_direction(g) = sign(Z_monkey(g))
判定:      预测正确  ⇔  sign(Z_monkey) == sign(Z_human)
可替代性标注:  同向 = +1(可替代) / 反向 = −1(物种特异分歧)
```

## 二、验证协议（关键：null 用置换，不是 50%）

**⚠️ 方向一致率绝不能跟 50% 比**。两侧方向分布不对称（衰老下调基因占比
猴 80% / 人 41%，即边际分布都偏），随机配对的同向率期望 = P(↓)² + P(↑)² ≠ 50%。
本例 null 均值 = 44.29%，不是 50%。

正确做法（双侧偏离检验）：
```python
null = np.array([(d_m[mask] == d_h[rng.permutation(n)][mask]).mean()
                 for _ in range(2000)])   # 打乱配对，保留边际分布
p_two = min(2*min((null>=obs).mean(), (null<=obs).mean()), 1.0)
```
- 打乱的是 **d_h 的配对**（保留 d_m、d_h 各自的边际方向分布），不是随机翻符号。
- 双尾：obs 显著低于 null 均值 ≠ "噪音"，而是「真实反向/分歧信号」。

## 三、定音结果（可直接写专利）

| 层 | 观测方向一致率 | 置换 null 均值 | 双尾 p |
|---|---|---|---|
| 全量 16030 基因 | 41.55% | 44.29% | **0.001** |
| 双侧显著 5391 基因 | 35.32% | 42.14% | **0.001** |

- **整体可替代性不成立**：猴子衰老方向不能预测人，方向**显著反向**（p=0.001）。
- **单调性规律（可写权利要求）**：双侧显著性越强（S=−log10(max p) 越高），
  同向率**越低**（43.8% → 37.4% → 32.7% → 32.3%）——衰老效应越强的基因越物种特异。
- **真实保守信号只在子集**：1904 个「双侧显著 且 同向」基因，88.2% 是衰老可及性
  下降（SLC1A2/NRXN1/GRIA1/GRIA2/CELF2 等海马 ExN 突触基因）。

**专利落点 pivot**：不是「猴能替代人」的 yes/no，而是「方向一致性分类器 +
非随机性置换证明 + 单调性规律」三者合成的可替代性打分系统。

## 四、必查坑：Stouffer Z 符号 vs tile 级 r 符号必须交叉核对

**症状**：tile 级 r 两侧都是 ~57% 负（分布几乎一致），但基因级 Z 猴侧 80% 负、
人侧仅 41% 负——量纲上对不上。人侧显著 tile 63% 负却组合出 Z 41% 负，违反
Stouffer 的 sign(r)·|Z| 加权逻辑，疑似符号口径/组合 bug。

**铁律**：下任何生物学方向结论前，先核对三处方向分布是否自洽：
1. tile 级 r 符号分布（两侧应同量纲、同方向主导）；
2. 显著 tile（p<0.05）的 r 符号分布；
3. 基因级 Stouffer Z 的符号分布（应与 #1/#2 同向，否则有 bug）。

三者矛盾 = 先修符号口径，再谈结论。方向分布若猴/人一侧 80% vs 41% 的极端不对
称且同时 tile 级 r 又是对称的，「反向」结论的生物学解读需重新审视（可能是真
实物种重编程差异，也可能是 human_ageDA_all.csv 的符号约定 bug）。
