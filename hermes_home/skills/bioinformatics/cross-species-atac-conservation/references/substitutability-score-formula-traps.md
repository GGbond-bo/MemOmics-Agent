# 替代性 S 评分公式设计陷阱 + 置换判别"方向陷阱"

> 适用：给「人猴衰老染色质可及性可替代性」设计/复审 S 评分公式、或解读其置换检验判别力时。
> 上游：Z_m/Z_h 年龄效应本身的真实性见 `age-label-shuffle-validation.md`；衰老响应量纲一致性见 `aging-response-surrogacy-stats.md`；**年龄编码口径（连续 Age vs Age_group 分组）见 `age-encoding-continuous-vs-grouped.md`**（被问「换分组是不是更好」先读）；**Z 聚合层口径（Stouffer vs Fisher-Z vs n_eff、p 反推饱和、τ_A 重标定）见 `cross-species-z-aggregation-stats.md`**（改聚合公式或辩护 z 显著性先读）。本文件只讲**评分公式本身**的两个坑 + 复算方法。

## 坑①（最致命）：置换检验"判别力 p 显著"必须先看观测值 vs 空分布的**方向**

一个"同源性方向一致性"型统计量的置换检验，p 值显著 ≠ 可替代性成立。p 显著只说明"真实同源配对**区别于**随机配对"，但区别有正反两个方向：

- **obs > null_mean** → 同向配对显著多于随机 → 支持"可替代/同向保守"。
- **obs < null_mean** → 同向配对显著**少于**随机 → 是**反相关/不可替代**的证据，不是可替代的证据。

本会话实测（人 40 例连续年龄 / 猴 20 例 4 年龄簇，基因级 Stouffer 聚合 Z 值，16031 对 ortholog）：

| 证据 | 数值 | 含义 |
|---|---|---|
| 全体基因人猴同向比例 | **0.4155**（< 随机 0.5） | 同向**少于**随机 |
| Z_human vs Z_monkey Pearson r | **−0.0627** | 整体负相关 |
| 信号越强同向越少 | \|Z\|≥1.96 时同向仅 0.353；≥5 时 0.347 | 不是尾部放大器 |
| 真实配对 vs 随机配对的同向比例 | 0.4155 **<** 0.4429（置换 500 次） | 真实反而更低 |
| A 级(同向) vs B 级(反向) | **1904 < 3487** | 反向比同向还多 |

→ 旧脚本"判别力 p=0.0008"的真实含义是"同源配对的反向**显著**多于随机"，是**不可替代证据**，不是可替代证据。复核任何"判别力/富集比"结论时，先打印 `obs` 与 `perm_mean` 的大小关系，不要默认"显著=支持我的假设"。

## 坑②：`min(|Z₁|,|Z₂|)` 双侧对称评分公式的统计方向是反的

旧公式 `S = min(|Z_m|,|Z_h|) × sign(Z_m·Z_h)` 的"有益效果"叙事写的是"防单侧假阳性（type II 控制）"，但数学后果是**相反**的：

- `min` 取**弱侧** → 当一侧是小样本（猴 n=20、测不准）时，S 被噪声弱侧主导，大样本强侧（人 40 例的可靠信号）被反向截断。
- 后果是**假阴性爆炸（type I 失控）**：大量"人侧铁证 + 猴侧方向一致但猴侧本身不显著"的元件被推到显著阈值之下。
- "防单侧假阳性"叙事与实际后果（假阴性爆炸）完全相反——审查员只要懂一点统计就能捅穿这条"有益效果"。

**修正（主-参考非对称结构）**：`S = Z₁ × w(Z₂)`
- `Z₁` = 大样本主体物种（人）效应量，是评分强度的**唯一来源**。
- `w(Z₂)` = 小样本参考物种（猴）的方向门控，只给符号：`+1`（同向且方向可信） / `−1`（反向可信） / `0`（方向不可靠，归 C 级"方向参考不足"）。
- 关键：`w` 的方向可信度阈值必须**低于** τ=1.96 才体现"降级"的技术效果——若 w 阈值也取 1.96，则新公式与旧 min 公式**数学等价**（A 级都=1904），降级就是空话。可选阈值：`|Z₂| ≥ 1.645`（p<0.1，方向一致性检验常用宽松门槛）→ 本数据下 A=2180，或更保守的 `|Z₂| ≥ 0.5` → A=3548。

## 坑③：真同向信号只存在于极少数超强效应基因

中低效应基因的人猴方向近乎随机/略偏反（r=−0.06）；只有 `|Z|>15` 的 top 超强效应基因人猴真同向。本会话 7 个"突触脆弱轴"基因全同向下调且猴侧 p_m=0.0000：

`SLC1A2(|Z_m|≈33) / NRXN1 / SYT1 / EPHA5 / EPHA6 / GPM6A / NELL2`

→ 专利若要"可替代性"这个 claim 站得住，必须**收窄**为"识别极少数跨物种同向保守的衰老脆弱核心元件"，而不是"全元件可替代性分级"。诚实定位：整体方向无关（ρ≈0/−0.06），同向可替代只在尾部超强效应基因成立。

## 坑④（2026-09-05 复算补证）："显著性 p"筛不出同向保守，必须双侧强效应阈值 + 同向门控

坑③ 说"同向只在尾部超强效应基因"，本次复算给出更硬的数据证据——**显著性筛出的仍是反向主导，不是同向**：

| 口径 | 基因数 | 同向 | 反向 |
|---|---|---|---|
| 双侧 Bonferroni 显著 (p<3.1e-6) | 1207 | 407 | **800** |
| 双侧 FDR<0.01 | 3028 | 1017 | — |
| `min(|Z₁|,|Z₂|)>12` 且同向 | **37** | 37(全) | 0 |

→ 结论：跨物种"同向保守"不是**显著性**概念，是**效应量双高 + 方向一致**概念。A 级定义必须写成 `min(|Z₁|,|Z₂|) > τ_A`（τ_A 远高于 τ=1.96，且两侧都要过），而非"|Z|>1.96 且同向"——后者会筛出 1903 个反向占多的伪同向。

**37 个核心元件 = 一条自洽的谷氨酸-突触稳态轴，不是孤立的 SLC1A2**：
- SLC1A2 (GLT-1/EAAT2, |Zh|≈34/|Zm|≈33 领衔榜首) + GRIA1/GRIA2 (AMPA 受体) + NRXN1 (突触黏附) + SYT1 (突触囊泡) + EPHA5/EPHA6 (轴突导向) + SORL1 (AD 风险基因) + GPM6A/NELL2/GLIS3...，全部人猴双高同向下调（p 均达机器零）。
- 机制 = 谷氨酸能兴奋性突触稳态在衰老中跨物种同步脆弱化。
- **专利措辞训**：claim 写"SLC1A2 唯一铁证"是错的（自废火力，实为 37 个梯队）；应写"SLC1A2 领衔 37 个核心元件的谷氨酸-突触稳态轴"。

**"窄而硬"降级训（专利）**：宁要 37 个双侧强效应同向的核心元件 + 其余元件诚实标"方向无关/不可判定"，也不要 16031 个"全元件四分级"——后者里反向比同向还多（B 级 3487 > A 级 1904），一打就倒。其余标"不可判定"是**方法边界声明**（宁可漏检不误判方向），不是认输；反向双高元件（如 GRIN2A |Zh|=25/|Zm|=13 但反向）可单列作"物种分歧"观察性证据，不作 claim。

**多文件术语一致性收尾**：改完核心公式后必须 regex 全库扫残留旧术语——本会话权利要求书和交底书曾同时残留"四分级 / B 级 / C 级 / 方向参考不足 / 翻转的 Z₁/Z₂ 下标"等旧词，导致两份文件相互打架，需对每份文件 `re.findall` 复查旧分级词（B 级/C 级/D 级/四分级/伪替代/主体不显著/方向参考不足）直到清零。

## 复算方法（不必重跑 tile 级，直接重算 A/B/C/D）

基因级 Z 值已在 `E:/专利/P3_L1_data/v4b_gene_substitutability_table.csv`（列 `Z_monkey/Z_human/p_monkey/p_human/n_tiles_m/n_tiles_h`）和 `v5_substitutability_all.csv`（多 `same_direction/S/class`）。复算新公式只需：

```python
import pandas as pd, numpy as np
df = pd.read_csv('E:/专利/P3_L1_data/v5_substitutability_all.csv')
tau, thr = 1.96, 1.645            # 主体阈值 + 猴侧方向可信度阈值
Zh, Zm = df.Z_human.values, df.Z_monkey.values
sd = Zh * Zm > 0                   # 同向
w = np.where(sd & (np.abs(Zm) >= thr), 1,
    np.where(~sd & (np.abs(Zm) >= thr), -1, 0))
A = ((np.abs(Zh) >= tau) & (w == 1)).sum()
B = ((np.abs(Zh) >= tau) & (w == -1)).sum()
C = ((np.abs(Zh) >= tau) & (w == 0)).sum()
D = (np.abs(Zh) < tau).sum()
print(A, B, C, D)                  # 定义 thr=1.645 → 2180/3963/4713/5175
```

复核判别力方向必加一行：`print('obs同向比例', sd.mean(), 'vs 随机0.5')`——obs < 0.5 即反相关，别当可替代。
