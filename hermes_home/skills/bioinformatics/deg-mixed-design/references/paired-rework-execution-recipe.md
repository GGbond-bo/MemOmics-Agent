场景：人骨骼肌单核 RNA-seq，AUCell 程序打分，24 donors（Young 10 / Old 对照 7 / Old+T2D 7），
每人 Pre/Post，22 score × 10 亚群 × 5 效应 = 1100 格。效应量热图 5 面板共用 `TwoSlopeNorm(−3,0,3)`。

## 1. 新口径（可直接照抄的实现）

```python
gm = meta.groupby(["type", "annotation_L3", "donor"])[SC].mean()   # ① donor 级聚合

def hedges_g(x, y):                     # ② 独立比较，方向 = y − x
    n1, n2 = len(x), len(y); df = n1 + n2 - 2
    sp = np.sqrt(((n1-1)*x.var(ddof=1) + (n2-1)*y.var(ddof=1)) / df)
    d = (y.mean() - x.mean()) / sp
    J = 1 - 3/(4*df - 1)                # Hedges 小样本校正
    g = d * J
    return g, J, np.sqrt((n1+n2)/(n1*n2) + g**2/(2*(n1+n2)))     # g, J, SE

def d_av(pre, post):                    # ③ 配对比较，方向 = post − pre
    diff = post - pre
    s_av = np.sqrt((pre.var(ddof=1) + post.var(ddof=1)) / 2)     # 与独立 pooled 同尺度
    return diff.mean()/s_av, diff.mean()/diff.std(ddof=1), np.corrcoef(pre, post)[0, 1]
    #    ↑ d_av         ↑ d_z（仅审计）      ↑ r（审计 + 判读配对效率）
```

- 独立主检验 = `stats.mannwhitneyu(y, x)`；副检验 = `stats.ttest_ind(..., equal_var=False)`
- 配对主检验 = `stats.wilcoxon(post, pre)`；副检验 = `stats.ttest_rel(post, pre)`
- 配对**必须按 donor 对齐**：`common = ca.index.intersection(cb.index)`
- FDR = BH，检验族 = 每效应内 220 格（面板口径），但先跑四族敏感性

## 2. 结果对比

| 效应 | 设计 | v4 效应量（中位） | v4 显著/170 | v3 显著/170 |
|---|---|---|---|---|
| Aging | 独立 n=10/7 | g = −1.203 | **88** | 62 |
| T2D | 独立 n=7/7 | g = +0.287 | 0 | 0 |
| ExYoung | 配对 n=10 | d_av = −0.168 | 0 | 1 |
| ExOld | 配对 n=7 | d_av = +0.208 | 0 | 4 |
| ExT2D | 配对 n=7 | d_av = −0.117 | 0 | 1 |

**⚠️ 反面直觉 #1：效应量几乎没变。** 配对组 `d_av` 与旧 pooled `d` 的
**Spearman = 0.997**（中位 `|d_av|` 0.397 vs `|pooled d|` 0.403）。
原因：该数据 Pre/Post 相关**偏低**（r 中位仅 0.322），配对设计的方差削减收益本就有限。
⇒ 修正改变的是**数值合法性与星号归属**，**不必然改变生物学格局**。
**不要把「口径已修正」讲成「结论变了」**；也不能因为数值几乎没变就怀疑返工没生效
（生效证据要看 **p / 星号分布**：Aging 62 → 88/170）。
注：`n₁ = n₂` 时 pooled `d_s` 与 `d_av` 数值恒等 ⇒ **d 相同不能推断口径，只有 p 会说话**。

## 3. 配对 QC —— 负相关是个真发现，别藏

| 效应 | r(Pre,Post) donor 级分布（逐 score×亚群） |
|---|---|
| ExYoung | 中位 **+0.495**（Q1 +0.278 / Q3 +0.619） |
| ExOld | 中位 **+0.413**（Q1 +0.097 / Q3 +0.690） |
| ExT2D | 中位 **−0.195**（Q1 −0.399 / Q3 +0.153）← 负！ |

- 对齐核对：24 donors × 2 时间点，**单时间点孤儿 = 0**，组别 donor 数 Y10/O7/OD7 ⇒ 配对编号无误
- 负 r ⇒ 该组配对检验**效率低于**独立检验。**不许偷偷切回独立口径掩盖**——配对是设计正确的
  做法（控制 donor），应如实报告「该组 Pre/Post 抗相关」并另出独立口径敏感性对照交用户决定
- 负 r 的生物学外提示：常指向 Pre 与 Post 的**建库/测序批次不同**，值得让用户回看批次
- **低细胞分层复核**（关键：排除噪声解释）：per `(组,亚群,donor)` 细胞数 min=**2**、中位 408、
  22 格 <50。剔除 <50 细胞的格后 ExT2D 198 格 r 中位仍 **−0.208** ⇒ **不是噪声，是数据稳健特征**
- r 与最低细胞数的 Spearman 仅 −0.264（弱） ⇒ 细胞数不是 r 的主要驱动

## 5. 功效与 CI —— 「0 显著 ≠ 无效」的实证依据

功效模拟（α=0.05，2000 次重抽样，配对组用 r=0.32）：

| Cohen's d | n=7 配对 | n=7 独立 MWU | n=10 配对 | n=10 独立 |
|---|---|---|---|---|
| 0.2 | 0.068 | 0.046 | 0.078 | 0.058 |
| 0.4 | 0.113 | 0.076 | 0.137 | 0.126 |
| 0.6 | 0.188 | 0.135 | 0.289 | 0.234 |
| 0.8 | **0.312** | 0.227 | **0.481** | 0.357 |

⇒ n=7–10 时 **d<0.8 功效普遍 <0.5**。`0/170 显著` 只能写「**未检出显著证据（功效不足）**」，
**禁写「无效/没有效应」**。

效应量 95% CI：Aging 中位 CI 宽 **2.10**（94/220 格含 0）；T2D 宽 2.12（213/220 含 0）；
运动三效应宽 1.27–1.58（168–194/220 含 0）。

⚠️ 功效模拟的坑：配对噪声必须写成 `post = r*pre + √(1−r²)*noise + d`
（⇒ `corr(pre,post)=r`、`sd(diff)=√(2(1−r))`）。**写成 `post = pre + d`（零噪声）会让
Wilcoxon 恒显著 → 功效假象 = 1.0**。本次首版就踩了。

## 8. 结论表述硬约束（交付时必须写进结论文档）

1. 禁把 `0/N 显著` 写成「无效应」——须写「未检出显著证据（功效不足）」并给效应量 + CI + 功效
2. 主效应主导者在四种 FDR 族下都应稳健（本例 Aging 71–112 格），但 CI 宽要如实报
3. 配对组 r 为负时须在正文/补充材料说明，或对该组另出独立口径敏感性分析
4. 共用色标的跨设计比较有边界：g 含 J 校正、d_av 假定 Pre/Post 等方差，**不等价**，
   正文不宜把两类面板数值当完全同质直接比
5. 低细胞格（本例 22 格 <50 细胞，最少 2 个）打分数值噪声大，引用单格数值需谨慎
