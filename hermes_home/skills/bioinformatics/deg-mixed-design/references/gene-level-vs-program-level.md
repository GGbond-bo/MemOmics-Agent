# 基因级 FDR 检出少 → 三步归因 + 换分析层次（实测配方）

> 场景：多组 × 配对设计的 snRNA-seq（如 24 donors × Pre/Post = 48 样本 × 10 个 annotation_L3 亚群），
> pseudobulk + dreamlet 基因级 DEG 在"运动前后"这类对比上只检出几个到几十个基因，
> 用户直觉"不可能没改变 / 这方法不适合我的组织"。
> **错误反应有两种**：顺着说"方法坏"（不查证），或硬辩护"就是生物学，小效应而已"（拿不出判据）。
> 正确做法：用下面三步把归因做实，再谈换不换。

## 一、三步归因（每一步都必须用工具实查，不许猜）

| 步 | 做法 | 判据 / 实测示例 |
|---|---|---|
| ① **阳性对照** | 同一流程、同一脚本在**另一个对比**上的检出量 | 实测 Aging(O_Pre−Y_Pre) 检出 **29,550** 个 FDR<0.05（名义 P<0.05 占 32.4%），10/10 亚群全跑通 ⇒ **流程未坏**。流程性错误会同时打死所有对比，不可能只打运动 |
| ② **π1（Storey 真实变化占比）** | 每对比估计"真变了的基因比例" | 实测 Ex_Young **π1 = 21.5%**（约 1/5 基因确在变）、Ex_Old 27.2%、Aging 48.7% ⇒ **不是"没变"，是"大面积小幅度"** |
| ③ **检测下限反推** | 由表里 `CI.L/CI.R` 反算 `SE = (CI.R−CI.L)/1.96/2`，求过 FDR 需要多大 \|logFC\| | 实测下限 **\|logFC\| ≥ 0.92（≈1.9 倍）**；而 Ex_Young 中位 \|logFC\| = **0.170**、\|logFC\|>1 仅占 **0.6%** ⇒ 结构上不可能检出 |

**根因是"分析层次错配"**：亚群内 BH 家族 = 12,268–26,879 个基因（各亚群差 2.2 倍）
⇒ 需 **P < ~1e-6** 才能过 FDR。生物学的**协调**变化（通路/程序一起小幅动）永远到不了这个门槛。
⇒ 结论应导向 **换层次**，不是废掉 pseudobulk。

## 二、换层次：四层替代（本地可做，不必回集群重跑）

| 层 | 做法 | 为什么能看见 |
|---|---|---|
| **A1 程序打分（最快见效）** | AUCell 打分（`score*_AUC`，若 meta 里已有则零成本）→ **样本级均值** → 检验 | 把一组协同基因汇总成 1 个数，**不受 12k–27k 基因 FDR 家族稀释** |
| **A2 细胞组成** | 每样本每亚群细胞数 / 每样本总细胞数 → 比例 → 同框架检验 | 组成变化 ≠ 亚群内转录变化，DEG 对组成**结构性失明** |
| **A3 通路/GSEA** | 用**全基因排序**（t 或 `sign(logFC)·(−log10 P)`）跑 fgsea / limma roast | 小幅协调变化在基因集层可见；**不要只喂 FDR<0.05 的基因列表** |
| **A4 粗粒度聚合** | 按纤维类型大类（I / IIA / IIX 或 I / II）聚合重跑 dreamlet | 减少检验数 + 增加每格细胞数，作为降家族负担的敏感性 |

**检验框架（配对/独立必须分派，别用一套）**：

| 对比类型 | 检验 | FDR 家族 |
|---|---|---|
| 配对（同 individual，Post−Pre） | **paired t**（主）+ **Wilcoxon signed-rank**（副） | 每对比内 across（程序数 × 亚群数），如 14×10=140 |
| 组间独立（Aging / DM） | **Welch t** + **Mann-Whitney U** | 同上；比例层 across 亚群数（如 10） |

方向约定（与 DEG 表保持一致，避免误读）：`diff = 组2 − 组1`，其中
`Aging = Y_Pre→O_Pre`、`DM = O_Pre→OD_Pre`、`Ex_Young = Y_Pre→Y_Post`、
`Ex_Old = O_Pre→O_Post`、`Ex_DM = OD_Pre→OD_Post`。

**实测结果（这套换层次后运动信号立刻清晰）**：

| 对比 | 程序层 | 细胞比例层（同步） |
|---|---|---|
| Ex_Old | Pure Type IIX `scoreIIx` **d = −2.89（FDR = 0.049 ★）**；`scoreIIa` 在 **8 个亚群**同时上调（d = +1.6~2.3：RP_high(II) +2.33★、OTUD1+(II) +2.23★、Pure IIX +1.97、RP_high(I) +1.82、Pure IIA +1.78、Specialized MF +1.69、OTUD1+(I) +1.65、RSS +1.59） | Pure Type IIX 3.49%→**1.18%（比值 0.34**，FDR=0.062）；OTUD1+(II) 2.22×；Specialized MF 1.85× |
| Ex_DM | **10/10 亚群 `scoreIIx` 一致下降**（d = −0.9 ~ −1.33；FDR 未过但方向 100% 一致 —— 这是"协调变化"的典型特征） | Pure IIX 5.70%→3.11%（0.55） |
| Ex_Young | Insulin 程序 d = +1.37（LRP1B+(I)）/ +1.36（Pure Type I） | 无显著 |
| Aging | 77/140 组合 FDR<0.05（最强） | Pure Type IIA 0.59★、RSS 6.40★ |

**结论链**：`scoreIIx` 下降 + `scoreIIa` 上升 + Pure IIX 细胞比例腰斩 = **经典 IIX→IIa 纤维类型转换**，
三条独立证据指向同一件事 —— 而同一批样本的基因级 DEG 表上这件事**完全空白**。
⇒ **一句话口径**：pseudobulk 基因级回答"哪些单基因大幅变了"；运动适应这类**程序级 + 组成级**
变化它看不见。**该换层次，不是换掉方法。**

## 三、两个必须避开的自造显著性陷阱

1. **🔴 面板富集的"选择偏倚"**：若对候选面板基因取"**跨亚群最小 P**"（挑最显著的那个亚群），
   却对全基因组率**不取最小**，就会自造出 fold 3–5、p~1e-6 的"富集"。
   **修正**：面板与全基因组**同样处理**（都取每基因的跨亚群最小 P，或都不取），再算
   Fisher / Mann-Whitney。实测修正后 fold 0.94–1.27、p = 0.79 / 0.31 / 0.24 —— **富集不显著**，
   原先那个"显著富集"必须撤回。**发现自己的检验有偏倚时，先撤回数字再往下讲。**
2. **组成变化 vs 表达变化别混**：细胞数差异可能来自解离/捕获偏倚而非真实组成位移
   ⇒ 比例差**必须做配对检验**（n=7–10 方差大，均值比值不能当结论），并说明是否有组织学/免疫染色可正交验证。

## 四、交付口径（写 methods / 汇报时必须带）

- 不写"**无**运动效应"，写"**在当前亚群、细胞数、FDR 家族和检测下限下基因级 FDR 未广泛显著**"，
  并列 **π1 + 中位 |logFC| + 检测下限（如 \|logFC\|≥0.92）+ 名义 P/效应量分层**。
- 同时报**基因级（作对照）+ 程序级 + 组成级**三层结果，并说明各层回答的是**不同问题**。
- 跨亚群**不要横比显著基因数**（家族大小 12k–27k 差 2.2 倍；组间 vs 配对功效也不等）。
- 因共享项导致的对比间相关（如 Ex_Old 与 Aging 84% 方向相反）**不得作生物学解读**，见 SKILL.md 陷阱条。
