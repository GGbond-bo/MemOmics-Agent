# 混合设计效应量口径：独立 vs 配对（公式库 + 审计配方）

> 触发场景：混合设计（多组独立 + 同一受试者前后配对）下要出**效应量热图**
> （如 FigA2 五效应矩阵 `effect5_d_v2.csv` → 出图脚本），或审计"这张图的数怎么算的"。
> 出处：Lakens D. 2013 *Front Psychol*，**PMID 24324449 / DOI 10.3389/fpsyg.2013.00863**
> （d_z / d_av / d_rm 三式与 Hedges' g 校正因子的原始出处，公式命名以该文为准）。

---

## 1. 公式库（按设计选，不按喜好选）

| 设计 | 公式 | 何时用 |
|---|---|---|
| 独立样本 | `d_s = (x̄₂ − x̄₁) / s_p`，`s_p = √[((n₁−1)s₁² + (n₂−1)s₂²) / (n₁+n₂−2)]` | 仅作中间量 |
| 独立样本 | `g = d_s × J`，`J = 1 − 3/(4·df − 1)`，`df = n₁+n₂−2` | **同一格**的最终值 |
| 配对/重复测量 | `d_z = mean(diff) / sd(diff)` | 功效分析、单研究内报告 |
| 配对/重复测量 | `d_av = mean(diff) / √[(s_pre² + s_post²)/2]` | **跨设计比较 / 共用色标** |
| 配对/重复测量 | `d_rm = d_av × √(2(1−r))` | 同上，且要显式报 r |

**独立组该用 Hedges' g 而不是 Cohen's d**：n 小（donor 数在个位～十几）时 `d_s` 有系统性正偏差，
`J` 是纠偏因子。实算（别估）：

| n₁ / n₂ | df | J | g / d_s |
|---|---|---|---|
| 10 / 7（本项目 Aging） | 15 | **0.9492** | 0.95 |
| 7 / 7（本项目 T2D） | 12 | **0.9375** | 0.94 |
| 5 / 5 | 8 | 0.9032 | 0.90 |
| 4 / 4 | 6 | 0.8696 | 0.87 |

⇒ **本类数据（n=7~10/组）的校正幅度只有 ~5-6%**，远小于配对侧 `d_z` 的放大（r=0.8 时 +58%）。
**因此不许\"只给独立两列上 g、运动三列留裸 d\"**：两族在同一色标上会系统偏 5%，
\"跨列比深浅\"不严谨，审稿人也会问\"为什么只对两列做小样本校正\"。
**规则 = g 要上就 5 列全上**（t 值/p 不变，只有 d 乘 J）；配对列固定 `d_av`。

---

## 2. 铁律：**一张图共用一个色标 → 配对比必须用 `d_av`（或 `d_rm`），不能用 `d_z`**

理由不是一个数字问题，而是**色标可比性**问题：

```
d_z / d_av ≈ 1 / √(2(1 − r))        # r = 同一受试者 Pre/Post 的个体内相关

r = 0.3 → 0.85×     r = 0.5 → 1.00×     r = 0.8 → 1.58×
```

同一人 Pre/Post 的组学打分（AUCell/通路分）常见 r ≈ 0.6–0.9，因此：

- **用 d_z**：运动三格被放大最多 ~58%，在与 Aging/T2D 共用的 ±3 色标上凭空出现
  「运动效应比衰老效应强」的**假象** —— 差异来自 r，不是生物学。
- **用独立法（当前缺陷）**：pooled SD 把个体间差异也算进分母 → 分母偏大 → 效应量**被低估**
  （保守方向），同时 p 因未消个体方差而功效损失。

两条错法方向相反，所以"看起来还挺合理"是巧合，不能当作没问题的证据。

## 3. 审计配方：回答「这张图到底怎么算的」

**入口陷阱**：出图脚本常常**只读表不重算**（`read.csv` 取 `d` / `q` 列后直接 `tapply` 涂色），
算法藏在**建表脚本或验表脚本**里。只看绘图脚本会得出错误结论。

1. 读绘图脚本 → 确认它读的是哪张表（`EFF_CSV <- ".../effect5_d_v2.csv"`），公式不在这里
2. `search_files "effect|d_v2|verify|matrix"` 找**建表/验表**脚本 → 公式在这里
3. 拿**一格的 d/p 真值**，枚举 `{聚合层级} × {d 公式} × {检验族}` 变体复现，看谁同时命中
4. 判定口诀：
   - **d 命中、p 不中 → 检验族错**（如独立 t 用在了配对设计）
   - **d 与 p 都不中 → 聚合层级错**（细胞级 vs 个体级 vs 亚群级）
5. ⚠️ **`n₁ = n₂` 时 pooled `d_s` 与配对 `d_av` 数值恒等** → **d 相同不能推断口径**，
   只有 `p` 会说话。别用"d 对得上"下结论。
6. **FDR 检验族必须同步复核**：全表 vs 每 score vs 每效应（如 1100 / 每 score / 220 格三种口径
   会给出不同的 q）。**d 换了、q 的族没换 = 口径错配**，星号会挂错格子。
7. 报审计结果时给**影响量化**（同数据只换检验，p 变成多少），让用户决定是否返工 —— 只报
   "口径可能不对"不给数字，用户无法判断值不值得重跑。

## 4. 本类数据实测记录

**2026-09-25，骨骼肌 MF AUCell 打分（`MF_AUCell_meta.csv` → `effect5_d_v2.csv`）**

- 缺陷：5 个效应（Aging / T2D / ExYoung / ExOld / ExT2D）**全部**用
  个体级 pooled-SD `d_s` + **Welch 独立 t**；3 个运动效应是同一受试者 Pre/Post，配对信息完全没进模型
- 数据单位：先按 `(type, 亚群, donor)` 取均值 → donor 级（`samplename` 去 `_Pre`/`_Post` 得 donor）
- 影响量化（只换检验，同一份数据）：
  | 效应 | 独立 p（现） | 配对 t p | 结论 |
  |---|---|---|---|
  | ExOld | 0.4521 | 0.2874 | 方向不变、功效显著改善 |
  | ExYoung | 0.4272 | 0.4008 | 略改善 |
  | ExT2D | 0.8341 | 0.8501 | 基本不变 |
- n=7/组 时这个差距**足以改变"是否有信号"的判断**，且解释了此前"BH 校正后大面积不显著"
  中相当一部分是**功效不足**而非"真的没效应" → 必须同时报效应量 + 置信区间，不能只看 p
- 返工口径：Aging / T2D → Hedges' `g`；三个运动效应 → 配对检验（Wilcoxon signed-rank 或配对 t）
  + `d_av`（共用色标）；FDR 检验族同步重定
