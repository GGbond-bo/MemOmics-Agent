# Figure Completeness Check — Post-Report Generation

## Problem

HTML reports generated via the `ReportBuilder` only include figures that were explicitly
passed to `add_figure()`. When the LLM generates the report, it often omits figures
generated by earlier analysis steps — especially from `CellChat`, `deg-analysis`,
`functional-enrichment`, and other automated pipelines that produce many PNGs.

**Symptom**: User opens the report and says "I only see CellChat figures, where are the
DEG/enrichment/other figures?"

## Root Cause

The LLM does not auto-scan the results directory. It only adds figures it "remembers"
from the immediate context. After a long multi-phase analysis (CellChat → DEG →
Enrichment → WGCNA → Report), the context may only contain the most recent figures.

## Fix Procedure

After generating the report HTML, run this verification:

```python
import os, re

report_path = "path/to/report.html"
results_dir = "path/to/results/session_dir/"

# 1. Count PNGs on disk
pngs = []
for root, dirs, files in os.walk(results_dir):
    for f in files:
        if f.endswith('.png'):
            pngs.append(os.path.join(root, f))
print(f"PNGs on disk: {len(pngs)}")

# 2. Count base64 images in report
with open(report_path, 'r', encoding='utf-8') as f:
    html = f.read()
b64_count = len(re.findall(r'<img src="data:image/', html))
print(f"Base64 images in report: {b64_count}")

# 3. If mismatch, embed missing PNGs
if len(pngs) != b64_count:
    print(f"⚠️ MISSING {len(pngs) - b64_count} figures!")
    # Embed all missing as base64 at correct section boundaries
```

## Embedding Pattern

When figures are missing, use this pattern to embed them:

```python
import base64

def png_to_b64(full_path):
    with open(full_path, "rb") as f:
        return base64.b64encode(f.read()).decode()

def make_fig_html(title, caption, b64, method="", result="", bio="", params=""):
    return f'''<details class="subsection" open>
  <summary><h3>{title} </h3></summary>
<div class="fig-block">
  <div class="fig-container">
    <img src="data:image/png;base64,{b64}" onclick="openLightbox(this.src)">
    <p class="fig-caption"><em>{caption}</em></p>
  </div>
  ...
</div>
</details>'''
```

Insert each figure block at the appropriate section boundary using `str.replace()`
with unique anchor strings from the existing HTML.
