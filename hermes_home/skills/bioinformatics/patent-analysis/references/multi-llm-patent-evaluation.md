# 多LLM专利方案评审框架

> 2026-07-21 · 用于跨物种可代替性方法专利方案的三方评审

---

## 模式

用户可能将专利方案同时提交给多个LLM（如Kimi K3、DeepSeek、MemOmics），然后要求MemOmics裁决各方的评价。这是一个**可复用的方法论评审模式**。

## MemOmics的角色

作为**终审裁决者**，需做三件事：

1. **逐条裁决**：对每个外部LLM的每个论点做对/错/半对半错的判定
2. **萃取真创新**：从各方评价中识别真正有专利价值的差异化特征
3. **融合最终方案**：取其精华去其糟粕，产出终版方案

## 裁决标准

| 维度 | 判断依据 |
|:---|:---|
| 专利法合规性 | A25(智力活动) / A22.3(创造性) / A26.4(不清楚) 三类驳回的防御是否充分 |
| 与现有技术的差异化 | 是否准确识别了阮航/郭国骥/周展/Jaroszynski等人的空白 |
| 方法论的统计根基 | Pseudobulk个体聚合、混合效应模型、SDI是否有充分统计学支撑 |
| 商业可行性 | 是否有清晰的企业使用场景（不是"能算出分数"而是"能帮企业省多少钱"） |
| 独权进入策略 | ESM-2不进独权(黑盒风险)、SDI统计量进独权+阈值进从权(留弹性) |

## 本次裁决实例

| LLM | 做对的 | 做错的 |
|:---|:---|:---|
| **Kimi K3** | A+C双专利架构、同日提交策略、人源数据挖掘AD对照组 | S300方法论是"加权打分+bootstrap"——缺乏真实的创造性防御 |
| **DeepSeek** | 指出K3的创造性软肋、贡献pseudobulk+Mixed Model两个真武器 | ESM-2进独权(学术理想主义→审查风险) |
| **终版融合** | K3的架构 + DeepSeek的统计内核 + ortholog兜底 + MemOmics的S205/S335/S600增强 |

## 关键教训

- 通用LLM容易把"加权组合已知指标"当作创新 → 审查员的标准驳回模板专门打这个
- 学术LLM容易把黑盒模型(ESM-2)推进独权 → 审查员A26.4驳回无法答辩
- **只有同时懂专利审查规则+生信统计方法的评估，才能识别真正的创新点**
