# 交底书「缺件」审计：从权实施例落点 · 形式项 · 黑白附图

> 适用：交底书（或 claims/disclosure 交付件）**内容与数字都对账通过之后**，用户仍贴来一份
> 复核清单，形如「检索记录 🟡 未做 / 摘要附图 🟡 未指定 / 权 5 权 10 实施例 🟡 未做 / 权 12 支撑力 🟡 偏薄」，
> 并说「**这几个也做一下**」（2026-09-12 实测）。
> 这类问题的共同点：**不是数字错，是"该有的落点没有"**。修法与数字替换完全不同——
> 数字替换靠 grep，缺件靠**补跑实验 + 补写段落 + 指明附图**。

## §1 四类缺件速查表

| 症状 | 为什么是硬伤 | 要做什么（不是润色） | 交付判据 |
|------|-------------|-------------------|---------|
| 检索记录 🟡 无检索式 / IPC / 对比文件 | 交底书给代理人撰写用，无检索记录 = 代理人无法判新颖性；IPC 是申请文件必备形式项 | 补 **3 组检索式**（技术圈 / 抽象方法圈 / IPC 分类号）+ **IPC 建议分类号** + **D1–D3 对比文件表** | 表里每条对比文件有**真实可核的标识**（PMID/DOI 或专利号），不是"某研究" |
| 摘要附图 🟡 全文零命中 | 形式项缺失，受理阶段即要求补正 | 在「附图说明」里**指名一张**（`摘要附图：图 1`）+ 摘要正文出现「摘要附图」字样 | `grep 摘要附图` 命中 ≥2 处（说明段 + 摘要段）；只选 1 张，优先**流程总图**（信息量最大） |
| 权 N 实施例 🟡 无落点 | A26.3 实施例不充分——从权写了几种方式/几项用途，实施例只落地了其中一种 | 逐一**补跑实验或补写实施例段**（见 §4） | 每个从权声明的**每一种方式 / 每一项用途**都能指到具体实施例段落 |
| 权 N 支撑力 🟡 偏薄（n 小） | 小样本实施例撑不住权项；审查员按 A26.3 质疑"无法证明技术效果" | **不是改文字**：① 报三元组（观测/零假设/z）② 给区间估计 ③ 补一个**样本量大得多的同族实施例**（见 §5） | 支撑数从个位数提升到可统计量级，或至少给出 CI 下界 + 效应量 |

⚠️ 顺序：**先把"有没有落点"判完，再改文字**。落点缺失时改文字 = 让文档更自洽地缺证据。

## §2 检索记录写法（补空白，不是铺量）

结构（表格化，代理人可直接抄）：

1. **检索式**——三组，逐组写明库与限定：
   - 组 1 技术圈：具体技术词（如 `跨物种 AND 染色质可及性 AND 筛选`）
   - 组 2 抽象方法圈：去掉技术词只留方法语义（比组 1 更重要，漏检通常漏在这）
   - 组 3 IPC 分类号：`G16B 40/00`（生物信息学数据处理）、`G16B 20/00`、`G16B 30/00`、
     `C12Q 1/68xx`（核酸分析）、`G01N 33/50`——**分类号只作为检索入口与申请文件形式项，
     不要把它当"技术属于该分类"的论证**
2. **对比文件表 D1–D3**：交底书 §四（现有技术）里**已经点名过的文献必须落成 D1/D2**（否则正文提了
   名字、对比文件表里却查不到 = 自相矛盾）。D3 选**最接近的第三类**（本例：跨物种染色质外部验证源）。
3. **真实性红线**：D1–D3 的 PMID/DOI/专利号必须**实际检索核实**（`search_papers` / Google Patents），
   🔴 凭 §四 的叙述反推编号 = 造引文。检索不到的宁可写"待补"并说明检索路径。

## §3 摘要附图

- 位置 A：`五、附图说明` 段末 → `摘要附图：图 1　技术链示意图`
- 位置 B：`零、说明书摘要` 正文 → 结尾加「摘要附图为图 1。」
- 选哪张：**流程总图**（一张图说清五个步骤）> 结果图。摘要附图要独立可读、不依赖正文数字。
- 附带清理：附图说明里每张图的图注若引用了正文数字，摘要附图选定后要复核该图注与正文一致。

## §4 从权实施例落点（最常见的两类）

### 4.1 从权写了「两种方式」，实施例只有一种（标本：权 5）

从权 5 原文：「限定**年龄标签置换**与**同源对应关系置换**两种方式」——正文却有**年龄标签置换**一个落点，
同源对应关系置换**全目录零命中**。

处置 = **真跑**同源对应关系置换（不能只写一句话）：

- 置换对象 = **同源配对关系**（打乱"参考侧哪个单元↔主体侧哪个单元"），不是年龄标签；
- 保留强度、只破配对（与符号置换的区别要写清，避免与已有零假设重复）；
- 分层置换更稳（按覆盖度/可比对性分层内置换，与权 11 的"层内匹配基准率"呼应）；
- 报告 **观测 vs 空分布均值±SD vs 配对 z**，并明说该置换**检验的是什么技术问题**
  （统一网格的映射是否携带信息，而不是"同源比随机更同向"这类进化常识——后者是废话级结论）。

🔴 与已知边界的一致性：若文档已在"失效边界"披露"参考物种尚不宜作方向参考"，同源置换的结果
**必须与之一致叙述**，不要造出一个互相矛盾的正结果。诚实写负结果 + 技术解释，比硬凑正结果安全。

### 4.2 从权并列 N 项用途，无一项有实施例（标本：权 10）

权 10 原文并列三项用途（可替代性评估 / 靶点筛选 / 干预跨物种转化验证）。补实施例时**逐项落点**，
且**落点必须是已有的真实资产或已算过的数字**，例如：

| 声明用途 | 可给的实施例落点 |
|---------|----------------|
| 参考物种可替代性评估 | 本数据集标定结论（含"不宜作方向参考"的定量依据）——就是失效边界段 |
| 脆弱元件 / 药物靶点筛选 | 核心元件清单 + 生物学可解释性（通路/轴上的具体基因） |
| 干预的跨物种转化验证 | 明确写"需配套干预实验"，给**输入输出规格**（输入什么表、输出什么字段），不虚构结果 |

⚠️ 用途实施例**允许**是"输入输出规格 + 可执行流程"，**不允许**是编造的下游结果。

## §5 从权支撑力：小 n 的三条补强（不是改文字）

标本：权 12 的 bin 级门控实施例 —— `|z̄|≥1.5` 时**输出 8 个单元、同向率 100%、配对 z=+3.27`，
但 **n=8** 撑不住"门控有效"的主张。三条：

1. **三元组 + 区间估计**：报 `(观测率, 匹配零假设期望率, 配对 z)` **并给率的置信区间**
   （8/8 的 Clopper-Pearson 95% 下界约 0.63，不是 1.0）。只给点估计 = 掩盖小 n。
2. **加密扫描、看单调性**：把阈值从稀疏几档加密（0.3→2.0 每 0.1 一档），**单调趋势比单点更有力**；
   同时补精确二项检验，避免只看配对 z。
3. **补一个同族但 n 大得多的实施例**（最有效）：权 12 讲的是**单元粒度（bin 级）实施**，
   而现有实施例是**基因级代理**（n 只有几十/几）。真正的 bin 级网格有 **221,069 个单元** →
   在真网格上跑同一门控，n 提升 4 个数量级，支撑力问题从根上消失。
   🔴 补跑前先确认网格文件列齐（`Z_m/Z_h/p_m/p_h/count_m/count_h/bin/symbol`），并**保留原实施例**（作对照）。

## §6 黑白线条附图（专利附图形式要件）

法规依据：《专利审查指南》第一部分第一章 2.4 —— 说明书附图应当用制图工具和**黑色墨水**绘制，
线条均匀清晰、**不得着色**、不得涂改。⇒ **彩色 PNG 不合规**，需另出一套纯黑白版。

### 6.1 制作手法（不依赖颜色区分系列）

- **填充图案**替代色块：斜线 `///`、反斜线 `\\\\`、交叉 `xx`、点纹 `..`、横线 `--`
- **线型**替代色线：实线 / 虚线 / 点划线
- **标记**替代色点：实心 ● / 空心 ○ / 方块 ■ / 三角 ▲
- 标题条用**黑底白字**（比灰底更清晰且仍是纯黑白）
- 柱状图/箱线图：白底 + 黑边 + 图案填充；多系列靠图案区分

### 6.2 量化校验（必做，不能只肉眼看）

```python
from PIL import Image
import numpy as np
im = Image.open(p).convert('RGB')
a = np.asarray(im)
color_px = (a.max(axis=2).astype(int) - a.min(axis=2).astype(int)) > 12   # 非灰阶像素
print(p, im.size, '彩色像素 %.3f%%' % (100*color_px.mean()))
```

判据：**彩色像素 0.000%**（阈值内允许 JPEG/PNG 压缩噪声，>0.1% 即需重出）。
另附墨迹占比（`<250` 的像素比例）确认不是空白/过淡。

### 6.3 两套并存策略

| 版本 | 用途 | 目录 |
|------|------|------|
| 黑白线条 | **专利附图**（提交/送代理） | `figures_bw/*_bw.png` |
| 彩色 | 交底书内部配图、答辩 PPT、论文插图 | `figures/` |

交付汇报时**分别说明两套的用途**，并给出黑白版的量化校验结果（每张尺寸 + 彩色像素占比 + 墨迹占比）。

## §7 执行纪律

- 一个产物**一个探针跑完全部检查**（形式项 + 缺件落点 + 附图形式一次输出），禁止"想到一项写一个小脚本"；
- 补跑的新实验**另存新文件**，不覆盖原实施例；
- 交付时报「已做 / 未做 / 待用户拍板」三分类，**不要替用户决定删减权项**。
