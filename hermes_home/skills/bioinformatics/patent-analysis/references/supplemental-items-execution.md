## ① 后验富集（辅助权项，如「权 5 衰老基因集后验富集」）

### 配方

| 要素 | 取值 |
|---|---|
| 前景 | 主方案产出清单（如核心元件 150 个 symbol） |
| 背景 | **全部单元**（如 16,029 同源单元）；另做**敏感性背景**（如「人侧有 peak 的 15,865」）复算 |
| 检验 | 单侧超几何（`hypergeom.sf(k-1, N, n, K)`）+ BH-FDR |
| 基因集 | Enrichr API 实下载（**严禁凭记忆手写**），见 `scripts/enrichr_ora_hypergeom.py` |

### 🔴 四个必踩的坑

1. **基因名大小写**：Enrichr 全大写 → 前景/背景 symbol 必须 `.str.upper()`，否则命中恒为 0。
2. **库名拼错不报错**：不存在库返回 **404 HTML**，`urlopen` **不抛异常** → 检查首 4 字节 `<!do` 或行数。
3. **校正口径**：撒网全库（数千条）时 FDR 极易全不过。实测同一数据三种口径差异巨大：

   | 口径 | 检验数 | 名义 p<0.05 | FDR<0.05 | 最小 FDR |
   |---|---:|---:|---:|---:|
   | 全库（8 库合扫） | 3,794 | 107 | 1 | 0.0082 |
   | 预限定衰老签名子库 | 842 | 28 | 0 | 0.0506 |
   | **单库 GEO-aging-up** | 286 | — | **1** | **0.0219** |

   → 若分析前已限定语义子库，可做**库内 BH-FDR**，但**必须在报告和说明书里显式标注口径**。
4. **签名层 ≠ 通路层**（易被审稿人抓）：
   - 表达**签名**层（`Aging_Perturbations_from_GEO_up/_down`、`GTEx_Aging_Signatures_2021`）：实测显著，fold 3.2–5.4×，多个独立数据集重复（Mouse neuroretina GSE38671 10 hits / fold 4.53；Mouse bone marrow adipocyte GSE25905 8 hits / 5.41；Rat entorhinal cortex GSE14505 8 hits / 4.03）。
   - 经典**机制通路**层（Reactome Cellular Senescence R-HSA-2559583 / KEGG hsa04218 / SASP R-HSA-2559582）：实测**不显著**（2 hits p=0.361；2 hits p=0.384；0 hits）。
   - → **两层分开写**，结论限定在实测显著的那一层；阴性层如实写。辅助权项非硬门，阴性不阻塞送审，但**隐瞒会被抓**。

## ② 对照侧聚合（如「猴侧序列保守」）

### 关键技术：用**本物种坐标映射列**落回同一窗口

若对照物种的 peak/区间表自带**目标坐标系**的映射列（实测 `l1_full_monkey.csv` 含 `hg38_chr / hg38_start / hg38_end`，288,326 行 100% 非空），则可直接：

```
对照侧 peak（本物种坐标）→ 取 ___hg38_ 映射列作为窗口坐标 → 按前景同一套基因窗口（±2 kb）聚合
```

**比 liftOver 稳**：本任务 liftOver 路线已因本地唯一 chain 是旧装配（rheMac3→hg38，2010）而判死；映射列来自上游锚定管线，坐标体系天然一致。**先探映射列，再谈 chain**。

### 实测产出（可作为配方验收参考）

| 指标 | 值 |
|---|---|
| 双物种均有 peak | 15,860 / 16,029（98.9%） |
| 前景（150 核心元件）对照侧覆盖 | **100%** |
| 前景对照侧保守均值 vs 背景 | 0.4348 vs 0.2187 = **2.0×** 富集 |
| 两侧保守分数相关性 | Spearman **ρ=0.7644（p≈0）**；Pearson r=0.7672 |
| 双物种均达阈（≥0.50） | 42/150 = **28%** |

### ⚠️ 主张边界（辩论裁决 modify）

- ✅ 可主张：**聚合层 / 对照侧富集层**的跨物种保守（ρ、覆盖率、2.0× 富集、98.9% 双物种可及）
- ⛔ 不可主张：前景元件**逐一**双物种均保守（仅 **28%**）
- 📌 必写：阈值敏感性（0.25 / 0.50 两档）+ 28% 作为限制条件
- 📌 待补（非阻塞）：独立实验验证（MPRA/ChIP）、bootstrap 置信区间

## ③ 装置端封装（对应装置权项，如权 14）

### 结构（六单元类 + CLI + 说明书）

```
装置_<ver>/
  <name>_screener.py      # 主装置：六单元类串联
  run_device.py           # CLI（--units/--config/--out，可选 --human-peaks/--monkey-peaks）
  config.example.json     # 阈值/窗口/黄金区间（全部可覆写 → 参数可追溯）
  README.md               # 说明书 + 「权利要求 N 模块 ⇄ 装置类」对应表
  demo_out/               # 真实数据运行产出
```

单元 ⇄ 权项模块一一对应，便于举证：同源锚定 / 序列保守(L1) / 跨物种可及(L2) / 年龄效应(L3) / 三柱交集 / 输出质控。

### 两个「装置区别于脚本」的必备产出

| 文件 | 作用（撰写要点） |
|---|---|
| `gate_trace.json` | **逐层基数溯源 + 本次阈值快照** → 支持「参数—产出可复现」主张 |
| `qc_report.json` | 黄金区间判定 / 各柱收缩率 / 必需列完整性 / 越界告警 → 装置具备**自检能力** |

### 验收标准（缺一不可）

- **端到端用真实数据跑通**，且**复现主流程数字**：实测 16,029 → L1 3,180 → L1∧L2 1,604 → 三柱 AND **150（与主流程完全一致）**，退出码 0（落在黄金区间）。
- 装置说明书里写出这条一致性复现命令 → 构成**可实施性证据**，把装置权项从「描述」升级为「可运行实现」。
