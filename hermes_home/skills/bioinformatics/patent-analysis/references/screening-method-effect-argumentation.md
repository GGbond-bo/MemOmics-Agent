## §1 先分清两件事 —— 定位锁定铁律

| 层 | 内容 | 被否后的正确动作 |
|---|---|---|
| **生物学结论层** | "人猴共享衰老程序 / 筛出的是保守可外推集" | 报告它不成立；**不得据此改 claim 定位** |
| **方法/效果层** | "逐元件判定方向可迁移性、输出带误差控制的清单" | 补强证据；**独权动词链一字不动** |

🔴 **2026-09-12 实测教训**：判定"结论层不成立"后，我自行提议把专利重定位成"误差控制 / 风险标定"框架 → 用户当场不满：「我想做的就是跨物种保守性可代替性方向的……**你一直在改**……**我们的专利不应该是筛选方法吗？**」

**根因**：`生物学结论被否` 和 `专利要改` 被我用了同一个词"专利"，于是来回摇摆。**这两件事必须分开说、分开处置。**

**铁律**：
- 两层判定的用途**只是报告**（哪层成立、哪层不成立），**重定位只能由用户拍板**。
- 用户一旦点名"筛选方法"，该定位即**锁定**，不得再提换保护对象 / 改发明名称 / 改独权落点。
- **自查信号**：若你正在提议改独权落点，而用户从未要求 ⇒ 立即停手。
- 正确动作 = 保留现行独权动词链不动，只做**防守性补强**（见 §3 末尾那句实用性防线）。

## §2 效果证据的三条可用来源（都能从现有数据出，不需重跑管线）

| 证据 | 怎么用 | 反驳的是哪句质疑 |
|---|---|---|
| **双实现互证** | 两套独立实现跑出同一结论（本项：锚定器 16,029 × 管线 16,010 → 357 同向 / 533 反向） | 「这不是乱编的吗」—— 乱编不可能两套独立实现复现出同一批元件 |
| **输出带误差控制** | 每个元件给五态判定 + 置信分级 + 失效边界，而非丢一张名单；阈值由置换空分布定，可复核 | 「方法就是拍脑袋定阈值」 |
| **筛选性能三元组** | topK 成功率 **必须同屏报 (观测率, 匹配零假设, 配对 z)**（本项 topK=100 → 61.0% vs 56.2%，z=+1.24） | 「用了有什么用」—— 有可测的技术效果量 |

🔴 **率类指标只报绝对率 = 把零假设同步移动误读成信号增强**。诚实读法必须写出来：本项目是**从「显著低于随机」纠正为「与随机不可区分」**，一步没跨过随机 —— **不要写成"性能提升"**。

## §3 法理锚点

- **A22.4 实用性** 要求的是「**能够被制造或使用，并产生积极效果**」。一套能跑、输出确定、可复现的数据处理步骤**本身就满足**；**不要求**"筛出的集合在生物学上被证实为真衰老元件"。
- 审查员若追问技术效果 → 给**三基线横评**（见 §4），不给生物学结论。
- 消费者/企业视角的补强（skill 主文件已有"企业为什么用"要求）：效果句写成**可交付的东西**（带风险分级的元件清单），不写成**科学主张**。

**防守性防线一句话**（加进 `A22.3_对比实验与答辩论据.md` 末尾，不动独权）：

> 本方法输出的是带可信度标注的候选元件集，技术效果是**筛选与标注**，不承诺集合整体的生物学显著性；方法可复现、输出确定，满足 A22.4。

## §4 A22.3 三基线横评设计（用现有数据可出）

| 对照基线 | 指标 | 用途 |
|---|---|---|
| ① 两队列各自筛选取交集 | FDR 实测控制率 | 证明"天生校准"，替代要辩护的富集倍数 |
| ② 合并 Z 做 meta 分析 | 跨物种 hold-out 复制率 | 证明可迁移性，不依赖同物种复现队列 |
| ③ 单物种筛选 | 已知衰老基因集功能命中率 | 把主张从"发现共享程序"降级为"筛出更多已知真阳"——变弱但可证 |

## §5 靶点 / 元件验证：语义错配是头号陷阱

**2026-09-12 实测**：357 核心元件的 gene symbol 对 Enrichr `Aging_Perturbations_from_GEO_up/down`（286+286 条）做 Fisher：

| 集合 | 结果 |
|---|---|
| 357 核心 | 多数条目**期望 0.02 个、实际命中 0~1 个**；`fold=44×` 但 `p=0.022` 全库未校正 → **不显著** |
| 反向 19 | **全部 0 命中** |
| 背景池 | 16,010 基因（357 全部在池内） |

🔴 **读法不是「富集失败」，是「语义错配」**：元件是**染色质可及性**单元、邻近基因走 ortholog 锚定；GEO 衰老库是**表达差异**基因。**ATAC 可及性变化 ≠ 表达变化**，两套东西本就不该重合。

⇒ **禁止**据此宣称"方法无效 / 筛选是乱编"。先判错配，再判成败。

**可行的替代验证路径**（按性价比排序）：
1. **靶点级文献核查** —— 拿具体 symbol（CDH13 / NRXN1 / SLC1A2 / RBFOX3 …）逐个查 PubMed 有无脑衰老关联报道。回答的是"**筛出的东西有没有生物学意义**"，不是"方法有没有效"。
2. **元件级特征一致性** —— 核心元件是否富集于脑特异开放区 / 特定染色质状态（需额外注释数据）。
3. **ATAC–RNA 耦合** —— 同一元件可及性方向 vs 邻近基因表达方向是否一致（正交证据，最强；**需 RNA 矩阵，本项目本地无，须先核库存**）。
4. **参考侧内部一致** —— 不必跨物种：脑区间 / 细胞类型间方向一致率（snATAC 自带细胞类型）。

**汇报纪律**：用户自己已点明「靶点只是方法的一个结果」→ **不要在靶点列表上找方法的效果**，主动把这句分界说出来。

## §6 Enrichr 实操（可复用技术）

```python
import requests
# ① 取基因集库（可靠路线）
txt = requests.get("https://maayanlab.cloud/Enrichr/geneSetLibrary",
                   params={"mode":"text","libraryName":"Aging_Perturbations_from_GEO_up"},
                   timeout=120).text
sets = {}
for line in txt.splitlines():
    p = line.split("\t")          # 列结构: term \t (空) \t gene1 gene2 ...
    if len(p) >= 3 and p[2].strip():
        sets[p[0].strip()] = set(p[2].strip().upper().split())
```

- `addList`（POST，`files={"list":(None,"\n".join(genes))}`）**可用**，返回 `{"shortId":..., "userListId":N}`。
- `enrich?userListId=N&backgroundType=hs` **实测返回空 dict** → **不要指望它，也不要在它上面反复调参**（那是循环检测的高发区）。改走上面 `geneSetLibrary` + **自算 Fisher**，好处：背景池可控（用你自己检测到的基因集）、可同屏做反向侧对照、可自己 BH 校正。
- 常用库名：`Aging_Perturbations_from_GEO_up` / `_down`、`GO_Biological_Process_2023`。
- HAGR（genomics.senescence.info）的 GenAge / CellAge 在本环境下载超时 → **改用 Enrichr 等价库**，不要在下载重试上耗轮次。

## §7 统一网格要不要纳入 —— 纳入，但必须配套改门控

**纳入的理由**：统一同源元件网格（两物种坐标体系不一致 → 映射到统一同源单元，本项 221,069 单元 / 16,004 基因）把一个"统计规则"变成"数据处理步骤"，是防 **A25 智力活动规则**与 **A22.3 显而易见**的关键技术组件。

**硬约束**：**bin 级 `|Z|` 天然达不到 τ_A=12**（bin 内 tile 数少 → 聚合 Z 上不去；实测门控后只剩 n=82，与基线 n=890 不可比）。

⇒ **必须配套把门控改成与样本量无关的 per-tile 平均 `z̄ = Z/√n`**，否则统一网格会让门控失效 → 好组件变负资产。纳入前先跑一次**门控后样本量对照**，确认 n 未塌。

## §8 纪律（防循环检测）

- 🔴 **同主题的验证检索只配一个探针脚本**：多基因库、多 API 调整、正向+反向对照，全部塞进**同一个** `execute_python` 一次输出。本项目实测：连续 3 次调整 Enrichr 调用 → 触发系统「循环检测强制干预」。
- 收到干预后**立即停手**，产物已生成即视为完成，直接给结论，不要再补验证动作。
- 优先选**不依赖第三方富集接口**的路线（自算 Fisher），一次性成功率高、可控性强。
