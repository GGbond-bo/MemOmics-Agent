# 增量复审：v(N) 相对 v(N−1) 的审查员视角复核

> 触发：用户交付 v(N) 新版说「**内容重新完善了，你再次以专利审核员/审查员/答辩老师的角度进行评价**」「按上一轮意见改了，你再看看这版」「这版能不能送代理」。
> 要的是 **上一版问题的逐项验收 + 本轮新发现**，不是从头再评一遍，更不是采信"已修复"。

---

## §0 铁律：生成器自述 ≠ 证据

v(N) 生成器 docstring 会写"相对 v(N−1) 的变更（按审查意见清单 N 项）"，验收脚本会打 `PASS n / FAIL 0`。**两者都只是"申请人自己说的"**，不能当复核结论。

2026-09-12 实测（跨物种衰老专利 v12→v13）：
- 生成器 docstring 列 7 项改动 → 我逐项回磁盘独立复核 → **7/7 真落位**（①旧因果句零命中且新增"不作承诺"表述 ②525,137/p<0.005 在册 ③裸 `10,000` 零命中、`200 次` 一套、`单侧` 仅 1 处且在否定句 ④"不少于 30 例…连续梯度"在册 ⑤摘要实测 300 字符含空格/291 不计空格 ⑥版本 v13 全线 ⑦39.93% 等失效边界在册）。
- **同轮仍抓到 3 项新硬伤**（§2 的 A/B/C） → **自述对 ≠ 无问题**。差异来源：上一版没查过的维度（参数来源一致性、成对观测的披露完整性、源表列 vs 交付件表格列的差集）这一版才浮现。

复用规则：历史 `[结论]` 类已确认事实**直接复用不重跑**（省 token）；但每条"已修复"必须自己验。

## §1 四步执行链

1. **盘库存 + 拿"改了什么"清单**
   - `ls -la` 源目录 + 交付目录（`scripts/` `figures/` `results/` `_archive_旧口径/`），比时间戳看哪些件被刷新
   - 读 `scripts/NN_gen_*_vN.py` 的 **docstring**（改了什么、为什么）+ `scripts/NN_verify_vN.py`（它自称验了什么 → 找出它**没**验的维度）
2. **一个探针跑完全部机械检查** → `scripts/audit_deliverable_round.py`（结构计数 / 内嵌图字节反查源图 / 逐项落位 / 陈旧串零命中 / 摘要字数 / 附图色制式 / 形式项 / 权项-实施例覆盖 / 数字回源重算）。**一个产物只配一个探针**，跑完即汇报（防循环检测）。
3. **补一轮上一版没查过的维度**（§2 六类，逐类扫一遍，本轮新硬伤全是从这里出来的）
4. **四件套交付**（§3）

## §2 增量复审必查的六类（v12→v13 实测产出）

### A. 权利要求里被"确定/导出"的量，回说明书核它的实际出处 🔴
- **标本**：独权 1 写"**通过置换检验构造空分布并确定**显著性阈值 τ **与强效应阈值 τ_A**"；说明书 §三（八）却写"τ_A 取主体物种效应量约前 9% 分位的**观测落点**"、"该项检验…**不用于标定 τ_A**"；从权 13 又写"由**空分布高分位或**主体效应量高分位（约前 **10%**）导出"，实施例是"约前 **9%**" → 三处不一致。
- **判读**：独权要求的两个阈值来源不同（一个空分布、一个观测分位）→ 权利要求得不到说明书支持（**A26.4 不清楚**）。这是"代理人照着独权原样撰写就会被驳回"级别的硬伤，优先级高于任何文字润色。
- **核法**：把独权中每个"确定/计算/得到/导出"的量列一张表，逐量回说明书找它的**实际出处**；出处不同，或说明书用"**或**"并列两个来源 → 记一条。
- **修法（不动保护对象）**：独权改为"由置换检验构造空分布确定显著性阈值 τ，**并由主体物种效应量高分位确定强效应阈值 τ_A（τ_A > τ）**"；全文分位取值统一为一个数。

### B. 选择性披露：成对/分组观测只报了有利的一侧 🔴
- **标本**：`results/置换检验统计.csv` 有 `macaque` 行（`obs=34128 < null_mean=147794.11, ratio=0.2309, p=0.815, n_units=6,085,841, n_samples=20`，即参考侧**观测显著单元数低于随机空分布均值**）与 `human` 行（`ratio=24.3228` / 258.4 / 525,137 / p 触底）。交底书在 §三（八）、§四.1、图 2 注、表 2 里**反复报 human**，猴侧同一张表的结果一字未提。
- **判读**：审查员/答辩老师问一句"**参考物种侧的年龄效应本身有实证吗**"就会当场问住；且 §二（一）"猴'接近'不等于'可替代'"的立论正需要这一侧的证据。
- **核法**：产物 CSV 里所有**按条件分组的成对行**（species=…、方法=基线①②③、阈值 sweep 的每一档）逐组核对是否都进了交付件 → 漏披露的那组往往正是会被追问的地方。
- **修法（补披露反而强化论证）**：在说明书"失效边界"或置换节补一条，说明猴侧未检出富集及技术解释（20 例仅 4 个年龄簇、文库数≠个体数 → 参考侧统计效力不足）。这恰好与 `w(Z₂)` 只取方向不取强度的设计动机闭环 —— **补上比不补强**。

### C. 源产物 CSV 有列、交付件表格把列删了（三元组被删） 🟡
- **标本**：`results/三基线横评表.csv` 有 `exp_rate`（匹配零假设期望率）与 `z`（配对 z）两列（基线①b：期望 0.4136 / z=−0.87；②a：0.4156 / **z=+14.09**；②b：0.4429 / **z=+32.31**），docx 表 1 只留"输出数 / 反向混入率 / 精度 / 召回" → 60.1% 反向混入率单独陈述，读者无法判断是方法缺陷还是零假设本身就该 41.4%。
- **核法（零成本）**：**交付件每张表 vs 源 CSV 的列集合做差集**；差集里的"率类列"就是被删掉的三元组（观测率 / 匹配零假设 / 配对 z）。
- **修法**：为每条基线补两列（零假设期望率 / 配对 z），或至少加脚注说明期望率。

### D. 只找错、不找"被写弱的正证据" 🟡
- **标本**：`pertile_gate_sweep.csv` 的 per-tile 归一化门控 **z=3.09（|z̄|≥1.2, n=24）/ z=3.27（≥1.5, n=8）** 是整套交付件里**唯一 z>0 的门控证据**；docx §三（十）却只写"输出 24 个单元、反向混入 6 个""8 个单元、反向混入 0 个" → 把权 11/12 的实施例写成了**比基因级门控更差**的样子。
- **判读**：复审的产出不只是问题清单，还包括"**源产物里有、交付件没写**"的有利证据 —— 尤其当该证据能直接支撑某个从权的创造性时。
- **核法**：每个源产物 CSV 扫一遍它的统计列（z / concordance / precision），问一句"这列比交付件正文写的好还是差"，好的就要点名。

### E. 数字对账全绿 ≠ 文本自洽 🟡
- **标本**：docx 表 1 ↔ `三基线横评表.csv` 逐格一致、图 2 注 ↔ `置换检验统计.csv` 一致、§三（十）↔ `pertile_gate_sweep.csv` 一致、14 项权项对齐、5 张内嵌图**字节级**匹配源图 → 机械层全绿；但 §二（二）"避免方向误判" + §四.5"猕猴等动物模型对人类的代表性评估" 与 §三（十二）④"参考物种（猴）**尚不宜**作为主体物种的方向参考"**语义相斥**。
- **核法**：grep 失效边界段/自认边界段的**结论词**（"尚不宜""不承诺""不可判定"），在全文找与它相反的应用陈述。
- **修法**：把应用句统一成"用于**标定**参考物种能否作方向参考（本数据标定结论：不宜）" —— 自认边界从软肋变成方法的一个输出。

### F. 形式项清单式扫描（逐项 grep，命中数直接报）
`摘要附图` / `附图标记`（说明书须对附图中标记作说明）/ `检索式`·`IPC`·`分类号`·对比文件编号（交底书不强制附检索报告，但送代理前附检索式省一大截）/ `发明人`·`申请号`·`优先权` / 附图色制式（`PIL` 读 `mode`/`size`/`dpi` + 抽样算彩色像素占比；专利附图一般须黑白线条图，实测 5 张 RGBA 彩图彩色占比 4.8%–37.4%）/ 数字千分位格式一致性（同一数字 `1,409` 与 `1409` 混用）。

## §3 四件套交付骨架

1. **修复验收表**：`上一版问题 | vN 状态 | 我的复核证据` —— 三联必须有证据列（探针输出原值），不能只打 ✅
2. **本轮新发现**：按法条映射（A26.4 / A26.3 / A22.3），配一张紧凑 Mermaid 风险链（新发现 → 法条 → 后果 → 修法方向）
3. **未修复项**：沿用上一版、vN 未动的（形式项最常见）
4. **语义张力 + 授权可能性评级**：**方法层 / 效果层分开评**（方法层常"中等偏上"、效果层常已被自己数据否证）；末尾给送代理门禁一句（"在 N1 修掉前不要让代理原样撰写独权 X"）
5. **下一步三路径让用户拍板**，不擅自改交付件：
   - A 出 v(N+1)（列出范围）
   - B 只出《给代理人的 N 条修改建议》一页纸
   - C 只修唯一会被驳回的硬矛盾（如 §2A）

## §4 纪律

- **一个产物一个探针**，跑完全部检查再汇报；不要"想到一项检查就再写一个小脚本"（实测触发系统循环检测）。
- **不改交付件**：复审输出的是意见与路径，改版由用户拍板（属 §版本化改版流程）。
- **定位不动**：用户已锁定的定位（如"这是筛选方法"）不得在复审里重提重定位；建议只落在防守性补强 / 形式修正 / 一致性统一。
- **每条结论可指位**：必须能指到 docx 的段落/表号/章节编号或某个 CSV 的行列（如"docx 表 5 独权 1"、"`results/置换检验统计.csv` macaque 行"）。
- 报告里**同时报"被写弱的正证据"**（§2D），避免复审只输出负面清单。
