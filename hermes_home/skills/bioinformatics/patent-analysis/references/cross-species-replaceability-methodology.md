# 跨物种脑组织可代替性 — S200-S500 完整方法论

> 2026-07-21 · 猴→人海马衰老可代替性评估 · 专利 A 核心技术方案

---

## "可代替性"的精确定义

专利所述"可代替性"不是器官替代，而是：

> **"用第一物种的脑组织做实验得到的科学结论，能在多大置信水平上预测第二物种脑组织中该结论的成立程度。"**

评估单位是**基因×细胞类型×通路**，不是"整体像不像"。

## S200-S500 完整管线

```
S200  细胞类型锚定与跨物种基因对齐
  ├─ marker genes + scArches 锚定共享细胞类型（6-10类）
  └─ 基因对齐：1:1 ortholog（独权，稳）| ESM-2 嵌入（从权+备选实施例）
      ⚠️ ESM-2不进独权：黑盒不可解释 → 审查员充分公开驳回 → 无法答辩

S205  跨物种技术批次效应校正 🔑
  └─ Harmony/scVI 残差化 → UMAP 混合度验证
     若无法充分混合 → 标记该细胞类型"评估仅供参考"
     ⚠️ 不说清楚这一步，审查员会说"你测的是批次差不是物种差"

S300  分层可代替性评估（每细胞类型独立计算）

  S310 细胞组成层
  └─ Dirichlet-multinomial: proportion ~ species + age
     不看细胞群变化 → 基因评估结果可能是统计正确但生物学错误
     例：GFAP在两物种都下降，但猴是因为星形胶质细胞变少，人是因为每个细胞表达变少

  S320 基因表达层 🔑 pseudobulk个体聚合 — 核心创新点1
  └─ 每个体×每细胞类型×每年龄组 → pseudobulk平均表达
     三重相关：r_cross vs r_within_monkey vs r_within_human
     判定：r_cross ≥ r_within下置信界 → 物种差≤个体差 → 可代替
     ⚠️ 单细胞层面直接跨物种比较=伪重复,p值虚假膨胀
        pseudobulk按个体聚合后n=5 vs n=5才是真正生物学重复

  S330 衰老轨迹层
  └─ V_monkey = [log2FC_gene₁, ..., log2FC_geneₙ] per cell type
     V_human  = [log2FC_gene₁, ..., log2FC_geneₙ]
     cos(θ) = V_monkey·V_human / (|V_monkey|×|V_human|)
     仅用 Hallmarks/SenMayo/SASP 基因集（纯正常衰老，无AD）

  S335 年龄等效变换 🔑
  └─ age_scaled = (age - mean_species) / sd_species
     消除"猴5岁≠人20岁"的等效年龄偏差
     使 β_interaction 具有可比生物学含义："衰老速度是否不同"

  S340 方差分解层 🔑 混合效应模型+SDI — 核心创新点2
  └─ expression ~ species + age_scaled + species:age_scaled + (1|individual)
     提取：β_species, β_age, β_interaction 🔑, σ²_individual
     SDI = |β_species|² / σ²_individual
     SDI统计量进独权（客观定义），阈值进从权（经验选择留弹性）
     β_interaction: "猴老的方式和人老的方式是否相同" — 最锋利的指标

  S350 功能层
  └─ 衰老基因集×各层判定 → 通路级可代替性图谱
     输出：氧化磷酸化(神经元)=93% vs 神经炎症(小胶质)=31%

S400  四级基因分类（A/B/C/D）🔑 — 核心创新点3
  A级: SDI<1 且 cos(θ)>0.8 → 完全可代替 → ✅ 可在猴模型研究
  B级: SDI<1 但 cos(θ) 0.5-0.8 → 定量可代替 → ⚠️ 注意基线校准
  C级: SDI 1-3 但 cos(θ)>0.8 → 方向可代替 → ⚠️ 绝对值不能直接比
  D级: SDI>3 或 cos(θ)<0.5 → 不可代替 → ❌ 不能用猴模型
  ⚠️ A/B/C/D分类是"路由表"——A喂给C(签名), D喂给C(排除清单)

S500  IRS + 交付物输出
  └─ IRS总分（学术摘要用，企业不关心）
     企业真正需要的是：
     ① 基因级ABCD标签 → "这个基因能不能在猴身上敲"
     ② 通路级可代替性图谱 → "神经炎症通路31%→靶向小胶质的药要谨慎"
     ③ D级排除清单 → "以下312个基因不能用猴模型"
     ④ 细胞类型特异性评估 → "神经元89%可代替,小胶质51%"
```

## 进化锚点验证（最关键的方法验证）

```
验证1: 人vs人（不同个体） → 预期 IRS ≈ 0.95
验证2: 人vs恒河猴          → 预期 IRS ≈ 0.70-0.80
验证3: 人vs小鼠            → 预期 IRS ≈ 0.40-0.55
```

⚠️ **必须控制基因数量**：三个物种共有的1:1 ortholog交集。
否则IRS梯度可能来自"能比较的基因越来越少"而非真实生物学信号。
只用~13,000个三物种共享基因计算 → 排除基因数量假象。

这不是循环论证——方法内部没有用到进化距离信息，IRS完全从表达数据计算。
类比：尺子量身高，篮球队员>成人>小孩→证明尺子准。

## S310 为何必须在 S320 之前 — GFAP 实例

用户常见疑问: "看某个基因是否衰老变化一致,为什么要先算细胞群变化?"

**因为基因在细胞里。不先看细胞群,基因评估结果可能是统计正确但生物学错误。**

```
GFAP（星形胶质细胞标志基因）在猴和人衰老中都下降 → 看起来一致 → 可代替? ✅

但 S310（细胞组成层）揭示:
  猴脑: 衰老中星形胶质细胞数量 ↓30%（细胞变少了）
  人脑: 衰老中星形胶质细胞数量 ↑20%（细胞变多了）

真相:
  GFAP在猴中的下降 → 因为星形胶质细胞数量减少（细胞层面）
  GFAP在人中的下降 → 因为每个星形胶质细胞表达的GFAP变少（基因调控层面）
  虽然数值都下降，但生物学机制完全不同
  
结论: 用猴GFAP数据预测人GFAP → 看似一致，实则扭曲
→ S310通过 → 才放心做S320-S350基因级评估
→ S310不通过 → 该细胞类型的基因评估出报告时标注风险
```
