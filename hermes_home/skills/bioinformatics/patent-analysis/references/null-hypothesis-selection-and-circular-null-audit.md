# 零假设选择 与 循环零假设（观察自估期望）审计

> 触发：用户问「**随机比我们计算的高，是不是证明你计算的方法有问题？**」「为什么观测低于随机」「这个 p 是怎么来的」，或审计他人用「**匹配基准率（matched base rate）**」构造的零假设。
> 交付物 = **零假设分层判定表** + **循环性三判据结论** + **「低于随机」的两层判读**（计算层 vs 效果层），不是重算一遍数字。

---

## §1 先分清四种「随机」——回答的是不同问题，不能混用

| 零假设 | 构造 | 回答什么问题 | 已知陷阱 |
|---|---|---|---|
| **A 无信息常数 p=0.5** | 二项 / 正态近似 vs 0.5 | 观测率与"两者完全无关联"差多少 | **忽略效应量梯度** → 在梯度存在时会给出"显著低于随机"的假象 |
| **B 分层匹配基准率（matched base rate）** | 按混杂（效应量/深度/长度）分层后取层内期望 | 观测率是否超出"同等效应量水平本该有的率" | 🔴 **若层内率是用观测值自己算的 → 循环，永不可失败**（见 §2） |
| **C 打乱同源配对（置换）** | 置换两物种配对关系，保边缘分布 | 观测是否依赖**真实配对** | 只破坏配对、不破坏层结构 ⇒ 对"层内一致性"无鉴别力 |
| **D 打乱年龄标签（置换）** | 置换单样本年龄 | 单物种年龄效应是否**真实** | 只回答主体侧，与跨物种主张无关 |

**判据**：先问"这个零假设的期望值是从哪儿来的？"——① 外部先验（0.5）② **置换生成的经验分布** ③ **观测自估（= 循环）**。只有 ①② 能用于检验。

---

## §2 循环零假设判别法（可机器判定，三条判据）

任一条成立即判**循环**：

1. **包含性** —— 检验掩码是否**完全落在单个分层内**：`mask \ 顶层 == 0`
2. **等值性** —— 期望 `expB` 是否**等于该层自身的观测率**
3. **不可失败性** —— 把 mask 换成该层任意子集，`z` 是否恒 ≈ 0

### 🔴 三判据必须**全部命中**才判循环 —— 同一段代码还有第二种区间（2026-09-13 实测补）

**同一句 `groupby(strata).mean()`（观测自估期望）在不同区间会产出两种完全不同的东西**，
误把第二种也喊成\"循环\"会导致**当轮撤回**（本轮真实翻车）。用**包含性比例**分区间：

| 区间 | 包含性（被检验集合落在其所属层的比例） | 性质 | 判定 |
|---|---|---|---|
| **恒等式区间** | 集合 **100% 落在单个分层内**（`mask \ 顶层 == 0`），自我包含 56%+ | `exp` ≡ 该层观测率 ⇒ **z 恒 ≈ 0，检验永不失败** | **循环**（三判据全中） |
| **条件性区间** | 集合**横跨多个分层**，自我包含 **< 1%** | `exp` ≠ 集合自身均值 ⇒ z 会动、**不是恒等式** | **不是循环**，但是**条件检验**——它回答的问题 ≠ \"优于随机\"（见下） |

**两种区间的共同点**：期望都来自**观测自估** ⇒ 都**不能用来主张\"优于无信息基准\"**。
**区别**：恒等式区间**连数值都不可用**（z≈0 无信息）；条件性区间**数值可用**，但**语义必须改写**。

### 条件性区间的新指纹：`z > 0` 而观测率 < 无信息基准（0.5）

**这是本轮最有价值的一条**：条件性零假设的 `exp` 是\"**同等混杂水平下的层均值**\"，
而该层均值**本身就可能低于 0.5** ⇒ **`z > 0` 完全不等于\"观测率 > 随机\"**。

实测标本（`03_three_baseline_comparison.py` 的 per-tile 门控扫描 → `pertile_gate_sweep.csv`；
完整溯源见 `cross-species-cre-conservation` 的 `references/tile-level-da-significance-floor.md` §9.6）：

| thr | n_out | 观测率(concordance) | exp_rate | z | 读法 |
|---|---|---|---|---|---|
| 0.5 | 1506 | **0.4781（< 0.5）** | 0.4546 | **+1.83（> 0）** | 🔴 **决策性反例** |
| 1.0 | 75 | 0.6667 | 0.4459 | +3.85 | 高于**层内均值**，非高于随机 |
| 1.5 | 8 | 1.0000 | 0.4289 | +3.27 | 同上 |

⇒ **判据（一句话）**：拿到一个\"匹配零假设 z\"，先算它的 `exp` 是否低于无信息基准。
**若 `exp < 0.5` 而作者宣称\"显著优于随机\"，则主张与统计量脱节** ——
把\"层内残余富集\"读成了\"绝对优于随机\"，这是审查员/审稿人最容易抓的一句。

**附：真 matched null 应随集合变化。** 若**同一个常数**被复用到规模/组成完全不同的多个集合上
（本标本 0.4136 同时用于 n=894 / n=35 / n=1409 三个集合）⇒ 是**伪匹配**（未真正按集合分层匹配）。

### 本次标本（跨物种衰老可替代性专利 · v17，2026-09-13 实测）

```
N=16029   全局一致率=0.4636
strong n=1409 | 顶箱(|Z_h|>=11.32) n=1603
strong ∩ 顶箱 = 1409        strong \ 顶箱 = 0          ← 判据① 成立
顶箱自身观测一致率 = 0.4136 = expB                       ← 判据② 成立
  strong: obs=0.4131  expB=0.4136  zB=-0.041            ← 判据③ 成立
  gate  : obs=0.3993  expB=0.4136  zB=-0.866（自我包含 894/1603=56%，方差被低估、z 被衰减）
十分位一致率: [0.4928 0.4810 0.4785 0.4828 0.4760 0.4613 0.4616 0.4429 0.4454 0.4136]
```

**代码根因**（`21_null_convention_comparison.py:37`）：

```python
pb = pd.Series(sd).groupby(q).mean().reindex(q).to_numpy(float)  # ← 用观测 sd 算层内率
expB = pb[mask].mean()                                           # ← 再把这个自估值当"期望"
```

⇒ `expB` 是"**待检验集合所在那一层的观测率**"，而强效应池 100% 落在该层内 ⇒ **`z≈0` 是恒等式，不是检验；这个零假设永远不会失败。**

### 正确写法（二选一）

- **层内置换**：在每个分层内打乱参考侧符号 → 层内期望恒 0.5，可与 A 对照
- **换层 / 交叉拟合期望**：`leave-one-stratum-out`（用其它层拟合期望）或 K-fold 交叉拟合，使期望**不含有被检验的观测本身**

### 下游危害

交付件用循环零假设去**消解**"低于随机"的告警（标本：v17 §四.2 注 ***「期望反向混入率 58.64%（= 1 − 0.4136）、配对 z = −0.87（不显著）」）→ 审查员只需问一句「**你这个期望是用观测值自己算的吗**」即穿。这类"解释"必须删掉或改成层内置换重算。

## §3 「观测低于随机」的正确判读（回答「是不是计算方法有问题」）

**答案：不是。但它证明的是比"算错了"更麻烦的事。**

### ① 计算层 —— 不是算错

| 判据 | 实测 | 结论 |
|---|---|---|
| **偏差的形状** | 系统性单向偏差（z=−6.66，可复现、有方向） | **bug 产生的是围绕零假设的噪声**（无方向、不可复现）；有方向的稳定偏差 ⇒ **计算在正常工作**，它测到了真实的（负）关联 |
| **双实现互证** | 两套独立实现，核心指标逐位一致 | 排除单点实现错误 |
| **内部自洽** | 全局一致率与 `r(Z₁,Z₂)` 指向同一件事 | 两个独立量互相印证 |

> 🔑 这句是**反驳"方法坏了"的最强论据**：**bug 不会给出一致的符号，只会给出噪声。**

### ② 数据层 —— 这是真结论

观测率 **低于** 无信息基准（0.5）⇒ 两个物种的元件级效应**方向不是独立的，而是弱负相关**。这是**数据层**结论，不是计算层结论。

### ③ claim 层 —— 这才是被打的地方

独权卖点「同向 ⇒ 可信 ⇒ 可迁移」（符号门控 `w(Z₂)=+1`）依赖"同向率 > 随机"。
观测率 **< 随机** ⇒ **被判定为"同向"的元件，可迁移性不比随机高** ⇒ **效果层被申请人自己的数据否掉**。

🔴 汇报时必须**两层分开说**：计算层没问题 / 效果层站不住。混在一条回复里讲，用户会归因成"换口径导致结论变了"（见 `claim-premise-first-verification.md` §6 变更层级分离）。

## §4 报告纪律（本类问题）

1. **任何"率"同屏给三元组**：(观测率, 匹配零假设期望率, 配对 z)；且**必须说明零假设是怎么构造的**（外部先验 / 置换 / **观测自估**）。
2. **不许用循环零假设消解告警** —— 那是把把柄交给审查员。
3. **撤回与报警同等醒目**：本轮若推翻了上一轮的某个警报，**在当轮开头明说**（否则用户只看到警报流水，对交付件评价逐轮下降，而对象本身没变 —— 见 `patent-gap-attribution-and-negative-result-strategy.md` §6）。
4. **每条发现标等级**：🔴 改变 go-no-go / 🟡 只影响表述 / ⚪ 仅归档。不给等级的不许进正文。
5. 负结果**不得写进说明书**（自证无技术效果 = 自杀，见 `patent-gap-attribution-and-negative-result-strategy.md` §3）。
