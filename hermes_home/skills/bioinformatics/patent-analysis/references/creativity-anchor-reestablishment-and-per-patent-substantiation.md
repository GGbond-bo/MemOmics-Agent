# 创造性锚重立 + 断言逐件坐实（换承重的必然后续）

> 触发：用户说「换柱」「把独权的承重从 X 换到 Y/Z 三根柱子」「重新写一份蓝图」「你确定这个专利能过审核吗」「我会让老师评估，但希望先通过你的评估」后，进入换承重后的下一阶段。
> 前置：先读 `replace-claim-load-bearing-pillar.md`（换承重本身）。本文档是换承重的**必然后续**——换柱不是免费的，它同时拆掉了创新锚。

---

## §1 核心洞见：换柱的必然代价 = 拆掉创新锚

换承重（把塌掉的统计量换成三根独立金标准的柱子）是对的、是唯一正路。但它有一个**暗礁**：创造性锚被连带拆掉。

- 本例：v15 的创造性锚是「可替代性命题」（发现1：五件对比专利只问"多像"，只有我们问"能否替代"）。换柱后「可替代性」被 L2 可及性承接，而"两物种都开放/可及"几乎就是 D1 郭国骥 overlap≥0.5 判功能保守 → 三柱 AND 叠加的最自然读法是「D1 + D2 + 公开衰老基因集」的**显而易见组合**。
- 结论：**换柱救活了承重结构，同时要补一根新的创造性承重柱，且必须写进说明书，不能再拿旧锚（发现1）当锚。**

## §2 创造性锚重立三要点（写进说明书）

| 新锚 | 落点 | 为什么立得住 |
|---|---|---|
| **主锚 = 衰老维度（最硬）** | 把"元件年龄效应回归"（供体年龄梯度作变量，回归出每元件年龄效应量）写成创造性锚 | 五件对比专利**全都没有年龄梯度**；这是五件都没有的全新步骤 |
| **副锚1 = 表达→可及性映射方法** | 年龄效应为主判据、表达级基因集降为可证伪后验的双层衰老判据设计 | 解决"表达语义与调控语义不可直接混用"这个本领域未解决的技术问题 |
| **副锚2 = 三证据标定/阈值整合** | 黄金区间摸底 + 反推阈值，做成"标定"而非"三个现成过滤器叠加" | "标定后的多证据整合" ≠ 简单叠加 |

说明书技术问题同步改写：从「能否替代」→「如何在跨物种保守元件中识别出随衰老变化的调控元件」。

## §3 🔴 断言 vs 证据：创造性断言必须逐件坐实（逐件比对）

**这是"你确定能不能过审核"类请求的胜负手。** 蓝图里"五件对比专利全无年龄梯度"这类话，写出来时只是**断言**，不是证据。审查员会说"别人没做 ≠ 非显而易见"。要从"断言"升级为"证据坐实"，唯一动作是**逐件比对**：

1. 列全对比专利清单（从专利文献目录 / 蓝图里的 D1–D5 编号）
2. 逐件读**权利要求 1 + 摘要**（不要只读摘要），记录：公布号、申请日、申请人、核心方案步骤、核心维度
3. 用关键词（年龄/衰老/aging/age/senescence）逐件 grep，确认"该维度全无"
4. 落盘**证据文件**（含逐件比对表 + 三根柱各自被谁覆盖的"先有技术分布表" + 两处关键区分），并在蓝图创造性章节引用该文件

**三根柱的先有技术分布表**（关键：创造性锚精确锁定到唯一独有的那根柱）：

| 本案柱子 | 已被谁覆盖 | 新颖 |
|---|---|---|
| L1 序列保守 | D1(LiftOver)/D2(CNE)/D4(MSA) | ❌ |
| L2 跨物种可及性 | D1(overlap≥0.5)/D5 | ❌ |
| L3 年龄效应/衰老维度 | **五件全无** | ✅ 独有 |

锁定后：创造性锚不是"保守"（有）、不是"跨物种可及"（有），而是"物种内年龄效应回归 + 三柱 AND 整合"。

**两处关键区分（答辩必用，防审查员拿最接近的 D1/D5 模糊打击）**：
- 区分1：D5"胁迫（抗旱）"≠ 本案"衰老"，且 D5 方法学是深度学习归因 vs 本案统计回归，维度/锚点/方法三层不同；
- 区分2：D1 的跨物种分析落在"细胞谱系"维度（非"年龄"），无年龄效应回归步骤。

## §4 命门处置（换柱后必踩的两个命门）

1. **命门1 = 衰老基因集语义错配**：衰老基因集是表达语义、可及性元件是调控语义，中间 enhancer→gene 链接错误率极高。**处置：主门用元件自身年龄效应（数据回归，独立金标准），基因集降为后验富集检验（集合级 Fisher，不要求单元件命中）** → 错配从"生死判定"变成"可证伪富集结论"，还多一条权项可写（"输出元件富集于衰老基因邻域"）。
2. **命门2 = 黄金区间收缩**：三柱正相关时 AND 收缩远小于独立假设乘积，但两个极端风险 = 输出太稀（<10 实用性被质疑）vs 太滥（几千，"核心元件"名不副实）。**处置：先 L1∧L2 基数摸底（零依赖 L3），反推 L3 阈值，让输出落"几十到几百"。**

## §5 A26.4 措辞对齐（换柱后的支持性缺口）

换柱后独权输出的是"序列保守 ∧ 两物种可及 ∧ 衰老关联的元件清单"，语义上是**筛选方法**，不是"替代性评估方法"。若名称/定位仍写"可替代性"，出现"权利要求筛的是共享存在、说明书说的是可替代"的支持性缺口。**处置：独权落点诚实改为"跨物种保守衰老调控元件的筛选方法"，"可替代性"降为下游用途（权 10）。**

## §6 用户五条判断作为审查清单（复用）

用户对"换柱方案"的典型逐条判断，可直接作为审查换柱提案的 checklist：
1. 换柱对不对（数据否掉旧承重 = 唯一正路，非偏置）
2. 拆掉创新锚 = 最大暗礁（必须重立）
3. 命门①走"年龄效应为主、基因集降为先验"
4. 命门②黄金区间先摸底再反推阈值
5. A26.4 措辞对齐（独权落点诚实改"筛选方法"）

## §7 诚实裁决纪律

用户问"能不能过审核 / 能通过你的评估吗"时，**不给"确定能过"四个字**（那是不负责任的担保）。给**分层裁决**：新颖性/支持性/创造性/实用性四关逐关判"能过/卡在哪/差什么证据"，并明确"从 X 到授权级站得住，中间隔着 N 个硬动作，做完之前任何人说能过都是替它担保不是替它证明"。用户说"做"= 去做那 N 个硬动作（逐件比对 + 步骤0摸底），不是继续口头论证。
