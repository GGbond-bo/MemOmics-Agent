# 跨物种可代替性 — A+C 双专利架构与同日提交策略

> 2026-07-20 · 为毕业+专利场景设计 · 学校只要求受理通知书

---

## 架构总览

```
专利A: 可代替性定量评估方法 ("选模型")
  独权核心: pseudobulk聚合 + Mixed Model SDI + species×age交互 + ABCD分类
  授权概率估计: 65-75%
  毕业价值: 可单独满足毕业要求

专利C: 抗衰老化合物筛选方法 ("筛药物")  
  独权核心: 跨物种保守性过滤签名 + 细胞类型特异逆转评分 + D级靶点排除
  授权概率估计: 55-65%
  毕业价值: 加分项, 有时间就交, 没时间先保A
```

## 同日提交防自我冲突

> 两件专利出自同一份数据、同一个课题组 → 抵触申请风险

**规避方法**:
1. **同一天提交** → 互不构成抵触申请
2. **权利要求差异化** → 签名构建在两件中都写成上位步骤; 独权核心严格分开
3. **说明书互相不引用对方** → 各自独立引用公开文献

## D级排除清单 — 两件专利的串联点

A的输出(A/B/C/D分类) → D级基因 → C的输入(排除清单)

> 若化合物靶点落在D级(不可代替)基因上 → 即使逆转评分高也标记"需谨慎验证"
> 这条把A和C焊死成一个体系 → 审查员看到的是"组合发明"而非"拼凑专利"

## 时间线 (3个月, 只求受理)

| 时间 | 任务 |
|------|------|
