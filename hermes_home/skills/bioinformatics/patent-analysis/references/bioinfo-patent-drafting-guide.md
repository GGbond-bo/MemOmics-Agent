## 审查员三类驳回及防御

### A25 — 智力活动的规则和方法
**话术**: "这全是数学统计方法的组合，不构成技术方案"

**防御策略**:
- 权利要求中明确写"通过ESM-2蛋白质语言模型将基因映射到跨物种共享嵌入空间"
- 而非"计算基因表达的相似度"
- 每个步骤必须是可被计算机执行的、有具体输入输出的操作
- 必须声明产业应用的技术效果（如"用于筛选临床前动物模型"）

### A22.3 — 显而易见的组合
**话术**: "将D1(郭国骥)+D2(阮航)+D3(混合效应模型教科书)+D4(衰老余弦相似度论文)组合是显而易见的"

**防御策略**:
- 证明组合产生协同效果——每个单独步骤都做不到的事情，组合起来做到了
- 例如: "只有ESM-2嵌入+mixed model pseudobulk+species:age交互效应同时使用，才能鉴定出在物种内稳定但在物种间发散的'隐蔽不可代替基因'"
- 具体实施例必须展示"去掉任一组件后结果显著变差"

### A26.4 — 不清楚
**话术**: "可代替性的技术含义是什么？权重如何确定？"

**防御策略**:
- SDI = |β_species|² / σ²_individual — 有具体公式
- IRS权重通过留一交叉验证的网格搜索确定
- "不可代替"阈值通过进化锚点确定（人-人IRS=0.95, 人-小鼠IRS=0.45 → 猴阈值在中间）

## 权利要求撰写公式

```
独立权利要求 1 = 
  [数据输入形式: 基于ESM-2蛋白质嵌入的跨物种scRNA]
  + [不可替代组件: pseudobulk层级混合效应模型 + SDI]
  + [具体步骤(锁定为计算机实现): S1→ESM-2嵌入, S2→pseudobulk聚合, S3→mixed model拟合, S4→SDI计算分类]
  + [可验证效果: 输出IRS及ABCD基因分类结果]

从属权利要求 2-N = 
  逐步收窄场景（非人灵长类→人、脑组织、衰老研究）
  + 收窄方法细节（ESM-2模型版本、混合效应模型公式）
  + 收窄输出形式（可视化报告、基因列表）

系统权利要求 = 执行方法权利要求1-N的计算机系统
用途权利要求 = 该方法在筛选临床前动物模型中的应用
```

## 好 vs 坏的例子

### ✅ 好例子（可能授权）
> 一种基于蛋白质语言模型嵌入的跨物种单细胞转录组可代替性评估方法，包括：
> S1: 将第一物种和第二物种的单细胞转录组数据，通过ESM-2蛋白质语言模型将每个基因映射到跨物种共享的蛋白质嵌入空间，获得不依赖于基因符号同源关系的表达矩阵；
> S2: 对每个物种的每个个体，按细胞类型进行伪批量聚合，获得每细胞类型每基因每物种每年龄组的平均表达谱；
> S3: 构建混合效应模型 expression ~ species + age + species:age + (1|individual_id)，提取物种分歧指数 SDI = |β_species|² / σ²_individual；
> S4: 根据SDI和衰老向量余弦相似度对基因进行ABCD四级分类，输出定量可代替性评估结果。

### ❌ 坏例子（必然驳回）
> 一种评估动物模型可代替性的方法，其特征在于：
> S1: 计算细胞组成相似度；
> S2: 计算基因表达相似度；
> S3: 计算衰老轨迹相似度；
> S4: 加权求和得到综合评分。
