## 一、背景技术 — 要解决什么？

### 点名批评的现有技术

| 现有方法 | 问题 |
|----------|------|
| 大多数跨物种分析 | 只抽取**一对一同源基因**，按同物种流程分析 |
| CN115064220A（郭国骥） | 构建超大参考DB → Pearson相似度，但**只用1对1同源** |
| 通用问题 | "一对多"和"多对多"的同源关系信息**被丢弃**，远源物种注释精度不高 |

### 本专利的核心主张

> "本发明特征基因筛选中加入多种基因同源关系（1-1 + 1-N + N-N），并通过细胞-基因异构图建立基因同源关系的子图，通过Transformer模型整合基于元路径邻居生成的特征和多阶段训练进行数据增广，提高了跨物种单细胞注释精度。"

## 二、核心方法 — 四步法（S1→S4）

### 技术路线图

```mermaid

    subgraph S1["S1 数据质量控制与标准化"]

    S2 --> S3
    S3 --> S4
```

### S1 细节

- 归一化：使每个细胞表达读数 = 数据集中位数
- HVG：Top2000 标准差最大的基因
- Z-score 标准化后做 PCA，取前 30 个主成分

### S2 细节（核心创新1）

**异构图 = 三种子图叠加**：
1. **细胞-细胞图**：物种内 KNN(k=5) + 物种间 MNN(k=10, cosine相似度, 取top5互近邻)
2. **基因-基因图**：BioMart全同源关系，包含1-1/1-N/N-N
3. **细胞-基因图**：表达矩阵 × 节点基因

**节点基因筛选**：HVG ∩ DEGs ∩ 同源映射（BioMart）

**关键区别**：用全同源关系（1-1 + 1-N + N-N），而非其他方法只用1-1。

### S3 细节（核心创新2）

**4种元路径**：

| 元路径 | 模式 | 含义 |
|--------|------|------|
| CGGC | 细胞→基因→基因→细胞 | 通过同源基因连接跨物种细胞 |
| CGCC | 细胞→基因→细胞→细胞 | 通过基因+MNN传播 |
| CGGCC | 细胞→基因→基因→细胞→细胞 | 更长的语义链 |
| CC | 细胞→细胞 | 直接MNN邻居 |

**传播公式**：
H^(P) = A_P^(l) · A_P^(l-1) · ... · A_P^(0) · X_{c_l}

其中 A_P 是元路径对应的邻接矩阵行标准化形式。

**关键**：元路径传播在模型训练前**只做一次**，生成固定特征矩阵，不需要在训练时做图卷积。

### S4 细节（核心创新3）

#### Transformer 注意力整合

```
Q_i = H_i · W_Q,  K_i = H_i · W_K,  V_i = H_i · W_V
α_i = softmax(Q_i·K_i^T / √d)
Z_i = β · α_i · V_i
→ 串联(concat)所有元路径特征 → 线性层降维 → softmax分类
```

#### 双损失函数

| 损失项 | 公式核心 | 目的 |
|--------|---------|------|
| 分类损失 | 加权交叉熵（w_t处理类别不平衡） | 确保注释准确 |
| 物种间相似度损失 | MNN对在隐藏空间中的欧氏距离均值 | 拉近跨物种同类型细胞 |
| 正则项 | L2正则 | 防止过拟合 |

```
L_total = L_class + β·L_sim + λ‖Θ‖₂
```

#### 多阶段训练

```
阶段k → 预测测试集 → 筛选 maxPred > δₖ 的"可信"细胞
→ 加入阶段k+1训练集 → 重新计算类别权重 → 继续
```

```
L_{k+1} = L₀ ∪ {i: maxPred_i > δₖ}
```

**最佳模型选择**：用 AMI（调整互信息）而非准确率选 checkpoint。

## 四、实验验证

### 数据集

| 数据集 | 物种 | 细胞数 | 基因数 | 细胞类型数 |

| GSE84113 human | 人（胰腺） | 7,264 | 20,125 | 8 |

| GSE142585 human | 人 | 13,837 | 46,541 | 11 |
| GSE142585 macaque | **猕猴** | 21,574 | 23,029 | 11 |

> ⚠️ 注意：包含了猕猴→人的跨物种注释场景！

### 对比结果

所有方向（人↔小鼠、人↔猕猴）csMAHN均声称优于Seurat v5。

### 方法缩写

csMAHN = Cross-Species Metapath-based Aggregation Heterogeneous graph neural network

## 五、与"猴海马→人海马可代替性"项目的交叉分析

### ✅ 阮航没覆盖的（用户创新空间）

| 阮航没做的 | 用户可以做的 |
|-----------|-------------|
| ❌ 只有"注释"（打标签） | ✅ "可代替性定量评估"（更高维度） |
| ❌ 没有衰老/疾病条件 | ✅ 年轻 vs 老年海马比较 |
| ❌ 没有"不可代替基因集" | ✅ 鉴定哪些基因导致猴≠人 |
| ❌ 没有组织特异性（海马） | ✅ 猴海马→人海马专门场景 |
| ❌ 没有可代替性分数（IRS） | ✅ 综合评分系统 |

### ⚠️ 必须规避的方法要素 + 替代方案

| 阮航方法要素 | 替代方案 |
|-------------|---------|
| 异构图（细胞+基因节点） | 共享嵌入空间 / CCA / 对比学习 |
| 元路径 CGGC/CGCC/CGGCC | 不用元路径，用其他特征整合 |
| Transformer + 多头注意力 + 串联 | 不同整合架构（MLP+自编码器） |
| 多阶段伪标签增广（δₖ筛选） | Bootstrap / 交叉验证 / 贝叶斯方法 |
| 双损失（分类+MNN距离） | 单损失或不同多任务策略 |

### 📋 必须引用的现有技术声明

> "现有跨物种单细胞分析方法（如CN115064220A、CN118298926A等）主要聚焦于细胞类型注释/鉴定，尚未提出定量评估非人灵长类模型对人类脑组织可代替性的方法。"
