# Patent Defense Wording Templates (Chinese)

## A25 Defense — Core Paragraph (Must Appear in说明书 发明内容)

```
单独的混合效应模型、单独的 pseudobulk 聚合、单独的 Harmony 
校正都是已知方法，但将它们以 S200→S205→S320→S340→S400 的
特定顺序、应用到跨物种脑组织单细胞转录组数据这一特定数据
类型上、以个体而非细胞为统计单位、以区分物种效应和个体效应
为目标——这个整体流程在现有技术中未曾公开，且产生了'不可代替
基因鉴定'这一无法由任何单一已知方法独立实现的技术效果。
```

## A25 — Three Safety Anchors (Must Appear in说明书)

### Anchor 1: Data as Physical Measurement

```
本方法处理的单细胞转录组数据来自高通量测序仪对脑组织细胞的
物理测量结果（UMI counts），属于对自然产物的技术测量，而非
抽象的数字集合。
```

### Anchor 2: Clear Industrial Application

```
本方法的输出结果（可代替性分级 A/B/C/D）直接用于药物研发企业
的临床前动物模型选择决策，具有具体的产业技术应用场景，符合
FDA Modernization Act 2.0（2022年12月签署）对动物模型替代方法
验证的法规要求。
```

### Anchor 3: Error Detection as Technical System Proof

```
S205 步骤包含对跨物种批次效应校正结果的验证机制（UMAP 混合度
检查），若校正失败则主动标记该细胞类型为"评估仅供参考"。本方法
不是纯粹的数学演算，而是包含错误检测和风险控制的技术系统。
```

## Creative Step Defense — "Specific Combination" Template

```
单独的[步骤A]、单独的[步骤B]、单独的[步骤C]在各自领域都是
已知的，但将它们以[S1→S2→S3]的特定顺序、应用到[特定数据类型]
上、以[特定统计单位]为分析单位、以[特定技术目标]为目标——这一
整体方案在现有技术中未曾公开，且产生了'[独特输出]'这一无法由
任何单一已知方法独立实现的技术效果。
```

## Preemptive A25 Rejection Response Template

```
审查员可能认为本方法属于"智力活动的规则和方法"（A25），但：

(1) 本方法解决的是药物研发中动物模型转化失败率>90%的产业技术
    问题，而非数学问题本身；
(2) 本方法采用了 Harmony 批次校正、pseudobulk 聚合、混合效应
    模型拟合等计算机数据处理技术手段，非纯推理；
(3) 本方法输出了可直接指导 IND 申报决策的 A/B/C/D 可代替性分级，
    产生了产业技术效果；
(4) 本方法处理的单细胞转录组数据来自高通量测序仪的物理测量结果；
(5) 本方法涉及 23 万细胞×3 万基因的混合效应模型迭代计算，
    无法通过人脑完成，必须依赖计算机执行。
    
综上，本方法属于技术方案，不属于智力活动的规则和方法。
```

## Existing Patent Citation Template (背景技术)

```
现有跨物种单细胞分析方法主要聚焦于细胞类型注释/鉴定：
- CN115064220A（郭国骥，已授权）：通过构建 15 物种参考数据库
  进行跨物种细胞类型鉴定，但仅使用 1-1 同源基因，不涉及衰老
  扰动下的可代替性评估。
- CN118298926A（阮航，审中）：通过异构图网络和 Transformer
  进行跨物种细胞类型标注，但目的为注释而非可代替性定量。
- Jaroszynski et al. (2026, EBioMedicine)：通过潜在基因表达
  空间进行小鼠→人脑区的 bulk 映射，但不涉及单细胞分辨率、
  个体差异控制或衰老轨迹评估。

上述现有技术均未涉及跨物种脑组织的可代替性定量评估方法，
特别是不包含以个体 pseudobulk 为统计单位的物种-个体方差分解
步骤，也不包含基于混合效应模型 species×age 交互效应的衰老
轨迹可代替性判定。
```
