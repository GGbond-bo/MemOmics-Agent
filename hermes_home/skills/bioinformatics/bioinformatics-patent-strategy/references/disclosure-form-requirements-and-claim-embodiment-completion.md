## 1. 附图必须黑白线条版（形式要件，不是审美偏好）

《专利审查指南》第一部分第一章 **2.4 说明书附图**（原文已核）：

> "应当使用制图工具和**黑色墨水**绘制，线条应当均匀清晰、足够深，**不得着色**和涂改"

| 图 | 用途 | 要求 |
|---|---|---|
| 说明书附图（随申请提交） | **必须黑白线条版** | 线型 / 影线 / 空心·实心标记区分要素，**不依赖颜色** |
| 交底书内部配图 / 答辩 PPT | 可用彩色版 | 另存 `patent/figures/`，**不随申请提交** |

**做法**：另建 `patent/figures_bw/`，由独立脚本（本例 `15_make_figures_bw.py`）从彩色版重出；docx 生成器的 `FIG` 常量改指 `figures_bw/`。
**校验必须实测，禁止肉眼下结论**：
① PIL 数彩色像素 → 目标 **0.000%**；
② 解包 docx `word/media/*`，把每张内嵌图的**字节数**与 `figures_bw/` 源文件逐个比对，**全等**才证明真的嵌了黑白版（本次 5/5 相等）。
② 是"图文一致性二期（源图漏重出）"字节比对法的直接复用。

**体检口径**：逐条从权问一句——「它的每个技术特征，说明书里有实施例落点吗？」没有 = **纸面从权**，支撑力弱、易被 A26.3/A26.4 打。

本次体检（v14 时）：

| 权项 | 缺口 | 补法 |
|---|---|---|
| 权 5(2) 同源对应关系置换 | 全文无落点（只有年龄标签置换） | **实跑** 200 次补实施例 |
| 权 10 下游用途 | 仅并列 3 项断言，无实施例 | 用途一/二写实测；用途三标"实施方式（未执行）" |
| 权 12 跨粒度门控 | 只有单元数（8/24），n 过小 | 补配对 z + 明写规模边界 |

> 🔴 **铁律：用实跑补实施例，不用文字补。** 文字补出来的实施例经不起审查员追问数字。

### 4.1 同源对应关系置换的实跑模板

打乱两物种之间的同源配对关系（把参考物种侧的 `Z₂` 与 `p₂` **整体重排**到其它元件上），**保持两侧效应量边缘分布不变**，重复 200 次后重算分级 → 随机配对下的空分布。

```python
obs  = summarize(Z2, P2)                                        # 真实配对
null = [summarize(Z2[i], P2[i]) for i in rng.permutation(N)
        for _ in range(B)]                                      # 打乱配对
p_upper = (1 + (null[:, k] >= obs[k]).sum()) / (B + 1)          # 富集 → 上侧
p_lower = (1 + (null[:, k] <= obs[k]).sum()) / (B + 1)          # 亏损 → 下侧
```
必报四指标：**核心元件数 / 主体侧强效应池 / 强效应池内方向可信数 / 三层同向率**。
⚠️ 随机种子写进正文（本例 `20260912`）+ 脚本与输出路径 → 可逐位复现（这也是 L1 裁判 missing 里的"可复现细节"项）。
⚠️ 统计口径要对齐交付件：`summarize` 里的"方向可信池"要取**强效应池内**的交集，否则数字对不上已披露值。

### 4.2 🔴 两面结果都要写（选择性披露风险）

本次置换给出**一正两负**：

| 指标 | 真实配对 | 随机配对（200 次） | 判读 |
|---|---|---|---|
| 门控触发数 | **894** | 673.0 ± 18.7 | **1.33×，p<0.005（富集）** |
| 核心元件数 | **357** | 340.1 ± 16.3 | 1.05×，**p=0.164（未富集）** |
| 强效应池同向率 | 41.31% | 50.30% | 下侧 p<0.005（**显著更低**） |
| 可信池同向率 | 39.93% | 50.54% | 下侧 p<0.005 |
| 全局同向率 | 46.36% | 50.20% | 下侧 p<0.005 |

**写法**：三项全写；并把该置换**绑定到权项原文里本来就有的用途词**——权 5(2) 写的是"用于**校准**所述方向一致性门控与所述阈值 τ"，于是正文写「该置换仅用于标定门控与 τ 的空分布，**不作为富集证据**」⇒ 负结果与权项措辞自洽，**反成方法层证据**；同时把 ②③ 落入失效边界节。
**理由**：只披露对主体侧有利的置换、不披露参考侧负结果 = 选择性披露——审查员问一句"参考侧年龄效应本身的证据呢"就答不上来（本次审查意见 N2 即此项）。
**组合含义的写法**（把三个数讲成一个机制）：门控能识别"参考侧有可信方向信号"的元件（①），但这些元件方向**不更倾向于**与主体侧一致（③），故核心元件数相对随机配对不富集（②）。

### 4.3 率类指标给三元组 + Wilson CI

只报"反向混入率 60.1%"读者无法判断它是方法缺陷还是零假设本就该 41.4%。凡报「率」必给 **(观测率, 匹配零假设期望率, 配对 z)**。
配套 **Wilson 95%CI**（本次：41.31% [38.76–43.90]、39.93% [36.77–43.18]、46.36% [45.59–47.13]）——三者上限均低于随机配对水平，一句话强化边界结论。
