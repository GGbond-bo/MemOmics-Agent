# S 评分：跨物种衰老可替代性分级筛选（落地算法 + 真实数字）

配套脚本：`results/memomics-cd677556/scripts/v5_substitutability_score.py`
交付文档：`E:/专利/disclosure_substitutability.md`（交底书）、`E:/专利/claims_substitutability.md`（权利要求书）

## 1. 评分公式（独权灵魂）

### 当前版（主-参考非对称，2026-09 独权已升级）

```
S = Z₁ × w(Z₂)
```

- `Z₁` = 主体物种（人侧，大样本）效应量，**评分强度唯一来源**
- `w(Z₂)` = 参考物种（猴侧，小样本）方向门控函数：
  - `+1`：Z₂ 与 Z₁ 同向且方向可信（p<0.05）
  - `−1`：Z₂ 与 Z₁ 反向
  - `0`：方向不可靠（p≥0.05），不参与方向判定
- 输入 Z：tile 级 `sign(r)×Φ⁻¹(1−p/2)` 经 Stouffer 聚合 `Σ[sign(r)·Φ⁻¹(1−p/2)]/√n` 到基因级

### 旧版（对称 min，已弃用为独权，保留为对比实验基线）

```
S_old = min(|Z₁|, |Z₂|) × sign(Z₁ · Z₂)
```

- 旧版强迫两侧都报强度，小样本侧测不准 → 反向截断大样本侧真实信号 → 漏检 89%
- 新版让小样本侧只报方向、大样本侧报强度，两侧各自发挥所长
- **❌ 禁止在交底书/说明书中把 Z 写成 Fisher Z 变换 `0.5×ln((1+r)/(1−r))`** — 这是 Stouffer Z 不是 Fisher Z（2026-09-10 实锤翻车，见 SKILL.md §11 公式溯源铁律）

## 1.5 ⚠️ 实测 CSV 的 S 列 ≠ 文档公式（2026-09-10 全量验证翻车，必读）

**`v5_substitutability_all.csv`（16,031 行 ortholog 基因对）的 S 列实测实现是旧版对称 min，不是文档宣称的非对称：**

| 检验 | 结果 |
|---|---|
| same_direction=True 子集 S == min(\|Z_h\|,\|Z_m\|) | **100%（6,662 行全中）** |
| same_direction=False 时 S 的**绝对值** == min | 100%（S = −min，负号跟随"非同向"） |
| 全量 S == min(\|Z_h\|,\|Z_m\|) | 41.56%（因负号） |
| S == \|Z_h\| / \|Z_m\| / 其他公式 | 0-14%（不匹配） |

即：**CSV 的 S 列 = `sign(同向)·min(|Z_h|,|Z_m|)`** —— 数据文件从头到尾跑的是旧版对称 min 评分。

**后果**：交底书（v3→v8）把"主-参考非对称 S=Z₁×w(Z₂)"写成独权公式，但用于生成实施例数字的 CSV 还是 min 公式——**文档方案 ≠ 数据实现**。若律师照文档写权利要求、审查员拿实施例数据反推公式，会当场穿帮（A26.3 公开不充分 / A22.3 效果与方案不符）。

**但分类数字自洽**（class 列没有被污染）：class A=1,904（双侧 p<0.05 且同向，100% 验证）→ 其中 |Z_h|≥12 的 **336 个**核心元件 → 其中双侧 |Z|≥12 的 **37 个**最高置信。分类逻辑与交底书一致。

**处理铁律**（用户拍板前不得自动改文件）：
- 选 A（min，数据现状）：交底书公式改回对称 min，"89% 漏检修复"的非对称创造性论证需要重写；
- 选 B（非对称，交底书文字）：重跑生成 CSV 的脚本，S 列和核心元件筛选全部换成 S=Z₁×w(Z₂) 口径。

**列名混淆陷阱**（本次翻车根因之一）：`zcols[0]` 取到的是 `Z_monkey` 列，曾导致误判"人侧 |Z|≥12 只有 133 个"；实际人侧 |Z_h|≥12 是 1409 个。复现时必须显式用 `df['Z_human']` / `df['Z_monkey']` 指名，禁止按位置取列。

## 4. 数据粒度 = 保护范围（易漏的硬伤）

当前证据是**基因级**（tile 聚合到基因代表元件，因猴 T2T-MFA8→hg38 无现成 chain，用基因锚定映射）。
- 权利要求用「调控元件」上位表述即可覆盖，但**要拿到强 CRE 级保护范围**，必须把两侧坐标用 chain liftover 对齐，让 S 评分直接在 500bp tile/peak 级逐元件落地。
- 否则保护范围停在「基因符号」，对手可绕开「基因」只做「峰坐标」避让。

## 5. 统计陷阱：min() 对 Z 尺度不对称敏感

同一批数据里 Z 分布两物种尺度不同（人 Z std≈7.06、猴 Z std≈2.75；人侧基因 tile 数更大，Stouffer 的 √n 归一在基因内 tile 相关时被过冲，Z 尺度随 n_tiles 膨胀）。
→ `min(|Z_m|,|Z_h|)` 会系统性偏向方差较小的一侧（本例=猴），S 的符号/强度被猴侧主导。
→ 若要用「真正取弱侧」而非「随机取小方差侧」的语义，稳健版应**先按物种各自标准化 Z（或用每侧经验零分布）再取 min**。当前版是用户拍板公式，文档如实注明该尺度差异即可。
