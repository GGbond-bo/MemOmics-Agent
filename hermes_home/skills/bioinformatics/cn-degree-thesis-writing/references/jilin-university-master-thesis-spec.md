## 1. 结构

**前置部分（【硕】7 项，🔴）**：封面 → 原创性声明 + 使用授权声明 → 序或前言 ⚪ → 摘要及关键词 → 目次页 → 插图和附表清单 ⚪ → 符号/缩略词/术语注释表 ⚪
（【博】另有：指导教师评阅意见、指导小组/评阅小组评阅意见、答辩决议书）

**主体部分（🔴）**：引言（绪论）→ 正文 → 结论 → 参考文献 → 注释 ⚪ → 附录 ⚪
- **正文从另页右页开始，每一章另起页**
- 结论是「最终、总体的结论」，不是各段小结的重复；须点明创新点

**结尾部分（🔴）**：作者简介及在学期间所取得的科研成果 → 后记和致谢 → 封底
- 科研成果按「学术论文 / 专利 / 专著 / 获奖」分类，按公开时间顺序，注明：排序编号、作者、成果名称、出处、年份、卷期

## 2. 封面（含扉页）要素

| 要素 | 要求 |
|---|---|
| 论文分类号 | 《中国图书资料分类法》第四版（图书馆查询） |
| 单位代码 | **10183** |
| 密级 | 一般「公开」；涉密按校学位字〔2019〕14号办审批 |
| 研究生学号 | 研究生管理处统一编排 |
| 学位类别 | 【硕】学术学位 =「XX学硕士」（如"工学硕士"）；专业学位 = 直接写标准名称（如"临床医学硕士"，标准名见附件6） |
| 校徽 | 蓝色，**3×3cm** |
| 论文题目 | 中英文双语，英文写在中文之下；**含副标题合计 ≤30 个汉字**；封面中间居中 |
| 作者姓名 | 与有效身份证件**完全一致** |
| 专业名称 | 严格按「研究生教育管理信息系统」，**不得用简称** |
| 导师姓名 | 姓名后附职称，**姓名与职称之间空一个汉字** |
| 培养单位 | 具体单位（如"商学院"、"古籍研究所"） |
| 完成时间 | 封面**下部居中**，填写打印成稿年月 |

**硕士封面版式**：分类号/单位代码/学号/密级 = 宋体加粗小四；中文题目 = **黑体三号**；英文题目 = **Arial 小三**；作者姓名/专业/研究方向/指导教师/培养单位 = **宋体加粗三号**；底部"年 月"；**书脊宋体小4号或5号**。
**硕士扉页**：论文题目 **宋体三号** + 英文题目 **Arial 三号**；以下均**宋体四号**：作者姓名、专业名称、指导教师、学位类别、答辩日期。

## 3. 摘要与关键词

- 摘要须**可独立使用**；阐明研究目的、主要成果、论点及论据；客观阐述创造性、新发现/新见解及其地位意义。
- 摘要中**不用图、表、化学结构式、非公知公用符号和术语**（实在无变通办法除外）。
- 字数：**【硕】中文约 1000 字** /【博】2000 字左右；英文摘要据中文翻译。
- 非汉语撰写：【硕】中文摘要 **≥3000 字** /【博】≥5000 字。
- 关键词 **3–8 个**，紧随中、英文摘要之后。
- 排版：题目**宋体居中、比摘要正文大一号**；摘要正文宋体、字号同正文；「关键词：」与正文**相隔一行、左侧顶头、宋体加粗**；关键词**另起一行**、左空**两个汉字**、词间**逗号**分隔。

## 4. 目次页（另起页）

| 目次行 | 要求 |
|---|---|
| 目 录 | **三号黑体，居中** |
| 第1章 绪论………1 | 章目录：四号宋体，**左侧 0 缩进**，页码右对齐 |
| 1.2 综述…………3 | 一级节标题目录：四号宋体，**左缩进一个汉字**，号码右对齐 |
| 1.2.3 存在的问题…6 | 二级节标题目录：四号宋体，**左缩进两个汉字**，号码右对齐 |
| 第5章 结论 / 参考文献 / 附录 / 作者简介及科研成果 / 致谢 | 四号宋体，**左侧 0 缩进**，页码右对齐 |

章、条编号与绪论、附录等**顶格排**；标题与前面内容之间**空一个字**；章条与页码之间用「…………」连接，**页码不用括号**。

## 5. 书写格式硬指标

- **文字**：标准化汉字；除专业需要外不得用繁体/异体字。
- **标点/数字**：GB/T 15834-2011《标点符号用法》/ GB/T 15835-2011《出版物上数字用法的规定》。
- **页码**：前置部分（从序/前言起）**罗马数字**；主体+结尾（从引言/绪论起）**阿拉伯数字**；**封底不要页码**；单页印刷→右下角；双面印刷→单页右下、双页左下。
- **页眉**：仅**主体部分**用；**居中**、**楷体小 5 号**、**普通单划线**；单面=章的编号及标题；双面=单页章编号标题、**双页「吉林大学博士（或硕士）学位论文」**。
- **字体字号**：除特殊要求外**一律宋体**，5 号/小 4 号/4 号任选（全文统一）；章节标题字号**可略大于正文一个字号**。
- **章节序号**：`第1章 XXX` / `1.1 XXX` / `1.1.1 XXX`；序号与标题间**空一个汉字**；节标题**左起顶格**；终止层次的号码之后**不加点**；同级别必须同一系列序号。
- **图**：随文排于相关文字之后；**图号+图题在图下方**、居中、**黑体**、字号同正文；图号与题名间空一个汉字。
- **表**：随文排于相关文字之后；**表号+表题在表上方**、居中、**黑体**、字号同正文；表号与题名间空一个汉字；表格转页时在**续表左上方与表格左边线对齐处注明「续表」，并重复表头**。
- **公式**：另起一行居中；尽量在**等号处**或「+」「−」处回行；主要横线与等号取平；编号**右端对齐**，公式与编号间用「…………」连接。
- **名词术语**：用国标/部颁标准术语，全文统一；英语缩写除通用缩写词外**首次出现括注英文原词**。
- **量和单位**：国际标准符号和单位；自拟符号、制图规范**首次出现时说明**。
- **引文标注**：顺序编码制（引文**最后一个字的右上角**，方括号阿拉伯数字，**小 5 号宋体上角标**）或著者-出版年制（置于 `( )` 内），**全文必须统一**；🔴 **不得置于各级标题处**。
- **参考文献**：按 **GB/T 7714-2015**（附件5）执行 → 见 `references/gbt7714-reference-formats.md`。

## 6. 装帧

- 平装封面 **120 克白色布纹纸**；【博】可精装（紫檀色硬壳 + 烫金字）；【硕】**单、双面印刷均可**，【博】必须双面。
- **横开本，左侧装订**；A4（210×297mm）；**天头（上）与订口（左）≥25mm，地脚（下）与切口（右）≥20mm**。
- 装订剪裁后尺寸 **29.1 × 20.7 cm**。

## 7. 声明页（附件3/4）

- 原创性声明、使用授权声明：**标题 3 号宋体，正文 4 号宋体**，使用统一格式。
- 授权声明需填：论文级别（□硕士 □博士）、学科专业、论文题目、作者签名、指导教师签名、日期、作者联系地址（邮编）、联系电话。
